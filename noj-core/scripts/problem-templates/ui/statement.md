# 模板：界面题（规则调参）

## 题目描述

用关键词规则识别营销短信：在界面里填写**关键词**（逗号分隔）与**最少命中数**。
一条短信中出现的不同关键词个数达到最少命中数时，判为营销短信。

调整这两个参数，让规则在隐藏短信集上的 F1 尽可能高。

## 参数

| 参数       | 说明                                   |
| ---------- | -------------------------------------- |
| `keywords` | 关键词，英文逗号分隔，首尾空白会被忽略 |
| `min_hits` | 最少命中的不同关键词个数，1–5 的整数   |

## 示例

短信 `限时优惠！点击领取红包` 应判为营销短信；`明天下午三点开会` 不是。

## 评分

以营销短信为正类计算 F1，得分 = F1 × 100，满分 100 分。
