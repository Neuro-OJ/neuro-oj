# 模板：LLM 工程题（提示词构造）

## 题目描述

客服系统收到的留言里通常带有订单号（形如 `NO-12345`）。请实现
`build_prompt(message)`：返回一段发给大模型的提示词，让模型**只输出**留言中的订单号。

评测时，平台对每条留言调用你的 `build_prompt`，把返回的提示词作为唯一一条 user
消息发给大模型，再检查模型回复。

## 接口

```python
def build_prompt(message: str) -> str: ...
```

- 返回值必须是字符串，长度不超过 2000 字符；
- 你的代码**不能**直接访问大模型或网络，只负责构造提示词。

## 示例

留言 `您好，订单 NO-10001 还没发货，麻烦查一下。` 的模型回复中应包含
`NO-10001`。

## 资源与限制

- 每次提交评测共 5 条留言（含 1 条示例），每条调用 1 次大模型；
- 单次 `build_prompt` 调用超时 2000ms。

## 评分

- 正式得分只来自隐藏留言，各条等权，满分 100 分；
- 模型回复中包含正确订单号即该条通过。
