# 模板：代码题（函数调用）

## 题目描述

实现函数 `solve(input_str)`：给定一个整数列表，返回它的元素和与最大值。

## 输入格式

`input_str` 是一行 JSON 文本：

```json
{ "nums": [3, -1, 4] }
```

`nums` 可能为空。

## 输出格式

返回一行 JSON 文本：`sum` 为元素和；`max` 为最大值，列表为空时为 `null`。

```json
{ "sum": 6, "max": 4 }
```

## 示例

输入 `{"nums": [3, -1, 4]}`，输出 `{"sum": 6, "max": 4}`。

## 数据范围与限制

- `nums` 长度 0–1000，元素为 -10^9 到 10^9 的整数
- 单次 `solve` 调用超时 2000ms；内存限制 256MB

## 评分

- 正式得分**只来自隐藏用例**，各用例等权，满分 100 分；
- 输出解析为 JSON 后与期望**逐字段相等**才算通过；
- 题面示例作为可见用例运行并展示调试信息，**不计分**。
