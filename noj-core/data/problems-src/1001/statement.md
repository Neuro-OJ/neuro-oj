# 1001 T0-LMCC：A+B Problem

## 题目描述

给定两个整数 $a$ 和 $b$，计算它们的和。

## 输入格式

输入为一行，包含两个整数 $a$ 和 $b$，以单个空格分隔。

## 输出格式

输出一行，一个整数，即 $a + b$ 的值。

## 示例

### 示例 1

**输入**

```text
1 2
```

**输出**

```text
3
```

### 示例 2

**输入**

```text
-5 10
```

**输出**

```text
5
```

## 说明

- 数据范围：$-10^9 \leq a, b \leq 10^9$
- 时间限制：$1000\text{ms}$，内存限制：$256\text{MB}$
- 结果可能超出 32 位整数范围，请使用 64 位整数（Python 等动态语言无需关心）
