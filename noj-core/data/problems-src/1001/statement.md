# 1001 T0-LMCC：星港舱门报码归一化

## 题目背景

星港是一座用于向太空输送物资的集散港。运行区有一整套连接主压差环、减压环廊、货运气闸和外作业桥的标准舱门网络。任何一扇舱门报码不清，都会影响人员隔离、货箱转运和局部舱段的气压切换。

一线报码通常来自巡检蜂群、拖运司机和夜班值守员，短、急、乱，但主控台需要的是稳定、可解析、可落库的标准
JSON。你的任务是通过 Prompt 约束，让模型把这些自然语言报码整理成统一结构。

## 题目描述

对于每条输入报码，模型最终必须输出一个 JSON，包含两个字段：

1. `gate_id`：标准化舱门编号
2. `status`：标准化舱门状态

`gate_id` 的格式固定为 `X-YY`：

- `X` 为区域字母，只能是 `E / W / N / S / I / O`
- `YY` 为两位数字编号

`status` 只能是以下三种之一：`open / closed / maintenance`。

## 输入格式

输入包含一个字符串 `report`，描述舱门状态，例如：

```json
{ "gate": "A12", "status": "open", "timestamp": 1704067200 }
```

## 输出要求

输出标准化的 JSON，包含以下字段：

- `gate_id` (`string`) — 舱门编号
- `status` (`string`) — 舱门状态（`open` / `closed` / `maintenance`）

## 评分标准

总分 10 分。评测时使用公式：

$$ \text{score} = \frac{\text{正确字段数}}{\text{总字段数}} \times 10 $$

其中 $\text{正确字段数}$ 由评测脚本根据标准答案计算。

## 示例

### 示例 1

**输入**

```
舱门 A12 已打开
```

**输出**

```json
{ "gate_id": "A12", "status": "open" }
```

> 注意：输出的 JSON 键名使用 `snake_case`。

### 示例 2

**输入**

```
B-07 舱门维护中
```

**输出**

```json
{ "gate_id": "B-07", "status": "maintenance" }
```
