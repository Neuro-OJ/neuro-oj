# A+B Problem（OI · 原生后端）

## 题目描述

给定两个整数 $a$ 和 $b$，请输出它们的和 $a + b$。

本题使用 **OI
赛制**：程序从标准输入读取数据、向标准输出写出答案，评测按子任务给分。
评测后端为 **原生（native）** 后端，支持 C99 与 C++11。

## 输入格式

一行，两个用单个空格分隔的整数 $a$、$b$。

## 输出格式

一行，一个整数，表示 $a + b$。

## 样例

### 样例输入 1

```
1 2
```

### 样例输出 1

```
3
```

### 样例输入 2

```
-100 100
```

### 样例输出 2

```
0
```

## 数据范围与子任务

| 子任务  | 分值 | 数据范围                        | 依赖    | 测试点数 |
| ------- | ---: | ------------------------------- | ------- | -------: |
| `basic` |   30 | $-10^3 \le a, b \le 10^3$       | 无      |        2 |
| `large` |   70 | $-10^{18} \le a, b \le 10^{18}$ | `basic` |        2 |

- 答案范围：$-2 \times 10^{18} \le a + b \le 2 \times 10^{18}$，在 64
  位有符号整数范围内，请使用 `long long`（C）或 `long long`（C++），不要使用 32
  位整数。
- 时间限制：每个测试点 1000 ms；内存限制：256 MiB。
- `large` 依赖 `basic`：只有 `basic` 的全部测试点通过，`large` 才参与评分，否则
  `large` 记 0 分。

## 说明

- 输入保证恰好两个整数，以空格分隔，行末可能有换行。
- 评测使用默认
  checker：忽略行尾空白与多余空行后逐行比较答案，因此输出末尾是否换行不影响结果。
- 子任务内所有测试点全部通过才获得该子任务的分值；本题总分为 100 分。
