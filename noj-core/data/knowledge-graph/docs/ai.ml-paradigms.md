# 机器学习范式（监督、无监督、自监督、强化）

## 直觉理解

区分机器学习范式只需问一个问题：**“模型靠什么信号进步？”**
有老师逐题批改标准答案的是监督学习；没有答案只能自己按相似度分组的是无监督学习；把完整文章遮住一部分让模型自己猜剩下的叫自监督学习；放进环境里通过不断试错拿奖励分进步的是强化学习。

## 核心概念

1. **监督学习**：输入 $x$ 配对人工/真实标签
   $y$，覆盖分类与回归，是应用最广的落地范式。
2. **无监督学习**：只有输入 $x$
   没有标签，核心任务包括聚类（K-Means）与降维（PCA），用于数据发现与特征压缩。
3. **自监督学习**：从海量无标注文本或图像自身构造预测目标（如预测下一个词元、还原被掩码片段），支撑了
   BERT 与大语言模型的预训练。
4. **强化学习**：智能体按策略与环境交互获取延迟奖励，目标是最大化长期累积回报，并用于大模型对齐（RLHF）与推理能力训练。

## 常见误区

- 把“训练时用测试集看指标”或“自监督没有人工标签”当成无监督学习（自监督依然在优化明确的伪标签预测损失）。
- 在只有几十条标签但有大量无标注文本时盲目从零训练监督模型，忽略先用自监督预训练基座迁移。

## 例题与完整解析

**题目**：用同一组二维样本对比无监督 K-Means
与监督最近邻思路对未知样本分组的差异。

```python
import numpy as np

X = np.array([[0.0, 0.1], [0.2, 0.0], [5.0, 5.1], [5.2, 4.9]])
# 无监督：仅凭距离把样本分为 2 组中心
c0, c1 = X[:2].mean(axis=0), X[2:].mean(axis=0)
query = np.array([4.9, 5.0])
assign = 0 if np.linalg.norm(query - c0) < np.linalg.norm(query - c1) else 1
print("所属无监督簇:", assign)  # 输出: 1
```

**逐步讲解**：无监督只依赖数据几何分布，给簇赋予实际语义名称仍需要人工或结合后续标签校准。
