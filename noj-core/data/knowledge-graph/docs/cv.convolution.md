# 卷积层

## 直觉理解

一张 $224 \times 224$
的彩色图片直接展平送进全连接层，第一层参数就要上亿，而且图片里的猫往右移 5
个像素后权重就对不上了。卷积层用一个小的“模板窗口（卷积核）”滑过整张图，不仅大幅共享参数，还能把“边缘、纹理”等局部特征在空间上平移动起来一起检测。

## 核心概念

1. **核心超参数**：
   - **卷积核大小（Kernel $K$）**：常见
     $3 \times 3$、$1 \times 1$（跨通道线性组合与降维）。
   - **步长（Stride $S$）**：窗口每次滑动的像素数，$S=2$ 常用于下采样。
   - **填充（Padding $P$）**：在边界补零以保留边缘信息或保持输出尺寸不变（`same`
     填充）。
2. **输出尺寸公式**：对于输入高/宽 $H$，输出特征图边长为：
   $$H_{out} = \left\lfloor \frac{H + 2P - K}{S} \right\rfloor + 1$$
3. **感受野（Receptive Field）**：多层小卷积核（如两层
   $3 \times 3$）串联能获得等价于 $5 \times 5$
   的感受野，同时参数更少、引入了更多非线性激活。

## 常见误区

- 误以为二维卷积只在单张灰度平面上滑动——实际上每个输出通道的卷积核是一个三维张量
  $(C_{in}, K, K)$，会在所有输入通道上同步求和。
- 计算参数量时忘记乘以输入通道数 $C_{in}$ 与输出通道数
  $C_{out}$，导致低估或错判显存瓶颈。

## 例题与完整解析

**题目**：给定输入张量尺寸 `(C_in=3, H=32, W=32)`，经过
`Conv2d(3, 16, kernel_size=3, stride=2, padding=1)`
后，求输出尺寸与参数量（含偏置）。

```python
H, W = 32, 32
C_in, C_out, K, S, P = 3, 16, 3, 2, 1

H_out = (H + 2 * P - K) // S + 1
W_out = (W + 2 * P - K) // S + 1
params = C_out * (C_in * K * K + 1)

print(f"Output shape: ({C_out}, {H_out}, {W_out})")
print("Total params:", params)
```

**逐步讲解**：$\lfloor (32 + 2 - 3)/2 \rfloor + 1 = 16$，输出特征图为
`(16, 16, 16)`；每个滤波器有 $3 \times 3 \times 3 + 1 = 28$ 个参数，16 个共
`448` 个参数。
