# NumPy 数组与向量化计算

## 直觉理解

假设你要把 100 万张图片的每个像素值都减 128。用 Python 列表写 `for`
循环，每一步都要做类型检查和对象查找，慢得让人等不起。NumPy
把一批同类型数字放在一块连续内存里，交给 C
实现的内层循环一次算完，这种写法叫**向量化**。可以把它想成：列表像一排贴着标签的抽屉，得一个个打开；数组像一条传送带，整批货物同时通过加工机器。

## 核心概念

**ndarray** 有两个关键属性：`shape`（每个维度有多长）和 `dtype`（元素类型，如
`float32`、`int64`）。维度数叫
`ndim`。数组元素类型统一，所以不能像列表那样混装字符串和数字。

**视图与副本**：切片 `a[1:3]` 返回的是视图，改它会改到原数组；`a[1:3].copy()`
才是独立副本；布尔索引和花式索引（用整数数组取元素）则总是返回副本。

**广播**：形状不同也能运算，规则是从最后一维往前对齐，每一维要么相等，要么其中一方为
1，要么缺失（视为 1）。比如 `(3, 1)` 与 `(1, 4)` 相加得到
`(3, 4)`。广播只是"虚拟复制"，不额外占内存。

**轴（axis）**：`a.sum(axis=0)` 消掉第 0 维。对形状 `(N, D)`
的样本矩阵，`axis=0` 是"跨样本"，得到每列特征；`axis=1`
是"跨特征"，得到每行样本。

**向量化与内存**：`a * b + c` 在 NumPy 里会先产生中间数组再相加。数据很大时可用
`np.dot`、`@`、`np.einsum` 等融合操作减少临时内存。

## 常见误区

- 用 `for` 循环逐元素赋值：能跑通但慢几十倍，应改写为切片、布尔掩码或
  `np.where`。
- 误以为切片是副本：`b = a[:5]; b[:] = 0` 会把 `a` 也清零。
- 混淆 `v.shape == (3,)` 与 `(3, 1)`：前者参与广播时按行对齐，矩阵乘法前常需用
  `reshape(-1, 1)` 或 `[:, None]` 明确维度。
- 整数溢出：`np.int8` 的 127 加 1 会回绕成 -128，累加大数时默认用 `int64` 或
  `float64`。
- 在循环里反复
  `np.append`：每次都会重新分配内存，复杂度变成平方级，应预分配数组或收集到 list
  后一次 `np.array`。

## 例题与完整解析

**题目**：给一个 `(n, d)` 的特征矩阵
`X`，要求对每一列做标准化（减均值、除以标准差），然后计算 `X_std @ X_std.T`
的对角线之和。分别用循环与向量化实现并验证结果一致、比较耗时。

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(loc=3.0, scale=2.0, size=(2000, 50))

# 循环写法
def loop_std(X):
    out = np.empty_like(X)
    for j in range(X.shape[1]):
        col = X[:, j]
        out[:, j] = (col - col.mean()) / col.std()
    return out

# 向量化写法：mean/std 沿 axis=0 计算，结果形状为 (d,)，可广播到 (n, d)
Xs = (X - X.mean(axis=0)) / X.std(axis=0)
assert np.allclose(Xs, loop_std(X))
print("等价:", np.allclose(Xs, loop_std(X)))

# 每个样本标准化后向量的平方和 = 行平方和（对角线元素）
diag_sum = np.sum(np.sum(Xs**2, axis=1))
print("对角线和:", round(diag_sum, 2))

S = Xs @ Xs.T
print("矩阵迹一致:", np.isclose(np.trace(S), diag_sum))
```

**逐步讲解**：

1. `X.mean(axis=0)` 形状是 `(50,)`，表示每列均值；`(2000, 50) - (50,)`
   触发广播，把均值行复制到每行上相减，不需要写循环。
2. `X.std(axis=0)`
   同理得到每列标准差，逐列相除即完成标准化。注意这里用总体标准差（`ddof=0`），与循环里
   `col.std()` 的默认行为一致，所以两边结果相同。
3. 标准化后每列均值为 0、标准差为 1。`Xs @ Xs.T` 的第 `i` 个对角元素是第 `i`
   个样本与自身的点积，即 `sum(Xs[i]**2)`。因此迹等于所有元素平方和，也就是
   `n * d`（每列方差为 1，共 50 列，共 2000 行，理论值
   100000）。打印结果验证了这一点。
4. 用 `timeit` 或 `%timeit`
   比较两种写法，向量化通常快出数倍到一个数量级（数组越大差距越明显）。关键差别不在"少写了字符"，而在于循环发生在编译好的代码里。
