# 预训练任务（下一词元预测、掩码语言模型）

## 直觉理解

大模型不需要人类一条条标注几十亿句话的“正确答案”。只要把互联网和书籍里的原始文本拿来，要么让模型“遮住下一句猜后面的词（下一词元预测）”，要么“挖空中间几个词猜填什么（掩码语言模型）”，语料本身自带无穷无尽的监督信号。

## 核心概念

1. **下一词元预测（Next-Token Prediction / CLM）**：最大化联合概率对数似然
   $\sum_{t=1}^{T} \log P(x_t \mid x_{<t})$。在解码器前向传播中，通过一次并行矩阵计算即可同时预测序列中全部
   `T-1` 个位置上的下一个词，训练样本利用率达 100%。
2. **掩码语言模型（MLM）**：仅在被遮盖的位置（通常约
   15%）计算交叉熵损失，能够学到双向上下文语义，适合特征提取与理解任务。
3. **样本打包与文档边界（Packing + Document
   Masking）**：将多篇短文档拼接进同一个 `4096` 上下文窗口以提高 GPU
   吞吐，但需截断文档间的跨边界注意力并确保 `<eos>` 预测正确。

## 常见误区

- 计算 CLM 损失时忘了把标签左移一位（即 `logits[:, :-1]` 对齐
  `labels[:, 1:]`），导致模型直接“用自己预测自己”而训练 loss 瞬间掉到接近 0。
- 多篇不相关短文档拼接打包时没加文档隔离注意力掩码，让模型在无关上下文间学到虚假关联。

## 例题与完整解析

**题目**：给定词元序列
`tokens = [101, 45, 78, 92, 102]`，演示下一词元预测（CLM）的标准 `inputs` 与
`targets` 对齐方式及平均负对数似然。

```python
import numpy as np

tokens = [101, 45, 78, 92, 102]
inputs = tokens[:-1]   # [101, 45, 78, 92]
targets = tokens[1:]   # [45, 78, 92, 102]

# 模拟每步预测目标 token 的概率
pred_probs = np.array([0.40, 0.70, 0.25, 0.85])
nll_loss = -np.mean(np.log(pred_probs))

print("Inputs :", inputs)
print("Targets:", targets)
print("CLM loss:", round(float(nll_loss), 4))
```

**逐步讲解**：输入与标签严格错开一位，总共构造 `4` 个有效预测位置；平均交叉熵约
`0.7049`，困惑度为 $\exp(0.7049) \approx 2.02$。
