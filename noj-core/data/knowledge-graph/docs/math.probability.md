# 概率基础与条件概率

## 直觉理解

概率是用 $0$ 到 $1$
的数字刻画"不确定事件发生的可能性"。条件概率回答的问题更精细：**已经知道一些信息之后**，可能性是否改变？

一个经典场景：某种疾病的检测准确率很高，但患病率很低。你检测阳性，是否就等于"大概率有病"？直觉常出错，而条件概率与贝叶斯公式能给出正确答案。

## 核心概念

**样本空间与事件**。样本空间 $\Omega$ 是全部可能结果，事件 $A$ 是它的子集。概率
$P$ 满足三条公理：$P(A)\ge0$、$P(\Omega)=1$、互斥事件可加。由此推出互补事件
$P(A^c)=1-P(A)$、加法公式 $P(A\cup B)=P(A)+P(B)-P(A\cap B)$。

**条件概率**：当 $P(B)>0$ 时

$$P(A\mid B)=\frac{P(A\cap B)}{P(B)},$$

意思是"把样本空间缩小到 $B$ 内，看 $A$ 占的比例"。相应地
$P(A\cap B)=P(A\mid B)P(B)$。

**独立性**：$P(A\cap B)=P(A)P(B)$，等价于 $P(A\mid B)=P(A)$——知道 $B$ 对 $A$
的判断没有帮助。

**全概率公式**：若 $B_1,\dots,B_k$ 是互斥且穷尽的情形，则

$$P(A)=\sum_{i} P(A\mid B_i)P(B_i).$$

**贝叶斯公式**：

$$P(B_i\mid A)=\frac{P(A\mid B_i)P(B_i)}{\sum_j P(A\mid B_j)P(B_j)}.$$

分子是"先验 × 似然"，分母是归一化常数。后验正比于先验乘似然。

## 常见误区

- 混淆 $P(A\mid B)$ 与
  $P(B\mid A)$：前者常被称作"把关系方向弄反"，是各种反直觉结论的根源。
- 混淆互斥与独立：互斥事件（同时发生的概率为
  0）一般**恰好**不独立；两个概率都为正的事件不可能既互斥又独立。
- 认为"连续做两次检测都阳性，所以必然患病"：忽略了基础患病率（先验极小时后验仍可能很小）。
- 把"每次独立、单次概率 $p$"与"至少发生一次"混为一谈：重复 $n$
  次，至少一次的概率是 $1-(1-p)^n$。
- 乘法公式乱用：$P(A\cap B)=P(A)P(B)$ 只在独立时成立，一般应为
  $P(A\cap B)=P(A\mid B)P(B)$。

## 例题与完整解析

**题目**：某地某病患病率为 $0.5\%$。检测的灵敏度（有病检出阳性）为
$0.98$，特异度（无病检出阴性）为
$0.95$。某人检测为阳性，求其真正患病的概率。若复查仍为阳性（假设两次结果条件独立），概率又是多少？

```python
prior = 0.005
sens, spec = 0.98, 0.95

def posterior(prior):
    p_pos = sens * prior + (1 - spec) * (1 - prior)
    return sens * prior / p_pos

p1 = posterior(prior)
print(f"一次阳性后患病概率: {p1:.3f}")
print(f"两次阳性后患病概率: {posterior(p1):.3f}")
```

**逐步讲解**：

1. 全概率公式：$P(阳性)=0.98\times0.005+0.05\times0.995$。假阳性率
   $1-\text{特异度}=0.05$，因为健康人占 $99.5\%$，假阳性贡献很大（约
   $0.04975$），比真阳性（约 $0.0049$）多出十倍。
2. 贝叶斯公式：$P(\text{病}\mid阳性)=0.0049/0.05465\approx 0.0897$，约
   $9\%$。即使检测很准，低患病率仍使后验很小。这一步通常是本题最容易反直觉之处。
3. 复查：把 $9\%$ 当作新的先验再做一次贝叶斯更新，后验约升到
   $0.66$（$0.98\times0.09$ 除以
   $0.98\times0.09+0.05\times0.91$）。这正是"多源证据逐步修正信念"的思路，在朴素贝叶斯分类器里也表现为把各特征的对数似然累加。
4. 复查结果"条件独立"是关键假设；若两次检测使用同一台设备、偏差相关，真实后验会低于这个估计。
