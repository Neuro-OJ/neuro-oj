# 多层感知机

## 直觉理解

单个神经元只能做"加权求和 +
激活"，本质上画一条分界线。把许多这样的神经元排成层并堆叠起来，前面的层负责把输入搬到更容易分开的空间，后面的层在这个新空间里画界，于是就能表达弯曲的、复杂的决策边界——这就是多层感知机（MLP）的想法。

## 核心概念

**单层结构**。第 $l$ 层：

$$h^{(l)} = \phi\big(W^{(l)}h^{(l-1)} + b^{(l)}\big),$$

$W^{(l)}$ 形状为（本层宽度，上一层宽度），$\phi$
为非线性激活。最后一层按任务定：回归输出一个数，二分类输出一个 logit，多分类输出
$K$ 个 logit 配 softmax。

**为什么必须非线性**。若 $\phi$
是恒等映射，两层复合仍是线性变换，堆多少层都等价于一层线性模型。ReLU、Sigmoid、Tanh、GELU
等打破这个限制。

**万能近似**。含足够宽隐藏层的一层网络可以在紧集上任意精度逼近连续函数；这是表达能力上的保证，但没说要多宽、需要多少数据、能否被优化到——所以实际深度与宽度仍要靠实验决定。

**参数量**。每层参数 $\text{in}\times\text{out}+\text{out}$。

**相关要素**。初始化（如
Xavier/He）、激活函数选择、梯度下降与小批量、正则化（Dropout、权重衰减）、损失函数。

## 常见误区

- 以为层数越多必然越强：没有合适的初始化与归一化，深网络更难训练，梯度会消失或爆炸。
- 忘记激活函数，误以为"加深"就在提升能力。
- 混淆隐藏层宽度与样本量：宽度远大于样本数时极易过拟合。
- 输出层也套 ReLU 后再算回归损失：回归输出需要实数范围，不能截断到非负。
- 对多分类用 Sigmoid + 独立的二分类损失：标准做法是 softmax +
  交叉熵（多标签问题才用逐类 Sigmoid）。
- 忽视初始化尺度：所有权重都初始化为 0
  时，同层神经元永远保持相同，无法打破对称性。

## 例题与完整解析

**题目**：用 NumPy 实现一个两层 MLP 解决 XOR 问题（4
个样本），观察隐藏层如何让线性可分。

```python
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([0, 1, 1, 0], dtype=float)

rng = np.random.default_rng(42)
W1 = rng.normal(0, 0.5, size=(2, 4))
b1 = np.zeros(4)
W2 = rng.normal(0, 0.5, size=(4, 1))
b2 = np.zeros(1)

relu = lambda z: np.maximum(z, 0)
for epoch in range(5000):
    # 前向
    H = relu(X @ W1 + b1)
    logit = H @ W2 + b2
    p = 1 / (1 + np.exp(-logit))
    # 反向（链式法则）
    dz2 = (p - y[:, None]) / 4                     # 交叉熵 + Sigmoid 的梯度
    dW2, db2 = H.T @ dz2, dz2.sum(0)
    dz1 = (dz2 @ W2.T) * (X @ W1 + b1 > 0)         # ReLU 的导数
    dW1, db1 = X.T @ dz1, dz1.sum(0)
    W1 -= 0.5 * dW1
    b1 -= 0.5 * db1
    W2 -= 0.5 * dW2
    b2 -= 0.5 * db2

print("输出概率:", np.round(p.ravel(), 3))
print("预测:", (p.ravel() > 0.5).astype(int), "正确:", np.all((p.ravel() > 0.5) == (y == 1)))
print("隐藏层表示:\n", np.round(H, 3))
```

**逐步讲解**：

1. XOR
   无法用一条直线分开，所以单层线性模型在此必然失败——这就是需要隐藏层的原因。
2. 隐藏层宽 4 个 ReLU 单元，每个单元相当于一条"半空间判断"。输出层在 4
   维空间里对隐藏表示做线性组合，等价于在原始二维平面里用若干折线拼出非线性边界。
3. 反向传播按链式法则逐层回传：先得到输出层梯度 `dz2`，再乘上 `W2` 转置并乘以
   ReLU 的掩码得到隐藏层梯度。这是下一个知识点反向传播的完整实例。
4. 打印的 `H`
   显示，四个样本在隐藏层被映射成不同模式，原本标签交错的两类在这组新坐标里可以用线性组合区分。
5. 5000 轮后概率应接近 $[0,1,1,0]$，预测全部正确。实际训练时常用 PyTorch 的
   `nn.Linear` 与自动求导，避免手写梯度出错。
