# 卷积神经网络

## 直觉理解

单层卷积只能看懂像素附近的斜线和色块。把卷积层、激活函数与下采样（池化）一层层叠起来，浅层提取边缘角点、中层组合成车轮与眼睛、深层识别出整张猫脸或车辆轮廓，这就是卷积神经网络（CNN）的“层级特征抽象”。

## 核心概念

1. **三大结构归纳偏置**：
   - **局部连接**：每个神经元只响应局部感受野，契合图像的空间局部相关性。
   - **权值共享**：同一卷积核扫遍全图，大幅降低参数量并天然具备平移等变性。
   - **空间下采样**：通过池化层（Max/Avg Pooling）或 `stride=2`
     卷积逐步压缩分辨率、放大高层感受野。
2. **通道演化规律**：通常沿网络深度空间分辨率减半、通道数翻倍（例如
   `224 -> 112 -> 56 -> 28`，通道
   `64 -> 128 -> 256 -> 512`），最后用全局平均池化（GAP）替代巨大全连接层降低过拟合风险。
3. **现代演进**：VGG 确立了 $3 \times 3$ 堆叠范式；ResNet
   引入残差恒等映射打通百层训练；深度可分离卷积进一步把计算开销压进移动端。

## 常见误区

- 在特征图末端保留超大展平全连接层（如
  `512 * 7 * 7 -> 4096`），既浪费大量参数又锁死了输入图片分辨率，换用全局平均池化即可兼容任意尺寸。
- 忽视 BatchNorm
  层与激活函数的放置顺序及训练/评估模式切换（`model.eval()`），导致测试精度大幅波动。

## 例题与完整解析

**题目**：模拟一个微型两阶段 CNN
前向尺寸与全局平均池化流程，观察形状从空间特征到分类向量的变化。

```python
import numpy as np

# 模拟 batch=2, 1通道, 8x8 特征图
x = np.random.randn(2, 1, 8, 8)
# 假定经过 conv1(stride=2, out_c=8) 与 conv2(stride=2, out_c=16)
feat = np.random.randn(2, 16, 2, 2)
# 全局平均池化 (GAP): 在空间 (H, W) 维求均值
pooled = feat.mean(axis=(2, 3))
weights = np.random.randn(16, 5)  # 5 分类线性头
logits = pooled @ weights

print("Before GAP:", feat.shape)
print("After GAP: ", pooled.shape)
print("Logits:    ", logits.shape)
```

**逐步讲解**：`(2, 16, 2, 2)` 经 `mean(axis=(2, 3))` 压缩为
`(2, 16)`，再线性映射到 5 个类别 logits，整个分类头只有 `16 * 5 = 80` 个权重。
