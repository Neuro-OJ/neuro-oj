# 数据集划分（训练、验证、测试）

## 直觉理解

考试前老师会给你历年真题训练（训练集），给一套模拟卷自己检查漏洞（验证集），最终期末考用的是没见过的题（测试集）。如果期末考用的就是模拟卷原题，分数再高也不能说明你学会了。机器学习中的数据划分就是这个道理：**模型评估必须发生在它没见过的数据上**。

## 核心概念

**三种角色**。训练集用来学习参数；验证集用来选择模型与超参数、比较方案、提前停止；测试集只用于最终报告一次性能。

**划分比例**。小数据常用 6:2:2 或
8:1:1；数据量很大时测试集占比可以很小（只要绝对样本数够）。验证集太小会导致选择结果噪声大。

**分层抽样（stratified）**。分类问题按类别比例切分每一份，避免某个类别在验证集里样本太少。对高度不平衡的数据（少数类占
1%），分层几乎是必需的。

**保序划分（时间序列）**。数据有先后关系时不能随机打乱，应"用过去预测未来"：训练集在前，验证集与测试集在后。

**分组划分**。同一患者、同一用户、同一篇文章可能产生多条样本，随机切分会把近重复样本分到两侧，造成指标虚高。应按组切分（`GroupKFold`）。

**数据泄露**。任何在切分之前用全量数据拟合变换（标准化、缺失值填补、特征选择、超参数搜索）都会让测试信息渗入训练。

## 常见误区

- 先在整个数据集上做标准化/填补，再划分——最常见的静默泄露。正确做法是只在训练集
  `fit`，然后 `transform` 其余部分。
- 没有单独验证集，直接用测试集选模型。
- 类别不平衡时用简单随机划分，导致某一折几乎没有正例。
- 时间数据随机打乱，指标虚高。
- 同一对象的多条样本跨集合分布（医疗、推荐、文本近重复）。
- 在小验证集上反复调参后，把最佳验证分数当作泛化性能的估计。

## 例题与完整解析

**题目**：一个二分类数据集有 1000 条样本，正例 50 条。分别用随机划分和分层划分做
5 折，统计每折中正例数量的最小值，并演示标准的"先划分后标准化"流程。

```python
import numpy as np

rng = np.random.default_rng(7)
y = np.zeros(1000, dtype=int)
y[rng.choice(1000, size=50, replace=False)] = 1
X = rng.normal(size=(1000, 4)) + y[:, None]  # 正例整体偏移一些

def folds(y, k, stratified):
    idx = np.arange(len(y))
    out = []
    if stratified:
        for cls in (0, 1):
            part = rng.permutation(idx[y == cls])
            for i, chunk in enumerate(np.array_split(part, k)):
                if i >= len(out):
                    out.append([])
                out[i].extend(chunk.tolist())
    else:
        for chunk in np.array_split(rng.permutation(idx), k):
            out.append(chunk.tolist())
    return [np.array(f) for f in out]

for name, strat in (("随机", False), ("分层", True)):
    counts = [y[f].sum() for f in folds(y, 5, strat)]
    print(name, "每折正例数:", counts, "最少:", min(counts))

# 正确顺序：先切分，再只用训练集统计量做标准化
perm = rng.permutation(1000)
tr, te = perm[:800], perm[800:]
mu, sd = X[tr].mean(0), X[tr].std(0)
Xtr, Xte = (X[tr] - mu) / sd, (X[te] - mu) / sd
print("训练集均值(标准化后):", np.round(Xtr.mean(0), 12))
```

**逐步讲解**：

1. 随机 5 折时，每折 200 条样本，期望正例 10
   条，但各折数量上下波动明显（换一次随机种子或得到如 7、8、14、14
   这样的分布，极端时可能少到 3–5 条）。分层划分先按类别分别打乱再平均切成 5
   份，每折正例稳定在 10 条左右。
2. 正例稀少时，单折正例过少会让该折的召回率、AUC
   极不稳定，交叉验证的结论就不可信。这就是分层抽样的意义。
3. 标准化用 `X[tr]` 计算均值与标准差，然后分别作用到训练与测试。若改用全量
   `X.mean(0)`，测试集的信息就参与到了预处理中，评估结果偏乐观。
4. 真实项目中可用 `sklearn.model_selection.train_test_split(stratify=y)` 与
   `Pipeline`，后者自动保证交叉验证时预处理只在训练折上拟合。
