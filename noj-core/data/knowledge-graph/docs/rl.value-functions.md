# 价值函数（V、Q）

## 直觉理解

在某盘棋局里“走这一步表面看没吃子，甚至还送了个兵，为什么高手觉得这一步是妙手？”因为这一步把局面的“长期赢面期望”抬高了。价值函数就是用来给“某个处境（$V$）”或“某个处境下选某一招（$Q$）”的长期总收益算账的尺子。

## 核心概念

1. **状态价值函数 $V^\pi(s)$**：从状态 $s$ 出发、始终遵循策略 $\pi$
   所能获得的期望折扣回报： $$V^\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$$
2. **动作价值函数 $Q^\pi(s, a)$**：先在状态 $s$ 强行执行动作 $a$，之后再按策略
   $\pi$ 行动的期望回报。两者的桥接关系为：
   $$V^\pi(s) = \sum_{a \in A} \pi(a \mid s)\, Q^\pi(s, a)$$
3. **贝尔曼期望方程（Bellman Equation）**：把当前价值拆成“眼前一步即时奖励 +
   折扣后的下一状态价值”，使未知的长远未来可以通过局部一步递推求解。

## 常见误区

- 把状态价值 $V(s)$ 和即时奖励 $R(s)$ 混为一谈——即时奖励高的新手陷阱，长期价值
  $V(s)$ 可能很低。
- 忽略价值函数永远绑定在某个策略 $\pi$ 下（只有最优价值 $V^*, Q^*$
  才独立于具体策略）。

## 例题与完整解析

**题目**：一个 2 状态环路小模型：`A` 选择继续耗时 1 步拿到 `R=+1` 后进入终态
`B`，`B` 价值恒为 `0`；或者选择冒险动作：以 `0.5` 概率拿到 `R=+4` 进终态
`B`，`0.5` 概率留在 `A` 得 `0`。取 $\gamma = 0.8$，求一直选冒险动作时的状态价值
$V(A)$。

```python
# 贝尔曼方程: V(A) = 0.5 * (4 + 0.8 * 0) + 0.5 * (0 + 0.8 * V(A))
# 化简得: V(A) - 0.4 * V(A) = 2.0  => 0.6 * V(A) = 2.0
v_a = 2.0 / 0.6
print("Analytical V(A):", round(v_a, 4))

# 值迭代验证收敛
v = 0.0
for _ in range(50):
    v = 0.5 * 4.0 + 0.5 * (0.8 * v)
print("Iterative  V(A):", round(v, 4))
```

**逐步讲解**：解析解与迭代解均收敛于 `3.3333`，远高于保守动作的
`1.0`，说明只要长期期望占优，高风险延迟动作的价值依然更高。
