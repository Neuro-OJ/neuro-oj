# 向量与矩阵运算

## 直觉理解

在人工智能与深度学习里，图像、词向量、神经网络权重和整批样本本质上全都是向量和矩阵。矩阵乘法之所以重要，是因为它一次就能把“批量样本
× 权重参数”的全部加权求和并行算出来，既简洁又能直接吃满 GPU 算力。

## 核心概念

1. **内积与投影**：向量内积
   $\mathbf{a}\cdot\mathbf{b} = \sum_i a_i b_i = \|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$
   衡量两个方向的对齐程度，是线性打分与注意力打分的基础。
2. **矩阵乘法与形状规则**：形状为 $(m, k)$ 的矩阵与 $(k, n)$ 的矩阵相乘得到
   $(m, n)$，内维 $k$ 必须相等；一般不满足交换律（$AB \neq BA$）。
3. **转置与范数**：转置 $(AB)^T = B^T A^T$ 常用于对齐维度和推导反向传播；$L_2$
   范数 $\|\mathbf{x}\|_2 = \sqrt{\sum x_i^2}$ 衡量向量长度。

## 常见误区

- 把逐元素乘积（Hadamard 积 `A * B`）与矩阵乘法（`A @ B`）混用。
- 忽视线性层的批量形状约定：通常样本按行堆叠为
  $(B, d_{\text{in}})$，权重矩阵对应写成
  $W \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}$ 或转置。

## 例题与完整解析

**题目**：给定批量输入 $X \in \mathbb{R}^{3 \times 2}$、权重
$W \in \mathbb{R}^{2 \times 4}$ 与偏置
$\mathbf{b} \in \mathbb{R}^4$，计算线性层输出并验证批样本第一行的范数。

```python
import numpy as np

X = np.array([[1.0, 2.0], [0.0, -1.0], [2.0, 1.0]])
W = np.array([[0.5, -0.5, 1.0, 0.0], [1.0, 0.5, -0.5, 2.0]])
b = np.array([0.1, 0.0, -0.1, 0.2])

Y = X @ W + b  # 形状 (3, 4)，偏置广播到每一行
row0_norm = np.linalg.norm(Y[0])
print("输出形状:", Y.shape, "第 0 行 L2 范数:", round(float(row0_norm), 4))
```

**逐步讲解**：`X @ W` 得到 $(3, 4)$ 矩阵后，长度为 $4$ 的向量 `b` 自动沿第 0
维广播加到 3 个样本上。
