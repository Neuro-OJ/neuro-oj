# 逻辑回归

## 直觉理解

线性回归输出的是任意实数，但分类需要的是"属于正类的概率"，应当落在 $0$ 到 $1$
之间。逻辑回归在线性打分上加一层"挤压"函数：打分很高时概率接近
$1$，打分很低时接近 $0$，中间平滑过渡。它不是"回归"模型，而是一个线性分类器。

## 核心概念

**Sigmoid 函数**。$\sigma(z)=\dfrac{1}{1+e^{-z}}$，把实数映射到 $(0,1)$，且
$\sigma'(z)=\sigma(z)(1-\sigma(z))$。

**模型**。$p = P(y=1\mid x)=\sigma(w^\top x + b)$，决策规则通常是 $p\ge0.5$
判为正类，等价于 $w^\top x+b\ge0$，所以它的决策边界是超平面。

**损失**。交叉熵（对数损失）

$$L = -\frac{1}{n}\sum_i\big[y_i\log p_i + (1-y_i)\log(1-p_i)\big].$$

**梯度**。$\nabla_w L = \frac{1}{n}\sum_i (p_i-y_i)x_i$，形式与线性回归一致，这是设计成交叉熵的结果。损失是凸函数（$w$
的严格凸），梯度下降可收敛到全局最优；用牛顿法即 IRLS 收敛更快。

**多分类推广**。Softmax 回归把 Sigmoid 换成 softmax，损失仍是交叉熵。

## 常见误区

- 以为逻辑回归的损失是平方误差：平方误差配 Sigmoid
  是非凸且梯度常很小的，交叉熵才是标准做法。
- 把概率直接当标签：训练需要 0/1 标签，预测概率可用于排序和调阈值。
- 把 `predict_proba`
  输出的概率当作"校准良好"：逻辑回归在特征正确线性时校准不错，但加正则强度过大或换其他模型后未必。
- 用 0.5 为固定阈值却不检查类别不平衡：正例很少时，0.5 往往导致召回率极低。
- 与线性回归混淆：线性回归回答"多少"，逻辑回归回答"多大可能"。
- 忽略多重共线性：系数不稳定，不适合直接解释因果。

## 例题与完整解析

**题目**：用二维合成数据训练逻辑回归，手写梯度下降 2000
步，报告准确率并和"全预测多数类"的基线比较。

```python
import numpy as np

rng = np.random.default_rng(3)
n_per = 150
X0 = rng.normal(loc=[-1, 0.5], scale=1.0, size=(n_per, 2))  # 负类
X1 = rng.normal(loc=[1.5, 1.0], scale=1.0, size=(n_per, 2))  # 正类
X = np.vstack([X0, X1])
y = np.r_[np.zeros(n_per), np.ones(n_per)]

A = np.column_stack([np.ones(len(X)), X])
w = np.zeros(3)
for step in range(2000):
    z = A @ w
    p = 1 / (1 + np.exp(-z))
    grad = A.T @ (p - y) / len(y)
    w -= 0.5 * grad
print("训练损失:", round(-np.mean(y * np.log(p) + (1 - y) * np.log(1 - p)), 4))

acc = np.mean((p > 0.5) == (y == 1))
base = max(y.mean(), 1 - y.mean())
print(f"准确率: {acc:.3f}  多数类基线: {base:.3f}")
print("决策边界: %.3f + %.3f*x1 + %.3f*x2 = 0" % tuple(w))
```

**逐步讲解**：

1. 两类中心分别在 $(-1,0.5)$ 与 $(1.5,1.0)$，散布度
   1，有相当一部分重叠，因此准确率不可能接近 1。
2. 构造矩阵 `A` 时在第一列加常数 1，让梯度一次更新偏置与权重。
3. 每次迭代先算线性打分 `z`，再经 Sigmoid 得概率 `p`，梯度为
   `A.T @ (p - y) / len(y)`，这就是"预测减真实"乘上特征。学习率 0.5
   在这种尺度数据上稳定收敛。
4. 训练完成后，参数满足
   $w_0 + w_1x_1 + w_2x_2 = 0$，即一条直线，对绝大多数样本能分开两类。准确率通常明显高于
   0.5 的多数类基线。
5. 若数据按正例比例极不均衡，应按召回率或 PR 曲线选择阈值，而不要死守
   0.5。也可以加 L2 正则 $\lambda\|w\|^2$，在特征多、样本少时抑制过拟合。
