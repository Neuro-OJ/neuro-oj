# 思维链提示

## 直觉理解

面对多步计算题，人类也很难一眼直接心算出最终答案，通常会在草稿纸上一步步演算。思维链（Chain-of-Thought,
CoT）的本质，就是允许自回归大模型把“草稿纸”也生成出来——每一步写出的中间文字都会进入上文，供下一步注意力引用，从而把超单步计算能力的多步难题拆成可执行的逐行推理。

## 核心概念

1. **为什么有效**：自回归模型每个 token
   的前向计算深度固定，直接猜答案只有一次前向深度；展开 CoT
   等价于用序列长度换取“串行推理步数（Test-time Compute）”。
2. **两种经典写法**：
   - **Zero-shot CoT**：追加“让我们一步步思考（Let's think step by
     step）”激发已有推理模式。
   - **Few-shot CoT**：给出 2~5
     组含详细推演过程的示范样例，严格固定推演风格与单位换算规范。
3. **可检查性与局限**：CoT
   便于定位是审题理解错、公式用错还是最后一步算术错，但生成 token
   更多、延迟和成本也相应增加，且生成的推理文字未必忠实反映模型内部全部隐式判断。

## 常见误区

- 对简单的实体分类、提取任务强行套用长 CoT，平白多烧几倍延迟与输出
  Token，有时反而画蛇添足。
- 示范样例中出现跳跃步骤或隐含计算错误，Few-shot
  模型会原封不动模仿这种跳步习惯。

## 例题与完整解析

**题目**：构造一组规范的 Few-shot CoT
提示模板片段，演示如何将多步应用题拆为可解析的结构化步骤。

```python
prompt = """问题：仓库原有 18 箱货，早班卖出 7 箱，午后补进卖出数量 2 倍的货物，现在有多少箱？
思考：
1. 早班后剩余：18 - 7 = 11 箱。
2. 午后补进：7 * 2 = 14 箱。
3. 合计当前库存：11 + 14 = 25 箱。
答案：25

问题：会议室有 24 把椅子，搬走 6 把，又搬回搬走数量的一半，现在有多少把？
思考："""

print(prompt.splitlines()[-2])
```

**逐步讲解**：示例通过编号步进明确给出中间算式并统一在末行用 `答案：`
收口，大幅降低了模型心算混淆及格式漂移的概率。
