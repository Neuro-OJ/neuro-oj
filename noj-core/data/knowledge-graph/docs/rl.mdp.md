# 马尔可夫决策过程

## 直觉理解

强化学习不是一次猜对一个答案，而是像下棋一样“走一步、看一步、影响后面很多步”。马尔可夫决策过程（MDP）就是用数学语言把这种“当前选择既给眼前奖励，又改变未来局面”的连续决策问题严格框定出来。

## 核心概念

1. **MDP 五元组 $(S, A, P, R, \gamma)$**：
   - $S$ 状态空间（环境处境）、$A$ 动作空间（可选操作）。
   - **状态转移概率 $P(s' \mid s, a)$**：在状态 $s$ 执行动作 $a$ 后跳转到 $s'$
     的概率。
   - **奖励函数 $R(s, a, s')$**：单步即时反馈信号。
   - **折扣因子 $\gamma \in [0, 1)$**：平衡即时奖励与长远回报。
2. **马尔可夫性质**：未来只取决于当前状态和当前动作，与更早的历史路径无关：$P(S_{t+1} \mid S_t, A_t, S_{t-1}, \dots) = P(S_{t+1} \mid S_t, A_t)$。
3. **轨迹与状态设计**：如果原始观测不满足马尔可夫性（例如单帧图像看不出速度方向），可以通过堆叠连续帧或用循环状态来补全为近似马尔可夫状态。

## 常见误区

- 只传入单张静态截图就假定满足马尔可夫性，结果智能体分不清球在往左飞还是往右飞。
- 奖励函数设计不当导致“刷分作弊”（Reward
  Hacking），比如给接近终点每步都加正奖励却不设步数惩罚，智能体就会在终点前原地绕圈刷分。

## 例题与完整解析

**题目**：给定一个 3 状态（`S0 -> S1 -> Goal`）线性确定性 MDP，折扣因子
$\gamma = 0.9$，到达 `Goal` 奖励为 `+10`，其余每步移动代价 `-1`，计算从 `S0`
直接向右走到终点的折扣累积回报 $G_0$。

```python
gamma = 0.9
rewards = [-1.0, 10.0]  # t=0: S0->S1 (-1), t=1: S1->Goal (+10)
G0 = sum((gamma ** t) * r for t, r in enumerate(rewards))
print("Discounted return G0:", round(G0, 4))
```

**逐步讲解**：$G_0 = -1 + 0.9 \times 10 = 8.0$。若中途在 `S0`
多徘徊一步再出发，$10$ 分的贴现将再乘一次 `0.9` 变为 $8.1$
并多扣成本，最优策略天然倾向最短路径。
