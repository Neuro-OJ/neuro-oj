# 欠拟合与过拟合

## 直觉理解

背考题有两种失败方式：一种是什么都没学会，连课本题也做不对，这叫**欠拟合**；另一种是把习题册每一题连同答案编号一起记住了，遇到稍微变形的题就崩，这叫**过拟合**。理想状态是抓住题目背后的规律，而不是记住表面的细节。

## 核心概念

**误差分解**。对平方损失，期望测试误差可写成

$$\mathbb{E}[(y-\hat f(x))^2] = \text{噪声} + \text{偏差}^2 + \text{方差}.$$

模型太简单时偏差大、方差小，表现为训练与验证误差都高（欠拟合）；模型太复杂时偏差小、方差大，表现为训练误差很低而验证误差升高（过拟合）。

**复杂度与数据量**。模型容量要匹配数据量与信噪比。参数多、特征多、训练时间长都会增加有效复杂度；数据更多、正则更强、模型更简单都会降低有效复杂度。

**判断方法**。对比训练与验证误差：两者都高 → 欠拟合；训练低、验证明显高 →
过拟合。学习曲线（误差随训练样本数或训练轮数的变化）能更清楚地显示差距是否在缩小。

**应对手段**。欠拟合：增加特征、使用更灵活的模型、减少正则、训练更久。过拟合：增加数据或数据增强、降低模型复杂度、加入
L1/L2 正则、Dropout、早停、集成。

## 常见误区

- 认为训练损失越低越好：训练损失可以无限逼近 0，甚至完美记忆噪声。
- 一旦验证误差高就断定过拟合：先检查训练误差，两者都高其实是欠拟合。
- 用测试集决定早停或调参，把测试集弹性地用成了验证集。
- 只看单次划分的结果：验证集较小时差异可能只是波动，需要交叉验证或多次随机种子。
- 认为参数越多一定越容易过拟合：深度网络在参数远多于样本时仍可能泛化良好（所谓双下降现象），因为隐式正则与数据规模同样重要，因此要结合实证判断。
- 把"数据泄露"误当作"模型很强"或"过拟合"：先排查特征是否包含标签信息。

## 例题与完整解析

**题目**：用一条带噪声的正弦曲线生成 30 个训练点，分别用 1 次、3 次、15
次多项式拟合，在大量测试点上计算误差，判断哪种情况是欠拟合与过拟合。

```python
import numpy as np

rng = np.random.default_rng(0)
true_f = lambda x: np.sin(2 * np.pi * x)
xtr = rng.uniform(0, 1, 30)
ytr = true_f(xtr) + rng.normal(0, 0.15, 30)
xte = np.linspace(0, 1, 400)
yte = true_f(xte)

for deg in (1, 3, 15):
    # 手写最小二乘：设计矩阵 + 正规方程。高次时用极小岭项保证数值稳定
    V = np.vander(xtr, deg + 1, increasing=True)
    lam = 1e-6 if deg == 15 else 0.0
    coef = np.linalg.solve(V.T @ V + lam * np.eye(deg + 1), V.T @ ytr)
    err = lambda x, y: np.sqrt(np.mean((np.vander(x, deg + 1, increasing=True) @ coef - y) ** 2))
    print(f"deg={deg:2d}  训练RMSE={err(xtr, ytr):.3f}  测试RMSE={err(xte, yte):.3f}")
```

**逐步讲解**：

1. 数据只有 30 个点且含噪声，真函数是一个平滑的正弦波，真实复杂度较低。
2. 1
   次多项式只能拟合一条直线，无法弯曲，训练与测试误差都大，是典型的**欠拟合**。
3. 3
   次多项式刚好能刻画正弦的主要形状，训练误差与测试误差都较小且接近，是合适的容量。
4. 15 次多项式有 16 个参数，接近样本数，训练误差进一步降到 0.1
   左右，但在训练点之间剧烈摆动，测试误差升到比 3
   次模型还高，训练与测试的差距也最大，是典型的**过拟合**。注意发生过拟合时训练误差仍可能不是
   0（16 个参数不能精确插值 30
   个点），判断依据是二者的**差距**而非训练误差的绝对值。高次 Vandermonde
   矩阵条件数很大，加一个小岭项只是为了数值稳定，本质上仍是多项式拟合。
5. 若把训练点从 30 增加到 300，15 次多项式的测试误差会明显下降；若给高次模型加
   L2
   正则，效果类似。这说明"过拟合"是**容量与数据量的相对关系**，不是某个模型固有的属性。
6. 实践中通常先画学习曲线确认差距趋势，再决定加数据、加正则还是减容量。
