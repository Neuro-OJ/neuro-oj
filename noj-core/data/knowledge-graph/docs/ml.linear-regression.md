# 线性回归

## 直觉理解

在一张散点图上找一条直线，让它"整体最贴近"所有点。贴近的程度用竖直方向误差的平方和衡量，取到最小值的直线就是最小二乘解。推广到多个特征，直线变成超平面
$y = w_1x_1 + \cdots + w_dx_d + b$。

## 核心概念

**模型与损失**。预测 $\hat y = Xw + b$，损失

$$L(w,b) = \frac{1}{n}\sum_{i=1}^{n}(\hat y_i - y_i)^2.$$

**正规方程（闭式解）**。把偏置并入设计矩阵 $X$（加一列 1），令梯度为零得

$$w^\* = (X^\top X)^{-1}X^\top y .$$

实际计算中优先用 `np.linalg.lstsq` 或
SVD，避免显式求逆（病态时更稳）。特征间高度共线时 $X^\top X$
接近奇异，解对数据扰动敏感。

**梯度下降**。$\nabla_w L = \frac{2}{n}X^\top(Xw-y)$。数据大或需要在线学习时用梯度下降及小批量版本。

**评价指标**。均方误差 MSE、均方根误差 RMSE、平均绝对误差 MAE、决定系数
$R^2 = 1 - \frac{\sum(y_i-\hat y_i)^2}{\sum(y_i-\bar y)^2}$，$R^2=1$
表示完美拟合，$0$ 大致等于"总是预测均值"。

**基本前提**。线性回归假设关系近似线性、误差独立同分布、方差稳定。出现明显非线性或异方差时，应考虑特征变换、多项式特征或换模型。

## 常见误区

- 忘记加偏置项，导致拟合直线被迫过原点。
- 直接对 `X.T @ X` 求逆：特征共线或单位不一致时数值不稳，应改用 `lstsq`
  或先标准化。
- 不标准化特征就上梯度下降：各特征量纲差别大使条件数变差，收敛非常慢。
- 用训练集 $R^2$ 当泛化性能：对照验证集才有效。
- 把"线性"理解成模型只能处理直线：对特征做变换（如
  $x^2$、$\log x$）后仍是线性回归，只是特征空间里的直线在原始空间里是曲线。
- 把相关当因果：回归系数大不意味着改动该特征会导致目标变化。

## 例题与完整解析

**题目**：给定房屋面积和房龄两个特征，用正规方程求出预测房价的线性模型，并与"预测均值"的基线比较
$R^2$。

```python
import numpy as np

rng = np.random.default_rng(1)
n = 200
area = rng.uniform(40, 160, n)        # 平方米
age = rng.uniform(0, 30, n)           # 房龄
price = 0.8 * area - 1.5 * age + 20 + rng.normal(0, 6, n)  # 万元

X = np.column_stack([area, age])
mu, sd = X.mean(0), X.std(0)
Xs = (X - mu) / sd
A = np.column_stack([np.ones(n), Xs])  # 加偏置列

coef, *_ = np.linalg.lstsq(A, price, rcond=None)
pred = A @ coef
ss_res = np.sum((price - pred) ** 2)
ss_tot = np.sum((price - price.mean()) ** 2)
print("标准化系数:", np.round(coef, 3))
print("R^2:", round(1 - ss_res / ss_tot, 3))

# 还原到原始尺度：w_raw = w_sd / sd，b_raw = b - sum(w_raw * mu)
w_raw = coef[1:] / sd
b_raw = coef[0] - np.dot(w_raw, mu)
print("原始系数:", np.round(w_raw, 3), "截距:", round(b_raw, 3))
```

**逐步讲解**：

1. 数据由 $0.8\times面积 - 1.5\times房龄 + 20$
   生成并叠加噪声，正确模型应接近这组系数。
2. 标准化后 `lstsq` 求解，`coef[0]` 是截距（因为标准化后均值为
   0，截距等于价格均值），`coef[1:]` 是标准化尺度下的系数。
3. 标准化系数为 $0.8\cdot\sigma_x / \sigma_y$
   的形式，数值不大，便于比较特征重要性；但量纲不同，真正的解释要用原始尺度的系数。
4. 还原公式：$w = w_{\text{std}}/\sigma$，$b = b_{\text{std}} - \sum w_j \mu_j$。验证还原后的系数应接近
   $(0.8, -1.5)$，截距接近 $20$，误差来自随机噪声。
5. $R^2$ 约 0.95
   以上（不同噪声抽样会略有波动），明显高于"总预测均值"的基线（$R^2=0$），说明模型确实解释了大部分波动。
