# L1/L2 正则化

## 直觉理解

如果模型只顾着把训练误差压到零，权重往往会涨到极大去死记硬背个别噪声点。正则化相当于给复杂参数“收税”：不仅要预测准，还要参数尽量小或尽量简洁，迫使模型优先保留真正有用的泛化规律。

## 核心概念

1. **L2 正则化（Ridge / Weight Decay）**：在损失上加
   $\lambda \|\mathbf{w}\|_2^2 = \lambda \sum w_i^2$，每次梯度更新把权重按比例往
   $0$ 收缩，平摊共线特征的权重，抑制过大权重导致的尖锐决策边界。
2. **L1 正则化（Lasso）**：在损失上加
   $\lambda \|\mathbf{w}\|_1 = \sum |w_i|$。由于绝对值在 $0$
   处不可导的尖角特性，更容易把不重要特征的权重精确压成 $0$，自带特征选择效果。
3. **偏置项不惩罚**：正则惩罚通常只加在权重 $W$ 上，不加在偏置 $b$
   上，避免人为拉偏模型整体基线输出。

## 常见误区

- 特征没有标准化就直接做 L1/L2
  正则化：尺度小的特征因为需要更大权重才有效，反而被错误地施以更重惩罚。
- 把正则系数 $\lambda$ 设得过大导致模型欠拟合（全部权重趋近 0）。

## 例题与完整解析

**题目**：对比 L2 正则系数大小对高共线线性回归权重范数的影响。

```python
import numpy as np

rng = np.random.default_rng(0)
x1 = rng.normal(size=100)
X = np.column_stack([x1, x1 + 1e-3 * rng.normal(size=100)])  # 高度共线特征
y = 3.0 * x1 + 0.1 * rng.normal(size=100)

for lam in (0.0, 1.0, 10.0):
    w = np.linalg.solve(X.T @ X + lam * np.eye(2), X.T @ y)
    print(f"lambda={lam}: w={np.round(w, 3)}, ||w||={round(float(np.linalg.norm(w)), 3)}")
```

**逐步讲解**：无正则时共线特征权重剧烈震荡且数值极大；加入 $\lambda I$
后逆矩阵条件数显著改善，权重平滑分摊到两个相关特征上。
