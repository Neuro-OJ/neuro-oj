# 分类指标（准确率、精确率、召回率、F1）

## 直觉理解

一个滤网式垃圾邮件过滤器有三种评价角度：它拦下的邮件里有多少真的是垃圾（精确率）、真正的垃圾邮件里有多少被拦下（召回率）、整体判对了多少（准确率）。只报一个数字往往会掩盖问题：一个小偷都不抓的警察召回率为
0，但准确率可以高达 99.9%。

## 核心概念

**混淆矩阵**。以正类（通常是我们关心的类）为参照，把预测结果分成四格：TP（真正例）、FP（假正例，误报）、FN（假反例，漏报）、TN（真反例）。所有指标都由这四格推出。

- 准确率：$\text{Acc}=\dfrac{TP+TN}{TP+FP+FN+TN}$
- 精确率：$P=\dfrac{TP}{TP+FP}$，在**预测为正**的样本中正确的比例。
- 召回率：$R=\dfrac{TP}{TP+FN}$，在**实际为正**的样本中被找出的比例。
- $F_1=\dfrac{2PR}{P+R}$，是精确率与召回率的调和平均，任一方很低都会把 $F_1$
  拉低。

**多分类**。对每个类别分别计算，再取宏平均（各类别指标先算再平均，平等对待每类）或微平均（汇总所有格子的计数再算，大类别主导）。宏
$F_1$ 更能反映小类别表现。

**权衡**。阈值降低会提高召回率、降低精确率，反之亦然。指标选择应反映业务代价：漏诊代价高用召回率优先，误报代价高用精确率优先。

## 常见误区

- 在类别不平衡时只看准确率：90% 为负类时，全预测负类可得到 0.9。
- 把精确率与召回率弄反。记忆方法是"精确率的分母是你的**预测**，召回率的分母是**真实**正例"。
- 用算术平均代替 F1；$P=1,R=0$ 时算术平均是 0.5，而 $F_1=0$，明显不合理。
- 在多分类中混用宏平均与微平均，导致不同模型不可比。
- 用默认阈值 0.5 报告指标，却不说明阈值；概率输出类模型的排序能力更适合用
  ROC/AUC 或 PR 曲线描述。
- 忘记定义谁是正类：把类别标签换个方向，精确率可与召回率互换。

## 例题与完整解析

**题目**：某疾病筛查模型在 200 人上的预测如下：真实患病 20 人，模型找出了其中 16
人；模型共预测 30 人患病。求准确率、精确率、召回率与
$F_1$，并说明为何此时不该主推准确率。

```python
TP, FN, FP = 16, 20 - 16, 30 - 16
TN = 200 - TP - FN - FP
acc = (TP + TN) / 200
prec = TP / (TP + FP)
rec = TP / (TP + FN)
f1 = 2 * prec * rec / (prec + rec)
print(f"TP={TP} FN={FN} FP={FP} TN={TN}")
print(f"准确率={acc:.3f} 精确率={prec:.3f} 召回率={rec:.3f} F1={f1:.3f}")
print(f"全预测为健康的准确率={(TN + FN) / 200:.3f}")
```

**逐步讲解**：

1. 已知真实患病 20 人，模型正确识别 16 人，漏掉 4 人，所以 $FN=4$。
2. 模型预测 30 人为患病，其中 16 人确实患病，误报 14 人：$FP=14$。于是
   $TN=200-16-4-14=166$。
3. 准确率 $(16+166)/200=0.91$；精确率 $16/30\approx0.533$；召回率
   $16/20=0.8$；$F_1=2\times0.533\times0.8/(0.533+0.8)\approx0.64$。
4. 全部预测为健康的"傻瓜模型"准确率为
   $170/200=0.85$，与真实模型接近，说明本任务不均衡，准确率参考价值低。此时应关注召回率与精确率的组合，或者调整阈值：把阈值调低能扫出更多患者（召回上升），代价是误报增加。
5. 上临床前还需要看具体人群：若筛查人群患病率更低，精确率会进一步下降，这些都是只看准确率无法发现的。
