# 人工智能基本概念与发展

## 直觉理解

人工智能的目标是让机器完成通常需要人类智能才能做好的事。早期研究者把人类总结好的“如果……那么……”规则写进程序（规则驱动）；而现代
AI
的核心转向“让机器从大量数据里自己归纳规律”（数据驱动），大模型则是把这一路线推向通用理解与生成的最新阶段。

## 核心概念

1. **三层包含关系**：人工智能（AI，大领域总称）包含机器学习（ML，从数据中学习模式），机器学习又包含深度学习（DL，用多层神经网络自动提取表征）。
2. **规则驱动 vs
   数据驱动**：规则系统可解释、冷启动快但难应付复杂边界（如自然图像与口语变化）；统计机器学习与深度学习在海量样本下泛化更强，但依赖数据质量与算力。
3. **大模型时代转向**：从“每个任务单独训一个小模型”演进为“大规模预训练基座模型 +
   微调/提示/智能体编排”。

## 常见误区

- 把“大模型对话”等同于人工智能的全部；很多工业场景下（表格预测、推荐排序、传统搜索）轻量机器学习甚至简单规则依然更稳更省成本。
- 认为只要用上深度学习就不需要理解业务目标和数据分布。

## 例题与完整解析

**题目**：判断以下三个任务更适合规则驱动、经典机器学习还是深度学习/大模型：（1）校验订单号是否符合
`NOJ-8位数字`；（2）用历史消费字段预测用户下月续费率；（3）从长篇中文技术文档中抽取结构化结论。

```python
import re

def validate_order_id(text: str) -> bool:
    return bool(re.fullmatch(r"NOJ-\d{8}", text))

print(validate_order_id("NOJ-20261126"))  # True
print(validate_order_id("ABC-123"))       # False
```

**逐步讲解**：格式确定、规则完备的（1）直接用正则表达式零样本零成本最稳；（2）属于结构化表格任务，经典树模型基线常优于大网络；（3）涉及自由语言语义理解，适合采用深度学习预训练模型或大模型结构化抽取。
