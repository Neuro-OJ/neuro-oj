# 决策树

## 直觉理解

决策树模拟的是人类做判断时的“逐层提问法”：先挑区分度最强的问题（比如“年龄是否大于
30”），把样本分成两堆，再在各自堆里继续往下细分，直到每堆基本属于同一类别。模型天然可解释，能直接画成清晰的规则流程图。

## 核心概念

1. **划分准则（纯度提升）**：常用基尼不纯度 $G = 1 - \sum p_k^2$
   或信息增益（分裂前后信息熵下降量）。回归树则追求子节点方差（MSE）下降最大。
2. **生长与剪枝**：如果不限制深度，树会不断切分直到每个叶子只剩一个样本，严重过拟合。控制过拟合需做**预剪枝**（`max_depth`、`min_samples_leaf`）或**后剪枝**（代价复杂度剪枝）。
3. **工程地位**：单棵决策树方差偏高、对样本扰动敏感，却是随机森林与梯度提升树（XGBoost/LightGBM）的核心积木。

## 常见误区

- 认为深度越深一定越好：训练集准确率 100% 往往意味着记住了随机噪声。
- 忘记对高基数无序类别特征做妥善编码，导致树倾向于优先切分唯一编号列。

## 例题与完整解析

**题目**：计算数据集按某特征阈值切分后的基尼不纯度加权平均，决定最优划分方向。

```python
def gini(counts: list[int]) -> float:
    total = sum(counts)
    if total == 0:
        return 0.0
    return 1.0 - sum((c / total) ** 2 for c in counts)

# 分裂前: 正例 4, 负例 4
before = gini([4, 4])
# 划分后左子集 [3, 1] (4个), 右子集 [1, 3] (4个)
after = 0.5 * gini([3, 1]) + 0.5 * gini([1, 3])
print("分裂前基尼:", before, "分裂后加权基尼:", after, "纯度增益:", before - after)
```

**逐步讲解**：每次划分都枚举候选切分点并选取纯度增益最大的一项，递归建树直到满足停止条件。
