# 预训练文本编码器（BERT）

## 直觉理解

“苹果很甜”和“苹果发布了新手机”里的“苹果”意思是完全不同的。静态词向量只能给“苹果”分配同一个向量，而
BERT
通过双向自注意力先读完整句话的前后语境，再为当前位置算出融入上下文信息的动态表示。

## 核心概念

1. **双向编码器架构**：BERT 仅保留 Transformer
   Encoder，注意力矩阵不做因果遮罩，每个词元都可以同时关注左侧和右侧所有词元，非常擅长理解、分类、命名实体识别与检索表征。
2. **两大无监督预训练目标**：
   - **掩码语言建模（MLM）**：随机遮盖 15% 的输入词元（其中 80% 换为
     `[MASK]`、10% 随机替换、10% 保持原词），让模型利用双向上下文还原被遮词。
   - **句间关系预测（NSP）**：早期用来学习句子连贯性（后续如 RoBERTa
     证明单靠长文本 MLM 更有效）。
3. **下游微调范式**：分类任务取句首 `[CLS]` 向量接线性头，序列标注直接对每个
   token 的隐状态分类。

## 常见误区

- 把仅编码器结构的 BERT
  直接拿来做自回归长文本续写——它没有因果解码掩码与单向生成训练目标，不适合开放生成。
- 训练微调时只给 `[MASK]` 词表位置加分类，却忘记按 80/10/10 策略缓解预训练阶段
  `[MASK]` 与微调阶段无 `[MASK]` 的分布落差。

## 例题与完整解析

**题目**：演示为何掩码语言模型需要把注意力 mask 与输入 `[CLS]` / `[SEP]`
对齐，并用余弦相似度模拟同一词在不同语境表示的分离。

```python
import numpy as np

# 模拟静态词向量（无法区分多义词）vs 上下文编码向量
apple_static = np.array([0.8, 0.2, 0.1])
apple_fruit_ctx = np.array([0.92, 0.15, 0.05])
apple_tech_ctx = np.array([0.12, 0.89, 0.42])

def cosine(a, b):
    return float(np.dot(a, b) / (np.linalg.norm(a) * np.linalg.norm(b)))

print("Contextual similarity (fruit vs tech):", round(cosine(apple_fruit_ctx, apple_tech_ctx), 4))
```

**逐步讲解**：经双向自注意力融合上下文后，“水果语境苹果”与“科技语境苹果”的余弦相似度降至
`0.2649`，下游线性分类器因此可以轻松区分语义。
