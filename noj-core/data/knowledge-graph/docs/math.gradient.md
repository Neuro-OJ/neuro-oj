# 梯度与优化直觉

## 直觉理解

想象你站在一片起伏的山坡上，四周被浓雾笼罩，只能感受到脚下哪边更陡。想尽快下到谷底，最自然的做法是朝**最陡的下坡方向**迈一小步，然后再感受、再迈步。梯度就是"上坡最陡的方向"，沿负梯度走就是下坡；每一步迈多大，就是学习率。

## 核心概念

**方向导数与梯度**。对可微函数 $f:\mathbb{R}^n\to\mathbb{R}$，单位方向 $u$
上的方向导数为 $\nabla f(x)\cdot u$。它与 $u$ 做内积，当 $u$ 与 $\nabla f$
同向时取最大值
$\|\nabla f\|$，反向时最小。所以梯度既指向上升最快的方向，又垂直于经过该点的等值线。

**梯度下降**。从 $x_0$ 出发迭代

$$x_{t+1} = x_t - \eta\nabla f(x_t),$$

其中 $\eta>0$ 是学习率。对凸且光滑的函数（如二次函数），只要 $\eta$ 不超过
$2/L$（$L$ 为梯度的 Lipschitz 常数，即 Hessian 最大特征值），迭代就会收敛。

**一阶近似视角**。$f(x - \eta g) \approx f(x) - \eta\|g\|^2$，所以小步长下目标值必然下降；但当
$\eta$ 太大，这一近似失效，可能反而上升。

**局部与全局**。梯度为零的点（驻点）可能是极小、极大或鞍点。神经网络的目标函数高度非凸，深学习实践中的要点不是"逃离所有局部极小"，而是走好一阶优化路径、避开明显的坏点。

**常见变体**。随机梯度下降（SGD）用一小批样本估计梯度，噪声反而有助于震荡出尖锐极小；动量累积历史方向；Adam
用梯度的一阶与二阶矩做逐参数自适应步长。

## 常见误区

- 认为梯度下降一定能找到全局最优：只有凸问题才保证。
- 忘记负号：沿梯度方向上升，沿负梯度方向下降。
- 学习率越大越快：过大会发散、震荡甚至出现数值溢出。
- 忽略特征尺度：不同特征量纲差别大时，等值线变成细长椭圆，梯度下降会"之"字形缓慢前进，此时标准化特征非常关键。
- 把梯度当作函数在整条线上的斜率：梯度是**某一点**的局部信息，目标非线性时每一步的梯度都不同。

## 例题与完整解析

**题目**：用梯度下降最小化 $f(x,y) = x^2 + 9y^2$，初始点 $(1,1)$，学习率
$0.1$，迭代 20 步；再对比 $\eta=0.25$（接近临界值）时的表现，并给出理论最优解。

```python
import numpy as np

def grad(x):
    return np.array([2 * x[0], 18 * x[1]])

for lr in (0.1, 0.25):
    x = np.array([1.0, 1.0])
    for t in range(20):
        x = x - lr * grad(x)
    print(f"lr={lr}: f={x[0]**2 + 9*x[1]**2:.3e}, x={x}")
```

**逐步讲解**：

1. 梯度为 $\nabla f=(2x, 18y)$，Hessian 是 $\mathrm{diag}(2, 18)$，最大曲率
   $L=18$，收敛临界学习率为 $2/18\approx0.111$。
2. 学习率 0.1 时，$x$ 方向的更新系数为 $1-2\eta=0.8$，$y$ 方向为
   $1-18\eta=-0.8$，两个方向每一步都乘 $-0.8$：20 步后 $x$ 缩小到
   $0.8^{20}\approx0.012$，$y$ 是 $0.8^{20}$ 的 $(-1)^{20}$ 倍，即同样为
   $0.012$，$f\approx0.012^2(1+9)\approx1.3\times10^{-3}$，稳定收敛。
3. 学习率 0.25 时，$y$ 方向系数为 $1-18\times0.25=-3.5$，每步翻 $3.5$
   倍且正负交替，迅速数值爆炸，说明超过临界值就不收敛。
4. 这个例子说明：**收敛速度由各方向曲率差异决定**。若把 $y$
   缩放一下（或者对特征做标准化），条件数改善，同样的步数能收敛更快。理论与实验一致，最优解是
   $(0,0)$。
