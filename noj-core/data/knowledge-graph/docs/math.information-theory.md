# 熵、交叉熵与 KL 散度

## 直觉理解

信息熵衡量“一件事有多出人意料”，分布越平均越难猜，熵就越高；交叉熵衡量“用预测分布
$Q$ 给真实分布 $P$ 编码平均要花多少比特”；而 KL
散度则是交叉熵减去真实熵的那部分“额外浪费”——当模型预测 $Q$ 完全贴合真实分布 $P$
时，KL 散度恰好归零。

## 核心概念

1. **信息熵**：$H(P) = -\sum_x P(x)\log P(x)$。必然事件熵为
   $0$，均匀分布熵最大。
2. **交叉熵（Cross-Entropy）**：$H(P, Q) = -\sum_x P(x)\log Q(x)$。在分类问题和语言模型中，真实分布
   $P$ 常为 one-hot，此时交叉熵退化为 $-\log Q(y_{\text{true}})$。
3. **KL
   散度**：$D_{\text{KL}}(P \| Q) = H(P, Q) - H(P) = \sum_x P(x)\log\frac{P(x)}{Q(x)} \ge 0$。由于
   $H(P)$ 与模型参数无关，最小化交叉熵等价于最小化预测与真实分布之间的 KL 散度。

## 常见误区

- 以为 KL 散度对称（其实
  $D_{\text{KL}}(P\|Q) \neq D_{\text{KL}}(Q\|P)$）：前者惩罚模型漏掉真实模式（mode-covering），后者偏向集中单一峰（mode-seeking）。
- 实现交叉熵时未做概率裁剪或 `log-sum-exp` 技巧，导致 $\log(0) = -\infty$ 产生
  `NaN`。

## 例题与完整解析

**题目**：计算三分类真实标签 `y = 1` 与模型概率输出 `q = [0.1, 0.7, 0.2]`
的交叉熵损失及困惑度。

```python
import numpy as np

p = np.array([0.0, 1.0, 0.0])
q = np.array([0.1, 0.7, 0.2])
eps = 1e-12
ce = -np.sum(p * np.log(np.clip(q, eps, 1.0)))
ppl = np.exp(ce)
print("交叉熵:", round(float(ce), 4), "等效困惑度:", round(float(ppl), 4))
```

**逐步讲解**：交叉熵约为 $0.3567$；对语言模型而言，$\exp(\text{平均交叉熵})$
即困惑度，表示模型在每一步等价于在多少个词中随机选择。
