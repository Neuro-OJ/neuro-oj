# education

教学组织、作业、学情、反馈、求助和补题的业务模块。产品 Domain 由 workspace
解析，教学资源始终携带 domain_id，不以全站账号角色代替班级关系。

Classroom 的教练、助教、学生身份在数据库读取；助教只组合六项固定能力。班级
归档和退出保留身份及历史，管理变更使用 revision。跨模块仅使用 index.ts 门面，
评测与题库策略通过共享持久事件驱动教学进度，不由 shared 反向依赖本模块。

验证使用 `deno task test:domain education`。生产路由按升级计划等待完整资源隔离
验收后开放，未挂载的准备接口不代表教学阶段完成。

作业草稿使用 revision 编辑，发布按使用域绑定重新校验资源和名单，在同一事务
固定题目、要求、发布依据、实际接收者和教学事件。已发布集合不可直接编辑。
截止可有理由地延长，归档保留阅读；定时发布失败保存原因而不半发布。
学生离班结束计入区间，重新入班不回填离班期间练习。

当前持久事件生产契约位于 shared/education-events.ts。重算服务从同域实际学生的
当前正式判定计算按时与补做成绩，最高分与通过独立选择，记录来源及细粒度事实
revision。任务复制生成独立草稿。评测及名单事件驱动持久租约消费者自动重算，
后台循环同时处理定时发布；恢复不依赖 Redis 通知，业务状态均保存在数据库。
公开题单在发布事务展开，建立使用域绑定并固定集合；版本与策略沿革、资源下架、
模块停用、比赛结束及提交删除均驱动重算。过期矩阵显式更新状态，提供学生、题目、
状态、正式判定筛选及流式 CSV。历史提交读取单独验证班级及比赛权限。

整体／学生反馈、私人求助、追加回复和处理状态通过当前固定能力授权。通知在
业务事务落库、按页重新授权投递，目录与已读也执行当前关系过滤，不保存私人
正文摘要。教学 Web、源码／产物批注、SSE 与邮件仍在实施。
