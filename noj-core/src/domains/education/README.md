# education

教学组织、作业、学情、反馈、求助和补题的业务模块。产品 Domain 由 workspace
解析，教学资源始终携带 domain_id，不以全站账号角色代替班级关系。

Classroom 的教练、助教、学生身份在数据库读取；助教只组合六项固定能力。班级
归档和退出保留身份及历史，管理变更使用 revision。跨模块仅使用 index.ts 门面，
评测与题库策略通过共享持久事件驱动教学进度，不由 shared 反向依赖本模块。

验证使用 `deno task test:domain education`。显式域路由已接入应用组合根，并通过
双域身份与错误路径检查；完整教学旅程及发布验收仍按升级清单执行。

作业草稿使用 revision 编辑，发布按使用域绑定重新校验资源和名单，在同一事务
固定题目、要求、发布依据、实际接收者和教学事件。已发布集合不可直接编辑。
截止可有理由地延长，归档保留阅读；定时发布失败保存原因而不半发布。
学生离班结束计入区间，重新入班不回填离班期间练习。

当前持久事件生产契约位于 shared/education-events.ts。重算服务从同域实际学生的
当前正式判定计算按时与补做成绩，最高分与通过独立选择，记录来源及细粒度事实
revision。任务复制生成独立草稿。评测及名单事件驱动持久租约消费者自动重算，
后台循环同时处理定时发布；恢复不依赖 Redis 通知，业务状态均保存在数据库。
公开题单在发布事务展开，建立使用域绑定并固定集合；版本与策略沿革、资源下架、
模块停用、比赛结束及提交删除均驱动重算。过期矩阵显式更新状态，提供学生、题目、
状态、正式判定筛选及流式 CSV。历史提交读取单独验证班级及比赛权限。

整体／学生反馈、私人求助、追加回复和处理状态通过当前固定能力授权。通知在
业务事务落库、按页重新授权投递，目录与已读也执行当前关系过滤，不保存私人
正文摘要。原提交行批注固定文件、源码哈希及行范围；普通源码与学生 ZIP 文本预览
逐次验证班级和比赛权限，不返回存储直链。已有批注保留原提交依据，撤回不删除作者
和原正文，新提交不迁移批注。全班补题通过独立预览聚合未达标名单，不限于矩阵当前页；
创建时校验事实哈希和原作业
revision，排除过期、在途评测及不可用题目，生成统一题目
集合的独立草稿而不修改原成绩。作业发布、补入学生、截止调整、版本策略和资源变化
同事务登记通知；投递给实际学生、当前教练及获授权助教。历史读取只返回来源引用、
版本号与策略依据。原产物下载重新检查班级源码能力及比赛窗口，由服务器流式传输，
不返回存储地址；教学 SSE 与邮件仍在实施。

比赛补题通过 contest 公开门面读取获授权的完整实时榜或正式快照依据。教练身份不
解除比赛保密、本人榜或封榜；正式快照固定尝试，后续重测不改变来源。全班预览
排除在途、不可用和非参赛记录，创建时重新校验 revision 与事实哈希，生成带比赛
来源的独立草稿并保存来源审计。通过要求使用权威判定，不从满分推导通过。

已有本域成员可以通过专用入口申请班级学生身份，成员管理者分页审核，批准不提升
域角色或教学人员权限。CSV 支持最多 500 条，预览匹配／重复／错误，执行重新检查
事实并按账号→域→班级加锁。本域账号可直接入班，其他账号或新学生接受邮箱邀请。
邀请令牌只在首次响应返回，幂等记录不保存明文；显式重签原子撤销旧链接。 真实
PostgreSQL 测试验证锁等待与审计外键兼容，测试结束清理已提交夹具。
