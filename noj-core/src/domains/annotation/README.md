# 全局批注

批注属于明确的使用域，覆盖已发布题面、不可变提交文件和题解正文。全局是共同的数据模型与入口，不表示跨域公开。

个人笔记只属于作者。教学会话只属于一名学生和当前域 owner/coach；班级任职不参与授权。平台管理员通过治理入口填写原因并产生读取审计，普通读取没有平台管理员隐式旁路。

每次列表、详情、原文、通知和未读计数都重新验证当前域身份、会话范围与原文权限。快照及已收到通知不授予访问权。比赛期间允许定向交流，沿用来源资源的访问限制与正式排名规则。

来源服务只通过 catalog、submission、community 公开门面读取原文。所有引用都由服务端核验块和范围，原文变化不迁移旧锚点。写入幂等结果只保存资源 ID，跨副本状态持久化到数据库。
