# NOJ 界面设计依据

## 视觉权威

Neuro OJ 采用 **Precision Instrument（精密评测工作台）** 设计语言——以清晰的信息层级、克制的建筑发丝边框、统一的语义状态反馈与零多余装饰为原则。
所有颜色、字体、圆角、投影与容器宽度的单一事实来源为 [品牌规范](../design/noj-design-tokens.md)。

## 公共语言

- **工作台表面系统**：全站采用去噪冷白纸底（`#f7f8fa`）与纯白工作面（`#ffffff`），辅以 `1px` 发丝线（`#e2e8f0`）区分区域；代码做题工作区保留 `.editor-dark` 独立亮/暗双模切换（全站其余部分维持亮色，不承诺全站暗色验收）。
- **品牌交互与评测语义**：深钴天青蓝（`#0369a1`）承担主交互、导航激活态与焦点环；评测信号绿（`#047857`）专用于通过/运行就绪态；难度与评测结果使用独立的语义色板，禁止在页面组件中散落硬编码色值。
- **排版与浏览器原生表面**：使用离线系统无衬线 + 等宽字体栈；所有题号、分数、耗时、内存、排名与时间戳强制启用 `tabular-nums`；文本选区、光标颜色、滚动条与焦点环统一映射品牌色。
- **克制容器与圆角纪律**：通用组件严格使用 Nuxt UI v4（`U*`），普通卡片采用 `rounded-md`（6px）与 1px 边框（不使用重阴影或卡片套卡片），仅下拉与弹窗使用投影，禁止在卡片/列表项上使用 > 1px 的彩色侧边装饰框或标题上方 eyebrow 小标签。

## 页面构成与宽度契约

- 布局宽度统一由 `noj-ui/utils/workspace-layout.ts` 提供，`workspace.vue` 与 `BreadcrumbNav.vue` 严格对齐：
  - **域首页（`home: 1320px`）**：上方为紧凑域命令头（域名称、简介与直达题库/比赛行动入口）与快节奏签到模块并排，下方依次为公告、教学任务与最新评测。
  - **题库与提交列表（`library: 1040px`）**：页头、精简行内筛选工具条（可折叠高级筛选 + Active Filter Chips）、语义表格、对齐列宽的骨架屏与分页；手机端自动折叠次要列。
  - **题目详情（`problem: 1280px`）**：左栏主阅读（Header 聚焦题号/标题/难度/限额/主行动，题面与样例带复制即时反馈）+ 右栏补充元信息卡（类型/后端/提供者/通过率进度条/标签）与近期提交；信息零重复。
  - **独立做题工作区（`workspace` 全屏工作区）**：统一 `sm` 高度工具栏 + 活动栏 + 可调分隔侧栏（描述含样例一键「载入自测」、结构化提交历史卡、自测面板、设置）+ Monaco 编辑器 + 状态栏，支持 `Ctrl/Cmd+Enter` 提交、`Ctrl/Cmd+'` 自测、`Ctrl/Cmd+B` 折叠侧栏。
  - **管理与设置页面**：桌面分组导航加内容区，手机单列。

## 导航与层级

- **域上下文与切换**：顶栏在品牌标识右侧直接展示当前所在域，支持已登录用户一键切换域或进入域管理；用户菜单继续显示 `username@slug` 与个人/管理入口。
- **全域内 ⌘K 命令面板**：任意页面按 `Ctrl/Cmd + K` 或点击搜索栏均唤起域隔离的 `DomainCommandPalette`（支持快捷导航与分类型实时搜索），不再粗暴整页跳转打断上下文。
- **导航优先级**：「提交」进入主导航候选池，不强行隐藏进「更多」；业务链接严格维持当前 URL 域。

## 状态与动态

- 明确区分加载（骨架屏）、空态、错误与重试，页面失败不伪装成空数据。
- 签到反馈在 `450ms` 内完成并立刻呈现连续天数；提交列表存在进行中记录时自动启用条件轮询，全部终态后自动停表；所有动画严格遵守 `prefers-reduced-motion`。

## 验收

设计样板为全局顶栏/⌘K、域首页、题库、题目详情、独立做题工作区与提交记录。覆盖 `1440px` / `390px`、全站亮色与编辑器亮/暗切换、长标题、多标签、空数据、错误态与权限状态，并通过静态检查、单测、组件测试、SSR 构建与 Playwright 对比度校验。
