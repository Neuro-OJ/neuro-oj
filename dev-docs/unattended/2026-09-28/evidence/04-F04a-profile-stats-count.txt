被修的缺陷（面 1.4 审计 F-04a）：`queryProfileStats` 的 total_submissions / accepted /

收编的题目且该用户已通过"——比直接显示该行更隐蔽。

【修复后】`queryProfileStats(db, userId, viewer)` + 复用 `contestSecrecyCondition`：

用例覆盖的相位（同一流程一次锁死）：
  A) 未被任何竞赛收编        → 题解 1 条 / solution_count=1 / solved_count=1（基线，证明断言非恒真）
  B) 进行中公开赛收编        → 题解 0 条 / solution_count=0 / solved_count=0 / 已通过列表 0 行
  C) 竞赛结束                → 题解 1 条 / solved_count=1（赛后自动放行）
  D) **赛前筹备期（pending）** → 三者全为 0（F-01 与 F-04a 的共同修复点）
  E) 特权查看者（管理员/审核员）→ 题解、计数、已通过列表**同时**放行（不制造新的口径不一致）
