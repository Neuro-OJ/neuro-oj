# 工作空间、教学与多赛制升级实施记录

本文记录 2026-10-12 用户批准的产品架构升级，以及各阶段实际交付情况。
未勾选的项目不得视为已实现；每个阶段以独立、签名的 jj 提交保存。

## 已批准的产品契约

- 一次部署是一个 Instance，账号全局统一；Domain 是资源与权限边界，Classroom
  是域内教学组织。
- Community、Education、Team、Custom
  仅初始化可修改配置，重新应用须预览差异，不删除数据。
- 域创建支持管理员、申请审核、直接创建；默认仅管理员创建。固定角色，助教按教学能力授权。
- 班级邀请同时加入域基础成员；学生自行注册或邀请注册，不授权教师创建或重置全站账号。
- 取消 P/U，域内数字题号自 1001 分配；跨域引用始终使用来源的
  `slug:number`，不分配本地号。
- 统一 `/d/:slug/...` 与 `/api/v1/domains/:slug/...`，旧入口只解析默认域
  `main`。
- 仅共享公开题和公开题单；源授权撤销立即停止内容访问和新执行，保留原提交、成绩及反馈。
- 提交只归一个域；同域合格提交自动计入相关作业，跨域提交不自动计入。
- 作业固定题目集合与达标规则，作答版本和成绩跟随域题库策略，记录沿革及通知。
- 作业按时成绩与逾期补做分开，按受理时间判断；按时排队提交完成后补算，成绩跟随重测。
- 新生自动补入未截止作业；离班历史保留。教练查看本班学生全部同域提交，服从比赛保密。
- 作业支持全部现有题型；提供成绩矩阵、反馈、不可变提交行批注、求助、批量补题。
- 社区按域隔离；私信和关注保持统一账号关系，关联内容仍须授权。
- Provider、默认模型、预算和用量按使用域隔离；不得借用源域密钥，不承诺跨域 LLM
  成绩可比。
- 成员、题目、存储、提交频率、LLM 日/月限额实际生效，Judge 仍共用。
- 实例未上线、无旧比赛；U 题是否存在须只读核实，不擅自清除实际数据。

## 比赛契约

| 赛制     | 允许题型   | 计分                               | 赛时结果                         |
| -------- | ---------- | ---------------------------------- | -------------------------------- |
| Kaggle   | AI、客观题 | AI 最高分，客观题一次交卷原分      | AI 原反馈；客观题只返回总分      |
| OI       | OI、客观题 | 每题最后一次受理提交               | 不返回评测结果、分数或成绩榜     |
| IOI      | OI         | 每题最后一次受理提交               | 汇总与测试点结果，不返回数据内容 |
| IOI 严格 | OI         | 每题最后一次受理提交               | 仅汇总结果                       |
| ACM/ICPC | OI         | 解题数、首次 AC 时间及此前失败罚时 | 汇总判定、支持封榜               |

客观题沿用百分制原分，不乘题目权重；竞赛仅一次交卷，练习与作业允许重复。 ACM
默认失败加 20 分钟，CE/平台错误不计罚，赛前可配置。IOI
两种模式默认参赛者完整榜。
平台错误不伪造正式零分，不回退早期高分。正式比赛快照重测后须显式重新发布，作业成绩动态变化。

## 验证与工程约束

按仓库指定的 `deno task test:domain`、共享脚本、模块测试及 E2E 入口运行。
新增域同步接入域边界、测试分片和 CI 门禁。迁移通过 `db:generate`
生成，只追加；不手改 journal/锁文件。 跨副本状态使用
DB/Redis，权限撤销不依赖进程缓存；配置失效重新加载。
首版延期自定义角色、私有跨域授权、学期/课程、多班作业、AI 诊断、专属
Judge、复杂调度及计费。
