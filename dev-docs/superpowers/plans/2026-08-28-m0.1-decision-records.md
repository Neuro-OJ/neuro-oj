# M0.1 决策记录制度 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `.agents/notes/implemented/` 决策记录制度，并加入格式校验脚本、AGENTS 规则和 PR 模板检查项。

**Architecture:** 新增轻量 Agent Note 目录与格式；Deno 脚本扫描 `implemented/` 下的 Markdown，校验路径、状态和必需章节；AGENTS 与 PR 模板引用该制度。

**Tech Stack:** Deno 2（脚本与测试）、Markdown。

**Spec:** `dev-docs/superpowers/specs/2026-08-28-engineering-quality-roadmap-design.md`（Phase 0.1）

## Global Constraints

- 代码注释使用中文，标识符使用英文。
- 提交信息遵循 Conventional Commits，description 使用中文。
- 脚本与测试使用 Deno；测试通过 `deno test -A` 运行。
- 不修改与 M0.1 无关的文件。
