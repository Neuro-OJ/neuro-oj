# NOJ 设置、邀请、提交与评测队列改进

用户已批准实施。保留原 NOJ 视觉、三种固定域类型和教学能力；域及实例设置按功能分页。
Gemini 负责界面，主 Agent 负责后端、接口、权限和验收。使用 jj 管理签名小提交。

## 已确认规则

- 邀请：指定邮箱、通用、一次性；均提供链接和邀请码，域及班级共用。默认 7 天可改，
  邮箱及一次性限成功使用 1 人，通用默认不限人数、可设上限。服从实例注册政策。
- 提交：全题型同一列表，username 默认本人；清空查看授权范围内记录。他人仅有权
  访问题目的摘要，源码、客观题答案和教学矩阵仍按原权限及比赛保密规则处理。
- 队列：同一域页面切换 domain / instance；登录用户可看全局负载和计数，任务明细
  只含授权任务；无权访问的私有任务和他人自测不返回占位记录。
- 设置：域与实例全部采用功能页面导航。每页原子保存，保留草稿和未保存保护。
- 限额：区分继承、实例上限和新域默认值；null 无额外约束，0 禁止对应新增。
- 不新建组件库、权限编辑器或实时评测日志系统，不为未经证实的问题添加防御层。

## 验收要求

邀请覆盖到期、撤销、邮箱不符、重复兑换、并发最后名额、注册和班级加入；权限用
受控延迟复现并消除假拒绝。设置覆盖页级事务、冲突和草稿保留。提交列表、计数、
详情及队列均检查域与比赛权限。视觉验收覆盖 1440px / 390px、亮暗主题、长文本、
空态、加载、失败。标准测试、完整 UI 类型检查和构建通过后再报告实现完成。
