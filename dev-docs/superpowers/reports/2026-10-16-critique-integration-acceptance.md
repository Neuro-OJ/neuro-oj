# 管理界面评审修复的集成验收

日期：2026-10-16。范围见[任务清单](../plans/2026-10-16-critique-integration.md)。
Gemini 负责主要前端实现，Codex 核对实际 diff、补充测试、修复集成问题和执行验收。

## 实际修复范围

| 项目       | 实现与验证                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 页面职责   | 基本信息仅提交名称、简介，访问政策在独立页面编辑；组件测试校验精确 payload。                                               |
| 手机邀请   | 类型纵向排列，主操作独立；列表直接显示状态、到期与撤销，保留分页和次要详情；组件与实际浏览器生成/兑换流程通过。            |
| 额度       | GiB/MiB/字节切换保留原始整数；非法输入禁用保存；预计有效值仅在草稿改变时出现。实际 PATCH 验证 1 GiB + 1 字节不变。         |
| 列表与队列 | 显示短编号、复制完整编号、原详情链接不变；手机队列分层，范围按钮声明选中态，权限说明改为中性。                             |
| 条件政策   | 非邀请注册模式明确展示预设；切换模式保留值；默认域候选具有加载、错误重试和真实空结果。                                     |
| 导航       | 实例和域设置按基础政策、成员、内容、模型与额度、治理分组；全部为真实页面路径，仍按当前权限过滤。                           |
| 手机目录   | 长名称、slug 和负责人分层，管理与更多操作可见；390px 文档宽度断言通过，加载失败不伪装成空目录。                            |
| 系统设置   | 增加搜索和分类；手机字段纵向呈现，Nuxt UI 输入具有名称和帮助/错误关联；保护草稿，支持单项放弃；OI 标准移为次级可展开内容。 |
| 配置来源   | 按当前实际 source 区分 DB 与 env；重置说明准确表达回退来源，不因存在 env 兜底而在进入时阻断弹窗。                          |

原交付报告只覆盖部分范围。集成审查补齐导航、目录和旧系统设置，并通过新增测试
发现、修复存储四舍五入、未完成额度被清空、重新读取后输入未同步、候选域空结果
被当前值掩盖等问题。完整类型检查另发现 Nuxt UI 输入类型和同名 useToast 引用，
已修正。没有通过降低断言或新增延时掩盖失败。
