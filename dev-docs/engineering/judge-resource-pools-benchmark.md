## 四提交共享 16 槽位

四份独立的原始 road 提交同时编译评测，共享一个资源组的 16 个运行槽位及 2
个编译槽位。整批耗时 17729 ms，完整提交吞吐 0.226 次/秒，全部为 80 分。

| 提交 | 完整评测 ms | 运行准入 P50 ms | 运行准入 P95 ms |

| 2    |       17464 |            4844 |            8636 |
| 3    |       14379 |            1057 |            6749 |
| 4    |       17727 |            4768 |            8785 |

这是阶段准入等待，未覆盖真实 MQ 入队等待或用户 claim。四份任务的逐点
verdict、fuel 和预算与单提交对照一致。多个任务共享同一测量进程，RSS
只能作为整个基准进程的峰值解释。

## CPU 补充测量

在同一四提交、16 槽位配置下，补充运行整批耗时 14998 ms，Worker 进程所有线程累计
CPU 173143 ms，编译子进程累计 CPU 5151 ms。进程 CPU/墙钟约为 11.54
个平均占用核；这是整个基准进程的 CPU 消耗，不是单点耗时，也不是全宿主 CPU
利用率。四份提交的状态、fuel 和计量摘要与此前对照一致。
