# 全局批注的权限与教学信息边界

批注属于一个明确的使用域。“全局”指题面、提交文件和题解使用同一数据模型，
不表示跨域或全站可见。原文身份、使用域和当前访问人是三个独立的授权输入。

## 角色与读者

普通域只有 owner/member，教学域增加 coach。owner 以 domains.owner_id 为准，
coach 是全域教练。班级成员表只管理学生归属，联系人和历史助教授权不授予权限。

| 记录 | 作者 | 指定学生 | 当前域 owner/coach | 其他成员 | 平台管理员普通入口 |
| --- | --- | --- | --- | --- | --- |
| 个人笔记 | 可读写本人消息 | 不可读 | 不能读取他人的笔记 | 不可读 | 不能隐式读取他人的笔记 |
| 定向教学会话 | 仍须符合当前受众 | 可读、回复 | 可读、回复 | 不可读 | 仍按普通受众检查 |
| 平台治理查询 | 按当前普通授权 | 按当前普通授权 | 按当前普通授权 | 不可读 | 单独填写原因、重新验证平台权限并审计 |

以上每个“可读”都还要求当前域成员身份及完整原文访问权。退出教师组的作者也不能
因为“自己曾写过”继续读取原学生会话。被撤销题目共享、题解可见性或源码权限时，
连同批注正文、上下文、完整快照、目录项和未读计数一起暂时不可读，数据库保留依据。

新任教练可以接手历史教学会话，降级、移除或停用后下一次请求失去教师组权限。
个人笔记始终只属于作者。平台管理员不会通过普通目录、通知或详情旁路浏览私人笔记；
治理入口按会话 ID 查询，每次翻页也记录查询原因，不提供批量私人笔记浏览入口。

## 新建、发送与回复

页面初始只加载个人笔记，“与我共享”由用户主动开启。收到消息或打开授权深链不
改变后续页面的默认显示范围。新建表单即使由负责人或教练打开，也默认“仅自己”。

发送私人笔记生成独立教学会话，私人笔记保留。后续私人编辑不会自动同步，避免
作者误把备忘继续发给学生。学生只能向本域教师组提出自己的问题；教练指定一名
具有完整原文访问权的接收者。提交代码的接收者固定为该提交作者，不能另选同学。
第一版没有同学、全班或公开分享范围，引用和快照均不赋予新的原文访问权。

消息只能由原作者编辑或撤回。现任教练撤回他人的教学会话需要明确原因，不能改写
他人的消息正文。客户端使用 revision 防止覆盖并发修改，创建、发送和回复用数据库
幂等记录避免重复消息与通知；幂等结果只存资源 ID，重试响应仍执行当前授权。

## 原文定位

- 题面固定已发布 problem_version 和允许公开的字段，不开放答案或评测配置字段。
- 比赛题面额外固定比赛上下文，不能用另一版本绕过当前赛题版本。
- 提交固定 submission、文件名、原始 UTF-8 字节 SHA-256 和行范围。仅支持提交
  源码及受大小、路径、文件类型和 UTF-8 限制的产物文本，不读取题目支持包。
- 题解保留批注时完整快照和指纹。题解变化后显示“原文已有新版本”，不迁移旧锚点。
- 服务端由块身份和范围生成引用及前后各三行上下文，不采信客户端传来的引用正文。
  多个相同句子要求确认位置；页面无法唯一定位时转到固定原文，不猜测首个匹配。

完整原文单独按需读取。目录不返回全部快照或消息正文；通知不保存私人正文摘要。
列表、详情、原文和通知均禁止共享缓存。切换账号或域时清空草稿与详情，迟到响应
不能把上一身份的内容重新放回页面。

## 比赛与潜在作弊面

当前产品决策允许比赛期间继续私人批注和定向教学问答，也允许 owner/coach 正常
参赛并保留现有正式排名。系统不把有教练身份的参赛者改为非正式选手，也不通过
比赛阶段开关关闭批注。这意味着即时教学交流带来的信息优势是已接受的产品边界，
不能把本功能宣称为阻断场外辅导或维持严格独立作答的机制。

| 信息通道 | 实施边界 | 实际含义 |
| --- | --- | --- |
| 同学代码转发 | 接收者固定原提交作者；每次读取重新检查源码权限 | 不能通过批注把同学代码授予另一名学生 |
| 题解或题面引用泄露 | 双方必须当前拥有完整原文权限 | 引用不能绕过比赛题目、题解或共享限制 |
| 教练参赛信息优势 | 域教练本身具有本域资源和比赛管理权限 | 可以接触本域管理权限允许的数据，正式排名保持原规则 |
| 学生与教练即时交流 | 仅一名学生与当前教师组可见；持久记录作者和修改版本 | 允许指导，不能证明学生完全独立作答 |
| 旧角色继续读取 | 每次读取查询当前成员和域角色 | 离任、退域及停用不会保留会话访问权 |
| 通知和分页侧信道 | 授权过滤后生成目录、游标及未读数，不发送正文摘要 | 不返回不可读会话的标题、引用或存在数量 |
| 私人笔记的治理访问 | 独立管理员查询、必填原因和读取审计 | 普通管理能力不等于私人笔记阅览能力 |

批注模块复用 catalog/submission/community/contest 的公开门面，不能放宽原文的
比赛保密、判题细节、题解开放或冻结结果策略。域教练作为本域比赛管理者的可见范围
由比赛模块判定；普通参赛者的限制不因收到批注而改变。原文撤权后的引用正文也不能
作为“既然以前收到过就继续展示”的例外。

## 历史兼容与验证

旧行批注按当前来源授权导入为教学会话，保留原 ID、作者、学生、时间及版本。
新旧入口共同编辑全局消息表；旧表只保留历史输入，撤回会话不会再次从旧表导入。
不自动推送导入历史的重复通知。

验证分为角色与迁移测试、来源及会话服务测试、HTTP 契约、组件异步身份切换，
以及实际 SSR、导航和移动端页面验收。构建成功和单元测试通过分别是证据，不能
代替真实浏览器中的交互验收。
