# 前端文案表

NOJ 前端只提供简体中文界面。语言切换（中文 / English）已于 2026-11-08 移除：全站 283 个页面与组件中只有 5
个接入了翻译，切换到英文后绝大部分界面仍是中文，维护双语的成本与收益不成比例（issue #685）。

## 使用方式

- 文案集中维护在 `utils/i18n.ts` 的 `messages`（键 → 中文）。
- 组件中通过 `useI18n()` 取得 `t(key, params)`；纯函数中直接使用 `translate(key, params)`。`{name}` 形式的占位符由
  `params` 替换，未知键原样返回键名，便于发现漏写的词条。
- 面包屑标签（`utils/breadcrumb.ts`）复用同一张表，避免重复维护词条。
- 新增页面可以直接在模板中写中文；只有需要复用、或与错误码 / 面包屑共享的文案才放进文案表。

## API 错误

`utils/apiError.ts` 的 `extractApiError(err)` 优先展示后端给出的具体业务原因（`error`
字段）；后端未给出原因时，按机器码从 `error.<CODE>` 映射中文提示；再退回到超时、网络、HTTP 状态码等通用文案。
