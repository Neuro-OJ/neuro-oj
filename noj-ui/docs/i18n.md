# 前端国际化

NOJ 前端采用轻量、无路由前缀的国际化基础设施，默认语言为简体中文，同时支持 English。

## 使用方式

- `useI18n()` 提供 `t(key, params)`、`locale` 和 `setLocale()`。
- 语言保存在 `noj:locale` Cookie 中，服务端渲染与客户端导航共用该值，默认 `zh-CN`。
- 顶部导航的语言按钮在中文和 English 间切换；不改变 URL，因此不会影响 API 代理、权限守卫或 Monaco 编辑器。
- 文案集中维护在 `utils/i18n.ts`。新增页面文案时优先新增 key，再在模板中使用 `t()`，不要拼接后端返回的自然语言。

## API 错误

`utils/apiError.ts` 接受可选语言参数，已知机器错误码优先从 `error.<CODE>` 映射本地化文案；未知 code 才回退到后端提供的具体原因。统一 API 层会自动使用当前语言，因此 toast 不会在英文界面显示已知的后端中文错误。

当前覆盖认证、邮箱验证、题库、提交记录、竞赛大厅、公告以及通用网络/权限/限流错误。管理后台和社区等低频页面仍可逐步迁移，未迁移页面会继续显示原有中文，不影响功能。
