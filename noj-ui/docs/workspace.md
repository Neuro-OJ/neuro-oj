# 工作空间前端

当前提供空间目录、创建 / 创建申请、域概览、成员角色、加入申请审核、邀请与
负责人交接、配置 / 模板预览及成员 / 题目配额页面。显式域题库、作答、提交读取、
比赛与 LLM 管理，以及教学页面的客户端代码已接入新域契约；运行时统一开放仍等待
完整隔离验收。域搜索和完整浏览器旅程尚未完成，不能据页面或构建通过签收完整多域 OJ。

## 上下文及权限

`layouts/workspace.vue` 只建立一份 `provideWorkspaceContext()`，子页面通过
`useWorkspace()` 注入同一状态。Domain 始终从 `/d/:slug/...` URL 解析；导航偏好
只在主动进入空间时保存，不改变当前标签页域，不更换 JWT。

概览按域和统一账号缓存；响应中的实际 `actor_id` 必须与请求身份一致。
切换域或账号立即停止使用旧事实，背景刷新可保留同域名称但暂停使用旧权限。
所有动作仍由后端实时鉴权；可读 Session Cookie 不能授予管理能力。

`useWorkspaceActionScope()` 在确认之前捕获目标域和账号。切换、退出或卸载后
不继续旧确认，不把旧请求结果显示给新账号。生成的邀请明文只在当前创建响应
显示，目录不返回令牌或哈希。

`workspacePath`、`workspaceProblemPath` 保留使用域。引用 `main:1001` 时网址仍为
`/d/school/problems/main:1001`。资源缓存键另包含资源、稳定 ID 和版本；现有题目
页面及 IDE 模板草稿使用明确的使用域，完整客户端协同发布和扩展宿主交互验收仍待完成。

## 题库、提交与比赛

`/d/:slug/problems` 及题目页读取来源题号和目标域作答版本，支持代码、产物 ZIP 和
客观题作答。草稿按账号、域、题目、版本和语言保存；版本冲突保留输入，确认后切换。
读取模板带所见版本，替换现有代码前确认。
题目页可按需展开分页版本沿革，阅读版本号、发布说明和时间；当前作答版本按目标域策略标记，
沿革列表不提供任意旧版本作答或源数据下载入口。

资源编辑者可以从域题库创建源题，通过 `/d/:slug/problem-drafts` 找回未发布草稿，
在 `/d/:slug/editor/:reference` 编辑 OI、AI／LLM／产物或客观题。
AI 创建先选择实例许可的评测／运行镜像，并发送完整初始评测配置。
共用现有 Markdown、样例、Monaco 和小题表单；小题编辑保留稳定标识，草稿和发布
携带各自原始 revision。共享引用不能在使用域修改来源草稿。
保存不会改变作答版本；发布前必须检查已保存内容，内容或文件继续变化后重新预检。

OI 数据文件支持指定相对路径上传、授权文本预览和修改、删除及输入／答案配对预览。
先保存评测配置，再提交文件修改；未保存文件会阻止预检及发布。草稿冲突保留表单和
已选择的文件。题包 ZIP 导入只替换当前源题草稿及支持文件，不改题号或归属，也不隐式发布。
AI 表单仅编辑调用预算，不指定 Provider 或模型；镜像使用实例许可列表，命令和网络仍按
实例敏感字段权限控制。真实数据上传、发布及 Judge 旅程仍需协调开放后验收。

普通代码作答提供同域自测面板。OI 自测可选择公开样例或自定义输入，并分别表达
未比较输出和比较空字符串。创建携带所见版本，结果轮询、取消与独立详情页面都走域接口；
自测不会计入正式成绩或作业进度。用户用例 stdout/stderr 使用专门授权的自测结果字段，
源资源撤销后隐藏详情及输出，保留原代码和授权摘要。

`/d/:slug/submissions` 及提交详情只使用域内读取接口。比赛隐藏结果只显示回执；
汇总模式不渲染测试点及原始输出。源资源撤销后仍可按服务器授权读取原提交和成绩摘要。

域比赛列表、创建、管理、固定版本作答及榜单页面支持五种赛制；作答走比赛独立提交，
客观题一次正式交卷。进行中榜单定期重读授权接口，ACM 封榜保留已公开成绩并标记待揭榜。
正式成绩显示服务器快照，组织者可查看结算并显式发布新版本。真实赛制旅程仍需统一验收。

`/d/:slug/llm` 提供本域 Provider、默认模型、配额和用量界面。密钥只表单写入，列表脱敏；
历史 Provider 可停用。费用额度是与 Provider 单价相同单位的整数，不假定固定货币。

## 邀请注册

邀请链接使用 `/join#invitation=...` 或 `/register#invitation=...`，令牌留在 URL
fragment 中，以 POST 请求体向认证入口预览，不进入请求路径或 Referer。
预览只返回目标空间、受邀邮箱、到期时间和能否注册，不枚举账号。

已有账号可在邀请页登录及接受，支持两步验证码。其他登录方式可在新标签页完成，
回到邀请页时重新验证账号；初始密码更新使用独立页面，不改写已有账号凭据。
受邀注册固定邮箱，后端事务只加入目标域，管理员开户政策和签发者撤权仍生效。

登录回跳只接受经 `safeAuthRedirect()` 检查的本站路径。私有实例登录后只有一个
可用域时直接进入该域；两个以上域显示选择入口。邀请令牌不进入登录回跳查询参数。

## 配置与冲突

配置、配额和模板写入携带 `If-Match`。保存冲突保留未保存内容及原编辑 revision，
不能自动将旧修改绑定到新版配置。模板必须先预览差异再显式确认应用。
配额保存不清除基本设置草稿；基本设置继续使用原 revision，若需刷新，由用户
明确重新读取。域和账号变化后不复用其他空间的管理表单或邀请。

基础配额页面展示成员、题库条目的配置，存储和提交频率的管理及执行链继续验收；
不能根据可编辑表单推断所有额度已实际生效。LLM 额度在本域独立管理页配置。
归档和暂停状态由服务端政策决定，不隐藏失败响应。

布局导航和概览快捷入口已串联域题库、比赛、本人提交、已启用教学模块及具有管理能力的
LLM／成员／设置页面。所有链接保留当前使用域；导航代码完成仍不能替代接口完整隔离及协调开放。

## 教学准备页面

`/d/:slug/classrooms`、班级详情及 `/d/:slug/assignments/:assignmentId`
已接入教学准备接口，未加入公开导航，等待完整域隔离后协调开放。
班级列表可创建班级，班级详情按授权列出作业。作业页展示本人进度或教师矩阵，
支持按时／补做、当前／历史学生、用户名、题目、状态、正式判定及 CSV。
原提交侧栏提供代码／学生 ZIP
文本、哈希与行范围批注；反馈和求助使用独立教学能力。

班级详情已接入成员、单人邮箱邀请、助教固定能力、设置、交接与归档。
作业草稿支持本域题库与已引用题单、部分学生、精准最低分和截止配置，先保存再预览发布。
发布、定时发布、延长截止、提前结束、归档与手动补题复制复用后端事务。 修改携带原
revision，冲突保留输入，显式重新读取才替换编辑草稿。

班级成员页支持 CSV 上传／粘贴、逐行预览、执行及首次邀请链接下载，最多 500 条。
同域成员使用专用申请链接，管理者分页批准或拒绝；申请页面不开放同学数据。
重试返回已有结果，不恢复邀请令牌；需要新链接时显式重签并重新预览，旧链接失效。

域内通知目录只显示类型和时间，点击重新授权后定位到作业、求助或单条反馈。
作业变化历史分页展示来源题号、版本号、策略、操作者和理由，不恢复已撤销题面。

`/d/:slug/teaching` 和 `/d/:slug/my-learning` 通过服务端聚合读取获授权任务和求助定位。
教师统计为 null 时不转换成零，更新中的个人进度不展示旧达标数。每页 20 项，
当前页可筛选进行中或需要跟进；页面不逐个遍历班级请求矩阵。

矩阵可为当前页未达标学生快速预选独立补题草稿，跳过评测中、更新中、失效题和历史学生。
明确显示当前页及所选学生接收全部所选题的范围，教师预览后发布。批注作者可修改和撤回原批注，
写入携带服务器 revision。

全班未达标自动补题、比赛来源、成绩变化解释、客观题详情以及 SSE／邮件通知
尚未全部接入，准备页面不能当作已完成的教学产品。浏览器旅程与窄屏视觉验收仍待执行。

避免本地 Deno 下默认 fork 池全部断言通过后以 BrokenPipe 退出。

旅程；这些验收仍记录在
