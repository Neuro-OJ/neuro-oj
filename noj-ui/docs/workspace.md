# 工作空间前端

当前提供空间目录、创建 / 创建申请、域概览、成员角色、加入申请审核、邀请与
负责人交接、访问配置及成员 / 题目配额页面。显式域题库、作答、提交读取、 比赛与
LLM 管理，以及教学页面的客户端代码已接入新域契约；运行时统一开放仍等待
完整隔离验收。域搜索和完整浏览器旅程尚未完成，不能据页面或构建通过签收完整多域
OJ。

创建只提供社区、教学、团队三种固定类型，均有社区与域排行。教学域额外提供班级、
作业及教练工作台。域设置不提供模块开关、类型修改或重新应用模板；访问、发现和
加入政策仍可修改。实例限制由后端摘要表达，不能通过前端配置绕过。

## 上下文及权限

`layouts/workspace.vue` 只建立一份 `provideWorkspaceContext()`，子页面通过
`useWorkspace()` 注入同一状态。Domain 始终从 `/d/:slug/...` URL 解析；导航偏好
只在主动进入空间时保存，不改变当前标签页域，不更换 JWT。

概览按域和统一账号缓存；响应中的实际 `actor_id` 必须与请求身份一致。
切换域或账号立即停止使用旧事实，背景刷新可保留同域名称但暂停使用旧权限。
所有动作仍由后端实时鉴权；可读 Session Cookie 不能授予管理能力。

`useWorkspaceActionScope()` 在确认之前捕获目标域和账号。切换、退出或卸载后
不继续旧确认，不把旧请求结果显示给新账号。生成的邀请明文只在当前创建响应
显示，目录不返回令牌或哈希。

`workspacePath`、`workspaceProblemPath` 保留使用域。引用 `main:1001` 时网址仍为
`/d/school/problems/main:1001`。资源缓存键另包含资源、稳定 ID 和版本；现有题目
页面及 IDE
模板草稿使用明确的使用域，完整客户端协同发布和扩展宿主交互验收仍待完成。

## 题库、提交与比赛

无域前缀的题库、题单、比赛、提交和旧编辑入口在页面 setup 前固定重定向到 `main`。
旧 `P1001` 转成数字 `1001`，不读取导航偏好；`U1001`
返回不存在，不能指向同号新题。 旧题目 UUID
和题单公开标识只经默认域只读兼容接口解析稳定位置，解析失败不寻找其他域。
首页导航使用显式默认域网址，题号徽标不再区分 P／U 类别；引用题保留来源标识。

`/d/:slug/problems` 及题目页读取来源题号和目标域作答版本，支持代码、产物 ZIP 和
客观题作答。草稿按账号、域、题目、版本和语言保存；版本冲突保留输入，确认后切换。
题库按题号、完整来源题号或标题定位，可按难度、题型、标签及本人状态筛选；
条件与页码保存在 URL。本人状态和有效通过率只使用本域获授权记录，赛中结果不计入。
通过前隐藏算法标签，标签筛选也服从同一门控。
读取模板带所见版本，替换现有代码前确认。
资源管理页以分页管理本域源题与共享绑定，包括 any／exact 有效策略、展示范围、
可恢复下架和独立共享政策。限定共享填写目标域标识，授权由服务器解析；不手工填写数据库
ID。 公开资源发现只列当前向使用域开放引用的题目或题单，引用后继续使用当前域。

域题单支持浏览、创建和按原 revision
编辑题面、排序及可见性；公开题单引用保存来源。
详情按每题当前授权决定是否提供本域作答链接，未绑定题由获授权编辑者逐题引用，
源题撤销后停止链接和新导入。题单授权不能代替单题授权。

域内搜索首版提供题目、比赛和提交类型。题目来源引用由后端实时投影，显示来源题号，
链接保留请求域。域榜和本人名次只读取当前域；导航按 analytics 开关显示域榜入口。
题目页可按需展开分页版本沿革，阅读版本号、发布说明和时间；当前作答版本按目标域策略标记，
沿革列表不提供任意旧版本作答或源数据下载入口。

资源编辑者可以从域题库创建源题，通过 `/d/:slug/problem-drafts` 找回未发布草稿，
在 `/d/:slug/editor/:reference` 编辑 OI、AI／LLM／产物或客观题。 AI
创建先选择实例许可的评测／运行镜像，并发送完整初始评测配置。 共用现有
Markdown、样例、Monaco 和小题表单；小题编辑保留稳定标识，草稿和发布 携带各自原始
revision。共享引用不能在使用域修改来源草稿。
保存不会改变作答版本；发布前必须检查已保存内容，内容或文件继续变化后重新预检。

OI 数据文件支持指定相对路径上传、授权文本预览和修改、删除及输入／答案配对预览。
先保存评测配置，再提交文件修改；未保存文件会阻止预检及发布。草稿冲突保留表单和
已选择的文件。题包 ZIP
导入只替换当前源题草稿及支持文件，不改题号或归属，也不隐式发布。 AI
表单仅编辑调用预算，不指定 Provider 或模型；镜像使用实例许可列表，命令和网络仍按
实例敏感字段权限控制。真实数据上传、发布及 Judge 旅程仍需协调开放后验收。

普通代码作答提供同域自测面板。OI 自测可选择公开样例或自定义输入，并分别表达
未比较输出和比较空字符串。创建携带所见版本，结果轮询、取消与独立详情页面都走域接口；
自测不会计入正式成绩或作业进度。用户用例 stdout/stderr
使用专门授权的自测结果字段， 源资源撤销后隐藏详情及输出，保留原代码和授权摘要。

`/d/:slug/submissions` 及提交详情只使用域内读取接口。比赛隐藏结果只显示回执；
汇总模式不渲染测试点及原始输出。源资源撤销后仍可按服务器授权读取原提交和成绩摘要。

`/my/submissions` 兼容入口固定跳转到默认域提交目录，不提供跨域汇总。
失去域权限或资源授权后，保留本人原代码、原回答和允许公开的成绩摘要，移除题目返回入口。
域内客观题通过 `/d/:slug/objective-submissions`
读取，题目页提供按本题筛选的历史入口；
域入口仍要求进入权限，失权历史使用统一账号入口。所有比赛隐藏结果只显示受理回执，
平台失败不作为正式零分。原判断题回答显示“选择对／错”，不冒充逐题正确性。
本人原产物经 `/api/v1/me/submissions/submission/:id/artifact`
下载，离域后仍保留此入口；
服务器检查实际历史授权，不返回存储直链。下载失败显示具体原因并保留当前详情页。

域提交任务页保留原记录与升级后新记录的独立定位。客观题详情仅提供本人历史；
点击不可读的其他学生记录时在任务页提示通过获授权班级训练入口查看，不导航到失效详情。

域比赛列表、创建、管理、固定版本作答及榜单页面支持五种赛制；作答走比赛独立提交，
客观题一次正式交卷。进行中榜单定期重读授权接口，ACM
封榜保留已公开成绩并标记待揭榜。
正式成绩显示服务器快照，组织者可查看结算并显式发布新版本。真实赛制旅程仍需统一验收。

`/d/:slug/llm` 提供本域
Provider、默认模型、配额和用量界面。密钥只表单写入，列表脱敏； 历史 Provider
可停用。费用额度是与 Provider 单价相同单位的整数，不假定固定货币。 Provider
与额度各有独立修订号，新建携带零、更新使用打开编辑时的资源修订号，不用域
revision 替代。冲突保留原表单；重读列表不会偷换仍打开的编辑依据。保存 Provider
或额度只刷新对应
列表，不覆盖尚未保存的默认模型。域额度展示实例每日／每月上限，空值表示不额外限制。
用户与源题配额使用分页成员和题目选择，展示用户名与来源题号；引用题仍按使用域计量。
旧 Provider／用量页面固定进入 main 的 LLM 管理，实例 global
额度管理保留平台入口。

## 邀请注册

邀请链接使用 `/join#invitation=...` 或 `/register#invitation=...`，令牌留在 URL
fragment 中，以 POST 请求体向认证入口预览，不进入请求路径或 Referer。
预览只返回目标空间、受邀邮箱、到期时间和能否注册，不枚举账号。

已有账号可在邀请页登录及接受，支持两步验证码。其他登录方式可在新标签页完成，
回到邀请页时重新验证账号；初始密码更新使用独立页面，不改写已有账号凭据。
受邀注册固定邮箱，后端事务只加入目标域，管理员开户政策和签发者撤权仍生效。

登录回跳只接受经 `safeAuthRedirect()` 检查的本站路径。私有实例登录后只有一个
可用域时直接进入该域；两个以上域显示选择入口。邀请令牌不进入登录回跳查询参数。

## 配置与冲突

平台管理员通过 `/admin/instance`
管理实例访问、注册、默认空间、创建方式、创建数量、
邀请注册、模块许可、新空间默认额度、各域资源上限及 LLM 日／月上限。
专用表单复用既有系统设置 API和原时间戳前置条件，不要求手写 JSON。
每次保存只更新对应配置的保存依据，其他未保存表单不重置；冲突保留选择，显式重新读取才替换。
平台治理目录可分页查找未公开发现的私有域和暂停域，管理链接与状态确认明确显示目标
slug。
创建申请按状态分页审核，批准后由申请人成为负责人；已处理冲突保留当前申请供重新读取。

配置、配额和模板写入携带 `If-Match`。保存冲突保留未保存内容及原编辑 revision，
不能自动将旧修改绑定到新版配置。模板必须先预览差异再显式确认应用。
配额保存不清除基本设置草稿；基本设置继续使用原 revision，若需刷新，由用户
明确重新读取。域和账号变化后不复用其他空间的管理表单或邀请。

基础配额页面展示成员、题库条目、存储字节和每分钟正式提交额度，并列本域配置、实例上限及
当前有效额度。成员、题库和存储已使用／预约量由授权接口返回，提交频率不混用持久计数。
域管理员只能降低有效额度，提高额度需要平台治理权限。额度执行链仍需完整故障及旅程验收；
不能根据可编辑表单推断所有额度已实际生效。LLM 额度在本域独立管理页配置。
归档和暂停状态由服务端政策决定，不隐藏失败响应。

布局导航和概览快捷入口已串联域题库、比赛、本人提交、已启用教学模块及具有管理能力的
LLM／成员／设置页面。所有链接保留当前使用域；导航代码完成仍不能替代接口完整隔离及协调开放。

## 教学准备页面

`/d/:slug/classrooms`、班级详情及 `/d/:slug/assignments/:assignmentId`
已接入教学准备接口，未加入公开导航，等待完整域隔离后协调开放。
班级列表可创建班级，班级详情按授权列出作业。作业页展示本人进度或教师矩阵，
支持按时／补做、当前／历史学生、用户名、题目、状态、正式判定及 CSV。
原提交侧栏提供代码／学生 ZIP
文本、哈希与行范围批注；反馈和求助使用独立教学能力。

班级详情及成员行提供学生训练入口，目录区分当前与历史学生。训练页读取全部获授权同域
提交，而不只列作业来源提交；进行中比赛记录服从后端保密过滤。学情和提交读取能力独立，
只有学情能力不会请求原代码；只有提交能力不请求学情任务。提交详情复用教学文本／产物
预览与原提交批注，另可进入本班作业的学情或反馈。缺少正式分数不展示零分或未通过，
客观题只显示学生原回答，不提供标准答案、解析或逐題正确性。
学生原产物通过带域与班级的授权下载入口获取；在线文本预览与完整 ZIP
下载分别授权， 页面不会提供可绕过撤权的对象存储地址。

班级详情已接入成员、单人邮箱邀请、助教固定能力、设置、交接与归档。
作业草稿支持本域题库与已引用题单、部分学生、精准最低分和截止配置，先保存再预览发布。
发布、定时发布、延长截止、提前结束、归档与手动补题复制复用后端事务。 修改携带原
revision，冲突保留输入，显式重新读取才替换编辑草稿。

班级成员页支持 CSV 上传／粘贴、逐行预览、执行及首次邀请链接下载，最多 500 条。
同域成员使用专用申请链接，管理者分页批准或拒绝；申请页面不开放同学数据。
重试返回已有结果，不恢复邀请令牌；需要新链接时显式重签并重新预览，旧链接失效。

域内通知目录只显示类型和时间，点击重新授权后定位到作业、求助或单条反馈。
作业变化历史分页展示来源题号、版本号、策略、操作者和理由，不恢复已撤销题面。
教学通知订阅带域 SSE，初始同步或通知事件都只重新读取授权
REST，不根据载荷展示正文、成绩 或未读数量。断线每 15 秒补读、30 秒重试
SSE；域或登录账号变化会关闭旧连接和重放依据。
失去当前成员关系或卸载通知页后停止订阅及轮询。模块停用仍可读取获授权历史通知。

`/d/:slug/teaching` 和 `/d/:slug/my-learning`
通过服务端聚合读取获授权任务和求助定位。 教师统计为 null
时不转换成零，更新中的个人进度不展示旧达标数。每页 20 项，
当前页可筛选进行中或需要跟进；页面不逐个遍历班级请求矩阵。

矩阵可为当前页未达标学生快速预选独立补题草稿，跳过评测中、更新中、失效题和历史学生。
明确显示当前页及所选学生接收全部所选题的范围，教师预览后发布。批注作者可修改和撤回原批注，
写入携带服务器 revision。

作业矩阵的选定学生侧栏提供训练前后记录比较，学生本人也可在作业页使用。
先填写两个按顺序且不重叠的时间窗，再显式读取；页面不为每个单元格发比较请求。
时间按浏览器本地时区填写、转换为带时区请求，统计半开区间内受理的同域任务题目提交。
比较展示当前有效策略、正式通过与达标的独立计数、候选／排队／版本不匹配及来源依据。
没有正式分数时不显示零分，没有两窗分数时不计算变化；高分也不代替权威通过判定。
这种比较解释训练记录，不改原作业成绩，不将变化直接作为能力评价。

全班及比赛来源补题、客观题历史、成绩变化解释和通知已有相应客户端契约。
教学邮件、真实完整旅程与窄屏视觉仍需整合验收，不能据自动测试签收完整教学产品。

## 验证

同一主机同时运行多个独立套件时，Cookie 不区分端口。分别设置
`NUXT_PUBLIC_AUTH_COOKIE_PREFIX`（例如 `noj-main` 与 `noj-restore`），重启 UI
后各自登录，避免另一套件的登录或注销覆盖当前身份。默认单套部署仍用 `noj`；
改变前缀会要求重新登录，不迁移已有令牌。此配置与当前 Domain 无关，域授权始终来自 URL。

```sh
deno task test
deno task test:components
deno task check:types
deno task check:types:nuxt
deno task build
```

Vue 新页面另用 `deno fmt --unstable-component` 格式化。组件测试固定线程池，
避免本地 Deno 下默认 fork 池全部断言通过后以 BrokenPipe 退出。
域来源、身份变化、缓存、确认期间切换、冲突草稿及模板预览有对应测试。
构建和组件测试不能证明真实交互、窄屏布局或完整 Public / Private / Mixed
旅程；这些验收仍记录在
[升级任务清单](../../dev-docs/superpowers/plans/2026-10-12-workspace-upgrade-tasks.md)。
