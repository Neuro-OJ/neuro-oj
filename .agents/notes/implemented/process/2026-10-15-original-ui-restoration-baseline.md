# Agent Note: 固定原版界面恢复的设计依据和实施边界

Status: implemented

## Problem

域升级后的页面虽然完成了功能修复，但布局和操作习惯偏离原版 NOJ。用户确认恢复
旧界面，并将域运营、域设置和独立做题流程合并实施，需要持久化准确的依据。

## Decision

PRODUCT 记录已确认产品事实，DESIGN 引用已有品牌规范并固定 cc05af79 的视觉依据；
实施清单以 4e710458 为功能基线逐项签收。首页配置内容而不配置模块，实例运营内容
优先于本域，签到及账号关系属于实例。默认域从自己的域设置管理内容。

代码题回到阅读详情后进入独立做题工作区的流程；出题草稿编辑保持独立。用户明确
取消未上线模型的历史转换预案，D01/D02 关闭，D03 按实例账号层确认。

## Alternatives considered

- 保留当前首页和题库，只调整配色：不满足恢复旧版结构和操作的要求。
- 重新选择视觉世界：用户已指定原版 NOJ，现有组件与品牌是设计依据。
- 先将设计与任务写成已交付功能：会掩盖未完成范围，清单仅按实际验证勾选。

## Consequences

后续实现可以沿用同一产品事实和验收范围，避免重复询问与偏离目标。本记录只说明
设计文档和执行清单已落地，业务交付及最终门禁以清单和验收记录为准。
