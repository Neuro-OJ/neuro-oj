# Agent Note: 搜索索引使用来源域数字题号

Status: implemented

## Problem

题库 API 已取消 P/U 分类，搜索索引的题目、题解和提交构造器仍读取旧 type
列并拼接前缀。继续保留这些读取会阻碍后续 Schema
收缩，也使搜索契约与新题号不一致。

## Decision

索引正文使用来源域 slug 和数字编号，例如
main:1001。题目元数据保留数字展示编号，增加来源域与完整引用，移除旧分类字段。题解和提交关联题目时同样查询来源域，不从创建者身份推导题库类别。

## Alternatives considered

不在索引中保留 P/U
兼容副本。旧链接的定位仍由默认域兼容入口处理，索引权限继续使用当前域与源资源授权查询。

## Consequences

search 标准模块测试在 PGlite 和隔离 PostgreSQL 均为 35 项通过、1
项环境专用忽略；题目索引回归验证数字、完整引用及旧分类字段缺失。该改动不代替最终索引重建及整个私有域查询验收。
