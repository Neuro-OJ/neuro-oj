# Agent Note: 原版界面恢复的浏览器验收契约

Status: implemented

## Problem

旧浏览器用例直接在题目详情寻找代码编辑器，无法覆盖已确认的阅读到独立工作区
流程；域运营内容需要验证实际管理控件，而不仅是服务层测试。

## Decision

代码和界面题用例从阅读详情点击主操作，进入使用域内的 solve 工作区，再通过
真实提交、Judge 和详情页核对结果。补齐代码历史面板的“查看评测”入口。

新增独立域运营旅程，实际从用户菜单进入域设置，通过共享编辑抽屉发布公告和
轮播，核对首页展示、实例优先、横幅来源、错误域访问和窄屏导航。

该用例与现有浏览器套件采用同一 NOJ_RUN_BROWSER_E2E 环境守卫，因为默认 API
测试环境没有前端与 Chromium；在标准 browser 任务及 CI 浏览器 job 中必须实际
执行。本次新增一处环境条件 ignore，重新生成静默跳过报告与基线，未增加运行中
提前返回、捕获忽略失败或已启用 browser 环境下的跳过。

## Alternatives considered

- 直接导航 solve 后提交：遗漏阅读入口可用性，主流程保留真实点击。
- 在普通无浏览器 API job 强行启动浏览器：不符合已有分层，沿用明确浏览器 job。
- 修改产品分数格式迎合测试：保留原版格式，断言采用实际的百分制小数显示。

## Consequences

标准旅程能发现页面入口断链；资源准备仍使用 API，发布和作答使用真实 Web。
局部用例通过不等同最终套件或 CI 通过，全部验收记录单独保留。

集中截图检查发现默认域因禁止归档、暂停而出现空状态卡片，改为仅在可用域显示
状态操作区域；不增加额外状态机或回退路径。

运营旅程另通过真实上传和字节核对验证私有域轮播图片：本域授权读取成功，游客、
其他域与实例图片入口均返回 404。题面标题和来源题号分别断言，避免把旧标题组合
当作产品契约。受影响 Vue 文件统一通过组件格式化，不扩展到未改动页面。
