# Agent Note: 浏览器搜索与评测使用独立公开题夹具

Status: implemented

## Problem

搜索与普通做题浏览器测试共用默认域种子题 1001。其他 E2E 创建进行中比赛后，
该题按合法保密规则从匿名搜索隐藏，普通练习入口返回 404，导致重复使用同一隔离栈
时的浏览器旅程失败。管理端浏览器旅程发布重大法律政策版本后，登录用户也可能需要
先完成政策更新同意。

## Decision

统一搜索与做题测试分别通过真实 API 注册题目维护账号、接受 main 域邀请并取得
域内编辑者角色。编辑者导入格式 2 的独立题包，再根据草稿 revision 显式发布，
使用自动分配题号；不修改种子题、比赛或 core 的保密规则。

搜索夹具等待正常持久事件使新题进入真实搜索索引，再通过浏览器验证命令面板、
分组、Tab 与 URL 同步，检查独立标题并点击其默认域题目入口。
做题夹具包含实际双容器 evaluator，通过 SolutionRunner 调用学生的加法实现。
浏览器仍从账号、域、源题和版本对应的编辑器草稿恢复代码，点击提交和查看评测，
读取实际 Judge 回写的 10 分正确结果与错误答案结果。

登录旅程通过浏览器会话读取当前法律状态。存在待同意的重大政策版本时，等待真实
政策更新弹窗并点击同意，等待弹窗关闭；注册旅程继续勾选服务条款和隐私政策。
没有绕过同意端点、删除法律政策或关闭法律模块。

## Alternatives considered

- 删除进行中比赛或放宽匿名搜索、普通做题权限：会改变已确认产品规则，改为独立题。
- 固定改用另一个种子题号：仍会被后续比赛复用，使用每轮实际创建的题目。
- 直接写搜索索引或数据库评测成绩：会跳过正常事件与 Judge 链路，保留真实执行。
- 登录时直接调用 API 写法律同意：无法验证用户流程，使用真实弹窗按钮。

## Consequences

两份测试通过格式与 lint 检查，标准 `deno task test:browser --no-run`
完成全部浏览器目录类型检查。2026-10-13 在当前协调栈启用浏览器门禁，运行标准
`deno task test:browser` 得到 15 passed（6 steps）、0 failed，耗时 57 秒。
独立搜索三项、实际正确与错误代码评测，以及同批教学浏览器六个步骤均完成真实执行。
结果属于本地完整浏览器门禁，不表示远端 CI 或性能验收已经完成。
修改仅涉及这两份浏览器测试与本记录，没有引入新的测试服务或生产权限分支。
