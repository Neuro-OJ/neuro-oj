# Agent Note: Public 与 Mixed 工作空间真实浏览器旅程

Status: implemented

## Problem

已有浏览器门禁证明注册、代码评测与私有教学，但尚未完成 Public 题单、社区、
比赛，以及两学校引用同一公开题的 Web 隔离。普通成员社区发布受未结束公开赛
静默规则限制，复用旧验收库会被遗留比赛阻断，不能通过删除比赛或授予审核员
权限把它算作普通成员验收。

## Decision

新增独立 `workspace-public-mixed-journeys.test.ts`，在主代理准备的新隔离栈中
执行八段旅程。开始时读取实例和 main 政策，核对公开访问、活动状态和社区模块。
账号、角色、不可变题目、题单、板块、班级和独立 Provider 为 API 前置夹具；
练习、发帖、互动、报名、交卷、发布正式成绩及空间切换均通过真实 Chromium 页面。

- Public 普通成员从旧题单入口进入 main，搜索公开题单，点击当前域作答并正式
  交卷。另一普通成员读取新讨论、评论和点赞，不授予发布者审核员角色。
- 两成员通过 Web 报名 Kaggle 客观题比赛，各一次正式交卷得到实际 100／0 分，
  赛时本人榜不显示另一选手。比赛在 45 秒真实窗口后自然结束；仅具有 main
  域管理角色的普通账号在 Web 发布正式成绩，参赛者读取两人的授权正式榜。 不通过
  SQL 或修改结束时间制造赛后状态，也不伪造评测成绩。
- 同一账号在学校 A 为班级学生，在学校 B 为域负责人及班级教练；工作空间菜单
  实际切换后，创建作业和教学导航按所属域能力显示。
- 两学校引用同一个已发布公开题，页面显示 `main:number`。同账号双标签页在 学校
  A／B 分别交卷得到 0／100 分，捕获的请求仍使用各学校路径。学校历史和 main
  历史不串记录；错域 ID、其他学校成员及同域另一学生的读取均被拒绝。
- 两学校分别在 Web 发布独立讨论，学校 B 学生能读取 B 内容，不能请求 A 内容。
  错误域路径返回 404，学校列表及公共 main 社区不显示另一域的私有帖子。
- 两学校独立的 Provider／模型在管理页面读取正确值，刷新用量请求保留学校域。
  同一账号切回学校 A 学生身份后没有 LLM 管理视图，Provider 请求返回 403。

测试临时通过既有设置 API 准备六项正常社区政策：启用讨论、评论、点赞，关闭
只读和新用户预审。写入使用当前 updated_at，finally 恢复原有效值并 GET
逐项核对。原验收库和比赛由主代理保留在原数据库及 Redis DB，不更改静默规则。

## Alternatives considered

- 让 main 发布者成为审核员绕过比赛静默：不能证明普通成员流程，使用新隔离库。
- 在测试中 API 发布帖子、交卷和正式榜：遗漏页面操作，API 仅准备前置资源。
- 通过修改数据库时间立即结束比赛：跳过真实受理窗口，等待自然结束。
- 两学校分别复制题目：不能证明共享来源与使用域分离，两处绑定同一源题。
- 重复大量 LLM 评测：已有真实跨模块 Provider／模型／持久计量门禁，本文件
  聚焦配置和用量页面的域归属，不向用量表添加假记录。

## Consequences

2026-10-13 在 `noj_upgrade_acceptance_e2e_20261013`、Redis DB 2 的新协调栈，
通过标准 `deno task test:browser --filter=public-mixed` 获得 **1 passed（8
steps）、0 failed、16 filtered out，63 秒**。 日志为
`/tmp/noj-client-public-mixed-browser-third.log`。新增文件通过浏览器目录
类型检查、格式和 lint；Agent Note 格式通过。

本文件没有单独执行 Public 注册或代码 Judge，既有浏览器门禁负责这些流程。
负向授权断言使用真实浏览器 Cookie 请求，同时检查对应 Web 列表与管理入口；
没有把这些请求说成错误页渲染验收。本文件的学校用量为空，只证明域内配置与
用量读取页面；实际 LLM 调用、费用和额度隔离由另外的真实 Gateway E2E 证明。
本批没有重跑其余 16 项浏览器测试，也不代表远端 CI、亮暗主题全部页面或 IDE
扩展宿主验收完成。
