# Agent Note: 执行归属收缩后的查询与管理夹具

Status: implemented

## Problem

执行记录的使用域与题库绑定收缩后，查询、比赛和账号测试中的手写提交不能再省略这两项归属。
旧相似度测试还以 `as never` 插入无域数组，绕过类型检查却触发数据库 NOT NULL。
此前无绑定的公开统计样本依赖历史空关联路径；建立真实绑定后，未发布源题应被公开查询排除。

## Decision

直接写入的单域题目提交复用已有测试工具，从实际源题明确取得域与 owned 绑定。
私域夹具保留其实际域，不注入全局 main 默认值。 教学跨域历史记录保存对应使用域
shared 绑定，同题同源的其他域提交仍不授予本班教师读取资格。
任务及有效任务条目保存可信父域和真实题库绑定，已有状态、幂等和权限断言不放宽。

公开统计和个人主页正向样本显式建立发布基线，保留历史提交的 unknown-version
语义， 不改写原分数或伪造已有评测版本。 相似度夹具改用真实执行上下文和
`submissions.$inferInsert`，同题、跨题及噪声行都接受正常类型检查。
清理先释放本场景的提交、题库绑定，以及真实比赛变更产生的教学
outbox，再移除源题。

公共主页撤除场景改为真实 Domain
访问政策由公开变为成员入口，不再把已有提交搬到另一域。
查询仍须立即隐藏原公开活动，同时保留提交创建后不可修改使用域的规则。

## Alternatives considered

- 在生产写入或数据库默认值中自动补 main：不能表达实际使用域，不采用。
- 保留类型断言并放松数据库约束：隐藏错误数据，无法验证收缩目标。
- 把公开统计期望降低为零：把未发布夹具缺失当作正确业务结果，改为补齐发布依据。
- 更改所有未知版本历史记录为已知版本：改变原测试语义，保留原提交事实。

## Consequences

本批只修改非 catalog、objective、submission 模块的测试与本
Note，不修改生产服务、 Schema、DDL、迁移或共享测试工具。 相关模块通过标准
`deno task test:domain` 在 PostgreSQL 与 PGlite 执行回归， Redis 使用独立 6390
测试服务，PostgreSQL 使用隔离 TEST_SCHEMA，不重启真实 E2E runtime。
