# Agent Note: 域 LLM 与既有跨模块 E2E 契约升级

Status: implemented

## Problem

五份跨模块测试仍使用 P/U 分类、v1 题包和平台模型设置，无法验收当前域执行契约。
部分双容器夹具没有实际支持包，存储故障测试在发布前读取空的题目投影，清理步骤则试图物理删除不可变版本。

## Decision

LLM 测试以一个公开源域和两所私有学校建立真实链路。两校负责人是普通账号，
分别配置带资源 revision 的 Provider
与域默认模型；同一个学生引用同一不可变源版本并提交。 评测器通过 SDK
使用冻结的域模型，经 Judge、测试 Gateway 与 Mock 服务完成调用，
断言持久用量的域、源题、版本、Provider、模型、attempt 和实际 8 tokens。 跨域
Provider 读取／改写／默认选择返回
404；无域配置在创建提交前拒绝，不回退源域密钥。
重测使用显式域任务并等待任务完成，再验证新
attempt、当前域新模型与原用量保留；另一学校继续使用自己的模型。 停用 Provider
阻止新提交，历史用量与另一学校 Provider 仍保留。

其余既有链路使用 v2 无分类题包及显式发布。默认域兼容 API
继续作为原调用路径回归， 双容器测试改为导入真实支持包，并等待实际满分结果；联网
capability 保留真实 TCP 出网与函数调用。 RBAC 拒绝用例区分普通域成员与已授权
editor，后者仍受实例敏感评测字段约束。
存储故障先发布并读取已发布投影，再删除本次夹具文件，验证下载故障、提交预检零记录与版本删除
409 保护。 草稿类别转换核对当前稳定错误
`400 CONTENT_KIND_IMMUTABLE`，不借其他卷面错误代替题型锁断言。

## Alternatives considered

- 继续使用平台管理员和默认域模型：会绕过域角色与预算归属，改为两名普通域负责人。
- 删除旧 U 题拒绝测试：替换成无本域配置与跨域 Provider
  拒绝，保留实际有效的边界覆盖。
- 重测后只读取 finished：可能读到原结果，先等待持久任务终态并核对新尝试用量。
- 发布后删除题目清理：违反不可变版本保护，隔离测试数据保留历史并验证拒绝删除。
- 将导入响应的空存储投影视为存储丢失：先显式发布，再按真实文件依据注入故障。

## Consequences

标准 `deno task test:domain cross-domain`
可过滤这五份目标用例，相关真实链路在当前完整隔离测试栈验证。 本批未修改共享
helper、业务实现、Schema 或运行时配置。 Mock
调用证明协调服务链路与域模型选择，仍不代表真实上游账单或所有限额故障组合的验收。
