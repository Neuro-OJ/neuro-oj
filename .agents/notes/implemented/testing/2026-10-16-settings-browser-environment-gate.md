# Agent Note: 设置浏览器旅程的环境门禁

Status: implemented

## Problem

新增设置浏览器旅程使用现有 `NOJ_RUN_BROWSER_E2E` 环境条件，静默跳过扫描因此新增
一处命中。没有浏览器与 UI 服务的 API 测试环境不能执行这份 Playwright 旅程。

## Decision

保留显式环境条件并同步生成清单和基线，记录新增原因，不改写成扫描器无法识别的
隐藏条件。E2E Browser 工作流通过现有 composite action 启用浏览器环境并执行该
目录，新增旅程在这里真正运行；本地也使用生产构建和隔离数据库实际执行。

## Alternatives considered

没有删除测试、取消断言或将浏览器用例注册到缺少 UI 的 API job，也没有通过封装
环境判断来绕过扫描器。已有测试的执行条件和基线不变。

## Consequences

命中数由 1102 增加到 1103，仅新增这一处浏览器环境条件。真实旅程覆盖设置导航、
503 草稿保留、键盘、短码查询、空用户名刷新及队列范围切换；不把环境跳过计作
验收通过。完整浏览器 CI 仍须实际执行该测试。
