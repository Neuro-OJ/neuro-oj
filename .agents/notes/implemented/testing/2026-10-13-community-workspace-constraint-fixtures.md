# Agent Note: 社区域非空与题解绑定约束夹具

Status: implemented

## Problem

板块、帖子、评论和域禁言的归属已收紧非空，题解必须有使用域题库绑定。
旧账号主页、搜索和社区分页夹具省略了这些字段，不能在新约束下继续验证
原有隐私、赛期保密与排序行为。

## Decision

仅修改八个测试文件。默认域板块、动态及搜索夹具显式使用其真实 main 域；
搜索门控的 raw SQL 评论使用父帖的实际域。私校题解复用已建立的学校 owned
绑定，默认域题解从真实源题和 owned 绑定取得执行归属。没有在全局插入器
自动填值，也没有创建跨域引用或从源域推断目标域。

0080 历史回填测试只模拟 updated_at 列不存在，其他当前约束仍保留；为其
代表性板块、讨论、举报和禁言填写明确的默认域，不额外撤销域非空约束。
性能夹具同样显式填写默认域，未在本批执行十万帖子性能测试。

生产写入、Schema、DDL、0139 迁移和 mixed 数据约束由协调 agent 处理。
本批没有把账号关注、全站封禁或私信举报移入 Domain，也没有扩展关联题目
讨论的产品契约。

## Alternatives considered

- 测试插入器补默认域：隐藏实际遗漏，也可能把私校资源错误归入 main。
- 题解任取源题绑定：无法证明帖子使用域与绑定一致。
- 为旧测试放松约束：失去本次收缩对真实业务数据的保护。
- 0080 模拟时撤销所有新约束：与其只验证 updated_at 回填的目的无关。

## Consequences

标准 deno task test:domain 两库回归通过：community PostgreSQL 与 PGlite 均
85/0；identity PostgreSQL 339/0、PGlite 332/0（7 个既有忽略）；search 两库均
35/0（1 个既有忽略）。每轮迁移与种子 8/0，没有新增忽略。 使用独立 PostgreSQL
schema 与 Redis 6390，不改变真实 E2E 或开发运行栈。

完整类型检查及本批八文件格式、lint 通过。0080 和性能文件的格式、类型
已检查，shared 回归由协调 agent 执行；不将静态检查写成实际性能验收。
