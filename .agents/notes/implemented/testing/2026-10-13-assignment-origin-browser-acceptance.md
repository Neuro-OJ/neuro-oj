# Agent Note: 浏览器验证作业来源与历史读取

Status: implemented

## Problem

提交来源的组件测试不能证明作业页面网址、普通交卷请求和历史读取共同保存实际
入口。浏览器旅程还需处理前序治理测试更新条款后出现的真实确认弹窗。

## Decision

教学旅程在学生点击继续练习后等待题目路由，检查网址中的作业和条目 ID；实际
交卷后核对响应来源，再以该学生身份读取已保存的客观题历史并核对同一来源。
不直接写入成绩或来源字段。

登录后读取浏览器 Cookie 授权的本人条款状态，需确认时通过页面点击同意，再
进行工作空间操作。保留生产条款政策及授权约束，不禁用弹窗。

## Alternatives considered

- 只查看前端请求参数：不能证明受理和历史记录真正保存来源。
- 固定等待导航或直接修改历史：会隐藏路由与服务端问题，使用实际路由等待和读取。
- 删除条款弹窗：无须改变产品行为，测试完成真实前置操作。

## Consequences

更新后的 UI 与 core 在隔离 E2E 库运行标准浏览器入口的教学过滤，1 项测试、 6
个依赖步骤实际通过（17 秒）。包含建域、建班、邀请、发布、作答、来源历史、
反馈、求助、补题、390px 矩阵及两个私有域标签页。此次来源断言采用客观题；
代码、产物及自测已有双数据库 HTTP 回归，不将本场景计为这些题型的浏览器验收。
