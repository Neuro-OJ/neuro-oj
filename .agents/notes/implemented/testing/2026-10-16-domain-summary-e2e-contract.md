# Agent Note: 教学端到端测试采用授权提交摘要契约

Status: implemented

## Problem

完整跨域 E2E 中两条旧断言仍要求同域同学的提交详情返回 404，与本轮已批准的
“可以读取授权题目的提交摘要，源码和答案另行授权”规则冲突。

## Decision

普通和客观题详情改为断言摘要返回 200，并明确核对实际提交者、源码和答案能力 为
false、原代码和答案缺失、他人作业来源不返回。客观题也不返回题目答案结构。
矩阵、私有反馈、Provider 及错误域路径的拒绝断言保留。

## Alternatives considered

没有恢复旧授权分支，也没有删除隐私断言或跳过全题型教学旅程。仅修改与产品
决定不一致的预期，继续在真实服务与 Judge 环境执行五题型流程。

## Consequences

本地 API 教学和设置旅程三项通过。40 人五题型教学剩余步骤继续由完整跨域 CI
执行，不用本地没有 Judge 的环境替代它的验收证据。
