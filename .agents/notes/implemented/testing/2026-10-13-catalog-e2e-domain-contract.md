# Agent Note: 题库端到端夹具改用明确工作空间与发布契约

Status: implemented

## Problem

旧 E2E 使用 P/U 分类查询和格式 1 U
题包，管理员创建题目后期待物理删除已发布版本。普通成员也被当成具有题单创作权限。这些输入已经不符合批准的新模型，导致当前测试栈无法执行后续评测与权限验证。

## Decision

样例定位只使用默认域数字题号；题包使用格式 2，不携带 P/U
分类。测试验证导入后共享草稿的默认运行命令，并在显式发布后真实提交评测，以实际运行证明支持包可用。

题单作者显式获得 main
的资源编辑者角色。用于匿名题面和标签验证的题目先发布有效版本；客观题标签夹具添加合法小题。已发布或具有历史提交的源题物理删除必须返回
409，改用停止公开验证匿名题面和题单内容不再可读；历史版本仍保留，不把拒绝删除误判为故障。

## Alternatives considered

- 在兼容 API 恢复 P/U 参数：重新增加批准计划已取消的模型。
- 为普通成员放宽创作权限：会把测试缺失的角色授权变成产品权限缺陷。
- 级联删除版本和提交以清理夹具：破坏已批准的历史保留规则。

## Consequences

使用标准 `deno task test:domain catalog` 对当前 core、Judge 和独立 E2E
数据库运行，32 项通过、0
失败，包含题包上传、显式发布、真实评测、标签通过门控、题单进度和历史删除保护。7
个修改测试文件 lint 和格式检查通过。

兼容入口仍固定 main。本批未把其他域授权或全部产品浏览器验收归入该结果。
