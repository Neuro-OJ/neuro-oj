# Agent Note: 私有域教学与跨域标签页真实浏览器旅程

Status: implemented

## Problem

原浏览器门禁覆盖 Public OJ
的注册、登录与代码评测，尚未证明教师能通过新页面完成教学任务。 API
断言无法发现表单水合、邀请入口、反馈展示、补题预览或移动矩阵的交互问题。

## Decision

新增独立 `workspace-teaching-journeys.test.ts`，通过标准
`deno task test:browser` 和名称过滤运行。 API
只准备普通教师与学生账号、域角色和不可变客观题版本；核心教学动作使用真实
Chromium 页面。 管理员在 Web 创建 Education 域，普通教师建班并生成邀请，学生通过
Web 登录接受邀请。
教师选题、预览名单、发布，学生正式交卷后在双方页面验证进度；随后完成反馈、求助回复、处理与补题发布。
同一学生同时打开两个私有域题目，分别保存答案和交卷，验证请求路径及 100 分／0
分结果不会串域。 390px
视口使用学生卡片打开单元详情；真实跨域目录导航后第二个标签页仍保持自己的 URL
上下文。 表单操作等待 Vue 水合完成，避免测试在 SSR DOM
上填写后被客户端初始化覆盖。 步骤失败停止后续依赖动作，保留各浏览器会话的 trace
与截图；不修改原浏览器套件。

## Alternatives considered

- 仅通过 API
  创建作业和读取矩阵：不能证明教师实际操作，采用页面写操作并核对其真实响应。
- 复用平台管理员身份完成所有教学：会掩盖角色问题，班级与作业流程使用普通
  educator 账号。
- 为所有题型重建完整浏览器评测：本文件采用即时客观题验证教学闭环，原 Public OJ
  门禁继续负责真实代码评测。
- 通过固定等待时间同步页面：使用 Vue 挂载标记，并由 Playwright
  等待实际控件与响应。

## Consequences

新增浏览器门禁覆盖六段真实旅程，不把夹具 API 操作计作 Web 功能验收。
本地使用当前 core、gateway、Judge 与冻结生产 UI，隔离数据库为
`noj_upgrade_e2e_20261013`。 标准过滤运行通过一项主测试、六个步骤；既有 14
项浏览器回归由主代理另行运行。 此文件没有证明 40 人班级、全部题型教学性能或 LLM
预算隔离，这些仍属于其他验收任务。
