# Agent Note: 全量回归补齐旧迁移执行夹具

Status: implemented

## Problem

0137 的完整 core 回归通过 2246 项，但 PostgreSQL 专用的 0109 旧迁移测试仍 直接用
SQL 插入无域提交，触发现行非空约束。标准共享 PGlite 不执行该项，
各业务模块回归无法发现它。全仓 lint 另发现分类收缩留下的未使用导入，格式
检查发现模块说明及题目类型测试未格式化。

## Decision

旧迁移测试显式取得真实域与题库绑定，再写其历史平台失败和正式判定夹具。
仍直接回放真实 0109 SQL，并保留正式判定及平台失败的原断言，不跳过测试或
放宽数据库约束。删除未使用导入并格式化，模块说明同步去分类、域内题号与
显式域题库授权规则。

## Alternatives considered

- 将历史测试一律降级为旧 Schema：该测试验证旧回填语句对当前记录的处理，
  补齐当前执行归属即可，不需要修改其它数据库约束。
- 忽略 PostgreSQL 专用失败：会失去真实迁移语义的回归保护。

## Consequences

标准 PostgreSQL 共享入口 303 项通过、0 失败、6 项环境专用忽略；core 全仓 lint
通过，格式问题已收口。首次 0137 全量的单项失败保留为记录，最终全量
复跑单独记录；不将局部复验冒称完整 core 已通过。
