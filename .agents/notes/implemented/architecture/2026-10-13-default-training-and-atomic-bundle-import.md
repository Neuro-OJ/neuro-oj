# Agent Note: 默认域题单授权与原子整包导入

Status: implemented

## Problem

旧题单入口未限定 Domain，按创建者和管理员布尔值读取私有题单，列表、管理接口及
稳定 ID 可以取得其他域内容。题目列表还读取源题投影、拼接 P/U 题号，进度未过滤
提交所属域及比赛保密窗口。旧整包导入先创建题目再上传支持包，上传容量不足时会
留下空题目和草稿。

## Decision

- 无域题单 API 固定 main；公开、个人和管理列表在分页前限定域，UUID/public_id
  同样校验所属域。所有读写重新读取当前工作空间角色及进入政策，调用者传入的
  管理标志不授予权限。旧平台管理题单入口传真实 actor，并保留平台治理能力检查。
- 题单作者必须具有 main 的资源编辑能力；编辑者可公开自己的题单，置顶需要实际
  域内完整题单管理能力。公开题单不能加入成员范围题目。已有共享引用的源题单
  禁止物理删除，以保留历史引用。
- 题目列表通过 main 绑定逐题检查实时共享及作答版本，显示数字或来源限定题号，
  删除 P/U 字段。撤销后不返回题目内容，数量同步过滤；有效通过进度按 main
  提交、绑定和比赛公开窗口聚合。
- 旧整包入口复用显式 Domain 的创建/草稿导入门面。上传对象先完成预留及注册，
  新题目、初始草稿和绑定同事务建立，失败补偿对象。旧 HTTP 按题号更新必须携带
  If-Match；可信 CLI 保留显式按当前草稿更新。目标模式继续使用指定 revision，
  不因包内 number 改变身份。
- 新题型预检明确返回 409 CONTENT_KIND_IMMUTABLE，拒绝发生在上传前。重导入只
  改草稿；公开版本、模板和历史提交保持原依据，显式发布后才切换。
- 原始 SQL 测试夹具显式建立绑定、发布版本及角色，不在生产授权中增加历史兜底。
  workspace/backfill 的 U 数据迁移保护继续保留。

## Alternatives considered

- 保留全局题单查询或相信 isAdmin 参数：会绕过 Domain 的实时成员、进入和撤销
  政策，不能保留为兼容行为。
- 为旧导入另外增加失败删除空题目：需要重复维护编号、草稿、对象和配额回滚，
  优先复用已有域原子门面。
- 导入后即时覆盖公开模板：会使尚未发布的草稿改变学生当前作答依据，因此保留
  草稿与版本分离。

## Consequences

- 原先仅有平台普通账号权限的用户不能通过旧入口创建题单；需要 main 的资源
  编辑角色。其他域 ID 在兼容入口返回 404，旧管理员布尔值也不能绕过。
- 已撤销的引用题不出现在旧题单内容或计数中；既有提交及反馈依据由原历史接口
  保留。显式 Domain 题单 API 继续提供资源不可用状态及管理能力。
- 标准 catalog 回归覆盖 PGlite 和独立 PostgreSQL schema，包括 main 题单对共享
  版本策略、源题撤销、跨域成绩隔离及存储容量失败不留空记录。完整验证结果见
  同批冻结报告；测试库不使用本地开发数据。标准 catalog 的 PGlite 与 PostgreSQL
  均为 363 项通过、0 项失败；源码和全部 catalog 测试类型检查、格式、lint、模块
  边界、导出 JSDoc 及 Agent Note 门禁通过。
