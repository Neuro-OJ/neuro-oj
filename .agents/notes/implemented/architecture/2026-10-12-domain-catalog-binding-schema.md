# Agent Note: 源题归属与使用域题库配置的分离

Status: implemented

## Problem

现有源题及题单没有工作空间归属，题库有效版本策略直接写在源题上。
共享题需要让每个使用域独立管理有效策略，同时复用不可变版本与文件字节。
复制题目或只在 URL 增加域参数都不能提供稳定的历史依据和数据库约束。

## Decision

生成扩展迁移 0115：源题和题单先增加可空 domain_id；新建题库绑定、题单引用、
公开共享配置、定向目标及绑定沿革七张表。绑定在域内对源题唯一，版本外键 使用源题
ID 与版本 ID 的组合，沿革同时校验绑定和版本属于同一源题。
绑定和共享记录不级联删除源题，保护未来提交与教学记录的引用依据。

PGlite 的源题 / 题单基础 DDL 和工作空间题库 DDL 分模块装配，并进入缓存指纹。
生成 SQL 去掉固定 public 前缀，使隔离测试 schema 正确解析外键。 元数据 journal
和快照均由生成器维护。主 DDL 文件缩至 1164 行，移除规模例外。

## Alternatives considered

- 把题库策略继续放在源题：目标域策略会互相覆盖，不能满足域内独立成绩规则。
- 跨域复制版本和支持包：造成重复存储、撤销难以即时生效及内容来源不明。
- 一步添加非空归属：存量回填和默认域初始化顺序尚未完成，不能安全收缩。
- 定向授权用 JSON 域 ID：缺乏外键与去重约束，改用目标关联表。

## Consequences

当前交付是扩展数据结构，domain_id 仍可空，旧 P/U 字段和唯一键尚未移除。
必须完成默认域回填、所有写入路径切换后，再生成非空及新编号约束迁移。
新增约束使用独立 savepoint 验证真实 PostgreSQL 错误码，防止事务中止造成
后续违规断言假阳性。共享执行、即时撤销和教学变化事件仍由后续服务接入。
