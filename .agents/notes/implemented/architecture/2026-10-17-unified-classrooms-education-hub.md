# Agent Note: 班级研练中心统一架构与教练工作流重塑

Status: implemented

## Problem

此前教育与教学子系统存在三头怪割裂架构：工作区侧边栏同时挂载「班级 (`/classrooms`)」、「我的学习 (`/my-learning`)」和「教学工作台 (`/teaching`)」三个入口，三者内部相互外链并重复挂载 `TeachingDashboard`。教练无法确定在哪里批改作业，学生无法快速找到作业闭环，且各页面容器宽度不一（72rem 与全宽跳动）。同时，班级成员管理页垂直堆砌 5 大模块，批量审核入班申请需要 40 次单独点击。

## Decision

1. **统一顶层导航与入口**：侧边栏整合为单一「班级研练 (`classrooms`)」入口，移除重复的导航项。`/teaching` 与 `/my-learning` 保留独立路由并注入架构统一指引，统一宽度为 `72rem`。
2. **多视角自适应中枢 (`classrooms/index.vue`)**：根据用户角色（教练/管理 vs 学生）自动呈现对应主视角，支持 `?view=teaching`（带班中枢）、`?view=learning`（我的学习）、`?view=rooms`（班级大厅）动态切换，提供指标看板（进行中任务、需关注预警、待答复求助、管理班级数）与紧急待办提示。
3. **成员管理三段式 Tab 与一键批量审核**：重构 `members.vue` 为「班级花名册」、「入班申请」和「批量导入与邀请」三段式 Tab；`ClassroomJoinRequests.vue` 支持全选本页、批量批准所选与一键全部批准当前页，极大提升开班审核效率。
4. **单班主页学情诊断化 (`classrooms/[classroomId]/index.vue`)**：作业卡片由扁平文字升级为包含全班达标率概况、状态徽章、时间元信息与直达批改矩阵的操作单元。

## Alternatives considered

- **保持三入口现状，仅做页面内部视觉微调**：无法根治信息架构混乱和用户迷失问题，各入口之间互相跳转的割裂体验依旧存在，故放弃。
- **直接废除 `/teaching` 与 `/my-learning` 页面文件**：现有外部书签与自动化端到端测试仍依赖这些路由，直接删除会导致硬破坏；采用保留路由并注入整合指引是更平滑安全的方案。

## Consequences

- 侧边栏与教学主页逻辑清晰，无论教练还是学员均具备明确的"第一主场"。
- 40 人规模学员入班审核从数十次点击等待骤降至 1 次点击完成。
- 现有全部 Vitest 组件测试与 Deno 单元测试保持 100% 通过。
