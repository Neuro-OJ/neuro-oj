# Agent Note: 客户端工作空间上下文与资源定位

Status: implemented

## Problem

全局“当前域”或账号 Cookie 不能用于授权；资源缓存、来源题号和延迟确认操作
需要保持 URL 的使用域，两个标签页不能互相改变提交上下文。

## Decision

增加客户端空间 / 成员 / 邀请 / 配额契约和统一 URL、引用、缓存键工具。
布局提供一份上下文供页面注入，实际响应查看者与请求身份必须一致。
域和身份变化停止使用旧事实；背景刷新保留同域名称但暂停旧权限。
确认与请求结果使用原目标的生命周期检查，离开、切换或换账号后取消旧操作。
所有管理 API 显式传 slug，偏好只用于导航。安全认证回跳拒绝外部或混淆路径。

## Alternatives considered

- JWT 携带当前域：切换需要换凭据且角色撤销延迟，沿用统一身份。
- 每页请求上下文：可能触发重复请求和刷新挂载循环，由布局提供统一解析。
- 用来源域替换引用 URL：会改变使用 Provider 与提交归属，保留使用域。

## Consequences

工具和上下文测试覆盖缓存中的域 / 账号 / 版本、来源题号、邀请 fragment、
实际身份不匹配及确认期间切换 / 卸载。客户端事实不替代后端每次资源授权。
现有题目页面、编辑草稿、SSE 和 IDE 的全面接入属于后续阶段，当前契约不代表
这些链路已具备完整隔离。
