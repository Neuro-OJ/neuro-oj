# Agent Note: 默认题库取消 P/U 分类与权限分支

Status: implemented

## Problem

域题库已经采用稳定源题身份和域内数字编号，旧无域入口仍按 P/U
决定创建、编辑、支持包管理和题号定位。它既会拒绝正常的域编辑者，也会让题目创建者身份绕过当前域角色。旧统计还可能混入引用同一源题的学校提交，学校比赛会影响默认域的公开统计。

## Decision

- 移除创建、更新、列表与响应 DTO 的题库分类，明确拒绝旧 `type`
  输入。数字题号和旧 `P数字` 都只解析默认域 `main`；`U数字` 不再作为入口。稳定
  ID 在旧 HTTP 入口也必须属于默认域，客观题子入口同样先执行这一检查。
- 内部 `getProblem` 保留稳定 ID 的通用读取能力，供已经解析并授权的新 Domain
  执行链使用；外部授权由对应入口落实，不把内部源题读取强制转换成 `main`。
- 创建、源题编辑、删除、OI 作者工具与支持包管理依据当前源域角色。`userRole`
  字符串不能提供题库管理能力；敏感镜像、评测命令与网络仍使用实例安全权限。
- 本域源题展示范围与新的 owned state 门面保持一致，依据本人 `write_own` 或全域
  `write_any`；共享引用状态和成绩策略仍需要
  `problem:policy`。展示范围与绑定同事务修改，保存新
  revision、历史依据、审计及教学事件。普通读取不返回未发布题面，草稿历史仍允许获授权编辑者读取。
- 默认详情显示本域绑定的有效版本策略与 revision。通用作答版本 getter
  优先读取源域 owned
  binding，只有未绑定的迁移遗留记录使用旧全局字段；使用域的跨域引用仍由新域解析服务处理。
- 删除旧 U 审核、转 P
  批量入口。管理员旧题库列表继续明确返回默认域数据，不形成其他域的治理旁路。
- 统计和算法标签解锁候选复用带域、资源授权及比赛窗口的查询谓词；默认域统计不聚合学校提交。比赛暴露查询新增可选域参数，默认兼容口径为
  `main`，学校比赛不抑制默认域通过率。
- 默认域题包的两处支持包上传和 OI 草稿上传显式传入默认
  Domain，执行持久存储预留与结算。
- 测试夹具显式建立默认域和所需角色。系统账号的域管理员关系只在测试夹具创建；普通成员、编辑者和管理员按用例单独授权，生产创建函数不借域负责人身份兜底。

## Alternatives considered

- 保留 P/U 作为授权兼容层会继续造成新旧入口权限分歧，因此只保留默认域旧 P
  数字链接的解析兼容。
- 把所有稳定 ID
  都限定为默认域会破坏已经授权的新域执行链，因此限制放在旧入口解析层。
- 自动为缺少 Domain
  的读请求建域或授予旧作者权限会掩盖初始化及成员关系缺失，因此修正测试和可信初始化调用。
- 重写版本、评测与存储系统不属于这次收缩批次；复用现有不可变版本、查询裁剪、绑定策略和存储配额服务。

## Consequences

新增真实 HTTP 回归覆盖普通成员创建拒绝、编辑者草稿、权限撤销即时生效、数字/P
兼容、U 拒绝、旧分类输入拒绝及其他域稳定 ID
对题面、草稿、支持包和更新入口的拒绝。新增统计回归证明学校提交不进入默认统计，学校比赛不抑制默认域结果。已有版本、导入回滚、共享撤销、绑定外部事务回滚和存储历史引用回归继续保留。

包含存储接线、owned 展示范围授权与历史一致性修正的最终标准
`deno task test:domain catalog` 在 PGlite 和隔离 PostgreSQL `test_catalog_pu` 均
361 通过、0 失败。完整 catalog 源码及测试类型检查、相关 lint、格式、域边界、
导出 JSDoc 和 Agent Note 格式检查通过；绑定策略及历史依据服从外部事务回滚的用例
在两种数据库中均通过。

本批保留数据库迁移过渡列，最终 Schema 收缩由集成工作统一执行；没有修改
journal、锁文件或版本控制。旧题包创建编排仍先建身份再上传，存储失败时的身份原子性应由后续兼容入口桥接域整包导入解决，本记录不把该旧编排限制表述为已完成的完整迁移验收。
