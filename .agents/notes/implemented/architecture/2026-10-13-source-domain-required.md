# Agent Note: 源题与题单归属完成数据库收缩

Status: implemented

## Problem

扩展阶段允许存量题目和题单暂时没有 Domain。新入口已经显式写入归属，数据库仍接受
NULL，无法保证题号和资源权限始终具有明确工作空间。

## Decision

题目与题单的 `domain_id` 改为 NOT NULL，Drizzle Schema、PGlite DDL 和自动生成的
0135
迁移保持一致。迁移先回填历史归属、建立缺失的本域绑定及策略沿革，再收缩约束。已有绑定、管理员配置、资源计数不被覆盖。

只有存在未归属资源且系统 root 已存在的旧库才在迁移中建立 main
及基础成员；空库仍由正常初始化建立工作空间。迁移保留稳定题目 ID 和数字题号，main
编号计数继续从已有最大编号之后分配。生产列没有隐式默认域，测试直接插入资源也必须明确
Domain；标准测试初始化复用既有默认域初始化能力。

## Alternatives considered

- 永久允许 NULL：新写入遗漏仍能落库，权限和题号模型没有完成收缩。
- 给列增加默认 main：会把缺失上下文的新写入悄悄归入默认域。
- 重建开发库：不能证明既有题目及版本能够正常升级。

道题及旧数据仍保留。按用户已授权的备份后清理规则，仅清理该隔离副本的 U 题和 5
场旧比赛，再从原始 Schema 完整迁移到 0135 成功；3 道 P 题的 ID、1001–1003 题号和
22 个账号保持，生成 3 份本域绑定，下一编号为
1004。另一份已扩展的隔离恢复库也成功升级，已有 3
个题目版本保留。两表实际列均禁止 NULL。
