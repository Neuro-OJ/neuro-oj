# Agent Note: 单一域角色与全域教学授权

Status: implemented

## Problem

组合域角色与班级助教能力叠加，使教练职责和成员治理边界难以判断，历史任职也
可能成为重新获得教学权限的依据。

## Decision

普通域固定 owner/member，教学域增加 coach。负责人以 domains.owner_id 为准，
成员只持有一个角色。coach 共同管理本域所有教学与资源业务，成员邀请、任命、
治理设置、额度及 Provider 凭据仍只由 owner 管理。班级联系人仅为元数据。

迁移 0120 将旧非负责人角色降为 member，结束旧教练和助教任职并清空旧授权；
0121 增加单成员单角色约束。成员接口使用单值 role；班级入口拒绝角色与能力入参。
教学邀请和导入不能成为教练增加域成员的旁路。旧任职和联系人不参与授权。

## Alternatives considered

保留组合角色和逐班授权会继续产生两套教学权限来源。自动把旧教学人员提升为
coach 会把局部权限扩大到全域，因此迁移要求负责人明确重新任命。

## Consequences

新任教练立即覆盖本域全部班级，撤职立即失权，退出后重新入域不会恢复旧角色。
旧客户端必须切换到单值角色契约。角色、存量升级、邀请及教学读取分别有测试，
整体发布仍需要模块完整测试和实际页面验收。
