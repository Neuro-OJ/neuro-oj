# Agent Note: 社区工作空间数据库契约

Status: implemented

## Problem

全局板块标识及帖子、评论记录缺少使用域，无法约束两个学校的社区内容和治理归属。
社区通知还需要与业务写入共同保存可重放事件，防止提交前发布使接收者读不到记录。

## Decision

由 Drizzle 生成追加迁移 0130，板块改为域内 slug 唯一，增加 revision；帖子关联使用域题库绑定，
评论以复合外键保证回复和帖子属于同一域。治理及通知记录携带可空域，账号层面的关系保留独立范围。
旧社区内容回填默认域，题解回填对应绑定；扩展阶段可空列兼容旧写入，后续收缩须先切换所有入口。
调整生成 SQL 中唯一约束与外键的依赖顺序，保留生成的 journal 和快照。

PGlite 基表与约束扩展同步，并更新模板指纹。公开 catalog SQL 门面复用实时共享授权检查，
允许社区在分页和计数前排除撤销题解；比赛保密查询支持明确使用域，避免学校比赛影响其他域。
SSE 记录函数接受业务事务 executor，提交后扇出继续复用现有广播函数。

## Alternatives considered

没有复制每个域的题解源题，也没有让目标域缓存的公开标记代替当前授权。
没有新建只为社区服务的事件表，现有持久 SSE 日志支持业务事务写入。

## Consequences

Schema parity 验证 104 表、951 列一致，迁移安全检查通过；共享回归 292 项通过，
catalog 355 项通过。独立 PostgreSQL submission 回归已执行新增迁移，迁移没有清除既有资源。
本记录只签收共享契约，社区全部入口和浏览器隔离由社区实现批次另行验收。
