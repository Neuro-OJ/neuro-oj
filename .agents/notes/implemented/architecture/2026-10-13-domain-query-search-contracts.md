# Agent Note: 使用域查询与搜索共享契约

Status: implemented

## Problem

共享正式提交 SQL 读取面没有使用域，搜索索引也没有资源归属字段。
查询模块无法在统计、分页和命中数计算前区分私有学校记录与公共数据。

## Decision

统一代码及客观题提交读取面增加使用域和题库绑定列，两类记录继续保留原稳定身份。
搜索索引增加可空域外键及域／类型／更新时间索引，通过生成的追加迁移 0131 回填五类资源索引。
账号、私信及平台公告保留账号或实例范围，源题只保存一份索引，不为每个引用域复制内容。
PGlite 基表、约束和索引副本同步，查询权限仍以当前源记录和绑定授权为依据。

## Alternatives considered

没有将客户端上次使用域写入账号 JWT，也没有把索引中的旧公开标记视为当前权限。
没有通过复制公共源题索引解决跨域共享，目标域授权查询由 search 模块继续接入。

## Consequences

Schema parity 验证 104 表、952 列一致，迁移安全和快照链检查通过，共享标准回归 292 项通过。
本记录仅签收共享契约；搜索服务、公共主页统计和域榜单的完整隔离由查询实现批次继续验证。
