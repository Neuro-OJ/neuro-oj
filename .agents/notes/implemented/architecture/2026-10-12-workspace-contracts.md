# Agent Note: 产品工作空间的角色和配置契约

Status: implemented

## Problem

平台角色无法表达同一用户在不同工作空间中的身份；模板名称也不能作为访问边界。

## Decision

共享层定义稳定域身份、请求上下文和来源题号。workspace
业务域提供内置角色的域内权限、独立模板配置、配置差异和模块依赖校验；管理员角色不包含平台全权限。新增域接入标准
domain 测试、静态边界和 CI 触发检查。

## Alternatives considered

复用全站管理员身份会扩大权限；固定 Education
类型会把访问政策与教学功能绑在一起，因此采用域内角色及可修改配置。

## Consequences

当前交付公共契约和纯策略，并以角色隔离、配置独立性和非法输入测试验证。资源数据归属和
HTTP 授权接入不属于这份契约提交的已交付功能。
