# Agent Note: 域存储归属与上传容量预约

Status: implemented

## Problem

实例存储对象登记可以保护物理删除和历史引用，但缺少域计量归属及跨进程容量预留。引用公共题不能复制源题字节或计入目标域存储。

## Decision

追加 `domain_storage_objects`，以域与对象地址的复合主键保存实际字节归属；追加 `domain_storage_uploads`，保存预留容量、有效期、已知对象地址及结算或释放状态。对象地址仍引用实例统一存储登记，不复制物理内容。同域重复引用同一对象只保留一份归属。Drizzle 生成 0132 扩展迁移，同步 PGlite DDL 和重置表集合。

## Alternatives considered

直接从每份共享绑定累加支持包会重复计量。进程内预留不能防止多副本并发上传突破额度。仅在上传完成后检查容量不能阻止已经发生的物理写入。

## Consequences

迁移只新增表，不修改原对象或版本身份。迁移安全、快照链及 schema parity 通过，当前 106 表、964 列一致。域存储测试在 PostgreSQL 通过 40 项，其中真实独立连接验证最后容量只能成功一次；服务执行与上传入口将在后续独立提交保存，完整产物上传和恢复旅程尚待验收。
