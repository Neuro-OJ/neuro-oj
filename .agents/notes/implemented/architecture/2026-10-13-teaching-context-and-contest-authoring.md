# Agent Note: 教学事务复用授权上下文与参赛维护者内容隔离

Status: implemented

## Problem

补题创建已经在事务内锁定并授权班级，插入草稿却再次加载班级；每个作业条目又
通过普通题目解析重复加载相同账号与使用域身份。另一方面，题目维护权限被直接
作为普通题面返回完整内容的依据，参赛编辑者可以从普通题面、指定版本或编辑草稿
读取比赛答案。工作空间授权读取收窄后，教学写入口也需要明确验证对应模块开关，
不能将非法的 truthy JSON 值当作已启用。

## Decision

作业内部写入强制接收同事务加载的班级上下文，复制和两种补题复用已有授权。 catalog
提供 `resolveDomainProblemInWorkspace()` 门面，复用使用域身份但继续逐题
读取绑定、当前共享及版本事实。普通请求入口仍先加载工作空间；不增加外部
skipAuthorization 参数，不跨事务保存身份。发布前再次检查题目保留。

同一使用域、进行中的比赛内，已报名选手若没有该场当前组织权限，普通题面使用
学生裁剪并返回 can_edit=false；草稿、发布、导入和评测数据管理入口暂停。旧默认
域编辑守卫及固定版本读取复用同一规则，客观题专用服务也通过该编辑守卫判定。
真实组织权限来自当前域 contest:manage，或本人创建且仍有 contest:manage_own；
源题维护权限仍独立检查。实例治理保留真实平台权限。查询实时读取比赛窗口，赛后
自动恢复；其他使用域的比赛不限制源域。

旧题库列表使用同一 SQL 谓词计算敏感维护字段可见性，不逐题重新加载身份。
教学写入统一调用 workspace 模块开关门面，保留 MODULE_DISABLED 和班级加入
接口错误契约；历史读取不因模块关闭或无关导航字段异常而被阻断。

## Alternatives considered

- 只在普通客观题 DTO 删除 answer：草稿、固定版本及数据入口仍是旁路，不采用。
- 所有域、所有题目编辑者都受到某场学校比赛限制：扩大跨域影响，不采用。
- 给内部服务增加 skipAuth 布尔值：难以说明授权来自何处，改为明确上下文参数。
- 删除重复身份加载时同时删除资源检查：共享和默认版本会变化，继续逐资源检查。
- 在模块写入失败后捕获并统一换码：直接由门面支持调用方原有错误码，不增加异常层。

## Consequences

代码中班级和工作空间身份加载位置更明确，逐题授权 SQL 范围收窄；题目维护者在
参赛期间暂时无法管理该域的赛题，赛后恢复。既有知识或赛前保存的题面不可能通过
服务端撤回，本变更证明接口行为，不声称消除出题人已知答案的问题。

新增真实 API 回归覆盖参赛编辑者、普通题面、显式版本、固定版本内容、草稿入口、
当前本人比赛组织能力及赛后恢复。教学事务回归覆盖上下文复用后绑定失效仍拒绝，
不留下半份草稿；非法模块开关拒绝新写而保留历史读取。catalog / education 标准
两种数据库完整回归、类型、格式和 lint 在本批冻结前执行。浏览器比赛旅程仍属于
整个产品升级验收，不由本 Note 代替。
