# Agent Note: 域内题号与题目创建事务

Status: implemented

## Problem

题目创建和两种题包导入分别以分类范围 MAX+1 分配编号，不能让两个学校各自使用
1001，也无法把题库绑定与容量计数和创建一起提交。

## Decision

生成迁移 0116，将唯一约束改为 domain_id × number。旧可空归属数据暂由部分
分类唯一索引保护。普通创建、编程题包与客观题包创建共用域行锁和原子编号游标。
显式题号只能推进游标；冲突返回稳定错误，不自动改变指定编号。创建同时保存
初始草稿、本域绑定、策略依据、容量计数及审计，失败全部回滚。

旧入口仍保留待移除的分类权限，但新写入归默认域；旧列表、分类题号查询及题包
更新匹配限定默认域。显式域创建使用当前域权限。未发布且没有共享引用、版本或
提交的题目可删除，原子释放容量并保留编号游标；历史资源仍拒绝物理删除。

## Alternatives considered

增加 MAX+1 重试次数不能消除编号竞争，也不能满足域内身份。另写一套域题目
创建逻辑会复制运行配置与草稿规则，因此复用既有创建服务并统一题包入口。

## Consequences

两个域可各自创建 1001；指定编号、失败回滚、删除不回收、额度和跨域拒绝均有
测试。PGlite catalog 348 项通过，真实 PostgreSQL 全 core 1986 项通过。
格式、lint、类型、Schema parity、迁移安全、快照链及域边界检查通过。

P/U 字段和兼容权限尚未移除；源题及题单归属尚待非空收缩，显式域 API 和
提交、搜索、社区、下载等入口的完整隔离仍是后续交付，不能据本批开放新域做题。
