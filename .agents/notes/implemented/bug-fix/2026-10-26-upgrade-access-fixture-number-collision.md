# Agent Note: 稳定升级授权题号夹具

Status: implemented

## Problem

`versioning-upgrade-access.test.ts` 为每条升级授权夹具从 `97800–98799`
随机分配题号。真实 Domain 测试会把多个模块的测试夹具放入同一个隔离数据库；
随机题号与其它版本测试夹具碰撞时，测试会在业务断言之前因
`problems_domain_number_unique` 失败，产生与升级授权语义无关的验收阻塞。

## Decision

改为按测试标签计算稳定哈希，并使用本文件独立的高位题号区间
`8_000_000–8_099_999`。同一文件的标签保持可复现，且与已登记的其它版本夹具
区间分离。

## Alternatives considered

- 保留随机题号并在插入冲突后重试：会让测试结果依赖随机状态，且不能保证并行运行时
  的可复现性。
- 在每个测试前清空所有题目：会破坏共享隔离库中的其它测试夹具，并掩盖真实的
  Domain 并行行为。

## Consequences

升级授权测试不再因跨文件题号随机碰撞而偶发失败；题号仅用于夹具，不改变生产题号
分配逻辑。若新增同文件标签，哈希区间仍需保持唯一。
