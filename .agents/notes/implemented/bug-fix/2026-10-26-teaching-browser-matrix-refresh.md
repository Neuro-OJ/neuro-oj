# Agent Note: 稳定教学窄屏成绩矩阵验收

Status: implemented

## Problem

教学浏览器旅程在发布补题后直接切换到 390px 窄屏成绩卡片。发布会先触发成绩投影
异步刷新；页面初始数据虽然已渲染，但刷新重渲染可能在展开学生卡片后把它折叠，
导致题目按钮无法定位并让浏览器验收超时。

## Decision

切换窄屏前复用桌面矩阵的显式“刷新成绩”动作，并等待学生及其未达标题目单元格
可见；随后再切换视口、展开移动端学生卡片并打开题目详情。

## Alternatives considered

- 增大题目按钮定位超时：不能消除异步刷新与展开状态之间的竞态，只会延长失败。
- 仅在窄屏卡片上重复点击学生行：会把数据尚未稳定与 UI 展开动作混在一起，且可能
  在刷新重渲染期间再次丢失展开状态。

## Consequences

浏览器验收先证明成绩投影已稳定，再验证窄屏交互；不改变生产代码或业务语义。
