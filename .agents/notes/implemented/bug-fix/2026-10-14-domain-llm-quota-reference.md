# Agent Note: 域内 LLM 实际额度与种子参考值

Status: implemented

## Problem

Gateway 种子包含作用域 ID 为空的用户和题目参考额度。这些行不限制真实调用，
域管理页面却与实际额度混列，目标显示为空，编辑时还出现“此前选择的用户”。

## Decision

实际额度保留在主列表，尚未指定目标的种子值放入“额度参考值（未生效）”折叠区，
明确说明不限制调用。按参考值新增时复制数值与窗口，清空记录 ID 和 revision，
必须先选择当前域的用户或题目，保存为独立实际额度。全域额度的空 ID 仍表示全域，
不能误判为参考值。当前选择页之外的实际目标显示明确用户或题目 ID，避免空白目标。

264 项组件测试、完整类型检查及 lint 通过。生产 UI 构建完成，真实浏览器读取
恢复库默认域的两个种子参考值，验证单独说明及“选择域内用户”的新增流程， 没有
JavaScript 错误。此验收未修改上游密钥或进行付费调用。

## Alternatives considered

- 隐藏或删除参考行：丢失可用的配置起点，单独展示其真实含义。
- 把空作用域视为所有用户的通配额度：改变 Gateway
  精确匹配语义，且错误限制所有成员。
- 将参考行原地绑定用户：种子 ID 与实际额度混淆，显式建立独立记录。

## Consequences

域管理员可区分真实限额和参考数值，不再把未绑定参考值视为已生效额度。
执行及预占结算规则保持现有 Gateway 契约。
