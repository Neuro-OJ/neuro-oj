# Agent Note: 运维题包导入显式使用目标域负责人

Status: implemented

## Problem

可信运维 CLI 仍以系统占位账号 0 调用域导入与发布。默认域完成真实负责人引导后，系统账号没有普通域成员身份，这些调用会被新域权限拒绝。

## Decision

CLI 从显式 `--domain`（默认 main）查找当前域负责人，并把该账号传给题包导入和显式发布。目标域不存在立即返回具体错误。一般业务创建服务仍要求真实调用者授权，不使用默认负责人作为 HTTP 请求的兜底身份。

## Alternatives considered

让系统账号自动取得所有域成员或管理员身份会扩大治理权限。一般创建服务在缺少 actor 时借用负责人会掩盖调用方的身份错误。

## Consequences

运维入口有明确目标域和执行者，仍由原域门面检查当前账号、角色、域状态及 revision。负责人转交或撤权后调用可能失败并需要重新执行，不会绕过权限。脚本类型检查与导入帮助检查通过；完整生产恢复演练仍待统一验收。
