# Agent Note: 默认域比赛管理入口隔离

Status: implemented

## Problem

旧平台比赛管理路径解析任意比赛 ID，可在没有明确使用域的情况下读取或修改其他学校的比赛。
旧排名导出夹具在默认域初始化后物理删除负责人，也与保留域负责人和历史身份的规则冲突。

## Decision

默认域管理列表显式限定默认域，全部单资源操作先复用默认域比赛访问门面。
详情、编辑、删除、参与者、提交、正式排名和导出不能通过其他域 ID 越过路径上下文。
导出测试清理采用软注销，测试事务仍在结束时整体回滚。

## Alternatives considered

没有为平台管理员在无域入口留下跨域例外；跨域治理需要明确目标并另行审计。
没有删除数据库负责人约束来迁就旧测试的清理方式。

## Consequences

contest 标准测试 114 项通过、0 失败、1 项环境专属测试跳过。
新增 HTTP 回归验证其他学校比赛 ID 的读取、编辑、删除返回 404，默认列表不包含该比赛且原数据未变化。
所有学校比赛的正常管理继续使用显式域 API。
