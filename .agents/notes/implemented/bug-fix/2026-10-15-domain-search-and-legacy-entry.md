# Agent Note: 旧业务入口与域内搜索归属

Status: implemented

## Problem

旧的本人提交汇总页和全局搜索仍能作为独立业务入口，平台侧栏也重复列出题库、
题单和比赛日常管理。域搜索的条件未进入 URL，刷新和返回时丢失上下文。

## Decision

- 旧 `/search`、`/my/submissions` 和默认题库管理地址转入明确的 `main` 域。
  兼容入口不读取导航偏好，不把学校资源 ID 解释成其他域资源。
- 搜索关键词、类型和分页写入当前域 URL；引用题结果继续在使用域打开。
- `Ctrl+K` 使用导航域打开搜索，账号与说明页也保留来源域。
- 平台侧栏保留实例治理、统一身份及公共分类，移除重复域业务入口。
  账号安全与私信的最终产品归属仍见 proposed 决策队列 D03。
- 提交列表索引启用服务端重定向；受控的单条历史记录入口保持原有读取约束。

## Alternatives considered

- 保留跨域汇总但隐藏菜单：不符合用户要求，直接移除汇总页面实现。
- 根据最近切换域解释旧链接：会使同一链接因用户偏好不同而指向不同内容。

## Consequences

旧链接具有确定归属，新业务地址显式携带域。274 项组件测试、281 项单元测试、
完整前端类型检查通过。生产构建的真实浏览器验收验证旧搜索重定向、类型切换、
刷新保留 `1001`，以及说明页 `Ctrl+K` 返回学校域搜索；没有页面脚本错误。
全套 CI 和完整角色旅程仍由任务清单 V03/V04/V07 单独验收。
