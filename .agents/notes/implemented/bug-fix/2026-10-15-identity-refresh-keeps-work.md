# Agent Note: 同一账号刷新保留教学选择与输入

Status: implemented

## Problem

最终 CI 的真实浏览器 trace 显示，教师刚点击矩阵单元时另一个 `/auth/me`
响应完成，学生抽屉随即关闭。原监听函数返回新数组，账号对象替换后即使 ID
相同也触发重置。相同写法也会清空正在编辑的行批注、反馈、成员操作和复制表单。

## Decision

将身份与资源重置监听改为 Vue 的多个独立 getter，只比较域、账号 ID 和资源 ID
的实际值。真正换账号、换域或换资源仍清空相应状态，同一账号的资料刷新保留输入。
保留服务端实时授权及既有作用域检查，不增加刷新锁、延时、身份缓存或事件屏蔽。

## Alternatives considered

- 只重跑失败测试：已从 trace 和组件回归复现实际输入丢失，重跑不能修复。
- 禁止资料刷新或延迟打开抽屉：掩盖竞态，影响权限更新和正常交互。
- 比较整个用户对象：姓名和权限资料更新不等于切换账号，ID 才是身份依据。

## Consequences

页面级回归验证同一账号刷新后学生抽屉与反馈对象保留，真正切换账号后清空。
行批注回归验证编辑中的文字保留；两项回归均在修复前失败、修复后通过。
当前权限仍从最新响应读取；保留输入不授予旧账号的访问能力。
