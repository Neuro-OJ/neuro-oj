# Agent Note: 教学反馈对象与社区加载错误

Status: implemented

## Problem

教师选中成绩矩阵单元格后，侧栏和反馈表单没有明确学生姓名，关闭侧栏仍会保留
个人反馈对象。社区初次帖子请求失败则被捕获为成功空列表，配置失败也显示为停用。

## Decision

- 侧栏标题显示学生与题号，反馈区明确当前学生和反馈覆盖本份作业；教师可显式
  切换为全体反馈。反馈列表通过已经授权的查询返回目标姓名，包括注销身份标记。
- 首次配置与帖子错误交给页面错误态，显示实际错误及重试按钮；成功空列表才显示
  空态。社区停用或没有可用内容类型时不继续请求帖子。
- 保留已有反馈权限过滤与分页，姓名联表不扩大可读反馈范围。

## Alternatives considered

- 关闭侧栏就自动改成全体反馈：教师可能误向全班发送，改用可见对象和明确切换。
- 网络异常按空列表处理：掩盖故障，用户无法判断是否有内容，也没有重试入口。

## Consequences

教学 124 项测试通过，包含个人反馈姓名与同学不可见校验。前端 281 项组件测试
通过，包含配置失败、首屏故障重试和目标姓名展示。真实浏览器验证选定学生、
侧栏学生题号、退出侧栏后的目标提示及切换全体；模拟帖子 503 后显示错误并成功
重试恢复，没有页面脚本错误。真实历史数据未转换，人工产品取舍仍在 proposed 队列。
