# Agent Note: 后台刷新保留作答与作业管理表单

Status: implemented

## Problem

真实浏览器验收发现，教学 SSE 重读作业时，加载态会卸载已经打开的补题弹窗。
管理组件监听一个每次新建的数组，也会把同一任务的新响应误认为切换任务。
题目详情的版本检查同样可能卸载作答面板，影响尚未提交的输入。

## Decision

题目与作业页面在已有数据时继续保留内容实例，首次读取才显示加载态；读取错误
仍明确显示。管理弹窗分别监听域和任务 ID，只在实际切换资源时重置表单。
不增加全局草稿状态、额外定时器或重复提交逻辑。

## Alternatives considered

- 禁用实时刷新：会丢失已交付的学情与版本变化提示。
- 刷新前序列化所有弹窗再恢复：扩大状态管理范围，没有必要。
- 监听完整任务响应并重置：响应对象更新不代表用户切换了任务。

## Consequences

同一任务后台更新不会关闭补题弹窗或清空标题；切换到另一任务仍会重置。
组件回归验证同 ID 响应替换时保留原表单与输入，以及真正切换 ID 时关闭弹窗。
浏览器矩阵和作答流程继续使用标准端到端入口验收。
