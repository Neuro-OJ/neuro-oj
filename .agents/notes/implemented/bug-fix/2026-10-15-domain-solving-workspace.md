# Agent Note: 域题目详情与长题面做题工作区

Status: implemented

## Problem

域题面与作答纵向排列，长题面使编辑器难以使用；通过要求、本人历史、题解与
当前域统计也缺少入口。真实自测还发现最终完成结果会被遗留进度显示为评测中。

## Decision

- 桌面使用独立滚动的题面、作答两栏；390px 窄屏切换面板。两个面板始终挂载，
  不因查看题面销毁代码、答案或已选文件。继续复用域内作答和自测组件。
- 显示题型、通过要求、OI 时空限制、成绩版本口径及本域统计；提供明确域题解
  和本人作答历史。样例补充显示说明。
- 统计复用 query 门面的当前域口径，进行中比赛的隐藏成绩不计入公开统计。
  只新增可公开的 OI 时空字段，不下发评测配置和测试数据。
- 自测完成后采用最终判定，不再传递遗留进度；公开样例与自定义用例不标为隐藏。

## Alternatives considered

- 嵌入旧全局编辑器：旧实现仍依赖无域题号、模板和结果读取，会引入另一套归属。
- 窄屏用条件挂载切换作答：可能丢失文件选择及未提交输入，改用显示状态切换。

## Consequences

题库 397 项测试通过，包含隐藏比赛与结束后详情统计的断言；前端工作区实例保留
和最终自测判定有组件测试。生产构建的真实浏览器验证桌面两栏、390px 无横向
溢出及切换保留代码；真实 C++ 自测 `st_fd01105d-4929-499c-8a26-07f9a71ba60d`
返回 100 分与输出 3，产物上传入口及题解关联导航正常。最终自测展示修复继续
随最终构建回归，完整类型、全套 CI 和所有题型旅程另由验收清单记录。
