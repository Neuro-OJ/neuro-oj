# Agent Note: 比赛时间边界与客观题反馈自动开放

Status: implemented

## Problem

开始、结束由时间推导，不一定增加比赛 revision。题目页只监听 revision 时，开赛前
打开的错误页不会恢复；榜单不更新比赛状态。客观题即时完成后，赛时隐藏的结果页
完全停止轮询，结束后仍看不到成绩。

## Decision

比赛题目同时监听状态与 revision。榜单在比赛结束前刷新上下文，状态变化时重读
允许的榜单；实时成绩仍用原有周期，结束后停止。客观题结果隐藏时继续读取受裁剪
接口，结束后显示服务端允许的摘要，终态可见后停止轮询。普通 OI 代码结果页保持
隐藏期间轮询，结束后自动读取判定。

267 项组件测试、完整类型与 lint 通过。新增回归覆盖 revision 不变的开赛、即时
评测但隐藏的客观题、开赛前打开榜单及结束时重读最终实时结果。 真实短 OI
旅程验证开赛前直接打开题目，约 1.6 秒后自动开放，浏览器输入 C++ 并提交，
赛时只显示受理回执，结束后自动展示 AC 与允许的明细。代码提交为
`2d308a1b-7c82-4ee3-bd51-620ae737117c`。 真实客观题提交
`d4e4fd14-b5a5-4804-b7be-42e3b3e28048` 赛时隐藏，结束后约 2134 ms 自动显示 100.0
分，浏览器无 JavaScript 错误。所有夹具属于独立恢复验收库。

## Alternatives considered

- 依赖教师保存比赛触发 revision：时间变化是正常事实，不要求人为修改配置。
- 隐藏结果时停止所有请求：不能识别公开窗口结束；继续只读取已裁剪接口。
- 赛后在前端自行显示缓存成绩：可能绕过服务端权限，始终重新读取当前结果。

## Consequences

学生可以留在页面等待开始或结果开放，终态后不持续请求。正式成绩发布仍需结算与
快照，状态变化不会擅自发布或改写正式榜单。
