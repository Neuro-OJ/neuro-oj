# Agent Note: OI 编辑保存的大数据处理与主线程隔离

Status: implemented

## Problem

OI 编辑器保存元数据或评分配置时仍读取和重新上传全部数据文件，并在 HTTP 主线程同步压缩派生 ZIP。大型 road 数据包使 Deno 单核心满载、阻塞其他 API 请求。

## Decision

没有文件变更的保存复用原包和文件索引。配置引用变化时只检查索引，旧包仅扫描 ZIP 目录及安全限额，避免展开内容。文件变更时复用摘要相同的已存对象，并在每次操作独立的 Worker 中处理解压、导入解析和低等级压缩；操作结束、出错或超时后回收 Worker。文件索引列表不下载全部内容，读取单个新格式文件只取对应对象。构建入口显式内置 Worker 模块。

## Alternatives considered

单纯降低压缩等级不能避免主线程阻塞；后台维护内存任务队列不符合跨副本约束；每次元数据保存强制转换旧包会造成不必要的数据重写，因此旧格式转换延后到实际文件变更。

## Consequences

现有题目数据与资源预算不变。文件变更仍原子发布配置和派生包，失败保留旧数据；原有 ZIP 路径和大小约束继续生效。测试覆盖配置更新不读取或上传大对象、缺失引用拒绝、归档内容往返、非法路径及主线程响应。独立 Worker 不属于评测 Judge，不改变用户控制 Judge 启停的约定。
