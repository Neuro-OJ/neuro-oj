# Agent Note: 成绩刷新保留手机展开与键盘位置

Status: implemented

## Problem

PR #694 的真实 Browser E2E 中，教师展开 390px 成绩摘要后，后台刷新让卡片折叠，
后续成绩入口点击超时。AssignmentMatrix 的 watcher 返回新数组作为单个监听值；
矩阵对象更新即触发重置，即使页码、范围、学生和题目身份均未变化。

## Decision

改为 Vue 多源监听，分别比较页码、统计范围、学生 ID 序列和题目 ID 序列。
相同结构的成绩刷新保留展开与键盘位置，并使用新成绩进入原有详情。
翻页、范围切换、学生变化和题目变化仍重置状态。

## Alternatives considered

延长 Browser E2E 超时或重复点击展开不能修复实际交互丢失。完全删除 watcher
会让翻页和筛选保留无效焦点，因此只改变监听粒度。

## Consequences

布局和业务权限合同沿用既有实现。组件回归先复现刷新折叠，再验证成绩刷新与
四种结构变化；原有完整浏览器旅程继续作为真实手机交互门禁。
