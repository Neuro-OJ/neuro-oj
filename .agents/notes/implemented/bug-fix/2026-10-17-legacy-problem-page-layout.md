# Agent Note: 按线上参考恢复题库与原有内容页布局

Status: implemented

## Problem

域升级后的题目详情回落到较窄容器和固定 260px 侧栏，主操作集中在侧栏，丢失旧版
题面工具条、本人提交摘要及页末题解。题库标题列的 `w-full`
挤压其余列；题单、提交、
排行榜混用管理页头，社区存在内外两重容器。前两次界面调整也留下文案断言和作业
截止阶段比较的回归。

## Decision

- 视觉依据为用户提供的线上 P20 截图及仓库保留的旧版题面组件。恢复 `max-w-7xl`、
  桌面 8/4 栅格、标题旁主操作、题面前版本信息、右侧资料和本人提交、底部题解。
- 题面使用原 `ProblemHeader`、`ProblemStatement`、`ProblemMetaCard`。域 DTO 通过
  `toDomainProblemView`
  转换；标签筛选、作答、编辑、提交和题解链接保留当前使用域。
- 详情接口补充公开评测后端、提供者和裁剪后的标签。提供者仅返回 ID、用户名和
  头像；未通过学生不能取得算法标签，不增加评测配置或答案字段。
- 题库移除强制标题列宽和逐行版本号，恢复编号、标签和状态的既有展示语言。
  题单、比赛、提交和排行复用公共页头；社区嵌入域布局时只保留一层内容容器。
- 本人提交摘要按当前账号及域查询，明确隐藏比赛结果；加入题单使用域接口及
  revision，保留题目顺序，同一源题不重复写入。
- 域版本接口当前只提供有效策略决定的作答版本和历史沿革；保留真实沿革入口，
  不增加只有外观而不能切换版本的下拉框。

## Alternatives considered

- 直接恢复旧的无域页面：会退回默认域 API，破坏共享题使用域、作业入口和权限边界。
- 另写一套题面卡片：继续产生与线上版本不同的组件和交互；因此复用既有组件。
- 对所有页面扩大公共布局：会影响教学和设置页面，故只为题目详情增加宽度选项。

## Consequences

恢复视觉组织，同时保留当前域资源模型、数字题号、版本策略、客观题与产物作答、
比赛裁剪和作业上下文。教学工作台及域设置保留现有结构，不移回旧全局路由。

验证包含 UI 单元 287 项、组件 334 项、完整类型检查、格式及 lint、生产构建，core
题库测试 397 项和类型检查，均通过。
新增测试覆盖共享题视图适配、隐藏算法标签、隐藏比赛成绩、本人提交作用域以及
题单追加的 revision 与去重。机械布局扫描无命中。本地 3040 通过真实学生登录后，
六类内容页的 HTTP／SSR 内容与前端 API 代理验收；题面及本人提交接口按当前域核对。

本次浏览器连接不可用，线上页面读取也失败；视觉依据是用户截图和既有源码，
不能将自动测试及构建通过描述为已经完成实时桌面／手机截图验收。
