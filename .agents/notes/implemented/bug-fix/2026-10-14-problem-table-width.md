# Agent Note: 题库表格默认完整显示

Status: implemented

## Problem

题库页面限制为 960px，Nuxt UI 表格单元格默认禁止换行。长题名撑宽表格，右侧状态列被横向滚动容器遮住，通过率标题也被挤成竖排。

## Decision

将桌面内容区和面包屑最大宽度同步扩大为 1200px。通过 UTable 的 ui 插槽样式允许单元格换行，缩减水平留白，列标题保持一行。长题名和标签可在可用宽度内折行。

## Alternatives considered

仅扩大页面宽度不能处理较窄桌面或长题名；隐藏状态列会丢失用户需要的信息；保留横向滚动只作为窄屏兜底。

## Consequences

桌面默认完整展示现有所有列，维持既有手机精简列规则和题库筛选值。需要在已登录状态下检查全部八列，以及不同桌面宽度与用户题库增加创建者列的情况。
