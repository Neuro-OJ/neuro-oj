# Agent Note: 上传作答明确显示已选文件名

Status: implemented

## Problem

真实浏览器中，默认上传控件选中 ZIP 后只显示文件图标，文件名处于隐藏的控件
预览层。学生无法直接确认准备提交的是哪个文件，后台检查版本后也难以确认文件
是否仍然保留。

## Decision

产物与预测题在上传控件下直接显示已选择的文件名，长文件名允许折行。
继续复用原文件对象、上传接口与移除操作，不增加第二份文件状态。

## Alternatives considered

- 依赖控件的悬停预览：触屏和未悬停状态无法直接确认。
- 重做上传控件：现有控件的选择与移除能力可继续复用。

## Consequences

学生在提交前可以读到准确文件名；移除文件后提示随原状态消失。
现有预测上传组件回归同时验证文件名提示，真实产物评测另记于验收报告。
