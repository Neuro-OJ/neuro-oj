# Agent Note: 修复教学页面透明加载容器导致的区块贴合

Status: implemented

## Problem

班级页面上一轮打磨后，部分独立组件仍然紧贴。真实 Chromium 截图和布局测量确认：班级概览与作业区、成员名单与批量导入、学生提交与作业入口、作业截止说明与成绩筛选、成绩分页与反馈卡片之间的距离为 0。

这些位置的父级使用 Tailwind `space-y-*`，但 `AsyncContent` 的数据分支为 `display: contents`。子元素外边距选择器不能跨过透明容器，容器自身的外边距也不参与布局，因此源码中的间距没有落到实际显示的区块之间。

## Decision

- 班级页面及相关作业、训练、评测沿革和提交审阅容器采用 `flex flex-col gap-*`，由父级直接分隔实际布局项。
- 页面区块使用 24px，作业及学生训练主要区块使用 20px，内容组使用 12–16px；保留既有设计 token。
- 作业标题、说明和截止提示放进独立内容组，避免展开透明容器后把组内元素误当作独立大区块。移除改用 gap 后重复的外边距。
- 独立返回按钮和历史按钮保持内容宽度，成绩筛选的用户名输入与搜索按钮使用同行间距。
- 不修改共享 `AsyncContent` 的默认结构，避免影响其他页面的表格、网格和加载状态。

## Alternatives considered

- 给每张卡片增加独立 margin：依赖前后区块是否存在，且没有修复父级布局本身。
- 全局修改 `AsyncContent` 的数据容器：调用方包含表格、网格和多根节点，超出本次教学页面的修复范围。
- 将所有间距统一放大：掩盖透明容器问题，并破坏内容组内部的紧密关系。

## Consequences

本次仅修改展示布局，不改变权限、请求、成绩或保存流程。验证使用独立 Chromium 测试会话，通过本地登录接口取得开发账号会话，不读取用户现有浏览器资料。

截图和布局测量覆盖桌面 1440px、手机 390px 的班级列表、概览、成员、设置、学生目录、学生训练、作业创建、比赛补题和作业成绩。修复后的验收同时检查区块间距、水平溢出和浏览器运行错误，并检查提交审阅抽屉及教学工作台。

实际结果：20 个页面与尺寸组合均无窗口水平溢出和已检测到的贴合区块，浏览器运行异常为 0；另检查两种尺寸的提交批注抽屉。原有 5 处零间距在桌面和手机上分别恢复为 24px、24px、20px、20px、20px。342 项组件测试、287 项单元测试、格式、Lint 和生产构建通过，教练与学生身份的 22 项 API / SSR 检查通过。

本地截图与测量保存在 `/tmp/noj-classroom-gaps-before/` 和 `/tmp/noj-classroom-gaps-after/`，属于开发验收产物，不提交仓库。
