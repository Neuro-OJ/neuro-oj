# Agent Note: 作答草稿按用户隔离并在退出时清理

Status: implemented

## Problem

旧编辑器与题库、比赛共用作答面板的浏览器草稿键缺少账号归属。在学校机房轮流登录时，同一道题会恢复上一位学生的代码或答案，退出登录也留下草稿。

## Decision

所有作答入口复用 `domainAnswerKey`，以当前账号 ID 或 `anonymous` 标识草稿归属，保留题库、比赛、题目和版本的上下文隔离。
旧无域编辑器使用 `global` 上下文。题库与比赛共用面板使用 `answer` 标识其整份作答；独立代码工作区继续按具体语言分开保存。

主动退出、会话验证失败、普通 API 的 401 清理，以及客户端账号替换或会话被清除时，删除原账号所有 `noj:draft:` 草稿和不能确定归属的旧格式键。
清理保留显式 `anonymous` 草稿和其他账号草稿，浏览器禁用存储时仍继续清除登录态。无归属旧草稿不自动迁移，避免将他人的输入认领给当前用户。

游客迁移继续只匹配同一作答上下文；已有账号草稿时仍由用户选择是否恢复游客草稿。账号变化不保存旧账号上下文，防止退出后重新写回；同一账号切换题目或语言仍保存旧上下文。
旧编辑器同步取消切键前的防抖任务，并校验延迟写入的目标键。保存时机、防抖时长和状态提示保持原有约定。

## Alternatives considered

- 仅退出时删除全部草稿：无法隔离退出前的账号切换，还会删除游客和其他账号的草稿。
- 将无归属旧键当作游客键迁移：无法确认实际作者，会把升级前另一位学生的代码带入当前账号。
- 仅给键加账号而不处理切键保存：退出清理后的挂起保存或卸载回调可能重新写入旧账号代码。

## Consequences

已登录用户退出或会话失效后，本地作答草稿不再保留；需要保留的内容应事先提交或另行保存。服务端提交和运行历史不受影响。
升级前无归属草稿不再自动恢复，并在会话清理时删除。显式游客草稿保留原迁移行为。
回归测试覆盖入口键、跨账号读取、清理范围、会话失效、防抖保存与游客迁移。
