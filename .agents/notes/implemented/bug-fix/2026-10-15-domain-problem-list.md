# Agent Note: 域题库的筛选、题号和本人状态

Status: implemented

## Problem

域题库只搜索标题，输入数字题号找不到题目；列表缺少难度、标签、通过率及本人
状态，筛选和页码不保存在 URL。恢复旧全局统计会错误纳入其他学校数据或赛中结果。

## Decision

本域授权条件在分页与计数前执行，再按数字题号、完整来源题号或标题定位，支持
题型、难度、标签与本人状态筛选。一页题目的统计和本人状态批量读取，只使用当前
使用域、当前授权绑定及已结束比赛的可展示记录。通过要求依据有效 AC，不从分数
推断。算法标签在本域通过前隐藏，筛选也不能用隐藏标签反推出命中数量。

全站排行开关仅影响排行，本人题库仍计入本域已结束但不计全站排行的比赛记录。
普通题型标签可直接查看；共享源域的管理员身份不自动授予目标域状态。 前端复用 URL
筛选工具，筛选变化回到第一页，刷新保留条件，引用题仍链接使用域。

验证：catalog 397 项、query 32 项、前端单元 285 项与组件 269 项通过；类型、 lint
和仓库级门禁通过。测试覆盖跨域 AC 不混用、隐藏比赛不影响统计和标签、
标签筛选权限、默认域不计全站排行的个人记录，以及分页与状态筛选。
真实浏览器使用学生账号按 1001 定位，按已通过筛选并刷新保留 URL，展示 本域 6
次有效提交及 83.3% 通过率；390px 无横向溢出，无 JavaScript 错误。

## Alternatives considered

- 前端过滤已加载题目：分页与总数不正确，在服务端先过滤。
- 复用全实例通过记录：跨域身份、模型与版本策略不同，统计限定使用域。
- 未通过时仍按算法标签筛选：虽不显示标签文本，命中数仍泄露算法，过滤同样受门控。

## Consequences

题库支持正常定位、筛选及练习进度判断。通过率分母为正式有效提交，不把排队或
平台失败当作失败成绩；既有重测投影继续提供权威判定。API 增加展示字段，不改题目、
版本或提交身份，不引入新的物理 Schema 或进程内缓存。
