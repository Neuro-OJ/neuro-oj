# Agent Note: 导航未读契约与认证默认状态

Status: implemented

## Problem

私信、空间社区、账号社区的未读接口具有不同结构。导航把私信当作嵌套响应读取，
使登录后的页面抛出渲染错误；模拟夹具沿用了错误结构。认证字段传入空错误字符串，
Nuxt UI 将其视为错误状态，首次进入即显示红框。

## Decision

UI 使用显式契约解析读取未读数，失败保留最近成功值，并按账号和空间隔离。
BFF 保留 Core 原始契约，生产验收夹具使用真实响应结构。认证字段将空错误转为
undefined，保留提交校验与真实错误文案。

## Alternatives considered

- 修改 Core 统一响应：扩大兼容范围，与本轮仅调整 Nuxt 的边界不符。
- 仅加可选链：只能隐藏崩溃，不能恢复正确角标与测试契约。

## Consequences

通知读取异常不再阻断整页，切换账号和域不显示旧未读数。失败期间角标可能暂时
落后于服务端，后续成功刷新恢复。组件及工具测试覆盖真实结构、错误状态与账号切换。
