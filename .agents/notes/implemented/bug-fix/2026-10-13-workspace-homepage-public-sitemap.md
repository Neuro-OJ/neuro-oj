# Agent Note: 工作空间首页配置与公开目录的即时授权

Status: implemented

## Problem

域设置提供了概览、社区、教学和题单首页选择，但域根页始终渲染概览。
同时 sitemap 复用一小时的公开资源缓存，上游故障时还返回过期完整目录；
实例或 main 政策改变、资源撤销后，缓存仍可能暴露已不可公开的资源定位。

## Decision

- 域根页使用已解析的 WorkspaceContext，把首页配置映射到当前导航实际允许的
  社区、教学工作台或题单入口。概览不重定向；缺少权限或模块关闭时保留概览。
  暂停域保留治理概览，归档域按既有授权导航读取历史。
- 未加入的登录账号保留概览的加入或申请表单。首次已获授权、上下文就绪或加入后
  引导到配置首页；已经导航到其他域资源页时，旧概览不发起新的重定向。
  不再额外查询 Domain，也不引入新的首页类型或产品页面。
- sitemap 每次以匿名请求读取 `/domains/main/problems`、`/domains/main/contests`
  与全站公开公告。题目使用 items/total，比赛使用 data/pagination，公告使用
  data/meta 的真实分页契约；输出题目和比赛的显式 main 地址。
- 删除 sitemap 的进程缓存及失效后的旧目录回退，响应始终 no-store。
  当前授权拒绝或上游失败直接使请求失败，不能用旧公开目录代替新授权。
  保留站点权威 origin 和 Host 校验，不转发访问者 Cookie。

## Alternatives considered

缩短缓存 TTL 仍留下权限撤销窗口；只在本进程删除缓存不能处理其他副本。
继续返回旧目录会把先前公开的记录重新当作当前公开，因此取消目录缓存。
首页无条件跳转会把学生送进未授权教学页面，或隐藏尚需加入空间的表单；
复用现有导航能力即可表达允许进入的目的地。

## Consequences

公开目录每次读取 core 当前事实，上游不可用时不提供目录。仍保留每类最多十页的
原有取数边界，不新增无界抓取、权限缓存或网络回退。
首页引导不代替后端资源授权，归档和模块停用的实际读写政策继续由各业务接口执行。

回归使用真实 sitemap handler，覆盖前次公开后的撤销、停止匿名访问、上游故障、
多页资源和不转发 Cookie。首页组件验证首次引导、上下文迟到、加入后引导，以及
其他资源页不会被旧概览抢走导航；独立规则测试覆盖教学能力、模块开关和域状态。
本批不重启运行栈，实际部署 HTTP 与浏览器导航由后续集成窗口验收。
