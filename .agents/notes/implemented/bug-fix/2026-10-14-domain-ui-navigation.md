# Agent Note: 明确域 URL 与头像菜单导航

Status: implemented

## Problem

域页面重复显示空间标题、全局导航与域导航，头像菜单仍链接跨域提交汇总。
页脚会转入默认域，域根页又自动跳到社区，当前域和用户任务之间的关系不清楚。

## Decision

根入口读取实例默认域并进入明确域 URL；私有实例的单一成员域直接作为入口。
域页面复用布局上下文生成一套主导航，移动端使用侧抽屉，头像二级菜单负责换域。
用户名显示 `username@slug`，移除常驻切换器；业务菜单、品牌和页脚链接保留使用域。
登录回跳保留完整来源 URL，域内快捷搜索进入本域搜索页。
域根页保持可访问，不再被可修改的旧首页配置自动跳走。
跨域提交汇总不再作为用户入口，旧列表链接固定兼容到 main 的提交列表。

## Alternatives considered

- 保留两套导航并继续调整折叠宽度：未解决域与全局入口混杂。
- 将当前域存入 JWT：与明确 URL 的权限和双标签页模型冲突。
- 复刻 Hydro 的独立域下拉区：用户指定换域放在头像二级菜单。

## Consequences

业务入口可以直接 review 使用域。账号设置与平台治理继续属于原身份层，
通过导航来源参数保留返回上下文，不把该参数作为业务授权凭据。 这批改动不代表全部
UI 修复完成；其余任务由修复清单持续跟踪。

验证：UI 单元测试 285 项、组件测试 250 项通过，完整 Nuxt/Vue 类型检查及 lint
通过。源码开发服务 `127.0.0.1:3007` 的真实浏览器检查验证根入口、登录回跳、
`e2e_admin@main`、头像二级菜单和移动端抽屉，未出现 pageerror。
这不是全部教学旅程或生产构建验收，后续阶段仍执行完整浏览器和 CI 检查。
