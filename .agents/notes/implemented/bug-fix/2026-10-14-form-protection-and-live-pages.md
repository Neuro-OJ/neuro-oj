# Agent Note: 表单输入保护与教学比赛页面刷新

Status: implemented

## Problem

比赛、作业、新题及域设置表单离开后丢失输入。已稳定的成绩矩阵不会继续轮询，
新提交或重测完成时无法更新。比赛页面也可能停留在开赛前或赛时的权限状态。

## Decision

增加共用的未保存修改保护，在路由离开、同页路由更新及浏览器刷新时检查表单基线；
取消离开保留输入，保存成功后更新基线。教学页面接收域内 SSE 提示并重新读取
获授权接口；重新读取班级后再决定是否刷新矩阵，撤销关系后不保留旧私有矩阵。
比赛与比赛提交页面轮询当前比赛状态，开始和结束后重新读取题目及结果权限。

本轮 264 项组件测试、完整 Nuxt/Vue 类型检查和 lint 通过。生产镜像完成构建并在
本地 3008 连接独立恢复验收库。真实浏览器验证比赛表单修改后取消离开保留标题，
确认离开进入本域题库。教学更新与比赛边界的组件测试已通过，完整真实 SSE 和
计时旅程继续纳入验收清单，不以组件测试代替实际服务验收。

## Alternatives considered

- 每个表单手写确认框：重复路由及刷新处理，采用共用 composable。
- 所有矩阵持续轮询：无变更时产生不必要请求；稳定状态使用事件提示重新读取。
- 用 SSE 载荷直接写成绩：绕过当前权限与比赛裁剪；事件仅提示重读。

## Consequences

普通表单获得一致输入保护，教学和比赛页面能响应服务端状态变化。作答代码继续
采用按域、用户、题目版本分隔的本地草稿。事件丢失时沿用现有 SSE 重连及降级轮询。
