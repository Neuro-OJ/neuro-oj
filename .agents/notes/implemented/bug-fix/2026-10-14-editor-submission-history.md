# Agent Note: 修复做题页正式提交历史缺失

Status: implemented

## Problem

从公开题号（如 P17）进入做题页时，正式提交列表以公开题号查询只支持内部 ID 的 problem_id 过滤器，返回空列表。自测使用已解析的内部 ID，因此 UI 题历史只显示自测。

## Decision

统一使用已加载题目的内部 ID 查询正式提交历史，分页使用接口支持的 per_page=30。保留竞赛专用历史接口及用户鉴权范围。直接部署基于 v0.10.5 的前端热修复，不改数据库。

## Alternatives considered

修改后端过滤器也能兼容公开题号，但涉及后端重建且前端已经持有正确 ID；本次采用前端修复。

## Consequences

UI 题与代码题共享做题页，均恢复正式历史记录。题目未加载时不生成全题库查询。保留原前端镜像和部署配置以便回退。
