# Agent Note: 教学通知授权读取复用投递事务

Status: implemented

## Problem

完整 40 人班级浏览器旅程在发布作业后卡住登录。实际 PostgreSQL 只有一条
idle-in-transaction 连接，停在通知受众查询；单连接池被投递事务占用后，收件权限
校验又从全局池申请连接，互相等待。外层测试事务会掩盖这类问题。

## Decision

通知投递把当前 executor 传入生命周期、反馈和求助权限读取；反馈及求助详情继续
调用原有授权链，整条读取复用同一个事务。事务提交后才发布已有 SSE 事件，
不改变通知受众和保密规则。

新增独立 PostgreSQL 事务回归，覆盖作业发布、个人反馈、学生求助三类通知。
测试退出时重置其隔离数据库，避免残留夹具影响后续事务包装测试。

## Alternatives considered

- 增大连接池绕开等待：不能修复事务外取连接的原因，小资源部署和并发仍有风险。
- 复制一份简化权限判断：容易与反馈、求助的真实读取权限漂移，复用原授权函数。

## Consequences

PGlite 教学 124 项通过；新增 PostgreSQL 单连接回归已通过。更新运行套件后，
原先无法返回的登录请求约 28ms 返回 200，40 人成员管理与助教授权步骤重新通过。
最终全量并行回归、完整浏览器旅程仍在本次验收中单独记录，不据局部结果签收全套。
