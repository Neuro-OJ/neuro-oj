# Agent Note: 竞赛附件访问解析公开编号

Status: implemented

## Problem

编辑器将 URL 中的竞赛公开编号传给题目界面与模板接口，访问校验却仅按内部 UUID
查找竞赛。普通参赛者因此收到 404，管理员因权限豁免无法复现。

## Decision

在统一竞赛访问校验入口先将公开编号解析为内部
UUID，再查询赛期、题目关联与参赛成员。解析失败仍拒绝访问。增加公开编号与内部编号判定一致、非参赛者、匿名用户及错误题目均不放行的回归断言。

## Alternatives considered

仅修改前端会遗漏其他客户端；公开题目不会绕过赛中保密规则。两者均不能替代服务端编号解析。

## Consequences

已报名用户可通过正常比赛 URL
加载界面和模板，无需改变题目可见性。保留赛期、成员和题目关联校验，无数据库迁移。
