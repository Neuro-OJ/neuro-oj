# Agent Note: 域首页内容与独立通知入口

Status: implemented

## Problem

域首页只有入口列表与设置说明，没有本域实际内容。教学域的通知按钮指向教学通知，
社区通知却缺少直接入口。助教没有创建班级权限时，导航隐藏了其可使用的工作台。

## Decision

首页加载当前域的统计、题目、比赛，以及获授权教学任务；各区块独立处理加载失败，
引用题继续保留使用域。教学首页可选择学习或教学视角，并直接进入作业、班级和
完整工作台。快捷入口收敛为对应类型的主要任务，其他管理入口保留在导航。

社区和教学通知分别提供按钮、目标地址与未读数量，教学计数从授权接口读取，
通知事件只提示重读。非教学首页不建立教学事件连接。教学工作台对教学域登录用户
提供入口，实际任务仍由后台按班级关系和助教能力过滤，不以创建班级权限替代访问权。
实例关闭班级仅联动关闭作业，不再错误关闭可独立提供的域排行。
删除已无调用者的旧首页自动跳转工具及其镜像测试，保留实际首页行为测试。

272 项组件测试、281 项单元测试、类型、lint 与仓库级门禁通过。真实浏览器验证
公开默认域的题目和比赛内容，教师进入本域首页看到五题型作业 A/B，社区通知地址
与教学通知地址不同。390px 无横向溢出，无 JavaScript 错误，实际截图已检查。

## Alternatives considered

- 首页自动跳去社区或工作台：会丢失明确域首页和加入入口，直接呈现本域内容。
- 一个通知按钮混用两类计数：无法区分需处理的事件，使用明确入口和各自未读数。
- 根据域角色隐藏助教入口：班级助教能力不等于域创建能力，由后端过滤实际任务。

## Consequences

域根 URL 成为可使用的首页；公开、教学和团队资源保持各自权限范围。首页显示错误
与重试，不把服务故障当作没有任务。导航不扩大任何授权，归档和模块限制继续由接口执行。
