# Agent Note: 重复导入复用支持包对象时保留当前引用

Status: implemented

## Problem

题包更新先上传新包、发布数据库引用后回收旧包。本地存储按内容寻址而非上传键命名，相同评测内容返回相同
URL；重复导入因此在成功发布后删除了当前包，后续正式评测报文件不存在。数据库更新失败后的回滚也可能删除复用的旧对象。

## Decision

统一题包更新在新旧 URL 不同的情况下才执行旧包回收或新包回滚清理。复用已有 URL
时保留当前对象，不调整评测预算、支持包权限或下载协议。现有重复导入路由测试验证支持包仍可下载，并注入数据库更新失败验证旧包字节完整保留；全链路导入测试继续实际提交代码。

## Alternatives considered

仅调整 E2E
的包内容以产生不同摘要会掩盖真实问题。禁用所有旧包清理会导致不必要的存储增长。比较实际存储
URL 能兼容内容寻址的本地提供者，同时保留 S3 独立对象的原有发布顺序。

## Consequences

重复导入相同内容保持幂等与可运行；失败时不再破坏复用的当前包。不同对象仍先发布新引用再清理旧对象，回滚保留旧引用。
