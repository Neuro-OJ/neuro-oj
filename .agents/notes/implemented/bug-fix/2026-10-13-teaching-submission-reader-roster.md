# Agent Note: 仅提交读取助教的学生目录与失效题单回归

Status: implemented

## Problem

仅获授学生提交读取的助教可以读取获授权的提交，却无法通过班级学生目录选择学生。题单资源管理新增逐题不可用状态后，教学回归仍要求单题失效导致整份题单不可读。

## Decision

班级成员读取将 `submissions:read` 纳入教学人员能力判定；成员 DTO 继续只向成员管理者提供助教授权。补充仅提交读取助教的测试。题单测试保留整份共享撤销的不可见断言，并将单题失效断言改为无绑定、不可引用、不返回题目标题。

## Alternatives considered

给提交读取助教附带学情或成员管理权限会扩大授权。整份题单在单题撤销时不可读会丢失仍获授权题目的入口，无法展示逐题失效状态。

## Consequences

学生训练目录能够按实际教学权限工作，失效题的来源编号仍可用于教师处理。标准 education 测试通过 96 项，0 失败，2 项 PostgreSQL 专用测试在 PGlite 环境跳过；真实浏览器旅程仍待集成验收。
