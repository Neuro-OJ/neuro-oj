# Agent Note: 修复管理员邮箱搜索与社区摘要重复计算

Status: implemented

## Problem

竞赛参与者管理页提示可按邮箱搜索，但实际调用的普通用户搜索接口只按用户名匹配且不返回邮箱。社区首页把 Markdown 摘要函数放在列表模板中，加载更多或其他响应式更新时会重复处理全部历史帖子。

## Decision

管理员竞赛搜索改用已有的管理员专用全局用户搜索能力，并在结果查询与总数查询中加入邮箱模糊匹配；普通私信搜索接口保持不返回邮箱。社区列表在首屏和分页追加数据进入页面时生成 `preview` 字段，模板只渲染该字段。

## Alternatives considered

直接给普通 `/api/v1/users/search` 增加邮箱字段可以减少前端改动，但会把邮箱暴露给所有可搜索私信联系人的登录用户。移除竞赛页的邮箱提示可以避免误导，却无法满足管理员按邮箱定位用户。社区列表也可以引入虚拟滚动或固定上限，但会增加依赖或改变游标分页的浏览语义。

## Consequences

管理员可以按用户名或邮箱片段准确添加竞赛参与者，邮箱搜索仍受管理员权限和既有限流保护。私信搜索的隐私边界不变；社区历史帖子不再因列表重渲染重复计算摘要，但列表仍保留现有游标分页行为和 DOM 增长策略。
