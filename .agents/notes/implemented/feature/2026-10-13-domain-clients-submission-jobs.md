# Agent Note: 域内升级与重测任务客户端

Status: implemented

## Problem

域题库和提交页缺少升级、重测以及可回访的任务进度，旧管理页只使用默认域接口。
新入口需要保持使用域、来源提交和目标版本，同时服从比赛保密和组织权限。

## Decision

新增 Domain submission-jobs API 层及任务详情页面，受理携带幂等键，条目按服务器分页。
展示持久条目状态、固定目标版本、原因、源提交及升级产生的新提交链接。
自动读取以两分钟和最多 60 轮为上限，终态或读取错误停止；之后可手动刷新。
取消只请求服务器取消尚未派发条目，已经受理的评测继续完成。

题目提供本域整题重测；本人普通／客观提交提供单条操作；组织视图提供本域整场重测。
重测区分原提交版本、源题最新发布版和本域当前所见作答版本指定映射，
不隐式切换题库或比赛策略。个人升级按本域当前作答版生成新提交，不改变原代码／回答和提交时间。
源失效、隐藏反馈、进行中评测或不具创建能力时不提供个人升级；
个人参赛记录需比赛已结束才提供练习升级，保留比赛上下文升级仅出现在真实组织权限视图。

统一账号历史仅在使用域和资源仍可访问时提供所属域详情入口，
失去域权限后的本人历史保持原记录和允许展示的摘要，不提供升级入口。
请求失败保留原内容，相同请求重试沿用幂等键，不切换到默认域接口。

## Alternatives considered

不复用旧管理页的全局读写接口，不在客户端收集全实例提交或循环扫描版本，
不为不存在的 Domain retry 接口提供按钮。策略调整继续使用独立域资源管理。

## Consequences

组件测试覆盖真实受理／读取／条目／取消路径、幂等重试、原内容保留、
指定域版本映射、角色能力与失效来源显隐、旧响应不能跨域导航、
有限轮询、未授权任务不读取条目、取消后的在途状态和新提交定位符。
客户端按现有真实 DTO 显示稳定 ID 与目标版本标识，不额外逐条查询题号元数据。
实际 worker 派发、比赛组织校验及浏览器闭环仍由跨模块验收验证。
