# Agent Note: 域题库与题单共享管理接口

Status: implemented

## Problem

题目和题单已有跨域引用服务，但 Web 管理界面缺少共享设置读取、目标 slug
转换、失效绑定列表和公开来源发现接口。题单详情也缺少编辑能力及可见性，缺目标题库绑定时不能明确区分来源可引用与本域可作答。重复引用已下架题还会让只有导入能力的教学人员恢复管理员禁用的绑定。

## Decision

- 新增域资源管理路由，提供题库绑定分页、来源题号引用、版本策略更新、题目共享读取/保存与公开可引用来源发现。已有下架/恢复路由继续复用
  `If-Match` 和持久变更依据。
- HTTP 共享配置使用 `target_domain_slugs`，在写入事务中解析为稳定
  ID。公开/可发现域及操作者当前成员域可以定位；隐藏私有域不可凭标识被探测。内部服务保留稳定
  ID 参数，供既有服务与测试调用。
- 共享 GET/POST 返回 `enabled`、`scope`、`revision` 和 `target_domains`
  摘要，方便前端按最新 revision 编辑。
- 管理列表保留已下架与共享撤销的绑定，但失效共享题不返回源标题或内容；按源名称搜索同样执行当前授权。只有本人可编辑的题或具有全域管理能力的人员可以读取未发布本域题的管理信息。
- 公开来源发现的分页与计数在数据库按当前授权过滤。题目返回公开来源标识、标题和版本摘要，题单返回公开来源摘要，不包含标准答案、隐藏数据或原始评测配置。
- 题单目录执行域及共享过滤，详情补齐可见性、编辑/共享能力及逐题
  `resource_available` /
  `can_import`。来源题号保持不变；未建立目标绑定时学生不能进入作答页面，具有导入能力的人员可以逐题显式引用。单题撤销保留题单结构和题号，隐藏可作答入口；题单授权撤销后详情及列表立即拒绝。
- 重复导入只在有效绑定上幂等复用；恢复已下架绑定必须具备
  `problem:policy`，不能凭教学导入权限撤销管理员决定。恢复保留原绑定
  ID，并记录新的 revision 与历史依据。

## Alternatives considered

- 让用户输入目标 Domain UUID 不利于核对目标，也容易产生越域枚举；使用 slug
  并在服务端按可读规则解析。
- 从引用题单自动建立全部题目绑定会让独立题库授权和容量变更隐含在题单操作中，首版沿用逐题引用及已有作业发布事务中的显式展开。
- 删除失效绑定会丢失提交、教学历史与恢复依据；管理 DTO
  保留配置，源内容按当前授权隐藏。
- 新增全域通用认证中间件会影响公开做题入口；管理路由逐条认证，通用域中间件只设置禁止缓存响应头。

## Consequences

接口已与 Web 客户端对齐，学生链接始终保留使用域。此批没有修改
Schema、提交执行、UI 或版本控制。组合根挂载由集成工作统一完成。

新增真实 HTTP 回归覆盖共享 slug、隐藏目标域、权限及 revision
冲突、重复引用、独立有效策略、下架/恢复、教学角色恢复拒绝、持久恢复依据、授权撤销后列表和搜索裁剪、题单共享及逐题使用域绑定。标准
`deno task test:domain catalog` 在 PGlite 与独立 PostgreSQL
`test_catalog_resource` 均 365 通过、0 失败；相关路由、服务与测试类型检查和 lint
通过。测试读取共享工作区当时的存储
Schema/hooks，本记录不代替存储配额阶段的验收。
