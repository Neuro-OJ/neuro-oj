# Agent Note: 题库资源下架与恢复

Status: implemented

## Problem

存在版本、共享引用或提交的源题不能物理删除，但管理员仍需要立即停止访问。
仅停止目标域引用也不能影响其他学校。下架不能丢失历史成绩和学生原代码。

## Decision

增加显式域题库状态准备 API，使用绑定 revision、当前资源权限和变更理由。
源题维护者可下架自己的源题，域管理员可治理本域资源；共享绑定状态只由目标域
管理员管理。改变本域展示范围同时同步源题可见性，避免共享与旧入口口径矛盾。

源题下架向所有使用域登记持久教学事件。目标域停用只影响目标绑定。恢复共享
引用重新验证源域、公开状态、共享目标及比赛窗口，沿用原绑定和历史 ID。
所有版本、提交、成绩和变更依据保留，正常新执行读取下架状态后拒绝受理。

## Alternatives considered

- 删除源题及版本：会破坏历史引用，因此使用停用状态。
- 下架时删除学生成绩：与教学追溯要求冲突，因此保留成绩并标记资源不可用。
- 自动新建引用恢复访问：会重复消耗额度，因此恢复原绑定。

## Consequences

不新增数据库字段，沿用绑定停用状态、revision 和不可变沿革。测试覆盖源题
下架立即阻止新请求及题库列表、消费者更新共享作业、保留原成绩及代码、恢复
原绑定，以及目标域独立停用、权限撤销和旧 revision 拒绝。

准备 API 等待全入口隔离验收。存储下载、搜索、SSE 和全部旧入口的撤销审计
仍属于后续隔离工作，本记录不将这些入口标为已完成。

验证：education 在 PostgreSQL 与 PGlite 各 47 项通过，受影响服务及路由类型、
格式、lint 和模块边界通过。后端状态切换测试验证共享作业保留 70 分及学生代码，
源题恢复后再次显示达标，并保留三次状态沿革。
