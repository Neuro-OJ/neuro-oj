# Agent Note: 默认域客户端兼容与原产物授权下载

Status: implemented

## Problem

旧公开页面和编辑表单仍使用没有工作空间前缀的网址，题号标识包含 P／U 分类。
提交任务中的客观题原记录链接也可能指向仅本人可读的详情并离开当前任务页。
本人历史和获授权班级训练可以读取产物记录，但缺少经服务器授权的原产物下载操作。

## Decision

- 使用全局路由中间件在旧页面 setup 前将资源入口转到固定的
  `main`，不使用导航偏好。 旧 P 题号转数字，U 地址拒绝；旧 UUID 和题单公开标识经
  main 的只读兼容门面授权解析。
- 默认导航、题号徽标和管理题库改用域入口，去掉 P／U 用户分类展示和筛选。
  创建页面接受旧 OI／AI／客观题入口的题型提示，不将旧题库分类写入新接口。
- 客观题任务记录在当前页先请求本人详情授权，无法读取其他学生记录时提示班级训练入口，
  不改变本人读取契约，不借管理界面恢复任意学生答案。
- 本人原产物使用统一账号历史下载接口；班级原产物使用带域、班级、提交的下载接口。
  两者共用 useApi 与 Nitro 代理读取 Blob，不返回或拼接存储直链。
  下载错误显示服务端原因，保留详情并允许重试；完成后释放本地临时 URL。

## Alternatives considered

- 从上次使用域推导旧入口：会令同一个旧链接指向不同题库，不能采用。
- 将 U 地址改成同号默认域题目：会错误定位已移除的开发资源，不能采用。
- 让任务页面读取所有学生客观题答案：会扩大本人接口权限，应使用已经授权的教学入口。
- 直接以产物存储地址下载：长期地址会绕过撤权，应由下载请求重新授权。

## Consequences

默认域旧资源入口、本人离域产物入口和班级产物入口具有独立且明确的授权语义。
组件回归覆盖旧入口、错误资源、失败重试、原始二进制、临时 URL 释放及教学能力。
标准单元 265 项、组件 200 项全部通过，Deno／Nuxt 类型检查、格式、lint
和生产构建通过。
此记录只签收上述客户端行为，不代替浏览器真实旅程、窄屏视觉、完整私有域隔离或
原产物服务端权限验收。
