# Agent Note: 阅读详情与独立做题工作区恢复

Status: implemented

## Problem

域题目详情内联了代码编辑器，破坏原来的阅读与做题流程；旧编辑器的提交、草稿、
轮询和自测又依赖全局 API，不能直接用于多域或比赛保密场景。

## Decision

恢复阅读详情，新增普通与比赛独立 solve 路由，作者草稿 editor 路由继续独立。
代码工作区复用原工具栏、活动栏、侧栏、拖拽分隔、Monaco 和状态栏，用现有域
提交、自测与结果组件衔接业务，不调用旧全局执行接口。

客观题、产物及预测保留详情作答，界面题进入独立界面。作业来源参数、来源题号
与返回路径保留使用域。比赛工作区只按固定版本和受理状态提交，不提供赛中自测，
读取结果使用服务器裁剪后的域接口。

草稿按账号、域、题目、版本、语言及比赛隔离。版本刷新不改写输入，变更后显式
确认再切换。侧栏面板保持挂载，切换题面与自测不丢失用例及运行。窄屏侧栏覆盖
代码区，可以返回代码；工具栏压缩次要操作。局部主题颜色改为在使用处解析，
修复暗色变量被根节点提前固定的问题，品牌数值保持不变。

题面公开样例与时空限制补齐比赛固定版本 DTO；不返回完整评测配置。首页数字
动画移至 mounted 后执行，修复恢复 SSR 首页时触发的 requestAnimationFrame 500。

## Alternatives considered

- 直接使用旧编辑器全局提交链：会绕过使用域和比赛版本，因此只复用其视觉组件。
- 给学生代码工作区继续使用 editor 路径：与作者草稿编辑混淆，采用明确 solve
  路径。
- 切换面板时卸载组件：会丢失自测运行，采用保留挂载的视图切换。

## Consequences

详情主要用于阅读，做题进入全屏工作区。后端继续负责版本、授权、比赛保密及执行，
前端不猜测隐藏分数。全题型和赛制的最终验收仍按完整实施清单继续执行。

验证：core 完整类型检查、catalog 397 项及 contest 116 项标准测试通过，后者
PGlite 模式另有 1 项跳过；UI 283 项单元、288 项组件测试和 Nuxt/Vue
类型检查通过。 仓库门禁通过。实际浏览器在默认域 A+B 完成阅读跳转、自测与正式 AC
100 分； 检查版本、切换面板、页面刷新保留代码和运行，390px
页面无横向溢出，页面错误为 0。
