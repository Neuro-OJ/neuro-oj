# Agent Note: 按明确时间窗比较学生训练记录

Status: implemented

## Problem

教师已有任务矩阵、反馈和补题，但缺少可解释的训练前后记录对比。直接比较两个
物化成绩值无法说明时间范围、版本策略或来自哪份提交，容易把缺少成绩误当零分，
也可能把最高分推导为通过或将练习统计解释成能力评价。

## Decision

增加作业内单个学生的训练比较 API，调用方明确选择前后两个带时区的半开窗
`[start,end)`。两窗按顺序且不重叠，返回规范 UTC 边界。题目集合来自已发布作业，
使用当前使用域绑定策略与权威版本结果，并返回策略 revision、默认版本及计算时刻。

查询先限制域、学生、任务题目及时间，复用当前教学提交关系；历史学生只保留原
任务／批注授权依据，不获得后续个人练习。尚未结束比赛和其他域记录排除。每题
返回两窗的提交、合格候选、在途与版本不匹配数量，以及最高分和正式通过各自的
提交、评测尝试、版本和受理时间。通过使用 accepted，不从分数推导。重测或策略
变化读取当前正式版本结果，不依赖异步进度投影，也不改写旧提交。

缺少正式成绩保留 null；两窗都有正式成绩时才计算整数 ×100 分差。汇总仅说明
有成绩、通过及达标题数和候选数量。本人可读，其他用户需要当前 progress:read；
学情能力不额外授予源码权限，响应没有代码、答案或 evaluator 原文。
平台治理读取保存明确域、学生、任务及窗口审计；撤销平台权限后不继续越过域入口。

## Alternatives considered

- 自动将发布前后或截止前后视为训练前后：不能表达实际训练活动范围，改为明确选择。
- 使用原作业截止成绩差值：与本功能比较的训练窗口不同，不采用。
- 所有空成绩按零分计算：会把未评测、版本失效和平台失败伪装成零分，不采用。
- 从最高分推导通过，或给出学习能力评分：与权威判定及首版范围不符，不采用。
- 对每道题请求独立成绩接口：采用一个受范围约束的查询，返回整份任务的两窗结果。

## Consequences

结果可说明来自哪些训练记录，但两个时间窗内的题目／模型／版本环境仍可能不同，
统计不表示能力提升。当前策略改变后历史窗口结果也可能变化，策略依据随响应
展示；不可用源资源保留允许读取的成绩依据并标注资源状态。

真实回归覆盖半开窗边界、最高分与正式通过独立、无成绩不当零分、在途计数、
跨域相同源题、比赛结果保密、any/exact 策略切换、客观题百分制、本人／教练／
仅学情助教权限，以及真实 HTTP 参数与错误域检查。冻结前执行完整 education
PostgreSQL / PGlite 回归、类型、格式、lint 和边界检查。Web 组件与浏览器验收
由独立客户端及整体验收批次完成。
