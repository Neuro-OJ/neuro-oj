# Agent Note: 显式域题库读写接口

Status: implemented

## Problem

新的题库绑定需要按使用域读取内容和管理草稿，旧分类列表、题号入口和源题作者
权限不能直接用于学校题库或共享引用。

## Decision

实现域题库列表、题面、创建、草稿读写和显式发布路由。列表在 SQL 分页和计数
前检查域成员、绑定、源共享、限定目标域、源绑定及比赛保密；读取绑定选择的
不可变版本，引用始终显示来源题号。目标域管理权限不能编辑共享源题，也不能
读取源评测配置；学生客观题内容裁剪标准答案和解析。

草稿写入在同一事务校验当前域关系和 revision。发布复用既有预检和不可变版本
服务，通过事务授权回调在实际写入前重查域权限。未发布题只能从编辑草稿入口
读取，不能从普通题面或列表泄露。

## Alternatives considered

先分页再逐条检查共享会导致命中数泄漏、页内缺项和大量请求。复制版本发布
流程会产生第二套内容事实源。采用 SQL 授权过滤和既有版本服务更直接。

## Consequences

PostgreSQL catalog 352 项通过，含创建、编辑、发布、学生读取、revision 冲突、
错误域路径、共享撤销、目标域 exact 版本和答案裁剪。类型及相关 lint 通过。

当前路由在测试组合根挂载；生产组合根按批准计划等待提交及查询隔离完成后统一
开放。Web 题库页面、下载、提交、题包格式 2 和旧分类移除仍是后续交付，不把
当前接口测试作为完整域隔离验收。
