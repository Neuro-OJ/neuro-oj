# Agent Note: 统一账号的本人跨域提交历史

Status: implemented

## Problem

用户可能在多个学校域练习同一源题，或在离域与源题撤销共享后仍需查看自己的原提交。普通域资源入口的进入检查不能同时承担这份受控历史读取。

## Decision

新增 `/me/submissions` 及 `/me/submissions/:kind/:id`。服务在 SQL 中限定当前账号，并按 `submission` 与 `objective` 保留类型、使用域及源题引用。列表不读取或返回源码和答案；详情仅返回本人原始代码或答案。

题目标题、可用性和域进入能力从当前数据库事实计算。离域或共享撤销后只保留原提交身份、代码或答案及成绩摘要，不开放题面、标准答案、原始评测输出或任意 details。OI 比赛期间，即使用户已离域仍隐藏成绩、判定与通过状态。摘要判定使用现有 OI 枚举投影。

服务提供仅由服务器授权入口使用的 Domain、题型和源题筛选，条件在计数及分页之前生效。客观题域路由继续负责进入权限和路径域一致性。

## Alternatives considered

将本人历史复用普通题目资源权限会使离域用户丢失原作答；绕过域资源授权读取完整旧 DTO 会恢复私有题面或测试数据。保留专门摘要能满足历史读取与当前资源撤权两项需求。

## Consequences

全账号列表可以跨域显示，但不代理读取其他账号。题目共享恢复不会恢复已经丢失的私有域进入能力。服务回归覆盖同源不同域、计数分页筛选、错误账号、共享撤销、离域、OI 赛中和赛后客观题原答案读取。
