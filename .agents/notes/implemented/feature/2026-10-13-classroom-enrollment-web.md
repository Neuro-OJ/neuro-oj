# Agent Note: 班级申请审核与 CSV 导入页面

Status: implemented

## Problem

批量入班准备接口需要供教师明确审阅、执行和保存首次邀请链接的界面，学生申请也需要一个不会开放同学名单的专用入口。

## Decision

班级成员页面接入 CSV
上传／粘贴、空模板、逐行预览、有效行执行及结果下载。修改输入或重签选项后丢弃旧预览；网络重试沿用原哈希、revision
和幂等键，不重复加入或创建邀请。

邀请链接只取本次响应实际提供的令牌，不从历史记录推测或恢复。重试明确显示已执行及令牌仅首次返回，教师可选择重签并重新预览，旧链接随新执行撤销。结果
CSV 对电子表格公式字符转义，令牌不进入浏览器持久草稿。

加入申请页面只显示班级名称和本人申请状态；成员管理人员可以分页审核，批准仅建立学生身份。响应、文件读取或执行期间切换域／账号／班级时不把旧结果应用到新页面。

## Alternatives considered

- 输入修改后继续使用旧预览：会改变已审阅名单的含义。
- 自动重签以掩盖网络中断：会让已经发出的链接突然失效，采用显式重签。
- 在普通班级详情中开放申请者访问：专用页面不开放教学内容和同学名单。

## Consequences

准备页面与后端已接入单批 500
条上限，仍等待完整域隔离后开放教学入口。浏览器旅程、满批负载和通知联动不以组件测试替代。组件测试覆盖逐行预览、稳定重试、输入变化失效及身份切换，单元测试覆盖安全
CSV 输出和缺失令牌不恢复。
