# Agent Note: 默认空间停用时独立处理私信举报

Status: implemented

## Problem

旧平台举报列表包含默认域社区内容和账号私信。后端分别验证两种归属后，默认
混合列表需要 main 社区权限；前端没有私信专项筛选，并将授权错误静默显示为空。

## Decision

举报页面增加帖子、评论和私信筛选，私信明确传递 `content_type=message`，
沿用账号治理权限，不回退到默认混合列表。展示读取失败的真实原因；切换筛选
清除上一范围的列表，旧范围请求返回后不覆盖当前结果。

## Alternatives considered

- 默认列表失败后自动改查私信：隐藏实际授权范围，改为用户明确选择。
- 将权限失败展示为零条举报：可能误导管理人员，展示后端原因。

## Consequences

组件测试真实覆盖默认 main 读取被拒绝、选择私信后的三状态查询参数和错误 清除，1
项通过。Nuxt / vue-tsc 类型检查、受影响文件格式和 lint 通过。 后端对应
PostgreSQL / PGlite HTTP 回归有独立治理记录；本批不把组件检查计为
浏览器治理旅程通过。
