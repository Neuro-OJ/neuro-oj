# Agent Note: 域批量提交任务与流式产物执行闭环

Status: implemented

## Problem

批量升级与重测需要使用提交所属域的绑定和当前权限，不能经过旧默认域入口换用源域策略。流式产物必须在写入每批字节前预留域容量。普通本人提交目录不能展示全实例私有域的排队活动量。

## Decision

新增显式域批量任务创建、详情、条目列表及取消路由。受理固定目标版本和提交集合，所有新任务及条目写入可信域与绑定；幂等作用域包括域、操作者和操作类型。升级使用本域当前作答版本，重测继续支持提交时版本、源题最新版本或指定版本。策略变更通过 catalog 公共门面与任务在同一事务受理。

首次执行在外部准备前及创建尝试事务内重新检查源共享、域状态、当前角色、原学生进入能力及比赛窗口。已创建尝试允许恢复和完成。取消跳过尚未创建尝试的条目，不重写已受理评测。普通代码、自测、产物和两种升级副本接入域频率限额，升级遇到分钟额度不足延期。

旧任务即使没有 `domain_slug`，也从持久任务的域 ID 读取稳定 slug；NULL 旧归属固定为 main，同样检查当前 Domain 进入和角色。扩展迁移期间 main 的未绑定历史行仍经当前 catalog 授权，不继承旧平台业务权限。测试夹具显式建立实际重测操作者的域管理员角色及原用户的编辑者身份，不使用生产授权例外。

流式产物按最多 1MiB 的实际字节批次增长持久预约后才写入。上传完成先独立登记物理对象与预约定位，再在提交业务事务结算。失败通过已有引用守卫补偿并释放预约，崩溃保留可供恢复盘点的定位记录。

`upgradable` 筛选及提交 `is_latest` 依据使用域当前作答版本；普通读取的实例全队列位置与长度返回 null，仅平台明确管理视图保留。

原比赛上下文升级在受理与首次执行时均要求当前比赛组织权限，普通本人练习升级继续可用。域任务条目批量提供新提交 ID、域 ID 和绑定 ID，供完成后进入新提交；不附带源内容或隐藏成绩。

## Alternatives considered

复制提交与 Judge 链会产生两套结果回写系统；直接按源题最新版升级不能满足目标域 exact 策略；仅在上传完成后检查容量会使并发上传超额。继续复用原任务 planner、持久 worker、尝试与存储引用守卫。

## Consequences

错误域路径及错误域提交 ID 返回不可访问结果。源题撤销或原学生离域后，已排队但尚未受理的执行失败，不改变原代码与判定。域限额与账号既有限流同时生效。回归包含两域同键隔离、版本策略独立、取消、共享撤销、离域、事务回滚、真实 Local 上传容量拒绝与失败补偿，以及 Redis 不可用时禁止新执行。

旧默认域题库策略 setter 的全局字段清理作为后续独立改动处理；本记录不宣称完成该兼容入口的迁移。
