# Agent Note: 三种邀请与实例配置页级保存

Status: implemented

## Problem

原邀请只支持指定邮箱的一次性链接，无法用于班级群分发。实例政策逐字段保存，
同页修改会产生多个独立结果，成员目录也固定每页 100 条。

## Decision

指定邮箱、通用和一次性邀请共用域与班级的成员加入事务；链接与随机短码只存哈希，
共享使用人数、有效期和撤销状态。每个账号的兑换记录保证重复请求不重复计数，
加入失败不消费名额。默认有效期 7 天；注册仍受实例政策及签发者当前权限约束。

实例配置按功能分组读取，版本来自数据库值及更新时间，在事务内锁定并校验后
整体保存。提交后重新加载本地配置并广播重新加载，沿用现有注册表和审计。
成员查询支持关键词、可选每页数量和一致的计数条件。

## Alternatives considered

不为每种邀请另建加入流程，也不复制账号注册系统。未采用前端串行提交各字段的
伪页级保存；未新增进程内版本号或邀请码使用计数。

## Consequences

新增标准生成迁移与 PGlite DDL，已有邮箱链接继续使用。完整凭据只在创建时返回，
历史目录不提供再次读取密钥的能力。单次消费语义调整为同一账号重试返回既有成功，
不会重新授予已撤销的成员关系。相应工作空间测试覆盖并发名额、失败回滚及设置冲突。
