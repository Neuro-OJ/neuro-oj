# Agent Note: 域题库版本沿革与功能导航

Status: implemented

## Problem

域题库已有版本元数据接口，但学生无法在 Web 阅读发布沿革。
工作空间仅提供概览、成员和设置入口，已实现的域题库、提交、比赛和教学页面难以进入。

## Decision

- 题目页按需加载分页发布沿革，只展示版本号、时间及更新说明，标记使用域策略决定的当前作答版本。
  查看沿革不切换作答版本，不读取旧版本内容，也不构造源域下载入口。
- 域导航与概览快捷入口统一按目标域构建，包含题库、比赛、登录用户本人提交、已启用的教学功能，
  LLM 与域管理按当前域能力显示。不同域角色不会共用导航权限。
- 现有班级内入口继续提供教学工作台，以支持只有班级教学能力而没有域教学角色的人员。
- 检查 IDE 结果流程时修复隐藏回执继续等待终态造成的超时：隐藏结果立即结束轮询，
  只显示中性受理信息；汇总模式不打印原始输出。

## Alternatives considered

没有为了快速串联页面将链接指向旧全局题库；所有入口保留使用域。
没有将历史发布列表做成任意旧版本作答选择器，以避免绕过域有效版本策略。

## Consequences

导航与版本沿革客户端代码已实现。准备接口将在完整隔离验收后统一挂载；
导航源码不代表所有路径已对普通用户运行开放。真实浏览器旅程、移动端呈现和共享撤销验收继续跟踪。
