# Agent Note: 受控原提交产物下载

Status: implemented

## Problem

教学和本人历史需要下载已受理的原产物。存储直链会绕过当前班级授权，整文件读取也会让大型
ZIP 下载占用过多内存。

## Decision

local 和 S3 Provider
提供流读取，服务器下载门面在确认对象存在后传输原字节，返回附件、长度和
private/no-store 头，不返回对象地址或重定向。

教学入口复用班级源码授权、固定助教能力及比赛窗口检查。本人历史入口仅接受当前账号自己的不可变提交
ID，不接受代理目标用户。源题撤销不删除已有原提交；离域后本人历史仍可下载原产物，教师撤权立即失去班级入口。本人历史
DTO 只增加是否存在原产物的布尔字段。

## Alternatives considered

不向浏览器返回 S3 预签名链接，不下载题目支持包，不把整个 ZIP
载入内存。在线文本预览继续使用已有 ZIP
安全限制；下载传输的是原提交文件，不进行解包。

## Consequences

实际应用测试覆盖助教能力、教师及学生撤权、源题停用、本人保留、非本人拒绝和对象丢失。education
标准测试 PGlite 101 项通过、2 项忽略；隔离 PostgreSQL 与真实 MinIO/S3 102
项通过、1 项性能专用忽略。共享测试 293 项通过、16
项环境专用忽略，包含流读取及取消释放文件句柄。浏览器下载交互仍待客户端和完整旅程验收。
