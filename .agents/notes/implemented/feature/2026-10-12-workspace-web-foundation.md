# Agent Note: 工作空间 Web 管理与邀请入口

Status: implemented

## Problem

已完成的工作空间治理接口缺少 Web 操作入口。继续使用全局导航、无域缓存或
浏览器当前域，会使切换页面与延迟确认请求之间串用身份、资源或管理目标。
邀请注册也需要保留正确空间入口，并遵守统一账号和实例注册政策。

## Decision

增加空间目录、域布局 / 概览、成员、加入申请审核、角色 / 邀请 / 交接及设置页面。 布局解析一次 URL
上下文并注入子页面；缓存包含域和账号，实际响应身份必须匹配。
切换期间停止使用旧权限，确认及请求结果检查原操作空间、账号和组件生命周期。
暂未完成隔离的资源和搜索不从新域菜单调用旧接口。

设置保存携带原编辑 revision，409 保留修改；模板差异必须预览及确认。 复制配置时拆出独立 features
对象，避免响应式代理克隆错误或直接修改服务端事实。 配额保存不清除基本设置草稿。邀请令牌通过 fragment 进入认证页并使用
POST 请求体预览；受邀邮箱固定，已有账号可登录、完成两步验证并接受邀请。 本站安全回跳及私有实例单可用域入口接入登录，JWT
不保存当前域。

## Alternatives considered

- 每个页面独立请求上下文：共享刷新时可能重复挂载，布局提供一份解析。
- 全局 currentDomain 状态：两个标签页和延迟动作可能互相改变归属，明确使用 URL。
- 自动采用更新后的 revision 重试：会覆盖并发配置，保留草稿并显示冲突。
- 邀请放在查询参数：增加日志和 Referer 暴露，采用 fragment 加 POST。

## Consequences

标准单元测试、组件测试、完整 Nuxt / Vue 类型检查和构建覆盖当前管理外壳； 组件测试包括实际 Vue 响应式
props、草稿冲突、模板预览、身份不一致、切换期间 取消操作及单空间切换器。品牌组件复用现有 Nuxt UI 和管理组件。
当前连接无法打开本地网页，浏览器交互及窄屏验收尚未完成，不将这些测试计为
浏览器旅程通过。完整实例治理、域资源、LLM、比赛和教学仍按升级计划实施。
