# Agent Note: 班级与我的学习展示关联竞赛

Status: implemented

## Problem

班级关联竞赛已有创建和榜单分组功能，但学生无法从班级或教学中心发现关联竞赛。

## Decision

扩展域竞赛列表，以班级或当前账号的有效学生身份筛选关联关系，在计数和分页前使用
EXISTS 去重。保留竞赛原有可见性与报名授权。共用展示组件用于班级概览和教学中心
“我的学习”，展示状态、时间、关联班级与详情入口。缓存键包含域、账号、班级和页码。

## Alternatives considered

不在前端逐班请求后合并；该方式会造成重复、错误总数和不完整分页。
不自动报名，不因关联班级放宽邀请赛访问条件。

## Consequences

无需数据库迁移。退班、域成员资格撤销及班级归档在后续请求中即时生效。
域服务测试覆盖分页前过滤、跨班去重、私有竞赛保密和退出班级后的结果变化。 本机
preview 的示例竞赛使用既有已发布客观题，可直接报名作答。
