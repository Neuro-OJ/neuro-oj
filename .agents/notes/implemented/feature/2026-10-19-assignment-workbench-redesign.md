# Agent Note: 作业详情页重组为批阅台

Status: implemented

## Problem

作业详情页把作业头、管理折叠区、7 个筛选控件、成绩矩阵、两张反馈卡与历史入口以近似
相同的视觉权重平铺在一列，首屏缺少清晰的阅读顺序；矩阵单元格重复「100 · 已达标」
文本，没有列达标率、状态图例或键盘漫游；面包屑直接显示作业 UUID；反馈/求助与
管理操作同时占据页面纵向空间，教练需要反复滚动定位。

## Decision

- 教练视角收敛为「学情矩阵 / 反馈与求助（待处理角标）」双标签。页头只保留标题、
  阶段徽标、班级、题量、截止/发布时间与单一「管理作业」入口。
- 矩阵工具条保留统计范围分段、搜索、筛选、导出与刷新；其余筛选收进可折叠面板，
  仅在非默认筛选时显示筛选计数与清除入口。矩阵改为纸面成绩表：列头同时显示题号、
  题名、达标要求与列达标率，单元格以「✓ 100 / 琥珀点 20 / —」编码状态，并显示
  行达标数与状态图例；桌面支持方向键在单元格间漫游。
- 作业管理操作（发布/截止/归档、复制、补题）与版本策略记录移入右侧抽屉；单元格
  抽屉提供「写反馈给该生」，直接切到反馈标签并绑定反馈对象、打开表单。查看单元格
  本身只打开提交抽屉，不自动绑定或展开反馈；反馈发送或「改为全班」后清空对象，
  取消反馈会丢弃草稿。
- 反馈与求助改为单面板：反馈时间线与求助收件箱按实际能力成栏（只有一栏时占满
  全宽），默认只显示列表，写反馈/求助由按钮显式展开；求助行展开后在原位展示全文，
  回复框与回复列表跟随各自问题在其下方展开，可同时展开多条且互不影响，不再把回复框统一放到列表底部；
  求助详情、回复分页与「标记已处理」都由单条求助线程独立管理。求助可关联作业题目：学生可从题目行
  直接「求助」，表单也可选择涉及题目，提交时携带 `item_id`；教练收件箱与详情显示
  题号与题名，教练点击题号可直接打开当前域题目页，未关联的旧求助明确标注「未关联题目」。
- 学生视角共用页头、标签与反馈面板，进度标签内以题目行为主体，训练比较与版本依据
  降为次级文字入口；没有作业管理权限的读者（学生、只有学情权限的助教）在页面尾部
  可打开只读版本依据，`?history=1` 对他们同样生效。
- 面包屑按作业标题回填，页面宽度与其他教学页统一为 72rem。数据请求、权限判定、
  轮询、通知刷新、CSV 导出语义与 `?help=` / `?feedback=` / `?history=1` 深链保持
  原有行为。

## Alternatives considered

- 单页降噪：保留所有区块同屏，只压缩筛选栏和反馈卡样式。改动小，但仍把管理操作、
  矩阵与反馈放在同一阅读层级。
- 矩阵 + 右侧待办栏：宽屏下反馈始终可见，但会持续压缩矩阵宽度，题目列多时需要
  横向滚动。
- 保留管理折叠区：减少一次点击，但折叠区仍占据页头下的主要位置，且管理动作与
  学情阅读混在一起。

## Consequences

- 页面阅读顺序变为「作业头 → 说明 → 性质标签 → 矩阵/进度 → 反馈」，首屏只回答
  学情；管理动作与历史多一次抽屉交互。能力不完整的角色不再看到无权限的空栏；
  移动端矩阵逐题展开后整行可点，提交抽屉成为明确入口。
- 组件测试同步改为稳定选择器，并在测试替身中登记面包屑 composable；矩阵新增
  无障碍单元标签断言。
- 未修改 API、权限、数据库或评测协议；矩阵与反馈仍使用原有视图 BFF 与细粒度接口。
- 定向反馈入口从页面内常驻表单改为抽屉内按钮，教练需要重新适应入口位置。
