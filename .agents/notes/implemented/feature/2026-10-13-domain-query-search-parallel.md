# Agent Note: Domain 查询、搜索与公共主页隔离

Status: implemented

## Problem

旧排行榜、公开统计、个人主页和搜索使用全实例提交或异步索引事实。
公开源题被学校引用后，私有域提交可能增加公开通过数；撤销共享后，
索引和旧统计缓存仍可能暴露内容。未结束比赛的结果还可能经搜索关键词、 榜单和 SSE
获得。

## Decision

显式域提供 stats、rankings、rankings/me、search 和提交统计 SSE。
旧统计、排行和资源搜索固定 main；用户、私信和实例公告搜索保持统一账号
入口，单独搜索这些账号资源不依赖进入 main。平台管理仪表盘继续用于实例治理。

排行与统计在聚合、分页前读取当前 Domain、源题绑定可用性和比赛公开窗口。
公共主页无论本人或平台管理员查看，都只聚合公共 main 的允许数据；
关注关系继续属于统一账号。公开榜单读取即时查询，不复用全域物化榜；
旧榜单刷新工具保留供现有管理与验证流程使用。

搜索索引新增源 Domain 归属；索引只提供候选，授权读取源题、帖子、评论、
比赛、提交和私信当前事实。目标域引用公共题可命中源题候选，撤销源共享、
停用引用或移除教学关系立即过滤。教练查看学生提交调用教育公开门面，
未结束比赛提交不会进入搜索，包含对状态关键词与命中分页的过滤。

比赛索引仅包含比赛摘要，不索引题目集合。既有比赛索引在读取时以当前
比赛说明重建匹配词向量，并移除赛题 metadata，确保不依赖重建索引消除旧泄漏。

统计 SSE 按域分频道，事件只作为更新信号。每次实时推送与持久重放重新
解析成员访问权限、重算允许字段，不转发事件中的 score、代码或任意载荷。
离域后私有长连接关闭。提交结果通知的域归属由可信源提交提供。

## Alternatives considered

仅给旧物化榜和 Redis 统计键增加 Domain 维度不能处理源共享实时撤销，
且旧物化榜本身仍汇总私有域，故当前读取直接使用带授权条件的数据库聚合。
只在索引消费者中过滤不能覆盖处理延迟或服务重启；分页后过滤也会泄露
命中数、has_more 并导致短页，故授权条件进入搜索 SQL。
将私信和关注改为域关系与已确认账号模型不符，未采用。

## Consequences

当前默认域兼容入口执行新的授权与保密口径。Domain 路由仍由应用组合根
统一挂载，不在本批提前开放未完成的整个平台入口。

PGlite query 31 项通过、6 项仅 PostgreSQL 检查忽略； 独立 PostgreSQL test_query
37 项全部通过。search 两个数据库各 35 项通过， 1
项环境条件测试忽略。新增用例覆盖同源题三个域独立、实时共享撤销、
停用单绑定、教练离职及学生离班、OI 搜索状态隐藏、旧比赛索引题号旁路、 统计 SSE
持久重放裁剪和成员撤权。公共主页新增测试覆盖本人及管理员视角
均不聚合私有学校提交或社区活动。identity PGlite 313 项通过、26 项环境条件
测试忽略；独立 PostgreSQL test_identity 339 项全部通过，包含既有赛前题解
