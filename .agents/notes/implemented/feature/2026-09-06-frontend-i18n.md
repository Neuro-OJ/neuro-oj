# Agent Note: 前端中英双语基础设施

Status: implemented

## Problem

NOJ 前端的认证、题库、提交、竞赛和公告页面文案固定为中文，后端错误信息也会直接显示，无法满足英文使用场景。

## Decision

使用无路由前缀的 SSR 安全轻量 i18n：通过 `noj:locale` Cookie 持久化语言，`useI18n` 提供响应式翻译；通过顶部按钮切换中英文。已知 API 错误码在前端集中映射为本地化文案，统一 API 层按照当前语言生成 toast。

## Alternatives considered

- `@nuxtjs/i18n`：路由和 SSR 能力完整，但当前项目未安装该模块，增加依赖与语言前缀会影响既有 API 代理和链接，故暂不采用。
- 机械替换全部页面：覆盖面更大，但会增加回归和维护风险；本次先覆盖核心用户链路，保留可扩展字典。

## Consequences

语言切换不改变 URL，现有路由、Nitro 代理和 Monaco 无需改造。低频管理/社区页面仍可能显示中文，后续可按 `utils/i18n.ts` 的 key 逐步迁移。
