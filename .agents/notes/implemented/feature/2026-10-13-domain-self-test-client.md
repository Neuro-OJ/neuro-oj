# Agent Note: 域代码自测与结果读取

Status: implemented

## Problem

域题目作答缺少代码自测入口，旧自测轮询依赖全局地址，不能保证目标域归属。

## Decision

- 普通域代码题新增自测面板，创建携带当前代码、语言和所见版本，使用显式域 API。
  OI 自测支持公开样例、自定义输入、可选预期输出及启用选择，空预期输出与未开启比较分别表达。
- 自定义用例按账号、域、源题、版本和语言保存。版本冲突保留代码输入并刷新题目，确认后才继续。
- 结果轮询和取消都走同域读取接口；取消后继续以服务器状态为准。新建独立自测详情页可再次读取原记录。
- 展示专门授权的自测 stdout/stderr 和编译诊断，不打印任意 evaluator details。
  源资源撤销后隐藏详情及输出，保留授权摘要与原代码；自测明确不计入作业正式成绩。

## Alternatives considered

没有复用旧全局自测读取和取消路由，避免旧入口变成其他域读取旁路。
没有复用比赛作答自测入口；比赛期间的同题练习限制仍由后端统一阻止。

## Consequences

客户端代码、协议和呈现测试已实现。真实 Judge 自测、公开样例执行和浏览器取消流程仍待统一验收。
没有提供产物或客观题的自测入口，沿用既有代码自测能力；正式提交系统独立处理这些题型。
