# Agent Note: 独立任务复制与部分学生补题草稿

Status: implemented

## Problem

已发布作业的题目集合和达标要求不能直接修改。教师需要将原任务复制为独立草稿，
选择部分题目或部分学生，再预览并发布；重试不能重复创建补题。

## Decision

新增带 revision 和幂等键的复制服务与准备 API。复制重新检查操作者的当前教学
权限、使用域题库授权和目标学生，只允许选择原任务条目，按原顺序生成独立草稿。
保留来源任务 ID 和达标要求，不复制发布版本依据、实际接收者或成绩。
默认不计发布前提交，可由教师明确开启。复制和普通创建共用一个事务写入过程，
不调用另一个根事务，以免重复取得班级锁。

## Alternatives considered

- 修改原已发布任务：破坏学生看到的发布依据，因此创建新任务。
- 复制原进度和接收关系：掩盖补题期间的实际练习，因此新任务重新发布和计入。
- 以两次独立事务创建和登记幂等结果：重试可能重复，因此共用业务事务。

## Consequences

PostgreSQL 与 PGlite 教学测试各 18 项通过，覆盖复制幂等、部分学生、来源与
要求保留、草稿依据清空、学生越权、错误条目和独立发布。受影响类型、格式和 lint
检查通过。公开题单展开、实时成绩、Web 补题筛选仍待后续交付，生产准备
路由尚未开放。
