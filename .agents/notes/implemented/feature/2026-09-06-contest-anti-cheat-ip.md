# Agent Note: 竞赛提交 IP 关联基础

Status: implemented

## Problem

竞赛缺少可供管理员复核的提交来源 IP、同 IP 多账号关系和提交时间线。客户端伪造代理头时不能把伪造值写入风控数据。

## Decision

提交创建时复用可信代理解析器，仅将安全解析出的来源 IP 写入提交记录；未知或不可信来源不落库。新增受 `contest:anti_cheat_read` 保护的同 IP 账号组和时间线查询，接口不返回邮箱、源代码或评测输出。IP 默认保留 180 天，后台任务只清理 IP 字段。代码相似度暂不自动判罚，后续只做离线候选和人工证据。

## Alternatives considered

- 信任客户端 `X-Forwarded-For`：实现简单，但可伪造，会导致错误关联和规避风控，拒绝。
- 将 IP 暴露给普通用户或公开提交接口：违反最小披露原则，拒绝。
- 立即自动封禁或取消成绩：同 IP 存在 NAT/共享网络误报，且缺少申诉证据链，拒绝。

## Consequences

管理员可以对竞赛内关联线索进行人工复核；IP 属于敏感数据，部署必须正确配置 `TRUSTED_PROXIES` 并按隐私政策设置保留期。第二阶段代码相似度仍未实现。
