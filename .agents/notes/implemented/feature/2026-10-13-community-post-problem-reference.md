# Agent Note: 社区帖子携带来源题号

Status: implemented

## Problem

域社区题解详情只有源题 ID 和标题，客户端无法据此生成保留使用域的数字题号
链接。额外加载完整题库会增加请求，也容易把引用题误导回来源域。

## Decision

已授权的帖子详情查询同时读取来源域与数字编号，通过 catalog 公开门面构造
problem_reference。引用题显示来源域数字，客户端继续以帖子所在域生成作答链接。
不关联题目的普通讨论返回 null，原 problem_title 和帖子 ID 保留。 使用同一 SQL
查询，不额外读取题面或评测内容；内部关联对象不进入 DTO。

## Alternatives considered

- 在前端再次查询题库：需要额外请求，详情已具备必要关联。
- 拼接 UUID 或旧 P 前缀：与域内编号及引用展示契约不符。

## Consequences

真实域 HTTP 回归检查引用来源、使用域、无题讨论和错误域 404。字段只提供
定位，不授予题面、版本或提交权限，当前资源授权仍由既有入口检查。
