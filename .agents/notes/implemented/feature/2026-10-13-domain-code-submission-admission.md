# Agent Note: 使用域普通代码提交与域内比赛练习限制

Status: implemented

## Problem

旧创建入口仅解析默认域。共享题在学校域无法保存独立提交归属；旧提交读取也没有按使用域拒绝记录。域题库使用全实例公开比赛保密事实，会使学校引用题比赛影响公共源域。

## Decision

增加显式域普通代码提交准备接口，以 URL
域及来源题号解析源题、使用绑定和当前作答版本，复用现有提交、尝试、Judge
任务和正式结果写入。客户端版本过时返回冲突，不静默切换代码所属版本。

外部准备后，在写入事务按稳定 ID
锁定使用域及源域，再锁源题和绑定，重新检查成员、状态、共享授权、默认版本与比赛限制。提交保存不可变使用域和绑定，评测投影采用该绑定策略。未配置使用域
LLM 执行链时明确拒绝，不能使用公共 Provider。

公开比赛保密在域题库读取中限定源题所属域。同域在赛选手不能从普通入口重评赛题；其他使用域及公共源域保留独立访问。旧提交列表、详情和单条队列状态只读取默认域及未回填的旧记录。

## Alternatives considered

- 在学校复制源题：保留不可变版本与源题 ID，以使用绑定区分策略。
- 按全实例源题 ID 禁止练习：限制属于当前使用域的比赛及参赛者。
- 从旧默认域入口接受任意域参数：新增显式入口，旧入口固定默认域。

## Consequences

普通 AI 代码提交与域内版本、共享、评测归属测试通过。PostgreSQL submission 模块
339 项通过、10 项跳过；PGlite 309 项通过、40
项跳过。新增案例包括两校独立策略与成绩、旧入口拒绝、撤权、归档、事务复查和比赛域范围。真实
Judge 执行及完整浏览器旅程尚未验证。

准备路由暂未在组合根开放。产物、客观题、自测、任务、完整查询和统计隔离、域内 LLM
及全部配额继续实施；本记录不代表第三阶段签收。
