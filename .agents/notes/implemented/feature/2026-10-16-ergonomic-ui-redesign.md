# Agent Note: 全站界面人体工程学焦点与视觉层级重构

Status: implemented

## Problem

原版前端在空间门户首页、题库列表、题目详情、提交判定及排行榜等页面存在容器过度嵌套（单一体容器混排无关业务）、操作热区层级不突出（如“开始编码”与辅助按钮缺乏明确主次权重）、缺乏吸顶辅助导航（长题面滚动后操作断层）、表格与指标未充分利用等宽数字（`tabular-nums`）导致视线扫视疲劳，以及通知角标与快捷键未提供清晰感知等问题。

## Decision

1. **容器与呼吸节拍解耦**：
   - 首页彻底打破单一巨型外壳容器，解耦为轮播签到 Hero
     区、独立空间加入引导栏、公告与教学待办卡片、双列推荐与实时评测流；
   - 页面统一遵循 4px 基础增量的节奏间距体系。

2. **核心操作人体工程学聚焦**：
   - 导航顶栏增加 `Ctrl+K` / `⌘K` 快捷键感知徽章与未读消息高饱和度圆点药丸；
   - 题目详情页采用黄金分割网格，右侧操作侧栏启用 `sticky top-20`
     吸顶能力，“开始编码”作为第一优先级 CTA 按钮以 primary
     色突出，消除长题面阅读后的滚动疲劳；
   - 题库与比赛列表集成操作按钮与统计徽标至同一标头行，减少无效纵向占用。

3. **数据可读性与状态信号体系**：
   - 评测结果详情页重塑为沉浸式判定大卡片（信号绿 Accepted、警示红
     WA/TLE、琥珀黄 Pending），搭配用时、内存与得分的数据胶囊；
   - 排行榜增加前三名奖章徽标、突出个人当前名次横幅，表格全面采用等宽数字
     `tabular-nums`。

## Alternatives considered

- **全量重写为全新视觉设计语言**：原设计在 main 提交 `cc05af79`
  已确立恢复原版直观风格的目标，推倒重来会破坏存量用户习惯与品牌承诺。
- **仅修改局部 CSS 类名**：无法解决外层 DOM
  容器过度嵌套与操作按钮行流错位的结构性体验问题。

## Consequences

- 前端全部 286 项测试保持通过，静态检查 `deno lint` 与格式化 `deno fmt` 零警告；
- 用户在桌面端与移动端获得一致、清晰、低认知负荷的解题与竞赛浏览体验。
