# Agent Note: Web 作答保留作业来源

Status: implemented

## Problem

学生从作业进入普通题目页后，提交只记录使用域和题目，无法还原实际入口。
服务端已支持同一事务验证并保存作业来源，Web 需要传递这份上下文。

## Decision

进行中已发布作业的有效接收者通过「继续练习」进入题页时，网址携带作业与条目
ID。代码、客观题和自测在既有 JSON 接口传递来源；产物上传在请求查询参数中
传递，避免流式上传等待文件之后的表单字段。

题页版本切换保留代码和入口上下文，仍由服务端验证来源与当前域、学生、题目
及绑定的关系。历史或关闭教学后的练习使用普通题目入口。
域内提交和本人跨域历史展示保存的来源；失去域访问权时不生成作业导航。

来源用于还原入口，不限制一个合格提交自动计入多份同域作业，也不授予结果读取
权限。作业成绩仍由教学模块独立计算。

## Alternatives considered

- 为作业另建提交接口：重复现有评测与客观题受理流程，不采用。
- 在浏览器保存全局「当前作业」：双标签页会相互影响归属，改由网址携带。

## Consequences

Web 单元测试 266 项、组件测试 223 项通过；Nuxt 类型检查、Deno 类型检查、
lint、格式检查和生产构建通过。组件回归覆盖版本切换后代码及来源保留，以及
失去域权限后的历史导航。真实浏览器的来源传递仍需使用更新后的 core 与 UI
执行，以上检查不代替该项验收。
