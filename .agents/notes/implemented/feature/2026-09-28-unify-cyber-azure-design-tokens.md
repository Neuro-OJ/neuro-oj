# Agent Note: 主站全站配色与设计体系对齐 noj-docs（Clean Cyber Azure）

Status: implemented

## Problem

此前 NOJ 主站（`noj-ui`）采用早期的「暖纸评测风」，页面底色为偏土黄灰色的
`#e8e8e2`，卡片与面板使用 `#f2f2ec`，主色为极深蓝黑墨
`#1B2B4A`。然而在实际开发中：

1. 页面中许多组件混用了纯白底色（`bg-white`），导致与 `#e8e8e2`
   的纸底产生突兀的脏色视觉反差，界面不协调；
2. `#1B2B4A`
   在亮色背景下过深，与常规正文几乎无法区分，作为链接、激活导航项或图标时缺乏视觉导向与科技活力；
3. 文档站（`noj-docs`）此前已率先演进并采用了现代高对比度的「Clean Cyber Azure
   (浅蓝科技调)」（清爽天青底 `#f5f8fc`、纯白面板 `#ffffff`、天青蓝
   `#0284c7`、工科评测信号绿
   `#059669`、微点阵背景网格），主站与文档站之间存在设计漂移，视觉语言割裂。

## Decision

参考 `noj-docs`
的设计语言与色彩规范，对主站（`noj-ui`）的配色、设计语言和设计系统进行统一升级：

1. **统一设计语言为「Clean Cyber Azure (浅蓝科技调)」**：
   - 页面背景更新为清爽天青浅蓝底（`--c-bg-page: #f5f8fc`）；
   - 卡片与面板统一为纯白高对比面板（`--c-bg-panel: #ffffff`）；
   - 沉底块与表头、代码背景采用浅蓝灰层级（`--c-bg-sunken: #edf2f9`）；
   - 边框与分割线统一为晶莹淡蓝灰（`--c-border: #e1e8f2`）；
   - 页面级容器注入与 `noj-docs` 一致的 28px 科技点阵微底纹（`radial-gradient`
     网格，类名 `bg-tech-grid`）。
2. **重塑文字与品牌对比度体系**：
   - 文字排版全面对齐 Slate 梯级：正文 `--c-text: #0f172a` (Slate 900，对比度
     17.5:1)，次要文字 `--c-text-secondary: #475569` (Slate 600)，弱化文字
     `--c-text-muted: #64748b` (Slate 500)；
   - 品牌主色升级为活力天青蓝 `--c-primary: #0284c7`（Sky 600，深色模式
     `#38bdf8`），并更新完整的 50–950 色阶与悬浮背景；
   - 评测信号绿升级为标准 Emerald 工科绿 `--c-signal: #059669`（深色模式
     `#00e07a`），保证白底上的 WCAG AA 易读性；
   - 保持 2–6px 近直角工业美学规范（默认 4px），数值文本统一启用
     `tabular-nums`。
3. **顶栏与各模块视觉微质感协调**：
   - 导航栏（`Navbar.vue`）升级为半透明毛玻璃质感（`bg-white/80 backdrop-blur-md`）；
   - 导航激活态改为柔和淡蓝胶囊底（`bg-primary-bg text-primary font-semibold`）；
   - 首页轮播渐变预设（`carouselGradient.ts`）由暖灰色调重构为清爽现代的天青、翡翠、紫罗兰、夕阳和微风渐变；
   - 首页签到卡与暗色沉浸
     Hero（`contests`、`trainings`、`about`）统一为深海科技黑底（`#0b0f19` /
     `#131b2e` / `#070a12`），配合天青与信号绿光晕。
4. **设计规范与文档同步**：
   - 同步更新单一事实来源 `dev-docs/design/noj-design-tokens.md`、根目录
     `AGENTS.md` 及 `noj-ui/AGENTS.md`。

## Alternatives considered

1. **仅修改主站背景色，保留 `#1B2B4A` 品牌蓝**：
   - 评估：`#1B2B4A` 亮度极低（L <
     15%），在高对比浅蓝底上极易被误认为黑色文字，丧失作为交互重点、按钮和导航激活态的提示作用。天青蓝
     `#0284c7` 在文档站已得到验证，兼具活力与可读性。
2. **两站分别保留暖纸风与浅蓝风**：
   - 评估：同一个产品的文档站与主站风格断层会损害品牌专业感与用户认知。统一步调是最佳选择。

## Consequences

- 主站与文档站拥有完全协调统一的现代工科品牌视觉，消除了灰黄底与纯白卡片的脏色突兀感。
- 文字、按钮、状态标签在亮暗模式下均严格满足 WCAG AA / AAA 对比度标准。
- 所有设计 token 在 `app.vue` 与 `main.css`
  集中管理，未来扩展暗色模式或其他微调时维护成本极低。
