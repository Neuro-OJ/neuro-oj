# Agent Note: 全班未达标补题预览与独立草稿

Status: implemented

## Problem

矩阵按 50 名学生分页，原补题预选只覆盖当前页。教师需要从全班当前未达标名单选择学生和题目，不能在浏览器无限翻页读取矩阵，也不能把陈旧成绩、在途评测或资源失效误判为未达标。

## Decision

增加作业补题预览和创建接口。服务端按当前作业接收关系、班级学生身份、域成员状态与实时资源授权聚合候选，复用矩阵的细粒度投影过期表达式。只纳入未开始和已有成绩未达标单元，排除待评测、过期、资源不可用及历史学生。预览保留来源版本、统计范围和事实哈希。

创建时重新授权、检查 revision、核实预览哈希和学生与选题交集，并生成原班级内独立草稿。幂等重试不重复创建；每名所选学生收到相同题目集合。原作业进度、提交和成绩不修改。部分单元更新中不会阻止教师选择其他稳定候选。

## Alternatives considered

只从当前页选人会遗漏末页学生；由浏览器抓取全部矩阵会产生无界请求。根据最高分反推正式通过或将评测中当作零分不符合成绩规则。直接修改原任务会破坏已发布题目集合和达标依据。

## Consequences

标准 education 测试在 PGlite 通过 98 项、2 项 PostgreSQL 专用检查跳过；独立 PostgreSQL 通过 99 项、1 项性能检查跳过。新增 56 人测试跨过第一页，验证候选排除、事实变化、错误域、学生越权、独立草稿及幂等重试，原成绩保持一致。相关类型、lint 通过。

Web 对应实现已另行保存，实际浏览器旅程仍待集成。比赛来源补题将在后续独立提交实现，本记录不将其标记完成。
