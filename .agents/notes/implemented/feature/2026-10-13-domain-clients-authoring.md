# Agent Note: 域内源题草稿编辑与发布客户端

Status: implemented

## Problem

域题库可以读取和作答，但没有正常创建、找回未发布草稿、编辑评测配置及支持文件、
预检和发布的客户端流程。沿用旧全局入口会丢失使用域和源题写入边界。

## Decision

使用真实域 API，新增源题创建、草稿目录和编辑页面；题面、样例、代码模板及客观小题
复用现有组件。OI 表单编辑子任务、依赖、checker 和测试点路径，客观小题修改保留稳定 key。
AI／LLM／产物表单只携带调用预算，Provider 和模型继续由使用域配置决定；镜像及敏感命令、
网络能力仍服从实例政策。
AI 创建先选择实例许可的 Evaluator／Solution 镜像，初次请求携带完整 runtime 配置；
默认评测命令和禁止网络与实例普通创建基线一致，不将必填配置延迟到创建后的草稿保存。

草稿保存、文件写入、题包导入和发布携带原始 revision。预检必须基于已保存内容；文件
修改未保存或正在写入时暂停发布。冲突保留本地表单和待上传文件。OI 支持逐文件目标路径、
安全文本预览修改、删除和输入答案配对预览；题包导入只写草稿，成功后重新读取，再预检和显式发布。

## Alternatives considered

不使用旧全局编辑或上传 API，也不把整个内容对象暴露为 JSON 调试编辑器。
不自动发布导入的题包，不在并发冲突后自动套用最新 revision。

## Consequences

组件测试覆盖草稿保存到预检、发布 revision、冲突保留输入、题包不隐式发布、文件上传路径、
冲突保留文件，以及客观小题稳定标识。当前客户端代码具备正常创作流程；域路由统一开放、
真实浏览器上传和 Judge 评测验收仍由整阶段集成检查完成，此记录不代表该阶段全部验收。
创建请求另断言实际 runtime payload、默认命令、网络关闭及不携带 P/U 或 Provider／模型。
