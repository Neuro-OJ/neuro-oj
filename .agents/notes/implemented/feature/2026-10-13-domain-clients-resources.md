# Agent Note: 域资源共享、题单与查询客户端

Status: implemented

## Problem

域内做题和出题链已经具备客户端，但公开资源引用、共享政策、有效版本、恢复下架、
题单浏览编辑和域查询缺少正常页面，管理员难以完成跨域资源使用闭环。

## Decision

新增绑定管理和公开资源发现；所有引用保留来源题号与当前使用域。共享政策独立保存 revision，
支持所有域及填写目标域 slug 的限定授权；策略和状态修改使用绑定 revision，并明确填写理由。
恢复下架不复制题目，也不跳过源资源当前授权。版本元数据分页支持选择已发布 exact 版本。

题单支持列表、创建、按原 revision 编辑、排序、独立共享和公开题单引用。内容编辑复用
Markdown 和域题库选择。详情仅为有可用目标绑定的题目生成当前域链接；无绑定题仅对服务器
授予 can_import 的人显示逐题引用，题目撤销时不把题单授权当作单题授权。

搜索和排行榜使用实际域接口。题目搜索链接读取后端实时投影的 ProblemReference，
不从旧索引数字推断目标域题号。导航、缓存、共享表单和确认后写入都保留域及账号上下文。

## Alternatives considered

不使用旧全局 API 代替域查询，不要求管理员手工编辑数据库 UUID 或 JSON。
不在题单引用时为只有题单权限的人自动建立题库绑定；采用逐题授权操作。
并发冲突不自动套用新 revision，也不清空未保存的配置。

## Consequences

客户端具备资源管理、题单编辑和查询页面；新增测试覆盖共享冲突保留配置、题单原 revision
和可见性、策略与状态的请求契约、来源相同数字题号的定位，以及题单学生链接和逐题引用能力。
实际浏览器旅程和后端组合根统一开放仍由整阶段集成验收完成，页面和构建通过不代表全部产品验收。
