# Agent Note: 工作空间后端治理与实例访问政策

Status: implemented

## Problem

统一账号需要按工作空间分别管理成员和角色；私有实例不能只关闭注册而继续通过原业务入口公开读取内容。

## Decision

workspace

revision、模板差异及生命周期

API；邀请注册的账号与成员关系在同一事务提交，域邀请不能绕过管理员开户政策。Provider
等业务资源接入不属于本提交的功能。

审计事件白名单由共享常量同步到生产 CHECK 与 PGlite
DDL，业务审计随治理事务提交。权限查询接受事务执行器，注册初始化不在持有 PGlite
事务时使用根连接，真实事务注册测试覆盖这一边界。

## Alternatives considered

将域角色写入 JWT

## Consequences

后端治理测试覆盖跨域权限、容量、邀请撤销、交接、模板沿革及私有实例门控。现有身份、系统模块使用规定的
domain
命令回归；测试物理清理显式删除合成成员关系，生产成员外键保护保留。新域尚无题库、教学或
LLM 业务入口，不把这些未接入能力标记为已完成。
