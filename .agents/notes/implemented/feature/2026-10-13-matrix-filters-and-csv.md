# Agent Note: 学情筛选与流式 CSV 导出

Status: implemented

## Problem

教师需要按学生、题目、状态和正式判定筛选学情，且不能把尚未更新的旧成绩当作
当前筛选结果。导出不能一次载入无界矩阵，也不能在教师撤职后继续读取后续页。

## Decision

矩阵在分页前执行学生及单元筛选，复用当前源授权和八类事实 revision。过期
投影只匹配 updating，不参与达标或正式判定筛选；资源不可用仍可按已保存的
正式判定定位历史成绩。题目列使用标准来源引用，当前域题显示数字，跨域题
显示来源域与数字。

CSV 与 JSON 使用同一授权及筛选服务。先完成初始授权再返回 HTTP 流，按页
及背压读取，后续页重新验证教学关系。导出明确区分中文状态、当前／历史学生、
通过及逾期，将 ×100 整数分转换为显示分。更新中单元不导出旧分数。文本使用 CSV
引号及换行规则，并处理电子表格公式前缀。

新增可选 PostgreSQL 性能基准，经标准教育测试入口运行；默认跳过，启用时
必须确认外部库可清理。100 名学生、50 道题、5000 份正式成绩和 10000 个双范围
投影，按 50 名学生分页，计时包含认证、HTTP 处理器和 JSON 编解码。同步验证 两页
CSV 每名学生恰好一行，以及撤职后下一页停止读取。

## Alternatives considered

- 在已分页学生中再筛选：会使数量和翻页错误，因此筛选进入数据库条件。
- 导出旧投影分数：会把旧口径当作当前成绩，因此输出更新中状态及空分数。
- 一次取全班矩阵：会扩大内存和撤权窗口，因此使用受控分页流。

## Consequences

不增加数据库字段。源题不可用仍保留合法历史成绩，矩阵不返回原始评测数据。
正式判定筛选只提供现有 OI 判定，不为 AI 题伪造测试点或错误结构。教学 Web
和浏览器旅程仍未交付，准备接口继续等待完整隔离门禁。

本地性能复跑 p95 为 43.15 ms，最大 48.43 ms；不含 TCP/TLS、浏览器渲染及
在途重测压力，不表述为生产环境或完整旅程验收。

标准教育专项 PostgreSQL 55 项通过（含性能及分页撤权），PGlite 54 项通过、 1
项性能明确跳过。完整类型、受影响格式 / lint、Schema parity、迁移快照、
安全、模块边界、CI 路径和文件规模检查通过。新增性能目录已登记并行豁免， CI
core-perf 经标准教育任务单独执行，目录覆盖守卫保留；首轮全量回归发现
此登记遗漏后修正，并重新运行全部分片。

修正登记后标准 PostgreSQL 全量并行回归通过：unit 377、db 1685，0 失败、 17
跳过，共 2062 项通过。性能目录独立运行，不把主分片中的排除当作性能通过。
