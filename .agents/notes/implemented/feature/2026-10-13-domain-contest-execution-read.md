# Agent Note: 使用域比赛提交与受控读取

Status: implemented

## Problem

显式域普通提交已经存在，但比赛作答需要保留同一使用域的固定版本、报名和受理窗口。
提交读取、模板及版本目录还需要保持域归属，并在源题撤销后仅保留本人原提交与成绩摘要。

## Decision

域提交列表和详情按路径域及当前身份读取，旧默认域入口不能用其他域的 ID 读取。
源授权撤销时保留代码与汇总成绩，去除评测详情、原始输出、尝试明细及题目标题。
比赛结果继续经过统一允许字段投影；域管理员身份不替代该场比赛的组织权限。

新增比赛标签提交路径，代码、产物和客观题复用原唯一提交与评测链。
每次受理及写入事务都验证路径域、当前报名、进行中窗口、绑定和比赛固定版本。
比赛固定 V1 而题库默认 V2 时提交 V1，不以题库默认策略覆盖比赛固定版本。
客观题保持一次正式交卷，Kaggle 返回百分制原分，OI 返回中性回执。

普通域题目新增模板及分页版本元数据接口，当前版本变化返回可处理冲突。
LLM 初次尝试、恢复与批量派发携带使用域，并在尝试执行快照保存 Provider、模型和域依据。

## Alternatives considered

没有新增比赛专用提交表或 Worker，也没有通过普通练习入口注入任意比赛 ID。
没有让历史固定版本绕过当前源共享授权，已有成绩的保存与新执行权限分别处理。

## Consequences

标准 submission 回归 PostgreSQL 349 项、PGlite 319 项通过，分别跳过 10、40 项环境专属测试。
catalog 355 项通过，相关新增服务及路由类型检查、lint 通过。
测试覆盖跨域路径、未报名、版本冲突、赛后提交、撤销、代码与产物归属、一次交卷和 OI 隐藏结果。
域社区、搜索、批量执行及所有下载入口的完整隔离与浏览器旅程仍待验收，准备入口暂未统一开放。
