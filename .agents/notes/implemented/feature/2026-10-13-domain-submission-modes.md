# Agent Note: 使用域产物、客观题与自测入口

Status: implemented

## Problem

显式域普通代码提交已有入库复查，产物、自测和客观题仍只能使用默认域创建接口，学生无法通过这些题型完成使用域作业。

## Decision

将域执行解析和事务复查作为 submission 公开门面。产物、自测与 objective
交卷复用同一权限、版本、共享和比赛练习检查，继续使用原流式存储、失败补偿、判卷和评测尝试。

准备接口支持 multipart
来源题号、域内自测和客观题交卷。旧自测详情、客观题列表、详情及最高分查询限定默认域，避免新记录从旧入口读取。自测只写独立运行记录，不产生正式提交或正式评测尝试。

## Alternatives considered

- 新建一套教学提交系统：复用现有提交与评测事实，作业消费者自动计入。
- 将绑定 ID 或域 ID 放入请求体：由 URL 与题目引用解析，客户端不能覆盖归属。
- 在域权限检查后继续运行旧源题全局访问分支：域执行使用绑定授权，避免公共源题内部学校比赛影响其他使用域。

## Consequences

新增实际流式上传、独立自测、OI
评测封套、客观题即时判定及三个入口比赛旁路测试。OI
测试覆盖任务封套与归属，尚未覆盖真实 Judge 沙箱运行；完整浏览器旅程也未完成。

冻结代码后，core PostgreSQL 标准并行回归 unit 379／db 1731 项通过、0 失败、17
项跳过。 submission 标准模块 PostgreSQL 344／PGlite 314 项通过；objective
两种数据库各 63 项通过。 完整源类型、lint、域边界、CI 覆盖、Schema
parity、迁移及文档门禁通过。

准备路由暂未开放。完整查询、作业／比赛上下文、批量执行、域内 LLM
与数值配额继续实施，本记录不代表提交隔离或全题型教学阶段已签收。
