# Agent Note: 实例模块与域资源政策的持久执行

Status: implemented

## Problem

工作空间默认配置只有创建政策，缺少实例允许模块、资源默认值和上限。 仅保存域
limits 表不能证明操作受实例上限约束；缓存传播延迟或错误配置也不能
放宽额度。域管理员不能通过修改自己的配额取得更多实例资源。

## Decision

实例新增三个 DB-owned 设置：允许模块、新域默认资源限额、各域上限。
结构化配置复用既有 text 设置存储，写入时验证完整字段、类型、依赖和数值范围。 API
及 limits 表均以 null 表示不额外限制，不使用负数哨兵。
所有生效额度逐项组合本域值与实例上限，任一层 null 不解除另一层限制。

新域复制并收敛默认限额及 Preset 模块，默认域和存量域不被新默认值覆盖。
成员加入、题库引用和配额治理在业务事务中直接读取当前持久政策。
域配额修改需要当前域权限及 If-Match，只允许域管理员降低有效额度；提高需要
平台治理权限，仍须在实例上限内。变化更新域 revision 并同事务审计。

身份和访问政策与资源政策分开读取：无效资源配置拒绝额度操作，却不阻断登录及
管理设置修复入口。教学模块守卫保留授权历史读取，新增写入须满足两层开关。

## Alternatives considered

- 配额只写 DB、执行继续读原缓存：通知延迟期间可能继续放行，改为事务直接读取。
- 统一用负数表示不限额：与批准的 null 契约不一致，选择完整结构化数值对象。
- 修改默认值时覆盖全部域：会改写已确认配置和迁移口径，默认值只初始化新域。
- 资源配置解析失败时阻断全部请求：管理员不能通过 Web 修复，拆分身份访问政策。

## Consequences

当前交付真实成员和引用题容量政策、治理接口以及模块守卫；存储预留、所有题目
创建、提交频率、LLM 及现有业务模块的全入口接入仍待实现。
域教学停用区间已有模型，但实例全局停用与教学进度的完整时间窗回填规则仍需
在教育模块接入时验证。结构化文本为存储细节，后续管理页面使用明确字段表单。
