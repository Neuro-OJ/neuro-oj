# Agent Note: 提交明细内展示 OI 实时进度

Status: implemented

## Problem

提交详情同时展示独立进度卡片和终态测试点表，评测过程中用户需要在两处追踪同一批测试点。

## Decision

移除独立进度组件，测试点明细同时接收实时快照与正式结果。实时行区分等待、运行中及已完成，支持多个并发运行用例；同一测试点的完成结果优先于重复运行标记。尚未启动且没有公开标识的测试点仅按剩余数量占位，不推测隐藏路径。终态忽略残留进度，展示正式明细。

## Alternatives considered

保留两张表会继续重复信息；仅展示已完成用例不能定位正在运行的测试点；根据题包路径补全等待行会引入不必要的隐藏数据读取。

## Consequences

进度阶段和完成数量在明细标题中展示，测试点状态在行内更新。既有 AI 与历史结果仍使用原归一化路径。新增测试覆盖并发、重复标记、排队编译期间的占位和终态切换；前端测试、类型检查和 lint 通过。
