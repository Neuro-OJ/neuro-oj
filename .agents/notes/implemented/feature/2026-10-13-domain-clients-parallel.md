# Agent Note: 显式域题库、比赛与 LLM 客户端

Status: implemented

## Problem

旧题库和比赛页面依赖全局接口，无法表达使用域、共享题来源题号和域内执行配置。
IDE 同样缺少域选择及提交归属，不适合直接接入多个工作空间。

## Decision

- Web 新增 `/d/:slug/problems` 题库与题目页，使用显式域读取和代码、产物、客观题提交接口。
  共享题显示来源题号，提交使用页面域。代码和客观题草稿按账号、使用域、源题、版本和语言隔离。
  收到版本冲突后保留输入、刷新题目，学生确认后才切换版本；模板读取携带当前作答版本，覆盖代码前确认。
- 新增域比赛列表、创建、编辑、详情、实时及正式榜、结算和发布页面。
  五种赛制展示对应题型限制和计分说明；开赛后仅允许修改名称、说明。
  榜单缺少正式结果时展示待处理，不将其转换成零分。
- 新增域 LLM Provider、默认模型、配额与用量管理页。Provider 密钥仅表单写入，列表使用脱敏字段；
  历史 Provider 通过停用操作保留。默认配置保存带 revision。
- IDE 新增域选择并将题库、版本、模板、提交和结果读取迁移到显式域 API，保留版本确认和代码草稿。

## Alternatives considered

没有将新页面代理到旧全局 API，因为该方式会把其他域请求落入默认域。
没有在浏览器复制源题或 Provider 配置；内容授权和执行归属均由服务器判断。

## Consequences

新客户端页面与 API 契约已实现。完成运行时组合根挂载和隔离验收后才能对普通用户开放全部流程。
此记录不代表 Domain 整阶段完成：比赛实际作答页面、域提交列表和详情仍需继续接入；
完整浏览器旅程、真实 Judge 执行和客户端协同发布仍待验收。
