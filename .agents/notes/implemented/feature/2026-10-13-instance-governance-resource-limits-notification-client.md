# Agent Note: 实例治理、资源额度及教学通知客户端

Status: implemented

## Problem

实例设置已登记但复杂政策需要手写
JSON，平台管理员没有可发现暂停私有域的治理目录和
创建申请审核界面。域配额页面只提供成员／题目数量，隐藏已实现的存储与正式提交频率配置。
教学通知只有手动 REST 读取，服务器的持久通知 SSE 尚未接入客户端。

## Decision

- 新增平台实例治理页面，以固定自然表单编辑十项已注册政策，复用既有系统设置
  GET／PUT 和保存前读取的时间戳；不增加配置存储或另建通用配置引擎。
  保存一项只更新该项依据，冲突保留草稿；管理员显式重新读取才重置政策表单。
- 平台治理使用专用分页目录，包含不公开发现的私有域和暂停域。 状态确认冻结所选
  slug 和原 revision，创建审核使用对应申请 ID。
  用户身份在确认期间变化时停止旧确认，服务端继续检查实际平台治理权限。
- 四项基础资源额度共用字段组件，区分 null 不额外限制与零禁止。
  域页展示实例上限、有效额度和授权服务器返回的六项已使用／预约数量，不用资源计数
  伪造当前提交窗口次数。存储保持安全整数范围，不继承成员数量的 32 位上限。
- 教学 SSE 使用既有连接／降级机制，事件仅触发授权 REST 重读。
  同一路径切换账号也重建连接并重置重放序号；断线每 15 秒补读、30 秒尝试恢复
  SSE。 当前成员失效、域切换及卸载后关闭旧订阅和计时器，不信任载荷正文或成绩。

## Alternatives considered

- 在普通域发现接口增加管理员绕过：普通目录与治理目录的权限含义不同，采用显式平台入口。
- 用 JSON 输入维护全部政策：易误填模块依赖和 null／零规则，采用固定契约表单。
- 每项保存后重载所有设置：会覆盖其他未保存修改，保留分项保存依据。
- 直接以 SSE 内容更新通知正文或成绩：无法替代最新资源授权，采用 REST 重读。
- 在断线后无限重复旧域连接：连接范围必须包含当前账号和 URL，切换时清理。

## Consequences

平台与域治理入口分开，管理员可以找到需要恢复的暂停私有域而不扩大普通目录。
配置并发仍遵守既有系统设置契约；首次默认配置没有 DB
时间戳时复用原接口的无时间戳写入
行为，不宣称已完成整个计划中全部配置的强制前置条件验收。
组件回归覆盖配置冲突、模块依赖、治理分页与确认、额度零／不限及大容量、通知断线重连和
账号／成员变化。构建及自动测试不代替浏览器、窄屏、完整额度执行或全链路治理验收。
域 LLM 上限 DTO 与 Provider／quota 并发契约仍待后端协调，本批没有改变这些 API。
