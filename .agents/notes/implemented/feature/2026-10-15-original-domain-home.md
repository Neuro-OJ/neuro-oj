# Agent Note: 恢复原版首页与域公告阅读

Status: implemented

## Problem

域首页被通用管理卡片替代，丢失了原来的轮播、签到、公告、随机题目与最新评测。
旧首页组件又使用默认域 API，不能直接套用到学校或团队域。

## Decision

恢复原版约 1320px 首页容器及轮播、签到、公告、双列内容和关注动态的排列。签到
保持实例账号行为，其他内容显式按当前域读取。教学域在公告后显示紧凑任务区，
只读取服务端已授权的任务。

域公告阅读合并实例和本域内容并显示来源，详情和列表保留使用域网址。实例公告
入口继续只读实例内容。横幅优先实例，并在域或账号变化时换用独立缓存。关注动态
沿用统一关注关系，读取和链接均指向当前域社区。

增加域首页评测基本信息接口：登录后读取本人练习，游客只看当前域允许公开的练习；
不返回代码、原始输出或比赛提交。统计沿用查询模块的当前授权与有效成绩口径。
最新评测复用原提交卡片，通过域内 SSE 触发重新读取，连接失效使用定时刷新。

## Alternatives considered

- 直接恢复旧全局 API：会混淆使用域与来源域，未采用。
- 保留首页作为域设置和身份面板：用户明确要求恢复原站布局，管理入口放入设置。
- 复制多套公告阅读页：提取共享阅读组件，由域入口和实例入口明确选择接口。

## Consequences

首页结构恢复，域运营内容可以通过已交付的共享管理组件配置。公告搜索结果保留
当前使用域。每块内容各自显示错误和重试，不阻断其他首页内容。

本批 query 标准测试 39 项通过；UI 单元、组件、类型及 lint 检查记录在本轮验收
日志中。完整浏览器截图、全题型旅程和最终 CI 在剩余界面完成后统一执行。
