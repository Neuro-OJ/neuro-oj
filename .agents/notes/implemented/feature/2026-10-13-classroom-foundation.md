# Agent Note: 班级组织及固定教学权限

Status: implemented

## Problem

Domain 成员不能表达班级教练、助教和学生关系，也不能安全地按班级授予教学能力、
保存离班历史或进行交接。仅按全站角色授权会把跨学校身份混在一起。

## Decision

新增 education 模块及班级、成员、六项助教能力、同域比赛关联和加入申请表。
复合外键约束班级、域成员和比赛的归属；账号及成员记录保留稳定身份，不级联
删除教学历史。

实现创建、编辑、列表、详情、成员任命、助教授权、离班、交接和归档。教练及
域治理人员管理本班，助教仅使用被授予的能力，不能修改自身权限或任命教练。
修改使用 If-Match/revision，授权读取当前数据库关系，不依赖 JWT 中的班级角色。
班级归档或教学停用后保留获授权读取，停止新的教学写入。

离域和注销在同一事务结束班级任职并清除助教授权，重新入域不恢复旧教学权限。
交接只修改主教练关系，原教练仍为教练，离职时再显式结束任职；已有记录不移动。

同步登记域边界、标准测试、并行分片、CI 路径与任务，以及模块和所有权文档。
生产组合根按升级计划等待资源隔离及教学流程完成后开放；准备路由在 HTTP 测试
组合根验证。

## Alternatives considered

把教练视为全域管理员会扩大源码及平台权限。把角色写入 JWT 会延迟撤权。直接
删除离班成员会使历史作业和作者失去身份依据。采用独立班级关系及固定能力。

## Consequences

PGlite 和 PostgreSQL education 标准测试各 8 项通过；workspace 回归 27 项通过、 7
项跳过。完整 PostgreSQL 并行 unit 374 / db 1641 项通过，0 失败、17 项跳过。
类型、lint、域边界、CI 覆盖、迁移安全、Schema parity、快照链及文件规模通过。

迁移 0119 在开发库、恢复库和隔离测试库通过。比赛 domain_id 仍是扩展期可空列，
同域关联禁止引用尚未明确归属的比赛，不替代比赛全链路归属验收。

班级邀请注册、CSV 导入、作业、学生提交读取、反馈及 Web 流程仍待实现，不把
当前基础接口或测试数量作为整个 Classroom 阶段验收。
