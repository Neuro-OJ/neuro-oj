# Agent Note: 统一私密批注与定向教学问答

Status: implemented

## Problem

题面、提交代码和题解缺少共同的教学批注入口。仅依赖班级行批注不能覆盖句子、
题解历史或不属于某个班级的提交，也难以表达私人备忘与教师组问答的区别。

## Decision

annotation 模块统一来源快照、可信选区、私密笔记、定向教学会话、消息、幂等
操作和通知。新建默认私密，页面默认只显示本人笔记；发送生成独立副本。
当前域 owner/coach 与指定学生构成教学受众，每次读取仍检查完整原文权限。
平台治理使用独立查询原因和读取审计。比赛期间继续定向教学，正式排名保持现有规则。

题面绑定发布版本及字段，提交绑定文件及字节指纹，题解保留历史快照。
服务端生成引用和上下文，旧行批注保留 ID 并汇入共同消息依据。UI 通过共用
批注面板和 UserIdentity 展示作者，不逐行查询个人资料。权限与信息边界详见
dev-docs/engineering/global-annotation-security.md。

## Alternatives considered

全班公开分享会产生额外的同学代码与题解传播面，第一版不提供。管理员在普通
接口隐式读取私人笔记会破坏私密语义，因此治理读取与日常问答分开。
原文变化后自动寻找相似文字可能悄悄误定位，因此保留固定快照。

## Consequences

原文撤权会同时隐藏正文、上下文、目录、通知和快照；记录保留以便重新授权和
治理追溯。新任教练可以接手历史会话，离任作者也不保留教师组访问权。
允许比赛定向交流意味着不能据此证明独立作答，相关信息优势属于当前产品决策。
服务、HTTP、组件及迁移测试分别覆盖边界，浏览器验收独立记录。
