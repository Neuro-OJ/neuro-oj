# Agent Note: 手机教学与账号设置布局

Status: implemented

## Problem

手机作业矩阵逐人展开全部题目，阅读长度随学生与题目相乘；已选作业题主要依赖
编号。个人设置连续堆叠独立表单，缺少稳定分组入口。

## Decision

桌面保留矩阵，手机使用连续学生摘要并逐人展开，保持原提交抽屉和反馈对象。
学生作业以进度和题目连续列表为主，维护操作折叠，题目按20题分页。题名摘要由
初始作业 BFF 提供，编辑与翻页使用固定使用域、最多20题的 Nuxt 摘要接口。
账号设置采用桌面侧导航和手机分组选择器，使用 hash 跳转，同页保持全部表单挂载；
资料、安全、第三方账号、数据隐私与注销保留现有独立动作。

## Alternatives considered

- 手机默认展开全矩阵：整班操作需要大量滚动，无法快速扫描。
- 切换设置时卸载分组：容易丢失未保存输入与二步验证临时状态。
- 浏览器逐题加载题名：增加请求瀑布，改由受限 BFF 聚合且不返回题面。

## Consequences

筛选、分页、导出、角色能力和通知深链保持既有语义。更新中的成绩不显示旧达标
数字；未知与不可用题名保留编号和操作。桌面无全站视觉重做，所有修改仅在 Nuxt。
