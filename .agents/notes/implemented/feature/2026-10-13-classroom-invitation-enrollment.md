# Agent Note: 班级邀请与原子注册加入

Status: implemented

## Problem

班级教练需要邀请学生，接受时同时建立 Domain 基础成员和班级学生身份；失败
不能留下半注册账号或半加入关系，也不能把班级管理能力变成全站开户能力。

## Decision

复用已有单次邮箱绑定邀请、令牌哈希、注册政策和账号事务，为邀请增加班级
定位及同域复合外键。班级创建、目录和撤销仅使用本班学生管理权限；预览和
消费重新检查签发者、能力、教学模块及归档状态。

接受在同一事务完成账号资格检查、域成员额度、基础成员和班级学生加入，并
消费邀请。现有教学人员不会被学生邀请降级，恢复的旧成员只取得学生身份，
不恢复以前助教授权。邀请注册仍需实例准许及平台或域邀请管理员资格；仅有
教练或助教班级能力可以邀请已有账号，不能绕过管理员开户政策。

客户端邀请预览显示班级及所属空间，接受提示明确两层加入。记录班级归档时间，
避免后续权限或配置更新改写归档依据。

## Alternatives considered

为班级复制账号注册和邀请协议会产生另一套身份及额度事实。直接创建学生账号
违背账号归属规则。采用原协议与事务，手动邮件通知不属于本批执行。

## Consequences

education PGlite / PostgreSQL 各 12 项通过，含真实注册加入、额度失败回滚账号、
域及班级关系、邮箱不匹配、重复消费、撤权、撤销、归档、令牌哈希及列表裁剪。
workspace 回归 27 项通过、7 跳过；identity 312 项通过、26 跳过。UI 标准测试 240
项、Nuxt 与 Vue 全源类型通过。相关 lint、格式、迁移安全和 Schema parity
通过，迁移 0120 在开发库、恢复库及隔离 PostgreSQL 库通过。

CSV 批量邀请、加入申请处理、班级页面及完整浏览器旅程待后续完成。生产组合根
仍遵守升级阶段开放门槛，不把当前准备接口当作整个教学流程上线。
