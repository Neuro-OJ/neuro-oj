# Agent Note: 教学工作台与我的学习聚合页面

Status: implemented

## Problem

已有班级和作业页面需要逐个进入，教师不能集中查看待跟进任务，学生也缺少个人任务入口。
在浏览器逐班请求所有作业会增加无界请求，并容易混合班级能力与统计权限。

## Decision

- 新增同域 `/teaching` 与 `/my-learning` 页面，只请求服务端已经按当前班级关系授权的分页聚合接口。
  页面缓存包含域、账号、用途和页码，不在客户端遍历班级。
- 教师任务卡展示服务器授权的学生数、未达标学生数、达标单元和失效资源，统计为 null 时不转换成零。
  学生页面只展示个人达标题数；过期投影显示更新中，不使用旧成绩生成结论。
- 工作台展示无正文的求助定位摘要，点击后由作业互动接口再次读取权限。
  各任务可进入作业、反馈或班级；当前页任务可以筛选进行中及需要跟进。
- 联调确认域 LLM 全域额度的对象 ID 必须为空，保存表单主动清空前一次用户额度的对象 ID。
  费用额度按 Provider 单价相同单位输入整数，不假定为美元或固定货币单位。

## Alternatives considered

没有在浏览器将多班作业和学生提交拼成工作台，以保持查询边界及分页成本。
没有把服务器隐去的学情视作零成绩，也没有将统计表述成能力评定。

## Consequences

客户端聚合页面和能力呈现已实现。后端聚合、浏览器旅程和完整教学任务验收仍由总计划统一验证。
当前页筛选不意味着筛选整个域；页面明确这一范围，跨页筛选可后续由服务端扩展。
