# Agent Note: 统一账号本人历史与域客观题记录客户端

Status: implemented

## Problem

当前域代码提交页不能展示完整跨域本人历史，普通客观题也缺少可回访的原回答和结果页。
失去域访问权后仍应保留原提交摘要，同时不能恢复源题内容或查看其他账号的数据。

## Decision

使用真实 /me/submissions 目录与 kind 详情接口，新增统一账号历史、用户菜单入口及域内返回。
每条保留使用域、来源题号和提交类型。题目入口同时要求 domain.accessible 和
resource_available；原提交和授权成绩使用独立摘要组件，不显示原始评测输出或数据。

普通域客观历史使用独立 Domain 列表和详情，列表按题目过滤并使用后端 total 分页，
不套用统一账号 pagination 响应。域入口仍执行当前进入授权；失权原提交经统一账号接口读取。
隐藏结果采用中性受理状态，平台 error 不展示尝试零分；正式通过使用服务端有效和 accepted 标志。
客观回答只呈现用户选择，判断题布尔值不称为评测正确性。

## Alternatives considered

不使用其他用户 ID 参数代理读取，不以导航偏好改变请求归属，不用旧全局客观详情绕过源授权。
不恢复不可访问域的题面链接，不把不同域结果汇总成公共排名，不渲染不受控 output/details。

## Consequences

新增测试覆盖域或资源失权后的链接移除、原代码及摘要保留、hidden 裁剪、平台错误零分、
原回答展示以及两种真实 HTTP 路径和分页契约。客户端实现具备本人历史闭环，
后端组合根统一开放和浏览器旅程仍由整体集成验收完成。
