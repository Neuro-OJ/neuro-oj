# Agent Note: 工作空间、教学与平台治理使用指南

Status: implemented

## Problem

工作空间与教学功能已经提供各角色的操作入口，正式文档站仍缺少账号层级、
带域作答、邀请入班、动态作业成绩和实例治理的完整说明。用户容易把来源题号
当作提交归属，或把作业截止理解成永久冻结成绩。

## Decision

新增工作空间指南、班级作业指南和工作空间部署治理指南，并在现有做题功能及
运营者侧栏登记。实际配置为 docs/.vitepress/config.ts，不新增另一份站点配置。

指南按学生、教师、域管理员、平台管理员的操作组织，核对当前 UI 与服务行为：
引用题保持来源题号及使用域、共享撤销保留授权历史、班级邀请与 CSV、作业
按时和补做双视图、版本与重测沿革、批注求助、补题、两窗训练比较，以及域 Provider
和额度。页面不包含 DTO、数据库锁或开发阶段状态。

部署指南说明 Public/Private/Mixed 的政策组合、仅管理员开户限制、资源默认值
与上限、协调升级和数据核实，并区分备份文件、文件校验和实际隔离恢复证据。
没有声称 CI、恢复演练或正式上线验收已经完成。

## Alternatives considered

- 将所有读者放在一份架构文档：实际操作难以查找，用户需要阅读实现细节。
- 仅提供 API 路径：缺少教师与学生可直接执行的页面流程。
- 把验收待办写进每个产品页：混淆当前使用规则与工程交付进度；工程缺口由 协调
  agent 单独跟踪。

## Consequences

读者可从现有侧栏进入三份指南，并按自己的角色找到可操作流程。工作空间
文档明确当前题库入口的作答版本要求；旧版本内容和成绩仍有授权历史依据。
新增页面继续使用现有 VitePress 主题，不修改品牌 token。

验证使用文档 README 的 npm run docs:build，构建检查站内坏链；另执行仓库 Markdown
链接门禁、格式和 Agent Note 格式检查。完整平台验收不由文档构建 结果代替。
