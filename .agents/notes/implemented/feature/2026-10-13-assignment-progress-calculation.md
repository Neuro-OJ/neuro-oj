# Agent Note: 同域作业候选与按时、补做成绩重算

Status: implemented

## Problem

作业不能从一次提交的最高分推断正式通过，也不能把跨域练习、离班练习或未开放
比赛结果混入矩阵。截止前受理但之后完成的评测必须补入按时成绩，重测降分需要
采用当前正式判定，不能累加或保留旧高分。

## Decision

实现按域、实际接收者、源题、时间区间和当前绑定策略查询候选。普通与客观题
复用现有 submission_version_results 的当前正式尝试。一次查询分别为按时和当前
范围选择最高分、通过候选及在途状态，只返回允许的成绩摘要。查询排除未结束
比赛、发布前默认不计的提交、离班间隙、结束与归档后的提交和教学停用区间。

重算以作业锁串行化，从最新事实覆盖当前投影，保留来源提交、正式尝试、版本、 策略
revision 和逾期标记。通过要求独立选择 accepted 候选；最低分不要求 AC。
批量上限控制 SQL 参数规模，唯一单元和 revision 条件防止重复或旧版本覆盖。

共享可用性通过 catalog 公共门面批量读取当前数据库授权。停止引用保留已有
成绩并标记不可用；目标域内部比赛不让公开源题在所有域隐藏。默认作答版本或
绑定策略变化保存当前沿革，能确定的操作者来自原绑定及版本记录。

持久事件同时更新 Domain 事实时钟和细粒度作用域 revision，其他学生或题目不
因无关评测被全部标为陈旧。事实时钟、失效范围和事件共用业务事务。

## Alternatives considered

- 直接读提交上的旧物化成绩：策略切换后可能陈旧，因此选择当前正式版本判定。
- 为每个矩阵单元读取全部尝试：请求和结果集随历史无限增长，因此使用窗口函数
  选择单元所需候选，并按学生页读取。
- 从高分推断 AC：与权威 accepted 判定不同，因此保存独立通过尝试。

## Consequences

当前交付重算服务和事实版本契约。评测生产者接入、租约消费者、过期矩阵读取、
通知、每一次中间策略变化的完整同步和 Web 尚未完成，不标记自动教学闭环完成。

教学 PostgreSQL 和 PGlite 测试各 27 项通过；赛制回归 106 项通过。新增测试覆盖
受理窗口、截止后完成、重测降分、重复覆盖、撤销后保留、同提交计两份作业、
跨域排除、赛中排除、客观题正式判定、最高分与通过分离、共享源比赛范围、any
默认版本切换和 exact 策略沿革及操作者。 类型、格式、lint、域边界、CI
路径覆盖、文件规模及 JSDoc 门禁通过。
