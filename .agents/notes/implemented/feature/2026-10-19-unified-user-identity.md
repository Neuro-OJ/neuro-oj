# Agent Note: 统一头像与用户名展示

Status: implemented

## Problem

用户身份在消息、题解、排行榜、课堂及域成员列表中由不同模板拼装，部分查询未带
头像，配置头像后仍只显示首字母。注销账号与域上下文也缺少统一表现。

## Decision

UserIdentity 统一头像、用户名、可选业务域后缀和个人主页链接。业务列表批量携带
用户摘要，组件不逐行查询用户资料。头像经用户头像代理读取，版本来自存储校验和，
不向外暴露对象存储地址。缺失或加载失败时使用首字母，注销摘要隐藏原姓名和头像。
域后缀使用当前业务上下文，显式空值可关闭；账号身份保持全站统一。

## Alternatives considered

逐行加载用户资料会放大列表请求量；仅替换模板而不补充 DTO 不能解决缺失头像。
复制头像控件到各页会继续产生链接、截断和注销态不一致，因此使用共同组件。

## Consequences

移动端长用户名截断并保留完整标题，头像独占显示仍提供可访问名称。外层已有链接
或按钮时关闭内部链接，避免交互嵌套。组件与摘要测试覆盖缺图、注销、域后缀、
安全代理路径和用户名转义；页面交互和图片失败的浏览器验收另行记录。
