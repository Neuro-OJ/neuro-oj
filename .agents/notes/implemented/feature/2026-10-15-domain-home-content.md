# Agent Note: 实例与域首页运营内容归属

Status: implemented

## Problem

原有公告与轮播只属于实例，域管理员无法配置自己的首页。直接复用全局管理接口会
混淆实例内容与域内容，也会使私有域公告或图片通过全局入口暴露。

## Decision

公告和轮播增加可空的 domain_id；空值表示实例。实例接口只读写实例内容，域管理
接口只操作路径指定的域。域公共接口先授权，再合并实例和本域启用内容，实例在前，
分别保留原有排序。横幅优先实例。正文、图片以及搜索都读取当前归属与访问条件。

管理入口经 workspace 公共门面授权，沿用系统审计。域图片上传复用存储预约、结算
与引用守卫；图片必须属于本域存储，删除最后一个引用后释放本域容量。私有图片由
授权接口读取，响应不进行公共缓存。迁移由 Drizzle 生成，同步 PGlite DDL。

## Alternatives considered

- 为每个域复制实例内容：会产生更新不同步与重复存储，未采用。
- 在全局管理接口信任客户端 domain_id：归属可伪造，未采用。
- 重写完整运营服务：原有校验、排序与审计可以复用，因此只增加明确的作用域参数。

## Consequences

旧实例内容保持空归属，实例管理流程不变。新域运营 API 可供共享的管理组件使用，
前端接入另行交付。域存储盘点与全局文件引用检查包含轮播图片。

验证：system 标准模块测试 163 项、search 35 项、workspace 标准模块回归通过；
core 完整类型检查、仓库门禁和 Schema parity（108 表、987 列）通过。
新增用例覆盖合并排序、启停、错误域、管理权限、私有图片、存储额度和搜索隔离。
