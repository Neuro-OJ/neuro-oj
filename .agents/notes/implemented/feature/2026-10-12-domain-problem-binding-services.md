# Agent Note: 域题号解析、回填与独立题库绑定服务

Status: implemented

## Problem

域题库需要用来源题号定位共享题，并选择使用域自己的有效版本策略。
源域修改策略不能覆盖学校设置，授权撤销也不能因管理员权限或缓存而继续放行。
存量归属回填必须保留 ID、版本、原数字和已有配置，不默默处理未核实的 U 题。

## Decision

catalog 门面提供数字 / domain:number 解析、默认域回填、绑定解析、公开题引用、
共享政策及绑定策略修改服务。引用复制源域绑定的当前策略，后续目标域独立修改； any
作答使用最新已发布版本，exact 使用指定同题版本。每次配置修改保存 revision、
理由、操作者、默认作答版本和事务审计。

读取共享题实时检查源域公开入口、停用状态、源题发布与可见性、源域绑定下架、
引用授权及比赛保密窗口；目标域管理员和平台管理员均不能绕过源授权撤销。
跨域写入按域 ID 顺序加锁；重复引用复用绑定且不重复扣容量。题库容量在锁内查
当前条目数量，并结算持久计数。比赛保密查询接受 executor，避免事务内根连接死锁。

`deno task db:catalog-backfill` 接入标准管理 CLI。在恢复库及原开发库各回填 3 道
P 题、创建 3 份本域绑定和初始沿革；原题 ID / 数字 / 版本对比一致，22 个
账号保留，main 下一编号 1004。恢复库第二次执行所有新增计数为 0。

## Alternatives considered

- 共享题分配本地数字：掩盖来源，并增加同一资源多重编号的歧义。
- 授权依赖缓存或索引状态：撤销后仍可能访问资源，选择实时数据库事实。
- 源策略变更广播覆盖全部绑定：会修改其他域独立的教学成绩依据。
- 回填每次重新复制策略：会覆盖管理员调整，改为只插入不存在的绑定。

## Consequences

当前是服务层交付，尚未挂载完整域题库路由或切换全部提交 / 版本投影读写。 旧 P/U
代码和可空归属仍在扩展阶段；默认版本变化通知、教学事件及全入口裁剪
由后续实现接入，不能据服务测试宣称资源隔离已完成。
单连接测试中的并发调用验证容量与幂等行为，独立并发数据库连接的完整额度验收
仍属于阶段 4 和阶段 9。新增约束及服务测试使用隔离数据库，不清理测试之外的数据。
