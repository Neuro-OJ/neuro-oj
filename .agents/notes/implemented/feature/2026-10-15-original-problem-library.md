# Agent Note: 原版题库表格与授权筛选

Status: implemented

## Problem

域题库以松散列表取代原表格，手机题名容易被挤压，缺少完整筛选、时空限制与评测
后端。全局标签目录也不能直接用于私有域或隐藏算法标签。

## Decision

恢复约 960px 的题库标题、题量、筛选、表格与分页。保留新的数字题号、来源题号、
版本和当前域成绩；手机隐藏次要列。题库管理动作收在列表操作区。

复用原筛选组件，移除其 P/U 输入，使用题型、难度、后端、标签和本人进度。筛选 由
URL 驱动，改变条件重置分页。旧题库页仅承载已由全局中间件重定向的兼容路由。

后端在分页和计数之前执行后端筛选；时空限制来自目标域当前作答版本的允许字段。
标签选项复用同一授权集合，隐藏算法标签在正式通过前既不展示关联，也不通过
筛选命中数泄露。不会返回整个运行配置或测试路径。

## Alternatives considered

- 直接在前端过滤本页：会使题量、分页和选项不完整，未采用。
- 下载所有题目再收集标签：请求无界且授权容易失效，改用数据库集合查询。
- 从最新源题投影读取限制：exact 绑定可能选择旧版本，改用实际作答版本。

## Consequences

列表和标签选项按使用域和查看者读取，不混入其他域的通过记录。另补齐 PGlite
存储测试的默认域夹具，保持外键有效；首页评测测试覆盖正式 graded 尝试及实际
分数，避免只有无评测记录的夹具漏掉结果契约错误。

验证：catalog 标准测试 397 项通过；PGlite system 163 项通过；query 的 PGlite
测试 33 项通过、6 项因该模式能力限制跳过。UI 单元 283 项、组件 285 项及本批
Nuxt/Vue 类型检查、lint 通过。最终截图与浏览器旅程另行验收。
