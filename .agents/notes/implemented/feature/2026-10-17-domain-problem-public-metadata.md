# Agent Note: 域题面公开信息与既有视图适配

Status: implemented

## Problem

域题面接口缺少提供者、评测后端和标签，无法复用既有题目信息卡；直接恢复旧页面
接口会丢失当前使用域与作答版本。

## Decision

域题面在现有授权和版本解析后补充公开元信息。提供者只返回 ID、用户名和头像；
算法标签仍要求本域编辑权限或本域正式通过，其他用户只得到普通标签与隐藏提示。
评测后端由已选不可变版本的公开投影派生，不向学生补回运行配置。

前端通过 `toDomainProblemView`
复用原有视图模型，保留完整来源题号、实际作答版本、
时间／内存限制和后端已裁剪标签。转换不请求旧全局接口。

## Alternatives considered

- 在页面按题型猜测后端或提供者：会产生错误信息，尤其不能区分 OI 原生与 WASM。
- 为恢复资料卡返回完整题目或作者对象：不必要地扩大字段及权限范围。

## Consequences

没有 Schema 变化。新增题面 API 断言验证学生看不到算法标签和账号敏感字段，作者
仍能维护完整标签；视图测试验证跨域来源、固定版本和公开元信息准确保留。
