# Agent Note: 作业反馈、求助与授权通知

Status: implemented

## Problem

教师需要整体及个人反馈，学生需要关联本人提交的私人求助。学情能力不能
隐含反馈或求助权限；离班、教师撤职、账号注销及通知延迟也不能泄露内容。

## Decision

新增整体／学生反馈、求助、追加回复和教学通知表，任务、实际目标学生、题目
及回复归属通过复合约束保护。正文统一校验，作者注销保留记录并显示已注销
身份。反馈编辑只允许原作者并要求 revision；教练和域治理可撤回其他反馈，
保留原正文及作者依据。普通助教不能替他人改写或撤回反馈。

学生只可读取整体及本人反馈，求助只显示本人或 help:manage 获授权人员。
关联提交必须属于本人及当前域，且匹配任务题目；提交删除不删除旧讨论。
回复只追加、幂等；教师可明确标记处理，学生追问重新打开。离班学生继续
读取原讨论，但不能继续新互动；教学停用或任务归档只保留历史读取。

反馈与求助在业务事务登记通知事件，通知不使成绩投影失效。持久消费者按页
投递，每位收件人重新检查资源读取权限，用事件与用户唯一键合并重试。通知
只保存类型及资源定位，不保存私人正文摘要。列表计数、分页和已读操作都检查
当前关系，撤回反馈或助教失去求助能力后旧通知不能恢复访问。

## Alternatives considered

- 所有教学身份统一读取：会扩大助教权限，因此按固定能力分别授权。
- 删除提交时级联删除求助：会丢失教学讨论，因此只清除可选提交关联。
- 在通知中保存反馈正文：撤权后容易继续暴露，因此保存位置并重新读取。
- 将通知当作成绩事件：会让无关单元过期，因此通知消费者独立处理同一持久队列。

建立；运行时 DDL、模板指纹、测试清理登记与迁移保持一致。开发库与恢复库
均完成追加升级，原资源不重建。

HTTP 认证、私人反馈、同学隔离、助教撤权、离班与停用、作者注销、
提交删除、复合约束、幂等回复、通知回滚、重复领取及点击重新授权。
