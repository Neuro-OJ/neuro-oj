# Agent Note: 题目与竞赛发布验收及数据说明

Status: implemented

## Problem

题目发布前缺少可执行的配置检查，竞赛排名没有不可变的正式版本，账户注销后的数据保留规则也缺少公开说明。

## Decision

增加管理员题目预检接口，检查运行配置、镜像白名单、模板与支持包，并返回当前内容指纹；增加竞赛排名快照表与管理员发布、查看、CSV 导出接口；增加可配置的数据说明页面，明确注销时清除和保留的内容。

## Alternatives considered

不增加预检会把错误留到正式发布后；只读取实时排名无法追溯正式成绩；只提供固定法律文本无法准确描述不同部署的数据处理方式。

## Consequences

预检不会自动证明任意评测器安全，也不会替代实际运行测试。正式成绩发布后重测不会修改已有快照，修订需创建新版本。运营者需要配置实际联系渠道和部署信息。
