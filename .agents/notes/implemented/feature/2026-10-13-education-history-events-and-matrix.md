# Agent Note: 教学变化沿革、停用区间与分页成绩矩阵

Status: implemented

## Problem

消费者延迟不能只保存最后一次题库变化。题目新版、共享撤销、域进入政策、比赛
结束、提交删除和模块停用都需要驱动进度更新。教师不能从旧口径矩阵得到未经
标明的成绩，也不能因多次刷新生成重复计算任务。

## Decision

源题发布为各使用域的 any 绑定递增 revision 并保存默认作答版本依据；exact
绑定保持原版本。作业按不可变绑定沿革补齐发布之后每一次变化，使用来源沿革 ID
及唯一约束保证重复事件不重复写入。每次最多补入 500 条沿革，后台持久游标
继续剩余部分，分数始终从当前事实计算。

接入版本、策略、可见性、共享、源域状态、班级归档、提交删除及模块政策事件。
删除提交前释放派生尝试指针，保留目标名单并重算其他候选。比赛结果受限时不
计入教学；到期事件持久保存，开始消费时递增事实版本，时间调整重排到期事件。
源题的成员展示范围不能被当作公开共享资源。

域模块暂停复用 workspace 已有的 feature 区间。实例模块暂停使用 Domain 为 NULL
的全实例区间，因此后来创建的域也受该停用时间段约束；政策及区间同事务
更新，重置政策也关闭区间。恢复后不回填停用期间练习，历史读权限继续有效。

成绩矩阵按 50 名目标学生分页，一次返回整页题目，提供统计范围、当前／历史
名单和用户名筛选。源码及 evaluator 文本不出现在矩阵 DTO。学生只读本人进度，
助教学情授权独立，撤权后立即拒绝。旧投影显示 updating 并隐藏旧口径分数，
数据库部分唯一索引合并刷新请求；本人小范围直接重算。

修正两个时间范围：新生首次接收作业沿用任务的发布前提交政策；已有目标学生
复入班级可继续补做旧任务，但离班期间仍排除，新生不自动取得截止任务。提前
结束只收紧按时窗口，后续练习仍能更新补做进度。

## Alternatives considered

- 消费时只记录当前策略：会遗漏中间版本，因此读取不可变的绑定沿革。
- 为每个域复制实例停用区间：会漏掉停用期间创建的域，因此保存全实例区间。
- 矩阵同步扫描每个单元：会产生大量查询，因此批量读取当前页、异步合并补算。
- 截止或提前结束后冻结所有进度：与允许补做冲突，因此分离两个统计范围。

## Consequences

追加迁移 0122，为作业沿革增加来源引用，为刷新事件增加部分唯一索引，并使
全实例停用区间可表达。运行时 PGlite DDL、模板指纹及迁移快照一致；原开发库
与隔离恢复库均完成升级，现有题目及账号不重建。

生产教学准备接口仍等待完整域隔离验收。通知、教师 Web、完整矩阵筛选及 CSV
导出、源码批注和其他教学工作台任务仍未交付。本记录只标记上述后端行为。

标准 PostgreSQL 并行回归通过：unit 377、db 1670，0 失败、17 跳过；PGlite
教学模块 40 项通过。测试覆盖真实版本发布、连续策略沿革、停用区间、并发刷新、
删除提交、比赛结束与延期，以及 HTTP 本人和教师权限。完整类型、格式、lint、
Schema parity、迁移安全、快照链、模块边界与 CI 路径检查通过。首轮全量回归
发现旧版本测试清理未删除新增沿革引用，修正清理后全量复跑通过。
