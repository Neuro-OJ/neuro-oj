# Agent Note: 域提交读取与教学反馈跟进页面

Status: implemented

## Problem

域内提交入口缺少对应的结果和列表页面；教师需要从成绩矩阵跟进未达标学生，
既有行批注页面也没有连接已经实现的修改及撤回接口。

## Decision

- 新增带使用域的本人提交列表和详情，页面 cache key 包含账号、使用域、提交 ID 或过滤条件。
  普通提交入口受理后链接到该域详情，不切换源题所在域。
- 结果组件按后端 `result_visibility` 展示：隐藏时仅回执，汇总模式不渲染测试点和原始输出。
  源资源撤销时只展示服务器保留的原提交及成绩摘要，原代码以文本显示。
- 作业复制面板新增当前页未达标学生快捷选择，仅纳入已更新的未开始或未达标单元。
  评测中、更新中、资源失效和历史学生不参与自动选择。面板明确名单及题目的组合，教师预览后创建独立草稿。
- 行批注作者可在有反馈权限时修改正文或确认撤回，写操作带服务器 revision，
  失败不静默覆盖，新提交不会继承旧批注。

## Alternatives considered

没有复用旧全局提交路由，以避免错误域归属和默认域读取旁路。
没有把当前页推断成整个班级；全班未达标批量选择需要服务端聚合及独立验收。

## Consequences

本记录范围为客户端功能；后端授权和结果裁剪仍为最终事实。
完整浏览器流程、比赛实际作答、整班自动补题和真实评测验收继续由实施总清单跟踪。
