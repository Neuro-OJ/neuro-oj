# Agent Note: 班级成员设置与交接 Web 流程

Status: implemented

## Problem

班级页面只有列表和作业目录，教师无法通过界面邀请学生、调整助教能力、处理离班或完成班级交接与归档。

## Decision

接入班级成员、单人邮箱邀请、邀请撤销、身份调整及六项固定助教能力。成员管理助教只能处理学生，教练和域治理人员可处理教学人员；具体任命权限仍由服务端验证。学生和未获授权人员不会从页面获取其他人的管理能力。

邀请令牌仅在生成后的当前页面展示为 fragment 链接，不进入 URL
查询或持久草稿。学生接受邀请仍走已有账号／域邀请流程，教师不批量创建平台账号。

班级设置保留原
revision，冲突不覆盖输入，显式重新读取才替换草稿。主教练交接选择当前有效教练，归档保留获授权历史。域、账号或班级变化后不沿用旧表单、邀请链接和未完成操作结果。

## Alternatives considered

- 任意助教权限字符串：使用固定能力列表，沿用后端约束。
- 通过教师邀请替学生创建账号：沿用实例注册政策，邀请不绕过管理员开户限制。
- 将交接视为搬迁数据：仅改变现班级管理关系，保留历史 ID。

## Consequences

单人邀请与管理准备页面已接入，CSV
导入、加入申请和批量邀请仍未完成；没有添加普通用户教学导航，也没有把阶段六标记为签收。班级及作业权限后端回归保持通过，浏览器操作仍待完整域隔离后验收。
