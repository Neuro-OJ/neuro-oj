# Agent Note: 管理后台全链路体验重构与工作站升级 (Phase 1 - Phase 4)

Status: implemented

## Problem

此前 Neuro OJ 的管理后台（`noj-ui/pages/admin/`）在快速迭代过程中累积了多项体验与架构痛点：

1. **导航臃肿与层级失衡**：左侧侧边栏导航分组不合理，单单「内容与评测」分组就堆积了 13 个菜单项，高度严重超出屏幕，需频繁滚动；折叠后缺少 Tooltip 气泡提示；
2. **缺少全局顶栏与命令入口**：桌面端主内容区无顶部全局栏（Topbar），没有面包屑路径、环境标识（Dev/Prod）、管理员身份展示与快捷搜索；20 余个管理子页面跳转效率低下；
3. **主容器硬性受限**：主内容区被硬编码限制在 `max-w-[1200px]`，导致宽屏显示器下两侧大片留白，而多列数据表格（提交记录、审计日志、用户列表等）却严重拥挤、频繁折行；
4. **仪表盘静态且缺乏行动驱动**：旧版 `/admin` 仅有 3 个静态数字和 1 个队列卡片，缺少待办事项提醒、系统依赖健康度、实时评测沙箱态势与快捷操作入口；
5. **表格交互效率低与状态丢失**：表格（`AdminTable`）缺少行选择和批量操作（Batch Actions）能力；筛选与分页未与浏览器 URL Query 双向同步，刷新或后退后状态丢失；状态徽标（Status Badge）缺乏统一的语义化映射；
6. **编辑流程交互割裂**：轻量级实体（如标签、黑名单、LLM Provider）的新建与编辑多采用粗糙居中的弹窗（`UModal`），遮挡底层表格上下文，操作断层。

## Decision

按照系统化重构路线图，完整实施 Phase 1 至 Phase 4 重构：

1. **Phase 1: 布局底座与导航重塑**：
   - 重构 `noj-ui/layouts/admin.vue` 侧边栏为 6 大清晰业务域：概览监控、题务教务、评测与算力、社区与风控、用户与安全、系统运维；
   - 新增 `AdminTopbar.vue`（全局操作栏）：提供动态面包屑、全局快速直达搜索触发器、本地开发环境标识、管理员身份胶囊与快速返回前台；
   - 新增 `AdminCommandPalette.vue`（命令面板）：支持全局快捷键 `Ctrl+K` / `Cmd+K`，支持拼音/英文/中文模糊搜索，键盘上下键选择并即时跳转 20+ 个管理页面；
   - 主内容容器升级为自适应流式全宽 `w-full max-w-[1600px] mx-auto`，释放横向数据空间。

2. **Phase 2: 仪表盘与大盘体验重构**：
   - 重构 `noj-ui/pages/admin/index.vue` 为行动导向运维中枢（Actionable Hub）：
     - **待办任务通知栏**：高亮提示待处理用户举报与评测积压，一键直达处理；
     - **核心指标网格**：用户规模、题库储备、历史评测量、今日评测吞吐（采用等宽数字 `tabular-nums` 与对比微色块）；
     - **双栏态势与服务中心**：实时评测队列状态（等待中、评测中、今日完成）搭配运行指示灯；核心依赖矩阵（Core API、PostgreSQL、Redis MQ、Docker 沙箱）；
     - **快捷运维工作流**：高频常用入口磁贴（新建编程题、创建竞赛、发公告、配 Provider、调权限、改设置）；
     - **近期系统审计动态**：接入最近 5 条审计日志流，实时感知平台动作。

3. **Phase 3: AdminTable 效率赋能与列表规范**：
   - 增强 `AdminTable.vue`：
     - 支持 `selectable` 模式：行 Checkbox 与表头全选/半选 Checkbox；
     - 提供 `#batch-actions="{ selected, clearSelection }"` 批量操作工具栏插槽，勾选后平滑滑入；
     - 支持 `comfortable` / `compact` 表格密度即时切换；
     - 容器样式对齐近直角 4-8px 与阴影规范（`rounded-lg shadow-card`）；
   - 增强 `useAdminList.ts` / `useAdminResource.ts`：
     - 支持 URL Query 双向同步（`?page=X&keyword=Y`），刷新不丢筛选状态，支持浏览器前进后退；
     - 增加 `totalItems` 响应式引用透出；
   - 增强 `AdminStatusBadge.vue`：
     - 覆盖评测状态（AC、WA、TLE、MLE、RE、CE、SE）、业务状态（公开、隐藏、正常、待审核、封禁），支持圆形小灯指示（`dot`）。

4. **Phase 4: 全局右侧滑入抽屉 (Slideover Drawer) 与高频编辑/详情工作流升级**：
   - 升级基础组件 `AdminDetailDrawer.vue` 与 `AdminEditPanel.vue`：全面采用 `@nuxt/ui` 内置的 `USlideover`，从生硬居中弹窗升级为平滑右侧滑入/滑出抽屉，配备表头视觉徽章与底部吸底操作栏；
   - **竞赛工作台全流程抽屉化与题目拖拽重排**：
     - `ContestFormModal.vue`：从居中固定弹窗彻底重构为响应式全高抽屉（`w-full sm:max-w-2xl lg:max-w-4xl xl:max-w-5xl`），双栏排版组织基础属性、时间窗口、防作弊与榜单规则，集成题目检索与分值挂载，绑定 `:open` 保证滑出动画平滑闭合；
     - **竞赛题目拖动排序交互**：已选题目列表支持基于原生 HTML5 Drag & Drop 的抓手（Grip Handle）拖拽排序与上下移动箭头微调，拖动或移位后实时重新自动编号题目标签（A、B、C...）与 `sort_order`，满分与提交上限随题目平移，无闪烁且具备拖拽高亮指示；
     - `contests.vue`「参与者管理」：从居中弹窗转为右侧滑入抽屉（`sm:max-w-xl`），提供即时用户搜索、一键添加入赛与名单管理；
   - **全后台多实体编辑与详情抽屉化替换**：
     - **权限与角色**（`roles.vue`）：角色编辑与细粒度权限勾选转换为抽屉；
     - **用户与风控**（`users.vue`）：用户封禁表单与封禁历史时间线转化为抽屉；
     - **举报治理**（`reports.vue`）：举报处理处置表单与完整会话消息上下文转换为抽屉；
     - **内容审查**（`content-review.vue`）：审查快照/会话上下文详情与处置弹窗转换为抽屉；
     - **题务管理**（`problems.vue`）：发布前质量预检报告（Preflight checks）转换为详情抽屉；
     - **标签运营**（`tags.vue`）：标签创建/编辑与标签合并转换为抽屉；
     - **算力与调用**（`llm/usage.vue`、`llm/providers.vue`）：LLM 调用明细与 Provider 配置转换为抽屉；
     - **平台运营与基础设施**（`announcements.vue`、`carousel.vue`、`judge-images.vue`、`blacklist.vue`）：统一采用 `AdminEditPanel` 抽屉。

## Alternatives considered

1. **继续使用居中弹窗（Modal）替代侧滑抽屉（Slideover）**：
   - 评估：居中弹窗严重遮挡底层数据表格，管理员在填写长表单或查看上下文时无法对照底层数据行（例如对比现有竞赛配置、查看待处理举报原帖）。右侧滑入抽屉在提供充裕编辑空间的同时保留了左侧视野与操作连续感，且右侧滑入滑出的过渡动效明显更契合现代专业管理台交互体验。
2. **在主内容区写死更大固定宽度（如 1400px）**：
   - 评估：写死固定宽度在笔记本屏幕或超宽带鱼屏上要么溢出要么浪费。采用 `w-full max-w-[1600px] mx-auto` 搭配响应式 padding 能更好兼顾各种屏幕。

## Consequences

- 管理员在侧边栏寻址效率显著提升，平均点击路径缩短；
- 具备 `Ctrl+K` 命令面板，可在几秒内直达任意后台功能；
- 列表页支持 URL 状态记忆与批量操作，解决了刷新重置的痛点；
- 原本粗糙零散的居中弹窗（竞赛新建/编辑、参与者管理、角色权限、用户封禁与历史、举报处理、内容审查、预检报告等）全面升级为具有优雅滑入/滑出动画的右侧抽屉，大幅提升了操作专注度与视觉一致性；
- 前端测试 191 项全部通过，`deno fmt` 与 `deno lint` 保持 0 错误 0 警告，Nuxt 顺利运行。
