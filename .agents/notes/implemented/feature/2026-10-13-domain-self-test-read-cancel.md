# Agent Note: 使用域自测读取与取消

Status: implemented

## Problem

域自测已独立入库，但客户端没有同域结果读取及取消入口。
复用旧全局读取会丢失路径域校验，复用正式提交裁剪又会隐藏用户自测用例的正常输出。

## Decision

新增显式域自测详情及取消路径，每次读取当前域及成员、本人或域内提交读取权限。
错误域和其他无权账号使用同一不可见结果；取消复用原数据库终态及 Redis 共享取消信号。
OI 自测使用专用允许字段投影，仅返回判定、资源元数据和用户用例 stdout/stderr。
源数据输入、checker 诊断和任意评测详情不返回；源题撤销后进一步隐藏全部输出、详情和进度。
本人原代码和汇总成绩继续保留，自测不进入正式提交、排行或教学成绩。

## Alternatives considered

没有通过全局自测接口读取学校记录，也没有在客户端猜测删除隐藏字段。
没有将正式提交投影用于用户自测，因为两类输入和输出的授权依据不同。

## Consequences

标准 submission 回归 320 项通过，0 失败、40 项环境专属测试跳过。
新增用例验证错域、无权账号、取消信号、原输入保存、用户 stdout/stderr、诊断裁剪及源撤销。
服务、路由及新测试类型检查通过；真实 Judge 和浏览器自测旅程仍待最终验收。
