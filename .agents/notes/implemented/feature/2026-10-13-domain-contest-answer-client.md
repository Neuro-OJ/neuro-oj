# Agent Note: 域比赛固定版本作答页面

Status: implemented

## Problem

域比赛题目列表已经提供比赛题标和固定版本，但没有对应作答页面。
使用普通练习提交会丢失比赛归属，也可能获取比赛不允许展示的反馈。

## Decision

- 新增 `/d/:slug/contests/:contestId/problems/:label` 页面，从比赛独立接口读取题面、模板和客观小题。
  编程和产物提交使用独立比赛提交接口，客观题使用独立一次交卷接口；不向普通题库接口注入比赛 ID。
- 草稿缓存额外包含比赛 ID，版本变化保留学生输入并要求重新确认。
  客观题以服务器提供的稳定小题 ID 提交答案，界面只显示授权总分或中性回执。
- 编程回执指向同域提交详情，继续使用后端统一结果裁剪。比赛榜单在进行中每五秒重读授权接口，
  正式榜单仅展示服务器快照，不在客户端重新计算成绩。

## Alternatives considered

没有把比赛标号转换成源题题库提交，因为比赛固定版本、一次交卷与保密规则需要同一比赛上下文。
没有在浏览器按赛制自行删除零散结果字段，服务器结果 DTO 仍是唯一公开依据。

## Consequences

本记录交付客户端代码和契约回归；完整比赛浏览器旅程、真实 Judge 结果及封榜/结算发布验收仍待进行。
实际接口是否对普通用户开放由组合根隔离验收决定，页面不能代替后端权限与提交窗口检查。
