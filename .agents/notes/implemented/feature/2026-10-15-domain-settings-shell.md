# Agent Note: 域设置入口与共享运营管理组件

Status: implemented

## Problem

域设置、成员、LLM 和社区管理入口散落在主导航，公告与轮播又只有实例页面。用户
需要在用户名菜单进入独立域设置，并沿用实例管理控件。

## Decision

增加按域能力生成的设置分组与手机选择导航。用户名菜单独立显示域设置，默认域
同样走这一入口；账号设置与实例治理继续属于实例账号。移除主导航内的管理入口，
保留题库、比赛、社区和教学业务导航。

将原公告、轮播管理页提取为共享组件。实例页面保留原 API，域页面传入明确的域
作用域，复用列表、表单、排序、图片上传和错误展示。编辑输入增加未保存离开保护，
域管理组件按域和操作者重新挂载。成员、LLM、社区管理复用统一设置导航。

## Alternatives considered

- 为域复制一套运营页面：样式和功能容易分叉，未采用。
- 将默认域继续放进实例设置：与其他域行为不一致，未采用。
- 用客户端当前域自动改写全局 API：作用域不明确，未采用。

## Consequences

实例设置仍可选择默认落地域，但不负责编辑默认域运营内容。域设置中的访问方式
与资源额度链接定位现有表单，避免增加重复写入接口。最终浏览器验收随首页和
做题工作区恢复后集中执行。

验证：UI 标准测试、完整 Nuxt/Vue 类型检查及本批文件 lint 通过；导航测试覆盖
普通成员无管理入口、权限分组、默认域与其他域一致的路径。
