# Agent Note: 教学矩阵与互动准备页面

Status: implemented

## Problem

班级、作业进度和互动后端已有准备接口，缺少供教师和学生使用的页面，也不能复用旧全局提交
API 来访问学校内的数据。

## Decision

新增域内班级列表、班级作业列表和作业详情准备页面。通过 `useEducationApi`
统一使用明确域路径，所有异步数据键包含域、查看者、资源及筛选。固定助教能力决定页面操作，服务端仍实时授权。

作业页支持按时／补做成绩、当前／历史学生、用户名、题目、状态和正式判定筛选，以及授权
CSV
导出。矩阵按学生分页并采用一次响应的单元，窄屏使用学生卡片；过期成绩只展示更新状态并自动补读。本人进度只调用本人接口，继续练习保留当前使用域。

单元详情读取原代码或学生 ZIP
文本，可按源码哈希和行范围留下批注。学生只查看本人原提交上的反馈。整体／个人反馈、求助、追加回复和处理状态使用现有互动契约，重试保留幂等键，状态修改携带
revision。切换域或账号后不把旧响应应用到新页面。

## Alternatives considered

- 从旧全局 API 读取教学数据：无法保留使用域和独立教学授权。
- 每个矩阵单元单独请求：导致大量并发请求，改为后端分页响应。
- 在更新期间继续展示旧分数：会让过期策略口径被误认为当前成绩。

## Consequences

页面及后端均属于准备实现，未添加公共导航入口，等待域资源隔离后协调开放。创建／编辑／发布作业、班级成员管理、客观题详情、提交成绩沿革、批注编辑、通知页面和完整教学工作台继续实施；本记录不代表教学阶段完成。

单元、组件、类型和构建验证不能替代真实教师旅程或移动端浏览器验收。后续验收必须实际连接正式授权接口，不用当前矩阵组件测试冒充浏览器旅程。
