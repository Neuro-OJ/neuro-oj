# Agent Note: 公开题型与评测后端标识

Status: implemented

## Problem

题目详情未区分 OI 与 AI 题，也未显示执行后端。普通选手无法读取完整运行配置，前端不能靠该配置推断原生与 WASM 后端。

## Decision

公开题目及竞赛题目响应增加只含执行器名称的 judge_backend，统一从持久化题型与运行配置提取。客观题无执行后端。共享题目头部与信息卡展示题型及 dual、oi-native、oi-wasm 标识；缺失字段不猜测后端。题库列表同时展示题型和后端，新增 URL 驱动的题型与后端筛选；服务端在分页前施加条件，AI 筛选排除客观题，非法值返回错误。题库筛选面板采用带标签的下拉框与响应式网格，支持一键清空。提交页用可复用 ProblemReference 展示题号与名称，并补充题型和后端；WASM 计量默认折叠，测试点只投影安全的计量字段为表格，不展示原始 JSON。后台统一计量面板补充直接从标准清单读取的内存成本与换算示例。

## Alternatives considered

公开完整运行配置会泄露测试点和 checker 信息；只在管理员视图显示无法满足选手需求；从语言推断后端无法区分两种 OI 执行器。

## Consequences

公开元数据增加但隐藏评测配置保持原有访问控制。独立与竞赛题面使用同一展示口径；客观题显示即时判定，不误标为双容器评测。无需数据库迁移，不改变评测行为。
