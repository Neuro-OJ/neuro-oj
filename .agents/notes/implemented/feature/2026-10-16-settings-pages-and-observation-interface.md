# Agent Note: 设置分页与统一提交、队列界面

Status: implemented

## Problem

域设置混合页内锚点和页面跳转，实例治理把多份表单及目录堆在同一页。权限初始化
期间出现假拒绝提示；队列缺少明确的域和实例范围，提交列表不能直接筛选他人摘要。

## Decision

Gemini 负责前端实现，主 Agent 负责后端契约、实际运行、验收及签名提交。域设置 统一为功能页面，旧成员、社区治理及 LLM
入口重定向。实例治理拆分访问注册、空间 创建、模块许可、资源及 LLM 上限、目录和创建申请，各页原子保存并携带 revision。
目录采用表格和操作菜单，模式和字段说明使用现有控件与品牌 token。

额度模式采用明确的选择器，继承模式隐藏数字，自定义空值保持待填写。数字输入 使用现有 UInput
随输入更新；原步进控件在失焦前不提交值，会让已填入有效数字的 保存按钮仍然禁用。保留整数、0
和有效上限的含义，不静默向下取整。

后台主内容的 flex 子项及 main 明确设置 min-w-0，使目录表格在自身容器内横向 滚动，不把 390px
手机页面撑宽。浏览器旅程检查文档宽度，避免只检查截图外观。

权限解析先呈现加载。401、403、404 清除当前权限；普通网络错误保留最近一次成功
的同身份、同域数据及表单草稿，并单独禁用写入，不把服务错误伪装成域已归档。
最近成功数据随请求上下文变更清除，保留服务端对象引用，不做深拷贝。

统一提交页使用用户名及题型筛选，显式空用户名写入 URL，刷新后仍保留空值。
详情依据源码、答案及比赛结果能力显示。队列在一页切换域和实例，统计范围、可见 明细范围及共享资源池分别说明；切换时关闭旧
SSE，并忽略旧上下文的慢响应。

## Alternatives considered

没有另建教育设计系统，也没有为实例队列的私有任务增加占位行。没有通过浏览器 合并多份分页结果，没有新增跨域账号身份或 JWT
的当前域字段。删除已被功能页面 替代的两份实例治理组件，避免保留两套表单和契约。

## Consequences

真实浏览器旅程覆盖导航、邀请码查询、空用户名刷新、队列切换及 503 后草稿保留。
浏览器另外发现表格缺少操作列，已修复目录与成员页的列配置；此前仅渲染所有插槽
的测试桩不能证明按钮实际存在。最终检查、截图和 CI 结果单独记录在实施清单及验收 报告，不以工具测试代替实际页面验收。
