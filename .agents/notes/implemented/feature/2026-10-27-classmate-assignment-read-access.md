# Agent Note: 同班学生完成情况与结束后代码互阅

Status: implemented

## Problem

学生原先只能读取本人班级成员记录与作业进度，无法查看同班同学完成情况。
需要在开放只读同伴学习入口的同时，保证进行中的作业代码不泄露。

## Decision

- 当前学生可查看有效同班学生名单，以及共同已发布作业中的同班完成情况。
  教师保留历史人员读取和 CSV 导出；学生不获得教学管理能力。
- 进行中作业隐藏他人提交定位指针，代码、文件列表、下载与单条详情均在服务端授权。
  截止时间已到、提前结束或归档后，才允许读取实际满足共同作业来源及计入窗口的代码。
- 每次读取重新校验当前班级和域身份、目标学生、共同作业及比赛保密窗口。
  `assignment_only` 不能开放同题的其他练习，离班不延续同伴访问权限。
- 学生保留“我的进度”，新增“同班完成情况”；只读同学代码不展示其教师批注。 导航
  RouterLink 的“班级研练中心”按用户要求改为“教学”。

## Alternatives considered

只隐藏前端代码按钮无法阻止直接请求；赋予学生教学人员源码能力会开放全域练习和
管理入口。采用独立的同班与已结束作业条件，并保持原有教师权限边界。

## Consequences

无数据库结构变更。使用独立 PostgreSQL、Redis 和存储目录运行教学域回归，
验证结束前后、跨班、离班、来源限制和批注隔离；前端重新构建后更新本机 preview。
