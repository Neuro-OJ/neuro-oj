# Agent Note: 域内本人客观题历史与提交频率

Status: implemented

## Problem

域内客观题客户端需要读取本人交卷历史，统一历史不能成为错误域路径或同学答案的读取入口。客观题正式交卷也必须使用真实的域提交频率额度。

## Decision

域列表及详情先解析当前可进入的工作空间，再调用 submission
的本人历史门面。列表固定用户、域和客观题类别，详情核对持久域归属；撤销题目授权后的本人原答案继续按受控历史规则读取，不恢复题面或标准答案。

交卷在事务锁定当前题库执行上下文后、写入正式记录前消费域提交额度。沿用服务端提交
ID 作为幂等依据，额度拒绝不会插入第二份正式交卷。

## Alternatives considered

不增加教学人员通用答案读取接口。教学读取继续通过班级门面验证学生关系和比赛保密规则。不在客户端推导域归属，也不以源题所属域代替使用域。

## Consequences

两项实际路由测试覆盖本人分页、错误域路径、他人 ID 及最后一个提交额度。objective
标准测试在 PGlite 和隔离 PostgreSQL 均为 66
项通过。生产路由仍等待统一接入和跨模块验收。
