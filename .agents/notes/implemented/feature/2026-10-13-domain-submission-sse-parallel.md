# Agent Note: Domain 提交 SSE、队列与当前教师读取隔离

Status: implemented

## Problem

旧提交 SSE 在建连时检查权限，实时推送和持久重放直接透传评测载荷，
成员撤权后连接仍可接收。旧队列跨全实例读取题名和提交，Redis 原始长度及共享
评测池活动也会增加公开统计。使用域提交详情尚未纳入当前班级教练读取能力。

## Decision

新增显式域提交和自测 SSE，事件仅包含提交定位、使用域、资源可用性和结果
可见性。每次推送和持久重放重新读取受裁剪详情、检查当前账号与成员权限；
私有域撤权后关闭长连接。源共享撤销后只通知资源不可用，不转发原始输出、 任意
details、代码、分数或测试数据。自测完成后新增其独立定位通知。

旧提交 SSE、队列和队列 SSE 固定 main。队列列表、完成数据及各项计数在
查询中按当前使用域及题库绑定授权过滤；公开赛保密题不经旧练习记录泄露。 pending
数量取已过滤条目，不使用全实例 Redis 长度。
普通队列响应不返回共享池活动与内存占用；实例治理健康接口保留。
创建、完成和移除队列任务时从可信源记录读取 Domain，发送对应域频道事件。

Domain 提交详情通过教育公开门面的当前班级关系允许教练及获授权助教读取。
离职、离班或离域后不再获得个人练习；原作业历史依据仍使用教育模块已有的
班级授权接口，不新增绕过全部历史关系的通用读取通道。

教师读取继续服从比赛保密。Kaggle 本人反馈保持原有内容，其他非组织者无法
通过教师身份查看赛中代码和结果；比赛结束后恢复已授权历史读取。 OI
系列使用既有允许字段投影，不新增第二套评测结果裁剪。

## Alternatives considered

只在建连时授权不能处理持久连接撤权。发送裁剪后的完整评测事件仍容易混入 原始
details 或乱序旧载荷，故 SSE 只提供定位信息并由客户端重新读取。
分页后过滤队列不能消除计数和短页侧信道，授权条件进入 SQL。 直接给教练平台
submission:read_all 会越过 Domain，未采用。
将历史班级关系与所有个人练习合并会在学生离班后扩大教师权限，未采用。

## Consequences

显式域 SSE 路由由组合根统一挂载，客户端收到定位事件后重新读取对应域详情。
历史本人跨域目录及域批量任务属于后续独立提交，不在本批声明已交付。

标准 submission 首次完整回归 PGlite 324 项通过、40 项 PostgreSQL/环境检查
忽略；独立 PostgreSQL test_submission_agent 354 项通过、10 项环境检查忽略。
新增用例覆盖错误域、代码/分数/测试数据重放裁剪、共享撤销、成员移除、
默认域队列不计私有学校活动、教师离职/学生离班以及 Kaggle 赛中与赛后读取。
最终类型、lint 和边界证据随本批冻结报告记录；完整浏览器与性能验收另行执行。
