# Agent Note: 题单视图与评测结果表达

Status: implemented

## Problem

题单详情仅显示编号，缺少题名与个人状态；结果组件把缺少 OI 判定的已完成任务仍
描述为排队或执行中。直接对整个长题单补齐摘要会扩大 Core 请求压力。

## Decision

Nuxt BFF 按当前页20题读取使用域题目摘要，复用请求内去重、四路并发与取消预算。
仅返回题名、类型和进度，未知与资源不可用独立呈现；不计算未加载的全题单完成率。
题单改为连续列表，共享维护由用户展开。结果按生命周期区分完成、处理中和平台
失败，保留 OI 判定、比赛保密与详情可见性规则。

## Alternatives considered

- 修改 Core 增加批量摘要：超出仅调整 Nuxt 的约束。
- 进入即全量补齐：长题单的请求数与等待不可控，用户选择按页补齐。
- 缺少 OI 判定就继续等待：不能代表多题型真实完成状态。

## Consequences

题单每次最多补齐20题，摘要错误不会吞掉条目或误标未作答；私有结果仍不跨请求缓存。
首屏与水合复用视图，翻页保持 URL。结果完成不自动推导达标或通过，平台失败不算答案错误。
