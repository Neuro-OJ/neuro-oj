# implemented Agent Notes 规则

`implemented/` 下的 Agent Note 描述**已交付的现实**。

- 使用当前时态，不用“将/计划/应该”。
- 代码、路径、配置、包名变化时，同步更新对应 Agent Note 的事实部分。
- 禁止出现 `## Proposal`、`## Plan`、`## Migration plan`、`## Acceptance criteria`。
- 必须包含：
  - `## Problem`
  - `## Decision`
  - `## Alternatives considered`
  - `## Consequences`
- 格式与分类见 `.agents/notes/README.md`。
