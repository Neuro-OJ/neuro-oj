## Context

NOJ 当前视觉以 Tailwind 默认蓝 `#2563eb` 为主，缺少设计 token 体系。本次设计决策将“暖纸评测风”正式化为可实施的品牌系统，视觉方法论参考工业编辑/纸张印刷风格，但所有具体元素都替换为 NOJ 自己的语义。

已有探索结论：
- 背景采用柔和暖纸 `#e8e8e2`，避免冷灰蓝科技感。
- 品牌蓝改为蓝黑墨 `#1B2B4A`，避免与常见 UI 框架蓝雷同。
- 交互/进行中信号使用评测绿 `#00d68a`，暗色使用 `#00e07a`。
- 全局背景使用低对比圆点，非等高线、非方点、非水印。

## Goals / Non-Goals

**Goals:**

- 建立 NOJ 可复用的视觉 token，覆盖亮色/暗色两套模式。
- 让全局背景有“评测稿纸”质感，同时不干扰文字阅读。
- 让 UI 的“稳定品牌色”与“动作信号色”分工明确。
- 让开发文档、文档站和前端样式拥有同一套设计语言。

**Non-Goals:**

- 不直接复刻《明日方舟：终末地》或 `dsh-theme-endfield` 的标志性元素（等高线、水印、雷霆大字、信号黄、`#14d0d0` 青、全直角 0 圆角、`ENDFIELD` 字标）。
- 不引入动画点阵、视差滚动或 JS 背景生成。
- 不改变后端业务逻辑、数据库、评测沙箱或部署安全边界。

## Decisions

### 1. 品牌设计 token

采用“纸、墨、品牌蓝、评测绿”四层结构：

| 角色 | 亮色 | 暗色 |
| --- | --- | --- |
| 纸底 | `#e8e8e2` | `#121310` |
| 面板 | `#f2f2ec` | `#191b17` |
| 沉底块 | `#dfe0d9` | `#0d0e0c` |
| 边框 | `#d5d6cf` | `#333631` |
| 正文 | `#1c1e1b` | `#f2f3ef` |
| 次要文字 | `#4c4e4a` | `#90938d` |
| 品牌蓝 | `#1B2B4A` | `#7C96D6` |
| 评测信号绿 | `#00d68a` | `#00e07a` |
| 信号深绿（纸面文字） | `#007146` | `#00d68a` |

**理由**：暖纸让系统柔和；蓝黑墨让品牌区别于常见 UI 蓝；评测绿只做信号，避免大面积铺色。

### 2. 圆角与排版

- 默认圆角改为 2–6px 近直角，不采用 `0` 全直角，保留纸裁边感且不完全照搬参考主题。
- 数字、分数、耗时、排名使用 `tabular-nums`，避免横向跳动。
- 卡片以细边框为主，阴影最小化。

### 3. 全局圆点背景

- 使用纯 CSS 重复背景，单位为 `radial-gradient` 或 `background-image` 点阵。
- 点型为圆点，尺寸 1–2px，间距约 28px。
- 亮色模式点色使用墨色低透明，如 `rgba(28,30,27,0.04–0.08)`。
- 暗色模式点色使用浅色低透明，如 `rgba(242,243,239,0.04–0.08)`。
- `background-attachment` 保持 `scroll`（默认），让点阵随内容滚动，不采用 `fixed`。
- 不做动画，不添加 JS。
- 可通过 CSS 变量控制 `--dot-size`、`--dot-gap`、`--dot-alpha`。

### 4. 不直接致敬的转化表

| 参考元素 | NOJ 处理 |
| --- | --- |
| 奶油纸底 | 使用同类柔和纸感，但可微调为 NOJ 专属纸色（如 `#e9e8e2`）或保留 `#e8e8e2` |
| 信号黄 / 武陵青 | 换成评测绿，色相/用途均不同 |
| 全直角 | 用 2–6px 近直角，而非 `0` |
| 等高线 | 不用；用低对比圆点或后续自创“评测刻度/波形” |
| 水印 / 雷霆大字 | 不用 |
| `ENDFIELD` 字标 | 不用；品牌字标保持 NOJ / Neuro OJ |

## Risks / Trade-offs

- [风险] 全局点阵若对比度过高会形成视觉噪点。→ [缓解] 默认极低 alpha，并作为可配置 token；通过对比度检查约束装饰层。
- [风险] 品牌蓝在暗色模式下原色对比度不足。→ [缓解] 暗色使用 `#7C96D6` 变体。
- [风险] 新视觉与现有组件大量使用 `text-primary` 的代码产生迁移成本。→ [缓解] 通过 token 变量一次性替换，避免逐组件硬编码。
