## ADDED Requirements

### Requirement: 未保存变更明确标识

系统 SHALL 在存在未保存修改的后台页面明确标识未保存状态（如"有未保存的更改"徽标），并提供保存与放弃操作。

#### Scenario: 修改后显示未保存标识

- **WHEN** 管理员修改配置（切换开关、编辑数值或应用预设）但尚未保存
- **THEN** 页面显示未保存更改标识，标识随保存或放弃操作清除

#### Scenario: 保存未保存更改

- **WHEN** 管理员点击"保存更改"
- **THEN** 所有未保存修改写入后端，成功后标识消失

#### Scenario: 放弃未保存更改

- **WHEN** 管理员点击"放弃更改"
- **THEN** 页面配置恢复为后端当前值，未保存标识消失
