## ADDED Requirements

### Requirement: 后台自动刷新不打断用户操作

系统 SHALL 在执行自动刷新（轮询）时静默更新数据：不得显示全表 loading 态、不得覆盖用户刚触发的搜索/分页/筛选结果、不得打断正在进行的编辑或弹窗操作。

#### Scenario: 轮询期间用户搜索

- **WHEN** 管理员在自动刷新进行中输入搜索关键字触发搜索
- **THEN** 轮询的旧响应不覆盖搜索结果，列表显示搜索条件下的数据

#### Scenario: 轮询静默不显示加载态

- **WHEN** 自动轮询刷新列表数据
- **THEN** 列表不显示 loading 态，已有数据保持可见
