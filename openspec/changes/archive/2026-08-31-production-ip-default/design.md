# 设计：服务器 IP 默认值

## IP 检测

新增 `detect_default_ipv4`：

1. 测试覆盖时允许通过环境变量提供确定的 IPv4。
2. Linux 优先执行 `ip -4 route get 1.1.1.1`，提取 `src` 地址。
3. 如果路由命令不可用，从 `hostname -I` 中选择首个非 `127.0.0.0/8` 的 IPv4。
4. 仍检测不到时返回空字符串，不阻塞用户手动输入。

## 配置向导

- `DOMAIN` 当前值优先；没有当前值时使用检测到的 IPv4，否则不设置默认值。
- 提示说明 IP 适合临时部署或已有 HTTPS 反向代理，正式环境建议输入域名。
- `APP_URL` 继续默认使用 `https://`，并保留生产服务对 HTTPS 的校验。

## 测试策略

- 验证 IPv4 默认值和用户域名覆盖逻辑。
- 验证未检测到 IP 时仍要求输入域名。
- 运行完整部署脚本回归、语法检查和 OpenSpec 校验。
