## ADDED Requirements

### Requirement: 前端密码规则错误提示

注册页和修改密码页 MUST 在前端复用完整密码强度规则：密码至少 8 位，包含至少一个小写字母、一个大写字母和一个数字，且不能与注册用户名/邮箱前缀或当前账号用户名/邮箱前缀相同。

当密码输入框失去焦点或用户提交表单时，若密码不符合任一规则，页面 MUST 在对应密码字段显示明确的中文错误提示，并 MUST 阻止向后端提交表单。密码符合规则后，页面 MUST 清除该密码字段的规则错误。

#### Scenario: 注册时密码规则不满足

- **WHEN** 用户在注册页输入不满足长度、字符组成或用户名/邮箱前缀限制的密码，并离开密码输入框或提交表单
- **THEN** 注册页在密码字段显示对应的规则错误
- **THEN** 注册请求 MUST NOT 发出

#### Scenario: 修改密码时新密码规则不满足

- **WHEN** 已登录用户在修改密码页输入不满足长度、字符组成或当前账号用户名/邮箱前缀限制的新密码，并离开新密码输入框或提交表单
- **THEN** 修改密码页在新密码字段显示对应的规则错误
- **THEN** 修改密码请求 MUST NOT 发出

#### Scenario: 密码规则满足后继续提交

- **WHEN** 用户将注册密码或新密码修改为满足全部规则的值，并填写其他必填字段
- **THEN** 对应密码字段不再显示密码规则错误
- **THEN** 页面允许继续执行注册或修改密码请求
