## Purpose

确保正式发布的容器镜像在完成构建后，能够被自动验证其内容摘要、签名、SBOM 和 GitHub 构建来源证明，避免流水线因验证环境配置缺失而误报失败。

## ADDED Requirements

### Requirement: 正式镜像验证必须具备来源证明查询权限

正式镜像验证流程 MUST 向用于查询 GitHub 来源证明的命令提供当前工作流令牌，并继续执行既有的摘要、签名、SBOM、来源证明和 smoke test 校验。

#### Scenario: 工作流令牌已配置

- **WHEN** 六个正式镜像构建、漏洞扫描和签名均成功，且验证任务开始执行
- **THEN** 验证任务能够查询来源证明并完成全部镜像验证

#### Scenario: 工作流令牌未配置

- **WHEN** 发布工作流缺少来源证明查询所需的工作流令牌配置
- **THEN** 发布前供应链配置检查 MUST 失败并指出缺少令牌配置
