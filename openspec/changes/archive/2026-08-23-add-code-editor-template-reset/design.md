## Context

见 proposal.md。编辑器已有模板 API 和 localStorage 草稿，但仅在首次打开且无草稿时自动加载。

## Goals / Non-Goals

**Goals:**

- 为标准题库做题页提供可见、可撤销的模板恢复入口。
- 让恢复后的模板继续作为当前草稿保存。

**Non-Goals:**

- 不为竞赛题新增模板读取能力。
- 不改变题目模板 API 或草稿保存策略。

## Decisions

- 重置入口置于编辑器工具栏，仅在调用方提供模板 URL 时显示。
- 覆盖前使用已有的统一确认弹窗，避免一次点击丢失未提交代码。
- 仅在模板成功返回后清除旧草稿并写入新模板；请求失败时原代码和草稿保持不变。

## Risks / Trade-offs

- [模板被管理员更新] → 重置始终请求最新模板，这是用户明确选择“回到模板”的预期。
- [覆盖本地编辑内容] → 通过确认弹窗明确提示该影响。
