## Purpose

确保用户清除做题草稿后可以立即回到题目提供的预设代码框架，同时避免模板不可用时丢失当前代码。

## ADDED Requirements

### Requirement: 清除草稿后恢复题目模板

当标准题库做题页提供题目模板地址时，用户在编辑器设置中执行“清除当前草稿”后，系统 SHALL 获取题目当前模板，删除旧的本地草稿，并将编辑器内容替换为该模板。

#### Scenario: 成功清除并恢复模板

- **WHEN** 用户点击“清除当前草稿”且题目模板请求成功
- **THEN** 编辑器显示题目预设代码，旧本地草稿被删除，恢复后的代码继续作为当前草稿保存

#### Scenario: 模板不可用

- **WHEN** 用户点击“清除当前草稿”但模板请求失败或返回空模板
- **THEN** 编辑器内容和原本地草稿保持不变，并显示失败提示

#### Scenario: 没有模板地址

- **WHEN** 当前做题上下文没有提供模板地址
- **THEN** 不执行模板请求，编辑器内容和本地草稿保持不变
