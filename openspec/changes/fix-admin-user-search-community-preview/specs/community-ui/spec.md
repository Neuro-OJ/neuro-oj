## ADDED Requirements

### Requirement: 社区列表摘要稳定处理

社区首页 SHALL 为每篇已加载帖子展示纯文本摘要；分页追加帖子时，已展示帖子的摘要内容 MUST 保持不变，且页面更新不得重复处理已加载帖子的原始 Markdown。

#### Scenario: 首次加载帖子摘要

- **WHEN** 社区首页加载一页帖子
- **THEN** 每篇帖子显示由其正文生成的纯文本摘要，且摘要不包含 Markdown 标记

#### Scenario: 追加帖子不重复处理历史摘要

- **WHEN** 用户点击“加载更多”并追加下一页帖子
- **THEN** 新帖子生成摘要，已有帖子继续使用此前生成的摘要，不因列表重渲染再次处理其正文
