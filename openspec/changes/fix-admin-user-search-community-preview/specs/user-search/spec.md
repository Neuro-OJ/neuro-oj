## Purpose

为管理员提供准确且受权限保护的用户搜索能力，支持在竞赛参与者管理中通过用户名或邮箱定位用户，同时避免普通用户搜索流程获得不必要的邮箱信息。

## ADDED Requirements

### Requirement: 管理员竞赛参与者用户搜索

系统 SHALL 为具备用户搜索权限的管理员提供用户搜索能力，按用户名或邮箱进行不区分大小写的模糊匹配，并返回参与者选择所需的用户 ID、用户名、邮箱和头像信息。

#### Scenario: 按邮箱搜索用户

- **WHEN** 管理员使用至少两个字符的邮箱片段搜索用户
- **THEN** 系统返回邮箱包含该片段的非 root 用户，并在每项结果中返回该用户的邮箱

#### Scenario: 按用户名搜索用户

- **WHEN** 管理员使用至少两个字符的用户名片段搜索用户
- **THEN** 系统返回用户名包含该片段的非 root 用户

#### Scenario: 非管理员访问用户搜索

- **WHEN** 未登录用户或普通登录用户请求管理员用户搜索能力
- **THEN** 系统拒绝请求，且不得返回任何用户搜索结果

### Requirement: 普通用户搜索隐私边界

普通登录用户使用私信联系人搜索时，系统 SHALL 保持原有的基本用户信息返回契约，不因管理员邮箱搜索能力而额外返回邮箱。

#### Scenario: 私信搜索用户

- **WHEN** 普通登录用户通过联系人搜索查找用户
- **THEN** 系统仅返回联系人搜索所需的非敏感基本信息，且不得返回邮箱字段
