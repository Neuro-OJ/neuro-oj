## Why

管理后台竞赛参与者搜索提示支持邮箱，但当前调用的用户搜索接口只按用户名匹配且不返回邮箱，导致管理员无法按邮箱找到用户。社区首页在模板渲染阶段重复处理所有已加载帖子的 Markdown，长时间浏览时会产生不必要的重复计算。

## What Changes

- 让管理员竞赛参与者搜索使用管理员专用用户搜索能力，并支持按用户名或邮箱模糊匹配。
- 返回竞赛参与者选择所需的邮箱字段，同时保持普通用户搜索接口不暴露邮箱。
- 在社区帖子首次加载或追加时生成纯文本摘要，模板直接渲染已生成的摘要，避免历史帖子重复执行 Markdown 清理。
- 为上述搜索匹配和社区摘要处理补充回归验证。

## Capabilities

### New Capabilities

- `user-search`: 定义管理员在竞赛参与者管理中按用户名或邮箱搜索用户的能力。

### Modified Capabilities

- `community-ui`: 增加社区列表摘要在分页加载期间保持稳定、避免重复处理的要求。

## Impact

- 影响 `noj-core` 全局用户搜索服务的匹配条件及其查询测试。
- 影响 `noj-ui/pages/admin/contests.vue` 的管理员搜索请求和响应映射。
- 影响 `noj-ui/pages/community/index.vue` 的列表数据类型、加载逻辑和摘要渲染。
- 不新增依赖、不修改数据库结构、不改变普通私信用户搜索的返回契约。
