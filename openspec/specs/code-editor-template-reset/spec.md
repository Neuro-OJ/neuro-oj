## Purpose

让标准题库做题页的用户能够在需要时安全恢复题目提供的启动代码，并防止覆盖操作导致无提示的数据丢失。

## Requirements

### Requirement: 做题代码恢复到模板

当标准题库题目提供初始代码模板时，做题工作区 SHALL 显示“重置”操作。用户确认后，系统 SHALL
获取该题当前模板并以其替换编辑器内容及对应本地草稿。

#### Scenario: 确认重置

- **WHEN** 用户点击“重置”并确认覆盖当前代码
- **THEN** 编辑器内容变为题目模板，后续重新进入该题仍显示该模板草稿

#### Scenario: 取消重置

- **WHEN** 用户在重置确认弹窗中取消
- **THEN** 编辑器内容和本地草稿保持不变

#### Scenario: 模板不可用

- **WHEN** 用户确认重置但模板请求失败或题目没有模板
- **THEN** 系统保留编辑器内容和本地草稿，并显示失败提示

#### Scenario: 竞赛题不显示重置

- **WHEN** 用户处于未提供模板 URL 的竞赛做题页
- **THEN** 工作区不显示“重置”操作
