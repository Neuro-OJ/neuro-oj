# 自带模型（BYOK）

> 一句话：练习 LLM 题时，可以改用**你自己的** OpenAI 兼容模型 Key 评测，不消耗平台额度；比赛与作业不能使用。

部分题目的评测需要调用大模型（题目通过 [capability](./capability.md) 让评测端代为调用）。默认使用工作空间配置的模型与额度；实例开启「自带模型」后，你可以保存自己的 Provider，在练习时选用。

## 配置

1. 打开 **设置 → 自带模型**。若显示「本实例未开启自带模型」，说明管理员没有开放此功能。
2. 填写：
   - **Base URL**：OpenAI 兼容接口地址，例如 `https://api.example.com/v1`。只允许 https，且主机必须在页面列出的「允许的服务地址」内。
   - **模型名**：题目声明的所有模型别名都会映射到这个模型。
   - **API Key**：保存后只显示脱敏值；修改其他字段时留空即保留原 Key。
3. 保存后可点 **测试连接**，平台会用 `max_tokens: 1` 发一次请求验证 Key 与模型名。

可随时停用或删除；删除会销毁已加密保存的 Key。

## 提交时使用

在 LLM 题的代码编辑器顶栏，点击 **平台模型** 按钮切换为 **我的 Key** 后再点「提交评测」即可（题目页内嵌作答区为 **使用我的模型 Key 评测** 开关）。每次进入编辑器默认使用平台模型。

- 只对题库练习生效；比赛与作业提交会被拒绝（`BYOK_NOT_ALLOWED`），作业页不显示开关。
- 不消耗工作空间的日/月额度，但仍受题目声明的**单次评测**调用次数与 token 上限约束。
- 调用费用由你的 Provider 计费，平台记录的成本为 0。
- 重测沿用提交时的选择：若你已删除或停用自带模型，重测会失败。

## 安全说明

- Key 由 LLM 网关加密保存，只在评测调用上游时解密；任何接口都不返回明文。
- 你的代码（Solution 容器）始终拿不到 Key，调用仍由评测端经网关代理。
- 网关只会访问管理员放行的公网 https 地址，不能借此访问内网。
