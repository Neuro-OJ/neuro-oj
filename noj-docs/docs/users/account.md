# 账号与密码

本页说明账号信息、修改密码、忘记密码与封禁规则。

## 账号信息

| 字段 | 说明 |
|------|------|
| 用户名 | 注册时设置，3–30 位字母、数字、下划线 |
| 邮箱 | 用于登录与密码重置 |
| 角色 | `user` / `admin` 等，由运营者分配 |
| 封禁状态 | 封禁时显示原因与解封时间 |

在「设置」页面查看与修改账号信息。

## 修改密码

在「修改密码」页面输入当前密码与新密码（规则与注册相同）。修改成功后**旧令牌立即失效**，其他设备的登录状态被撤销。

::: note 首次改密
运营者创建的账号若要求首次改密，登录后会被强制引导到修改密码页面。
:::

## 两步验证（TFA）

「设置」页可以启用或禁用两步验证：

- 启用：生成 TOTP secret 与 `otpauth://` 链接，使用任意标准 TOTP 应用（如 Google Authenticator）扫码绑定；确认后保存一次性恢复码。
- 登录：已启用 TFA 的账号在输入用户名/密码后，需要继续输入 6 位动态验证码或恢复码。
- 恢复码：仅显示一次，请妥善保存；可在设置页重新生成。
- 禁用：需要输入当前验证码或恢复码确认。
- 轮换 `TFA_ENCRYPTION_KEY` 会使已保存的 TOTP secret 无法解密，因此生产环境不得随意轮换。

## 头像

在「设置」页可上传头像，支持常见图片格式（PNG / JPEG / WebP）。头像会显示在提交记录、排行榜与社区内容中。

## 忘记密码

登录页点「忘记密码」→ 输入邮箱 → 通过邮件内的重置链接设置新密码。安全行为：

- 链接 **15 分钟内有效，且只能使用一次**。
- 无论邮箱是否注册，页面提示相同（防枚举）。
- 新密码强度不足时不消耗令牌，可修正后重试。

## 封禁

临时封禁期间无法登录，登录时显示原因与解封时间。认为封禁有误请联系运营者。
