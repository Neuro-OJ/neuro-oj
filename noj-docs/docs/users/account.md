# 账号与密码

## 账号信息

登录后，你的账号包含以下信息：

| 字段 | 说明 |
|------|------|
| 用户名 | 注册时设置，3–30 位字母、数字、下划线 |
| 邮箱 | 用于登录与接收密码重置邮件 |
| 角色 | `user`（普通用户）或 `admin`（管理员）等，由运营者分配 |
| 封禁状态 | 被临时封禁时会显示原因与解封时间 |

在「设置」页面可以查看和修改自己的账号信息。

## 修改密码

在登录状态下，通过「修改密码」页面可以更换密码：

1. 输入当前密码、新密码与确认密码。
2. 新密码规则与注册时相同：至少 12 位，包含小写字母、大写字母和数字，不能与用户名相同，也不能与邮箱前缀相同。
3. 修改成功后，旧的登录令牌会失效，系统会重新签发令牌——其他设备上的登录状态会被撤销。

::: note 首次改密
    如果运营者为你创建的账号设置了「首次登录需改密」，登录后系统会强制引导到修改密码页面，完成修改后才能正常使用。

## 忘记密码 {#forgot-password}

忘记密码时，在登录页点击「忘记密码」：

1. 输入注册邮箱并提交。
2. 如果该邮箱已注册，会收到一封包含重置链接的邮件。**链接 15 分钟内有效，且只能使用一次**——提交新密码后即作废。
3. 打开链接，设置新密码，然后用新密码登录。

几点安全行为说明：

- 无论邮箱是否注册，页面都显示相同的提示「如果该邮箱已注册，您将收到一封密码重置邮件」，防止探测已注册邮箱。
- 如果新密码强度不足，重置会失败，但**不会消耗令牌**——你可以修正密码后重试。
- 如果令牌已过期或已使用，会提示「重置令牌无效或已过期」，需要重新发起一次忘记密码流程。

## 封禁

如果你的账号被临时封禁，登录时会看到封禁原因与解封时间；封禁期间无法登录。若你认为封禁有误，请联系运营者申诉。
