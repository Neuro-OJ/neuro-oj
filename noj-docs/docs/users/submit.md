# 提交代码

本页说明提交代码的约定：语言选择、函数实现与提交后的流程。

## 选择语言

| 语言标识 | 说明 |
|----------|------|
| `python3` / `python` | Python 3（默认双容器运行时） |
| `cpp` / `c` / `javascript` | 标识已预留，暂无评测运行时 |

::: warning 运行时现状
当前评测运行时**仅完整支持 Python**（多语言评测为项目的决策性不做项）。`cpp` / `c` / `javascript` 是提交接口预留的语言标识，尚无评测运行时，请使用 Python 提交。
:::

题目可选的编程语言由出题人配置，以题目详情页显示为准。

## 实现题面要求的函数

优先实现题面声明的函数。例如：

```python
def solve(a: int, b: int) -> int:
    return a + b
```

不要依赖顶层 `print()` 作为答案输出——Neuro OJ 的 Python 双容器评测通过 Solution Host 加载你的模块，由 evaluator 调用函数评分。

## 调试输出

`print()` 可以用于辅助调试，但它不是答案通道。Solution Host 会把用户代码的 stdout 重定向到 stderr，调试输出可以在提交详情页的「输出」中查看。

## 代码限制

- 代码体积上限 **100KB**。
- 时间与内存限制由题目的运行时配置决定，超出会得到对应的资源限制状态。

## 提交后

1. 任务进入评测队列，编辑器侧栏实时显示排队位置与状态。
2. 在「提交记录」页查看全部历史，可按题目、语言、状态、时间段筛选。
3. 打开单条提交查看详细结果。

提交详情页展示状态徽章、得分、用时与内存、标准输出与代码。其中代码与用例级详情仅**你自己和管理员**可见。

## 常见错误

- `FunctionNotFound`：函数名与题面声明不一致，或模块无法导入。
- `WrongAnswer`：返回类型或结果不满足评分条件。
- `RuntimeError`：评测逻辑将失败归类为运行时错误。
- `SystemError`：评测环境或题目配置异常，通常不是改代码能解决的，请联系运营者。

完整状态说明见[理解结果](results.md)。
