# 快速开始

本页带你走完从注册账号到看到第一份评测结果的完整流程。

## 1. 注册账号

打开 Neuro OJ 前端站点，点击导航栏的「注册」。注册需要三项信息：

| 字段 | 要求 |
|------|------|
| 用户名 | 3–30 位，仅限字母、数字、下划线 |
| 邮箱 | 合法邮箱格式，用于接收密码重置邮件 |
| 密码 | 至少 12 位，必须同时包含小写字母、大写字母和数字；不能与用户名相同，也不能与邮箱前缀相同 |

注册成功后会自动登录。如果运营者关闭了开放注册（系统设置 `allow_register`），注册入口会不可用，请使用运营者提供的账号。

## 2. 登录

登录框同时支持**用户名或邮箱**。登录失败时统一提示「用户名或密码错误」，不会区分是账号不存在还是密码错误——这是为了防止账号枚举。

- 如果账号被临时封禁，会看到封禁原因和解封时间。
- 如果账号被要求首次改密（例如运营者创建的账号），登录后会被引导到修改密码页面，改完密码才能继续使用。
- 连续多次登录失败会触发限流：每次失败后需要等待一段时间才能重试，连续失败次数过多会临时锁定账号。请勿暴力尝试密码。

## 3. 忘记密码

如果忘记密码，在登录页点击「忘记密码」：

1. 输入注册邮箱并提交。
2. 如果该邮箱已注册，会收到一封包含重置链接的邮件，链接 **15 分钟内有效**。
3. 打开链接，设置新密码（规则与注册时相同），完成后用新密码登录。

出于防枚举考虑，无论邮箱是否注册，页面都会显示「如果该邮箱已注册，您将收到一封密码重置邮件」。

## 4. 查找题目

进入「题目」页面，可以按题号、标题、难度、题型或分类筛选题目。

题目详情页包含：

- 题面与输入输出说明
- 时间 / 内存限制
- 提交接口声明
- 提交入口

## 5. 阅读提交接口

Neuro OJ 的题目通常要求实现题面声明的函数，而不是编写读取 stdin 的主程序。例如 A+B 题要求：

```python
def solve(a: int, b: int) -> int:
    ...
```

评测时，出题人编写的 evaluator 会通过 Solution Host 加载你的模块并调用 `solve(a, b)`，根据返回值评分。

## 6. 提交代码

在题目详情页点击「去编辑器」，或直接进入编辑器页面：

1. 选择语言（当前支持 `python3` / `python` / `cpp` / `c` / `javascript`，具体以题目可选语言为准）。
2. 编写代码，代码体积上限为 100KB。
3. 点击提交。提交后可以在编辑器侧栏或提交记录页查看结果。

## 7. 查看结果

提交后会经历排队 → 评测中 → 完成几个阶段，可以实时看到排队位置。常见状态见[理解结果](results.md)与[结果状态参考](../reference/result-status.md)。

::: tip 第一步
    建议从一道简单题开始，先跑通「注册 → 找题 → 提交 → Accepted」的完整闭环，再逐步尝试更难的题目。
