# 做题人文档

做题人文档帮助你在 Neuro OJ 上完成做题流程，并掌握账号、榜单与消息等日常功能。

> 新用户建议先阅读[什么是 Neuro OJ](../intro/what-is-noj.md) 与[快速开始](../intro/getting-started.md)。

## 文档内容

| 页面 | 内容 |
|------|------|
| [提交代码](./submit.md) | 语言选择、函数实现、代码限制、产物提交、自测与提交后流程 |
| [LMCC IDE 插件](./lmcc-extension.md) | 在 LMCC IDE 或 VS Code 中登录、选题并一键提交 Python 文件 |
| [使用 capability](./capability.md) | 题目需要联网时，通过 `call_capability` 调用评测端能力 |
| [理解结果](./results.md) | 状态流转与分数详情，看懂每次评测的判定 |
| [账号与密码](./account.md) | 修改密码、两步验证、忘记密码、头像与封禁规则 |

其余日常功能见[功能主题](../features/)：

- 客观题套卷：单选 / 多选 / 判断作答见[客观题](../features/objective.md)。
- 排行榜与签到见[功能主题](../features/ranking.md)。
- 搜索与私信见[功能主题](../features/search-messages.md)。
- 社区、竞赛、题单、公告见[功能主题](../features/)。

希望在本地 IDE 完成练习时，请参阅 [LMCC IDE 插件](./lmcc-extension.md)。
