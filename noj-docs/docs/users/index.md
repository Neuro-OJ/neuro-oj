# 做题人文档

做题人文档帮助你在 Neuro OJ 上完成做题流程，并掌握账号、榜单与消息等日常功能。

## 文档内容

- **提交代码**：语言选择、函数实现与提交约定，让你的代码顺利通过评测。
- **理解结果**：状态流转与分数详情，看懂每次评测的判定。
- **账号与密码**：修改密码、两步验证、忘记密码、头像与封禁规则。
- **使用自带模型**：管理个人 Provider，并在普通题目提交中选择 BYOK 配置。
- **客观题套卷**：单选 / 多选 / 判断作答见[功能主题](../features/objective.md)。
- 排行榜与签到、搜索与私信、社区、竞赛、题单、公告见[功能主题](../features/)。

新用户建议先阅读[入门](../intro/what-is-noj.md)分区的[快速开始](../intro/getting-started.md)。

个人模型配置请参阅[使用自带模型（BYOK）](./byok.md)。
