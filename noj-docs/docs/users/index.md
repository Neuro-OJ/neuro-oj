# 做题人文档中心

欢迎来到 Neuro OJ 做题指南。无论你是准备参加 IOAI / NOAI / LMCC 竞赛，还是进行日常 AI 算法与工程练习，本指南将帮助你快速掌握平台的使用方式。

::: tip 新手第一步
如果你是初次接触平台，建议先阅读 [什么是 Neuro OJ](../intro/what-is-noj.md) 了解评测原理，并跟随 [做题快速开始](../intro/getting-started.md) 在 3 分钟内跑通你的第一道题目。
:::

## 📚 知识导航

### 1. 做题起步与提交规则
- [做题快速开始](../intro/getting-started.md)：账号注册、题目查找与第一次代码提交闭环。
- [提交代码与语言约定](./submit.md)：函数调用题实现规范、顶层输出约束、产物提交（Kaggle 模式）与自测方法。
- [理解评测结果](./results.md)：评测状态（`finished` / `error` 等）流转、得分详情与调试日志查看。
- [使用 Capability 网络能力](./capability.md)：当题目需要调用大模型或外部 API 时，通过 `call_capability` 安全交互。

### 2. 本地提效工具
- [LMCC IDE / VS Code 插件](./lmcc-extension.md)：无需频繁切换浏览器，直接在 VS Code 或 LMCC IDE 中一键登录、拉取题目、本地调试并提交代码。

### 3. 平台竞赛与社区功能
- [竞赛模式](../features/contests.md)：查看并报名参与实时竞赛，掌握赛制与封榜规则。
- [题单训练](../features/trainings.md)：跟随官方与教练推荐的学习路线进行针对性强化练习。
- [客观题套卷](../features/objective.md)：单选题、多选题与判断题的在线作答与即时判分。
- [排行榜与每日签到](../features/ranking.md)：天梯积分、解题数排名规则与每日打卡活跃度。
- [社区交流与讨论](../features/community.md)：题目讨论区、题解分享与社区发帖规范。
- [站内搜索与私信](../features/search-messages.md)：全文检索题目与用户，站内实时沟通。
- [系统公告](../features/announcements.md)：获取平台更新与赛事重要通知。

### 4. 账号与个人中心
- [账号与密码安全](./account.md)：修改密码、两步验证 (2FA)、第三方快捷登录与封禁申诉。
