# 搜索与私信

## 全局搜索

导航栏搜索按钮或 **Ctrl + K**（macOS 为 Cmd + K）打开搜索面板：

- 按类型切换：**题目 / 用户 / 帖子**（solution 与 discussion）。
- 输入即搜（带防抖），支持键盘选择；完整结果页显示「共 N 条结果，耗时 Xms」。
- 支持按题号搜索，如 `P1001` 直达对应题目。
- 题目搜索默认只展示主题题（P 型）；用户搜索仅管理员可用。

## 站内私信

「消息」入口在用户菜单，未读消息显示红色数字徽标（自动轮询）。

**发起会话**：消息页左侧搜索用户 → 点击创建会话 → 发送第一条消息。每对用户只有一个会话，不能给自己发消息。

**消息操作**：

| 操作 | 说明 |
|------|------|
| 发送 | 单条最长 10000 字符 |
| 已读 | 打开会话自动标记；未读数 = 晚于最后已读位置的消息数 |
| 加载更早 | 向上滚动加载历史消息 |
| 删除 | **仅影响自己的视角**（软删除），对方仍可见 |
| 实时刷新 | 新消息通过 SSE 推送触发刷新 |

会话列表按最后消息时间倒序，显示对方用户名（注销显示「已注销用户」）、消息预览（50 字截断）与未读数。
