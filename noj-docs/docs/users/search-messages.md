# 搜索与私信

## 全局搜索

在导航栏点击搜索按钮，或按 **Ctrl + K**（macOS 为 Cmd + K）打开搜索面板。

- 支持按类型切换：**题目 / 用户 / 帖子**（帖子指社区中的 solution 与 discussion）。
- 输入即搜（带防抖），支持键盘上下键选择、回车跳转。
- 完整结果页（「搜索」页面）会同步搜索词与类型，显示「共 N 条结果，耗时 Xms」。

搜索语法：

- 支持中英文分词匹配题目标题与正文。
- 支持按题号搜索，例如输入 `P1001` 可以直接定位到对应题目。
- 题目搜索默认只展示**主题题（P 型）**；用户提交的 U 型题不参与公开搜索。用户搜索仅管理员可用。

## 站内私信

「消息」入口在用户菜单中，未读消息会显示红色数字徽标（自动轮询刷新）。

### 发起会话

- 在消息页面左侧的会话列表中，可以通过搜索用户发起新会话——找到目标用户后点击即可创建会话，然后发送第一条消息。
- 每个用户对之间只有一个会话；向同一人再次发消息会回到既有会话。
- 不能给自己发消息；对方账号不存在或已注销时会提示。

### 消息操作

| 操作 | 说明 |
|------|------|
| 发送 | 输入内容后回车或点击发送；单条消息最长 10000 字符 |
| 已读 | 打开会话后自动标记已读；未读数 = 该会话中晚于你最后已读位置的消息数 |
| 加载更早 | 消息按时间倒序分页，向上滚动可加载历史消息 |
| 删除 | 删除**仅影响你自己的视角**（软删除）：消息对你隐藏，但对方仍然能看到 |
| 实时刷新 | 新消息通过 SSE 推送触发刷新，无需手动刷新页面 |

### 会话列表

会话按最后消息时间倒序排列，每项显示：对方用户名（对方注销时显示「已注销用户」）、最后一条消息的预览（50 字截断）、最后消息时间与你的未读数。
