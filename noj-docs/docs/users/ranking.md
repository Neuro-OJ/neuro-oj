# 排行榜与签到

## 排行榜

排行榜页面（「榜单」）公开可见，无需登录。它按以下口径排序（优先级从高到低）：

1. **独立通过的题目数**（降序）——一个题目只要通过过一次就计数，重复提交不计入
2. **通过率**（降序）
3. **总提交数**（升序）
4. **注册时间**（升序）

几点规则：

- **至少通过 1 题**才会出现在榜单上。
- **竞赛题目默认不计入**排行榜。竞赛是否影响全局排名由出题人/运营者在竞赛设置中决定（`affect_global_ranking`）。
- root 系统用户不计入。
- 排行榜分页展示（每页 50 人），排名跨页连续；前三名有金/银/铜徽章。
- 榜单中当前登录用户的行会高亮，方便定位自己的排名；点击用户名可进入用户主页。

## 每日签到

登录后，首页的签到卡片可以每日签到：

- **每天限一次**，按 **UTC 日期**统计（UTC 0 点刷新，而非本地时间）。
- 连续签到会累计连续天数（streak）：昨天签过则 +1，中断后从 1 重新计算。
- 签到**没有积分或奖励**，纯粹是连续天数记录。
- 当天未签到时显示「签到」按钮，签过后显示「已签到」与当前连续天数。

::: note 时间提示
    因为按 UTC 统计，北京时间（UTC+8）的每天 0:00–8:00 属于前一个 UTC 日。例如北京时间 7 月 26 日凌晨 1 点签到，会计入 7 月 25 日的 UTC 日期。
