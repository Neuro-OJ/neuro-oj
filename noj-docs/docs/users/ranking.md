# 排行榜与签到

## 排行榜

榜单页公开可见，按以下口径排序（优先级从高到低）：

1. **独立通过的题目数**（降序，重复提交不计）
2. **通过率**（降序）
3. **总提交数**（升序）
4. **注册时间**（升序）

规则：

- 至少通过 1 题才上榜。
- **竞赛题目默认不计入**（由竞赛的 `affect_global_ranking` 设置决定）。
- 每页 50 人，前三名有金/银/铜徽章，当前用户行高亮。

## 每日签到

首页签到卡片，登录后可用：

- 每天一次，按 **UTC 日期**统计（UTC 0 点刷新，非本地时间）。
- 连续签到累计 streak，中断后从 1 重计。
- 签到**没有积分或奖励**，仅记录连续天数。

::: note 时间提示
北京时间 0:00–8:00 属于前一个 UTC 日，签到会计入前一天的日期。
:::
