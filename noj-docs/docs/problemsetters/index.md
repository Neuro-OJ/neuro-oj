# 出题人文档

出题人文档帮助你把一道题从想法变成上线评测。与传统 OJ 不同，你不是准备输入输出文件，而是编写一个 evaluator，由它调用用户提交的函数并决定评分。

## 文档内容

- **快速出一题**：5 步端到端路径，新出题人从这里开始。
- **Web 题目编辑器**：创建题目、配置运行时与上传支持包。
- **产物提交题**：配置 zip 产物提交，并选择适合的 Solution / Solution AI 运行时。
- **A+B 示例题**：一份完整可参考的样例题。
- **出 LLM 调用题**：如何配置 Provider、开启联网并通过 `llm.complete` 调用真实 LLM API。
- **客观题套卷**：创建单选 / 多选 / 判断小题，无需评测容器，见[功能主题](../features/objective.md)。
