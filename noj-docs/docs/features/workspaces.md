# 工作空间：账号、域与题库

工作空间（Domain）把学校、团队和公共社区的题库、比赛、成员及教学活动放在各自
的范围内。你只需要一个账号，可以在不同空间拥有不同身份。例如，你在学校 A
是学生，在团队 B 是教练，在公共空间正常练习。

班级和作业的操作见[班级与作业指南](./classroom-assignments.md)。平台管理员配置
公开、私有或混合实例时，参阅[工作空间部署与治理](../operators/workspace-deployment.md)。

## 认识三个层级

| 层级                   | 含义                                 | 管理内容                               |
| ---------------------- | ------------------------------------ | -------------------------------------- |
| Instance（实例）       | 一次 NOJ 部署                        | 统一账号、注册政策、全站管理和资源上限 |
| Domain（工作空间、域） | 实例内的一所学校、一个团队或公共社区 | 成员、题库、比赛、社区、教学、LLM 配置 |
| Classroom（班级）      | 某个空间内的教学组织                 | 教练、助教、学生、作业、反馈和训练进度 |

退出一个空间不会删除账号，也不会改变你在另一个空间的身份。关注和私信使用
统一账号；消息中的题目、班级或提交仍要按其所属空间检查访问权限。

## 进入和切换空间

空间地址为 `/d/空间标识`，例如 `/d/main`、`/d/school`。空间标识创建后固定，
展示名称可以修改。保存或分享链接时保留完整地址。

已加入的空间可以从工作空间入口选择；公开空间允许按其访问政策浏览。空间的
加入方式分别为“直接加入”“申请审核”“接受邀请”。申请需要等待管理员处理。
持有私有空间的链接本身不会获得访问权限。

如果实例仅允许已登录用户访问，先登录再进入空间；收到邀请的新学生可按邀请
流程完成注册。只有一个可用空间时，可以直接使用该空间，不必先创建自己的域。

同一浏览器的两个标签页可以分别使用学校和公共空间。**提交归属于提交页面地址
中的空间**，不会因为另一标签页切换空间而改变。提交前确认页面的空间名称和题号。

## 角色分别在哪里生效

域内角色可以组合。例如，资源编辑者也可以兼任教学人员。

| 域内角色   | 常见工作                                            |
| ---------- | --------------------------------------------------- |
| 负责人     | 设置空间、管理成员及资源、配置 Provider、转交负责人 |
| 管理员     | 日常成员、资源、教学、社区与 Provider 管理          |
| 资源编辑者 | 创建、编辑和发布授权题目及题单                      |
| 教学人员   | 创建班级，管理自己担任教练的班级                    |
| 社区管理员 | 治理本域社区                                        |
| 成员       | 使用获授权的资源，查看本人提交                      |

资源编辑权限不会自动开放全域学生代码。教师读取学生提交还需要当前班级关系
和相应教学权限；比赛保密规则也会继续生效。域管理员的权限不能用于其他域或
平台账号密码管理。

班级内另有教练、助教、学生身份。助教可以分别获得查看学情、查看学生提交、
管理作业、撰写反馈、处理求助及管理学生成员的授权，具体以班级成员页为准。

## 数字题号与来源题号

每个新空间从 `1001` 开始自动编号，删除后不回收题号。完整题号由来源空间与
数字组成，题目引用不占用目标空间的本地数字编号。

| 你正在使用的空间    | 题目显示    | 作答地址示例                   | 提交归属 |
| ------------------- | ----------- | ------------------------------ | -------- |
| `main`              | `1001`      | `/d/main/problems/1001`        | `main`   |
| `school` 的本地题   | `1001`      | `/d/school/problems/1001`      | `school` |
| `school` 引用公共题 | `main:1001` | `/d/school/problems/main:1001` | `school` |

`school` 的 `1001` 与 `main` 的 `1001` 可以是不同题目。在学校引用公共题时，
来源题号始终显示 `main:1001`，学校的提交、统计和 LLM 费用仍属于学校。
点击来源链接前往源域后，再在那里提交会产生另一域的记录，不会自动计入学校作业。

旧 `/problems/P1001` 等入口解析到 `main` 的数字题号。它们不会跟随“上次使用
空间”；即使平台调整默认导航空间，旧兼容链接也始终属于 `main`。

## 管理题库与共享引用

有资源管理权限的成员进入空间“资源管理”，管理本地题与共享题绑定。源题的
题面和文件由来源空间维护，目标空间可以管理自己的展示范围和有效版本策略。
修改目标空间策略不会替其他学校修改策略。

引用公开题目的操作流程：

1. 来源空间将题目发布并设为公开。
2. 来源维护者在共享设置中允许所有域引用，或指定允许的目标域。
3. 目标域资源管理者在共享题库中选择来源题，建立本域引用。
4. 在目标域题库确认来源题号、展示范围和版本策略，再用于练习或作业。

能浏览公开题目并不意味着可以引用。来源空间、题目公开状态和共享许可必须
同时满足条件。公开题单也采用引用：用其发布作业时才固定本次作业的题目集合。

### 来源停止共享后

来源题转为私有、停止共享、下架或源域暂停后，目标域不能继续读取题面、模板、
附件和版本内容，也不能创建新提交、自测或新的评测执行。已经受理的评测可以
完成；学生本人原提交、成绩和已有反馈继续保留。保存历史成绩不等于恢复题面权限。

作业会显示资源不可用，教师可以联系来源维护者，或创建替代任务。共享恢复时
可以恢复原绑定，不需要复制题目。停止共享一个题单不会改写已发布作业的题目
集合；其中每道题是否仍可使用，分别取决于该题的当前共享许可。

## 版本策略与当前成绩

有效版本策略在**使用域**的题库中管理：

- “历史版本均有效”（`any`）：默认作答最新版，合格历史版本成绩也可以有效。
- “精确版本”（`exact`）：默认作答指定版本，当前成绩要求该版本的正式判定。

策略决定哪些评测结果计入成绩，发布新版不会改写原代码或原受理时间。页面打开
后作答版本发生变化时，保留本地代码或答案，重新确认当前题目再提交。已受理
提交可从历史中查看其提交时版本和评测依据。

作业会跟随使用域的默认作答版本和有效策略。具体变化与截止成绩的关系，见
[作业的版本与重测](./classroom-assignments.md#版本与重测)。

## 配置本域 LLM

负责人或管理员进入空间“LLM”页面：

1. 新增 Provider，填写名称、服务地址、密钥和计价配置；按上游服务能力设置
   每分钟请求数 RPM 与每分钟 Token 数 TPM，`0` 表示该项不额外限制。
2. 启用 Provider，选择本域默认 Provider，填写模型标识并保存。
3. 设置需要的每日或每月额度，检查本域用量列表。
4. 使用本域 LLM 题验证配置，并按实际用量调整额度。

新空间不继承公共域密钥。引用公共 LLM 题时，题目内容和单次预算来自源题，
Provider、模型及费用归使用域；未配置或 Provider 停用时，新调用会明确拒绝。
已经建立的评测尝试使用受理时解析的配置，新尝试使用之后的当前配置。

LLM 页支持域总量、用户、源题及用户与源题组合的日/月额度。空值表示本域不
额外限制，仍受实例上限约束；`0` 表示不允许相应新增使用。域总额度只能降低，
提高需要平台治理权限。费用额度的整数单位与 Provider 单价一致，查看界面说明
后填写。调用前的预估与调用后的上游用量结算可能有差异，不把估算额度视为上游
账单的绝对封顶。

不同学校可以使用不同模型，因此跨域分数不承诺可比。

### 模型别名

LLM 页的“模型别名”把本域能力名称映射到本域 Provider 和真实模型，例如将 `fast`
配置为学校可用的快速模型。`default` 是保留别名，使用当前本域默认 Provider
与模型，不能另行创建或删除。不同域可以使用同名别名并分别配置，
引用公共题不会借用来源域的别名或密钥。

负责人或管理员在别名表中选择本域 Provider，填写别名、真实模型名和说明后
保存。题目声明的是所需能力别名，实际模型在使用域评测时解析；一个题目的
模型集合须能解析到同一 Provider。出题人只能读取能力名称与说明，不能借此 查看
Provider 配置。删除已被本域题目声明使用的别名前，页面要求明确确认；
删除不会改写已发布版本，之后的新评测若缺少能力会返回配置错误。

Provider、配额和模型别名都按各自读取时的版本保存。其他标签页先保存时，旧
表单会报告冲突并保留输入；重新读取配置后再确认修改，不自动覆盖他人的配置。

## 预测文件与界面题

预测题在题面中选择并上传单个预测结果文件，具体列名、格式和大小按题目要求。
评分器读取文件计算成绩，不运行学生代码。它与产物题的 ZIP 上传不同；在学校
引用公共预测题时，文件和提交仍归学校域，评分内容取学校当前作答版本。

界面题在题面内提供题包界面，用控件填写参数并进行自测或正式提交。自测不
计作业进度，正式提交继续遵守本域题库、作业和比赛规则。运行历史可查看已
保存参数、与当前参数对比、回滚及撤销回滚；回滚只恢复当前输入，不改写原
提交或更换作答版本。不同域、账号、题目和版本分别保存草稿。

版本变化时先保留输入，确认切换后再作答；比赛使用比赛固定版本的界面与执行
模板。比赛隐藏结果时，界面只收到“已受理”等允许反馈，不通过界面开放原始
评测输出。题包界面运行在隔离 iframe，不能访问站点账号凭据或自行发起网络请求。

## 管理配额和空间状态

空间“设置”包含名称、简介、访问、发现与加入政策；成员、题库、存储、提交频率
额度显示配置值、实例上限和实际占用。域管理员可以在当前有效额度内降低配额，
提高额度需要平台管理员处理。降低到已用量以下不会清除成员或历史，只会限制
后续增加使用。引用题计入题库条目数，不重复计算来源支持包的存储字节；学生
上传的产物计入提交所在域。

域类型只提供 Community（社区）、Education（教学）和 Team（团队），创建后固定。
三种域均提供题库、题单、五种赛制、社区与域排行；教学域额外提供班级、作业和
教练工作台。域管理员不能任意组合功能或重新应用模板，实例允许列表仍限制运行能力。
实例停用教学功能后，获授权历史仍可读取，停用期间练习不自动计入作业，重新启用
也不自动补计这段记录。旧自定义域的转换须按实际用途明确决定，不自动改变历史数据。

归档空间保留获授权历史读取并停止业务写入；暂停由平台治理处理，普通成员
停止访问。负责人需要先完成转交再退出，不能直接移除唯一负责人。

公共主页和公开统计只展示允许公开的信息。私有学校提交不会因引用公共题而
公开给其他学校。“我的提交”只列当前域记录；离域后的本人原提交
和成绩摘要仍受控保留，题面与其他成员数据不会随之开放。
