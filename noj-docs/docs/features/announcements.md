# 公告

公告用于发布系统通知、比赛提醒、维护预告等内容，正文支持 Markdown。

## 做题人

- 首页公告区块与「公告」列表展示已发布（`is_active=true`）的公告，置顶公告优先，其后按创建时间倒序。
- 导航栏横幅会展示**最新一条带 `banner_text` 的已发布公告**（可关闭）。
- 登录用户可订阅公告变更 SSE；有新公告或公告更新时前端会提示刷新。

::: info 首页轮播与公告相互独立
首页的图片轮播由单独的「轮播」功能（`carousel_slides`）驱动，与公告内容解耦；
轮播的配置不在「公告」页，而在后台的轮播管理页。
:::

## 运营者 / 管理员

后台「公告」页支持：

- 创建、编辑公告（Markdown 正文，标题 1–100 字符、正文 1–50000 字符）。
- 填写可选的**横幅文字**（`banner_text`）：非空时该公告可出现在导航栏横幅；清空则不出横幅。
- 发布 / 下架（切换 `is_active`）。
- 置顶排序（`is_pinned`）。
- 删除公告（物理删除）。

权限：需要 `announcement:manage`（`admin:full_access` 通配放行）。
