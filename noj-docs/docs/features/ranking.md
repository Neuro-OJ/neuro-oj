# 排行榜与签到

本页说明全站榜单的排序口径、每日签到的统计方式，以及两者在页面上的呈现。

## 排行榜

榜单页（`/ranking`）**公开可见**，无需登录。

::: info 上榜条件
- 只有**至少独立通过 1 题**的用户才会上榜；root 系统账号不计入。
- 竞赛题目是否计入由该竞赛的 `affect_global_ranking` 决定（**默认不计入**）。
:::

排序口径（优先级从高到低）：

| 优先级 | 排序键 | 方向 | 说明 |
|---|---|---|---|
| 1 | 独立通过的题目数 | 降序 | 同一题重复提交只计一次 |
| 2 | 通过率 | 降序 | 通过提交数 / 总提交数 |
| 3 | 总提交数 | 升序 | 同题数下提交少者靠前 |
| 4 | 注册时间 | 升序 | 最终 tiebreaker，先注册者靠前 |

页面呈现：

- 每页 **50 人**（接口上限 100），支持分页。
- 前三名的名次徽章使用金 / 银 / 铜配色。
- 当前登录用户所在行高亮。

::: tip 榜单可能有数秒延迟
榜单优先读取 `user_rankings` 物化视图；评测结果写回后会**节流刷新**（约 5 秒一次），
因此刚通过的题目体现在榜单上可能有短暂延迟。
:::

## 每日签到

首页签到卡片，登录后可用：

- 每天一次，按 **UTC 日期**统计（UTC 0 点刷新，非本地时间）。
- 连续签到累计 streak，中断后从 1 重计。
- 签到**没有积分或奖励**，仅记录连续天数。

::: tip 时间提示
北京时间 0:00–8:00 属于前一个 UTC 日，签到会计入前一天的日期。
:::

用户主页的「活跃度」区块展示累计签到天数、当前连续天数、历史最长连续天数，
以及最近 365 天的签到日历（接口支持 30 / 90 / 365 天历史窗口，界面固定用 365 天）。

::: warning 签到活跃榜暂无独立入口
服务端提供按月统计的签到活跃榜（当月签到天数排名，登录用户可返回本人名次），
但当前站点尚未提供独立页面展示该榜单。
:::
