# 客观题套卷

客观题套卷（`is_objective=true`）是并入题目体系的一种特殊题目：没有评测容器与 `evaluate.py`，由服务端即时判定。

## 题型

| 题型 | 答案形式 |
|------|----------|
| 单选（single） | 恰好一个选项 key |
| 多选（multiple） | 一个或多个选项 key，全对才得分 |
| 判断（judge） | `true` / `false` |

## 做题人

- 在题目详情页或竞赛题目页直接内联作答，无需打开代码编辑器。
- 练习模式提交后立即返回得分、逐题判定与解析（如有）。
- 竞赛模式提交后只返回得分与判定结果，不展示答案与解析，避免泄题。
- 客观题套卷在题库列表中以「客观题」标记展示，不显示运行时限制。

## 出题人 / 管理员

- 创建套卷：选择「客观题套卷」，填写标题、描述与类型（U / P）。
- 添加小题：单选 / 多选 / 判断，配置选项、标准答案与解析。
- 客观题没有 `runtime_config` 与支持包，但支持通过统一题目包导入（`problem.json` 声明 `is_objective: true` + 根级 `questions.json`），用于批量创建/更新套卷。
- 客观题套卷不得关联算法标签（系统强制）。

## 判定规则

- 单选 / 判断：给定答案与标准答案精确相等。
- 多选：完全匹配才得分。
- 卷面分 = 正确题数 / 总题数，按 ×100 整数分存储。
