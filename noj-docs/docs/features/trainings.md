# 题单（Training）

题单用于把题目组织成有序列表，便于按专题、难度或备考路线刷题。

## 可见性

题单有三种可见性：

| 可见性 | 说明 |
|--------|------|
| `private` | 仅创建者可见 |
| `unlisted` | 不公开列出，但知道链接的用户可访问 |
| `public` | 公开展示在「题单」页 |

普通用户创建题单后默认只能设为 `private` / `unlisted`；设为 `public` 和置顶需要管理员权限（`training:publish` / `training:pin`）。

## 创建与管理

- 「我的题单」页可以新建题单，填写标题与描述。
- 题单详情页可以添加题目、调整顺序、移除题目。
- 题目详情页的「加入题单」弹窗会列出你已创建且包含该题的题单，可快速加入。
- 管理员可以在后台「题单」页编辑任意题单、设置公开/私有、置顶或删除。

## 进度

题单详情会聚合每题是否已通过（编程题以 `Accepted` 为准，客观题以满分卷为准），方便跟踪完成进度。
