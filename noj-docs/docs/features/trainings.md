# 题单（Training）

题单用于把题目组织成有序列表，便于按专题、难度或备考路线刷题。

## 可见性

题单有三种可见性：

| 可见性 | 说明 | 谁可以设置 |
|--------|------|-----------|
| `private` | 仅创建者（与管理员）可见 | 创建者 |
| `unlisted` | 不公开列出，但知道链接的用户可访问 | 创建者 |
| `public` | 公开展示在「题单」页与创建者主页 | 需 `training:publish`（默认仅管理员） |

::: warning 普通用户的可见性范围
普通用户创建题单时只能设为 `private` / `unlisted`；设为 `public` 与置顶分别需要
`training:publish` / `training:pin` 权限（默认仅管理员拥有）。
:::

## 创建与管理

1. 进入「我的题单」页，点击新建，填写标题与描述（可见性默认 `private`）。
2. 在题单详情页添加题目、调整顺序、移除题目。
3. 在题目详情页点击「加入题单」，可在弹窗中勾选你已创建的题单（已包含该题的题单会自动预勾选；
   取消勾选即从该题单移除）。弹窗内也可直接新建题单并加入。

::: tip 加入题单的限制
与建赛加题同规则：普通用户只能把**公开题或自己拥有的题**加入题单；私有题若不属于你则无法加入。
:::

管理员可以在后台「题单」页编辑任意题单、设置公开 / 私有、置顶或删除。

## 进度

题单详情会聚合每题是否已通过，方便跟踪完成进度：

| 题目类型 | 记为已完成的条件 |
|---|---|
| 编程题 | 提交状态为 `finished` 且分数 > 0 |
| 客观题套卷 | 得到满分卷（100 / 100） |
