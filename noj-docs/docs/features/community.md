# 社区

社区提供题解、讨论、短动态、关注、收藏、举报与审核等能力，是做题人与出题人交流的主要场所。

## 内容类型

| 类型 | 说明 |
|------|------|
| `solution` | 题解：针对某道题的解题思路与代码，通常需要先通过该题（由系统设置决定） |
| `discussion` | 讨论：围绕题目、算法或学习路线的公开讨论 |
| `moment` | 动态：短内容分享，适合日常记录与提问 |

## 互动

- 评论：对帖子发表评论。
- 点赞：对帖子或评论点赞。
- 收藏：收藏帖子，在「收藏」页查看。
- 关注：关注用户，在动态流中查看对方的新内容。
- 通知：收到评论、关注、系统活动等通知，可在「通知」页查看。
- 举报：发现违规内容可举报，由审核员处理。

## 板块与权限

- 社区可按板块组织内容，板块可以配置不同角色（`can_read` / `can_post` / `can_moderate`）。
- 系统设置可控制社区总开关、游客阅读、各模块开关、发布门槛（如新用户审核、题解需先通过题目）、内容长度与发布频率限制。

## 审核与管理

审核员 / 管理员可以在后台「社区」页：

- 管理板块与角色授权。
- 处理举报（resolved / dismissed）。
- 审核待发布内容，隐藏 / 删除帖子或评论。
- 锁定或置顶帖子。
- 对用户实施社区处罚（sanction）。

社区管理端点位于 `/api/v1/community/admin/*`，权限模型见[后台管理指南](../operators/admin-guide.md)。
