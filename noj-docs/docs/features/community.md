# 社区

社区提供题解、讨论、短动态、关注、收藏、举报与审核等能力，是做题人与出题人交流的主要场所。
私信与隐私的说明见[搜索与消息](./search-messages.md)，本页聚焦公开内容与治理。

## 内容类型

| 类型 | 说明 |
|------|------|
| `solution` | 题解：针对某道题的解题思路与代码，通常需要先通过该题（由系统设置决定） |
| `discussion` | 讨论：围绕题目、算法或学习路线的公开讨论 |
| `moment` | 动态：短内容分享，适合日常记录与提问 |

## 互动

- 评论：对帖子发表评论（支持回复一级评论）。
- 点赞：对帖子或评论点赞。
- 收藏：收藏帖子，在「收藏」页查看。
- 关注：关注用户，在动态流中查看对方的新内容。
- 通知：收到评论、关注、系统活动等通知，可在「通知」页查看。
- 举报：发现违规内容可举报，由审核员处理。

::: info 内容合规
帖子、评论在发布 / 编辑时可能经云审核：高置信违规会被**拒绝发布**（提示后请修改重试）；
疑似内容会**转人工复核，但不影响正常发布**。
:::

## 板块与权限

- 社区可按板块组织内容，板块可以配置不同角色（`can_read` / `can_post` / `can_moderate`）。
- 系统设置可控制社区总开关、游客阅读、各模块开关、发布门槛（如新用户审核、题解需先通过题目）、内容长度与发布频率限制。

::: warning 题解发布门槛与赛期门控
- **需先通过题目**：若系统设置了该门槛，则未通过题目的用户不能发布该题题解（审核员不受限）。
- **赛期门控**：属于「进行中竞赛」的题目，其题解内容对普通用户整体不可见，发布入口同时关闭；
  竞赛结束后**自动恢复**，按时间窗口实时计算、不依赖定时任务（审核员与管理员不受限）。
:::

## 审核与管理

审核员 / 管理员可以在后台「社区」页：

- 管理板块与角色授权（`community_board:manage`）。
- 处理举报（`resolved` / `dismissed`）。
- 审核待发布内容，隐藏 / 删除帖子或评论。
- 锁定或置顶帖子。
- 对用户实施社区处罚（sanction）。

社区管理端点位于 `/api/v1/admin/community/*`（管理域下的 community 子域），权限模型见[后台管理指南](../operators/admin-guide.md)。
