# 竞赛

竞赛模块支持 ICPC / IOI / OI 三种赛制，并提供封榜与 SSE 实时排名。

## 赛制

| 赛制 | 说明 |
|------|------|
| ICPC | 传统 ACM 赛制：按通过题数、罚时排名 |
| IOI | 按题目分值与部分分实时排名 |
| OI | 按题目分值与部分分排名，通常赛后统一评测或按规则展示 |

## 做题人

- 在「竞赛」页浏览公开竞赛并报名 / 参加。
- 竞赛期间在竞赛题目页提交代码或作答客观题套卷。
- 排名页可实时查看排名；封榜后按竞赛配置停止展示实时排名。
- 竞赛题目默认不计入全局榜单，除非运营者设置 `affect_global_ranking=true`。

## 运营者 / 管理员

后台「竞赛」页可以：

- 创建 / 编辑竞赛：标题、时间、赛制、题目列表、公开状态、是否计入全局统计、是否实时公开排名。
- 管理参赛者。
- 查看竞赛排名与提交记录。

竞赛相关 API 与排行逻辑见仓库 `noj-core` 的 `routes/contests.ts` 与 `services/contest/`。
