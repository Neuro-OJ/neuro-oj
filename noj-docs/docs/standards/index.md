# Neuro OJ 题目规范及质量要求

本大章节集中定义 Neuro OJ 的题目相关规范与质量建议，供出题人、审核者与运营者阅读。

> 三页各司其职：**怎么打包**（格式，强制）→ **怎么组织数据**（推荐 + 协议）→ **怎么算好题**（建议）。不确定从哪页看起？先读[题目包格式规范](problem-bundle.md)。

## 内容导航

| 页面 | 内容 | 约束强度 |
|------|------|:---:|
| [题目包格式规范](problem-bundle.md) | 统一题目包 zip 结构、manifest 字段、版本与校验、特殊题型 | **强制（MUST）** |
| [测试数据与样例规范](test-data.md) | 测试数据推荐格式、可见/不可见语义、样例自测与调试输出 | 建议（SHOULD）+ 协议约定 |
| [题目质量要求](quality.md) | 题目命名、tag 适用、题面与数据质量、评测脚本质量、难度与发布流程 | 建议（SHOULD） |

## 约束强度

::: warning 强制与建议的区别
- **题目包格式为强制规范（MUST）**：导入时系统强制校验，不合法直接拒绝。
- **题目质量要求为建议规范（SHOULD）**：不阻止导入，但推荐遵循。

即使导入成功，也不代表题目合格——发布前请完成[质量要求](quality.md)中的自测清单。
:::
