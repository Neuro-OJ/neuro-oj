# 竞赛风控数据说明

## 第一阶段：提交来源 IP

竞赛代码或产物提交成功时，服务端会记录经过 `TRUSTED_PROXIES` 可信代理链解析后的来源 IP。请求客户端自行提交的 `X-Forwarded-For`、`X-Real-IP` 在直连或非可信代理场景会被忽略，无法安全解析时不保存 IP。

该字段的用途仅限于竞赛期间的账号关联线索、提交时间线和人工复核。共享网络、校园网、企业 NAT、代理和动态地址都可能使多个无关账号使用同一 IP，因此同 IP 不等于作弊结论。

管理员可在竞赛管理中查看同 IP 多账号候选组和提交时间线。接口只返回复核所需的用户、题目、语言、状态和时间，不返回邮箱、源代码或评测输出；访问需要 `contest:anti_cheat_read` 权限，并应遵循最小权限和审计要求。

默认保留 180 天（环境变量 `ANTI_CHEAT_IP_RETENTION_DAYS`，`0` 表示禁用自动清理）。清理任务只将提交记录中的来源 IP 置空，保留提交、代码和成绩用于正常业务及成绩申诉。保留期可按赛事申诉周期调整，且不得超过组织方隐私政策和适用法规要求。

## 第二阶段：代码相似度（规划）

第二阶段计划对同一竞赛、同一题目、同一语言的代码做离线规范化和指纹候选，生成可供人工复核的证据。候选不会自动封禁账号、取消成绩或修改排名；具体算法、证据留存和申诉流程完成评审后再实施。
