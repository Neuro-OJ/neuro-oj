# 快速开始

本页带你完成第一次完整流程：注册 → 找题 → 提交 → 看到评测结果。

## 1. 注册账号

点击导航栏「注册」，填写用户名、邮箱与密码：

| 字段 | 要求 |
|------|------|
| 用户名 | 3–30 位字母、数字、下划线 |
| 邮箱 | 合法邮箱格式 |
| 密码 | 至少 8 位，含大小写字母与数字；不能与用户名或邮箱前缀相同 |

注册成功后自动登录。若运营者关闭了开放注册，请使用运营者提供的账号。

如果运营者配置了 GitHub 或 OIDC，注册页也会显示第三方登录入口。首次通过第三方账号登录时，系统可能要求先设置一个本地密码。

## 2. 登录

登录框支持**用户名或邮箱**。登录失败统一提示「用户名或密码错误」（防枚举）；连续失败会触发限流退避，请勿暴力尝试。

- 被临时封禁的账号登录时会看到原因与解封时间。
- 要求首次改密的账号会被引导先修改密码。
- 已配置的 GitHub / OIDC 账号可以直接点击对应按钮登录。

忘记密码？在登录页点「忘记密码」，通过邮箱内的重置链接（15 分钟内有效）设置新密码。详见[账号与密码](../users/account.md)。

## 3. 找到一道题

进入「题目」页，可按题号、标题、难度、题型或标签筛选。打开题目详情，重点阅读：

- 题面与输入输出说明
- 时间 / 内存限制
- **提交接口**：需要实现的函数签名

## 4. 提交代码

在题目详情页点「去编辑器」：

1. 选择语言（当前以 Python 为主）。
2. 按题面要求**实现声明的函数**（如 `solve(a, b)`），不要依赖顶层 `print()` 输出答案。
3. 点击提交，代码上限 100KB。

语言与调试约定详见[提交代码](../users/submit.md)。

## 5. 查看结果

提交后经历 排队 → 评测中 → 完成 三个阶段，可在编辑器侧栏或提交记录页实时查看排队位置与状态。常见结果：

- `Accepted`：通过
- `WrongAnswer`：未满足评分条件
- `TimeLimitExceeded` / `RuntimeError` / `SystemError`：超时、运行时或系统错误

完整状态说明见[理解结果](../users/results.md)与[结果状态](../reference/result-status.md)。

::: tip 建议
从一道简单题开始，先跑通「注册 → 找题 → 提交 → Accepted」闭环，再逐步深入。
:::
